## 2. 状态机

```
PlayLanded → AwaitChallenge（hand>0 非第一手；靶=池）
  ├─ 真/假 → ChallengeCommit → ack 接受 → RevealAfterAck → 18 RevealDraw → RevealFlip
  │                         → ack 拒 → 「质疑未生效」
  └─ 过/10s → Pass
```

| 拍 | 锁 |
|----|----|
| AwaitChallenge | 真·假同层；靶可见为池上本手 |
| ChallengeCommit | 牌仍背、仍在池上 |
| RevealAfterAck | **现在才**进 18；禁 ack 前翻 |
