## 2. 状态机

```
ConfirmReady → PlayLaunch → PlayLanded（落 lb_cmp_pool）
  ├─ hand > 0 ∧ 非第一手 → AwaitChallenge
  ├─ hand > 0 ∧ 第一手   → 下家 TURN
  └─ hand == 0           → RankSettle
```

| UI 拍 | 画面 | 禁止 |
|-------|------|------|
| PlayLaunch | `lb_cmp_play_fly` 飞向 **`lb_cmp_pool`** + launch SFX | 发牌路径；飞中结算 |
| PlayLanded | **池上本手牌背堆成形** + land SFX | 落身前当完成；堆未成形就分流 |
| AwaitChallenge | 入口认质疑入口-状态机；靶 = 池上该手堆 | hand==0 进来 |
| RankSettle | 打光入名次 | 飞中抢结算 |

## 3. 池上本手堆（废身前主读）

| 项 | 锁 |
|----|----|
| 落点 | **`lb_cmp_pool`** |
| 主读 | 只池上该手。front_pile **不得**再主读（= **身前扣区仍主读**） |
| 张数 | 边/叠露边 ≥10vp；禁 Text（糊 = **池上张数不可读**） |
| 空壳删除 | front_pile 可空壳再删；不得与池双主读 |

落点不在池 = **落点不在牌堆**。出牌抄发牌 = **出牌像发牌**。

### 3a. 开牌短桩

PlayLanded **不**开牌。ack 接受后 → [质疑入口-状态机](./质疑入口-状态机.md) → [18](../04-设计/18-局内开牌区规格.md) **RevealDraw→RevealFlip**。  
短句：**开牌无位** · **开牌挡脸·烛** · **开牌看不清**。数字认 18（56vp / 0.90× / 160ms）。
