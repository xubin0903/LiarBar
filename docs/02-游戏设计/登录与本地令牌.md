## 0. 裁定（硬锁）

1. **账号在云端**：VPS 负责注册并持久化账号数据；客户端**不得**本地签发令牌、不得本地伪账本当权威。
2. **本地只存会话**：Preferences `lb.auth` 仅存服务端下发的 `auth_token` + `auth_username`；用于冷启动跳过登录页。
3. **字段写死**：注册/登录仅 **用户名 + 密码**；无邮箱、无手机、无验证码、无 OAuth。
4. **fail-soft**：无网/超时/HTTP 非 2xx → 提示短句、不崩、不进大厅；不阻塞进程。
5. **零新玩法**：质疑入口 / 对局状态机 / 人机 AI 不动；不写 DeepSeek/LLM。
6. **文档岗零 ets**：本 PR 只改本文 + 目录索引一行；`string.json` 键数维持 341。
7. **与既有 Preferences 分离**：设置继续 `lb.settings`（21:468–481）；战绩继续 `lb.records`（21:254–257）；鉴权只用 `lb.auth`。

## 1. 云端 API：注册 / 登录

### 1.1 字段（写死）

| 字段 | 类型 | 客户端可测建议 | 说明 |
|------|------|----------------|------|
| 用户名 | string | trim 后长度 **3～16**；建议字母/数字/下划线 | 服务端最终校验为准 |
| 密码 | string | 长度 **≥6**；无复杂度强制 | 仅经网络提交（当前基址为 HTTP :18080；**不得**写入 Preferences） |

无邮箱、无手机、无验证码、无第三方登录。

### 1.2 基址

负责人 2026-10-23 开闸锁定（**http**，端口 **18080**）。

| 项 | 值 |
|----|----|
| 基址 | `http://101.33.196.35:18080` |
| 路径 | `POST /api/v1/register` · `POST /api/v1/login` |
| 传输 | HTTP（当前部署；需 `ohos.permission.INTERNET`） |
| 超时建议 | 连接/读各 **8s**（鸿蒙可调；到点走 fail-soft） |

| 动作 | 方法 | 路径（已锁） |
|------|------|--------------|
| 注册 | `POST` | `/api/v1/register` |
| 登录 | `POST` | `/api/v1/login` |

### 1.3 请求体（JSON）

```json
{
  "username": "player01",
  "password": "secret6"
}
```

注册与登录共用同一字段信封。客户端先做 §1.1 长度校验，再发请求。

### 1.4 成功响应（JSON）

```json
{
  "ok": true,
  "token": "<server-issued-session-token>",
  "username": "player01"
}
```

| 字段 | 要求 |
|------|------|
| `ok` | `true` |
| `token` | 非空 string；**服务端签发**的会话令牌 |
| `username` | 非空 string；与请求用户名一致（服务端归一化后回显亦可） |

服务端若附带 `expires_in`，本阶段客户端可忽略。

成功后客户端：写 `lb.auth`（§2）→ `flush()` → **replace 进大厅**。

### 1.5 错误响应（可勾选）

统一建议信封（运维可微调字段名，语义须可对下表）：

```json
{
  "ok": false,
  "code": "AUTH_BAD_CREDENTIALS",
  "message": "用户名或密码错误"
}
```

| `code`（建议） | 场景 | 客户端行为 |
|----------------|------|------------|
| `AUTH_BAD_CREDENTIALS` | 登录账密不匹配 | 停登录页；§5 `lb_str_auth_login_fail` |
| `AUTH_USER_EXISTS` | 注册用户名冲突 | 停注册页；§5 `lb_str_auth_register_conflict` |
| `AUTH_USER_NOT_FOUND` | 登录用户不存在 | 同登录失败短句（可与 BAD_CREDENTIALS 合并展示） |
| `AUTH_VALIDATION` | 服务端字段校验失败 | §5 `lb_str_auth_field_invalid` |
| `AUTH_RATE_LIMIT` | 限流 | §5 `lb_str_auth_rate_limit`（建议键；接线 ADD） |
| （无 body / 非 JSON） | 坏包 | §5 `lb_str_auth_bad_response` |

HTTP 层：

| 情况 | 行为 |
|------|------|
| 无网 / 超时 | 提示；不崩；不写令牌；§5 `lb_str_auth_network` |
| HTTP 非 2xx | 有 `code` 则对上表；无 `code` 时按 HTTP 状态映射上表语义（字段可为 `detail` / `message`）；不写令牌 |
| `ok!=true` 或缺 `token` | 当失败；不写令牌 |

错误码语义以本文表为准；字段名可跟运维 OpenAPI。若仅 HTTP 状态 + `detail`/`message`、无 `code`，鸿蒙按状态映射上表语义。

### 1.6 流程摘要

1. **注册**：校验 → `POST` register → 成功写令牌进大厅 / 失败短句。
2. **登录**：校验 → `POST` login → 成功写令牌进大厅 / 失败短句。
3. **禁止**：客户端本地生成 `token` 冒充已登录；禁止无响应写令牌。

## 2. Preferences schema（`lb.auth` · 仅会话）

对照 21:254（`lb.records`）与 21:468–481（`lb.settings` 单键写 + flush）。

### 2.1 键

| 键 | 类型 | 含义 |
|----|------|------|
| `auth_token` | string | 服务端下发的会话令牌；非空 = 本机视为已登录 |
| `auth_username` | string | 展示用用户名 |

**不写**密码、不写本地用户表、不强制 `auth_updated_at`（无验收项则省略，少一容错分支）。

### 2.2 何时写 / 清

| 事件 | 动作 |
|------|------|
| 登录/注册 API 成功 | put `auth_token` + `auth_username` → `flush()` |
| 退出登录 | 删除/清空上述两键 → `flush()` |
| 令牌损坏（类型非 string） | 清空会话键 → 视为未登录 |

写后必须 `flush()`。禁止写入 `lb.settings` / `lb.records`。

### 2.3 读档容错

- `getPreferences('lb.auth')` 失败：本运行视为未登录；不崩、记日志。
- `auth_token` 空/缺/非 string → 未登录。
- 有 token 缺 username：仍算已登录；展示名回落空串或「玩家」（接线定；本 PR 不加键）。
- **本阶段**冷启动不向服务器校验令牌有效性（有非空 token 即跳过登录页）。**已锁：本阶段不加** `GET /me`。

## 3. 路由与未登录拦截

### 3.1 冷启动

1. 读 `lb.auth`（可与 `lb.settings` 并行；BGM 仍按 21:482）。
2. `auth_token` **非空** → 已登录 → **进大厅**（跳过登录页）。
3. 空/缺/损坏 → **进登录页**（可切注册页）。

### 3.2 强制拦截（写死）

| 场景 | 行为 |
|------|------|
| 冷启动无令牌 | **不得**进大厅 |
| 未登录 | 开局按钮不可达（进不了大厅） |
| 登录/注册页 | **允许**未登录访问 |
| 已登录误入登录/注册 | replace 回大厅 |

**已锁：强制登录**（无令牌不得进大厅）。若改「可浏览大厅、开局前再逼登」，须负责人改票后改本文。

### 3.3 成功后路由

登录/注册成功 → `replace` 大厅；不保留返回栈到登录页。

## 5. 失败短句（看什么 / 算不过）

本 PR 不改 `string.json`（当前 341 键）。键名接线 PR 再 ADD。

| 场景 | 看什么 / 算不过 | 建议键 |
|------|-----------------|--------|
| 登录失败 | 看什么：停登录页提示；算不过：无提示进大厅 | `lb_str_auth_login_fail` |
| 注册冲突 | 看什么：提示冲突、不写令牌；算不过：静默进大厅 | `lb_str_auth_register_conflict` |
| 字段校验失败 | 看什么：原地提示；算不过：非法仍发请求或写令牌 | `lb_str_auth_field_invalid` |
| 无网/超时 | 看什么：提示、不崩；算不过：闪退或假登录 | `lb_str_auth_network` |
| 坏响应/缺 token | 看什么：当失败；算不过：空 token 当已登录 | `lb_str_auth_bad_response` |
| Preferences 失败 | 看什么：不崩可重试；算不过：假登录 | `lb_str_auth_prefs_fail` |
| 令牌损坏清空 | 看什么：进登录页；算不过：坏令牌进大厅 | `lb_str_auth_token_corrupt` |
| 退出后仍进大厅 | 看什么：停登录页；算不过：仍显示已登录/可开局 | `lb_str_auth_logout_leak` |
| 未登录进大厅/开局 | 看什么：无令牌落登录页；算不过：可进大厅或开局 | `lb_str_auth_gate_bypass` |
| 限流（可选） | 看什么：提示稍后重试；算不过：无提示狂刷 | `lb_str_auth_rate_limit` |
