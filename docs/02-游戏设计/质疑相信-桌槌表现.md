## 1. 写死（本批加严）

| 项 | 锁 | 禁（=失败） |
|----|----|-------------|
| **质疑砸主读** | **明显上下砸**：抬=**放大离桌** → 砸=**缩小贴桌+阴影落地** | **无上下砸读感**；像平面滑过 |
| **横移** | 只可**辅读** | 横移为主轨 = 不过 |
| **相信 / 朝向 / SELF / 旋座** | 沿用 v0.3.5～0.3.6 | 不动 |

### 1.1 砸拍

1. **抬**：上抬短位移 + scale 放大（离桌感一眼可读）。
2. **砸**：回落贴桌 + scale 缩小回搁 + 阴影落地；同起 `lb_sfx_hammer_hit`。
3. **回搁**：朝向按座；HOLD 0.8～1.2s。
4. 数字窗认鸿蒙方案（现基线抬 1.2 / 砸 0.92 可作起点；Rebuild 仍平面则加抬程/阴影对比）。
