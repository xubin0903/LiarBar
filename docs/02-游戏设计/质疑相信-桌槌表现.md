## 1. 写死语义

| 选择 | 桌上主读 | 禁 |
|------|----------|----|
| **质疑** | 该座木槌 **抬起→砸下**（短震 + 敲击声）= 叫破 | 同锤仅换色；动人模骨骼/换座贴图 |
| **相信** | 同槌 **平放搁置** 键旁/座旁（静止或极轻一顿）= 放过 | 与砸态同位同姿难辨 |

- 命名对外：**桌槌/酒槌**（冲淡法庭感）；资源 id 用 `mallet`/`hammer` 均可，文案禁「法槌」。
- **口播**（飞词若做；P0 可弱化）：质疑 `lb_str_choice_doubt_call`=「不信！揭开！」；相信 `lb_str_choice_believe_call`=「过。下一家。」
- 左上荷官句 = **规则播报**，不当事主读。

## 2. 时序

1. 按下质疑/相信键 → **本地键反馈 ≤120ms**
2. 正式路径：权威 **Commit/Trust ACK** 后 → 全员层播锤（自机=AI 同轨，对齐 F2）
3. 质疑 → 走开牌轨；相信 → 续出；**Reveal 起势前**收锤或淡出
4. **调试路径**：调试钮 **立刻**播本地座位锤，**零**业务（不揭牌、不扣烛、不要求轮到你）

## 3. 控件 / 资源 id

| 类 | id | 说明 |
|----|-----|------|
| 层 | `lb_cmp_choice_act` | 全员锤层；HitTest None |
| 调试 | `lb_btn_debug_hammer_doubt` / `lb_btn_debug_hammer_believe` | 局内调试面板；只播**本地玩家座位** |
| 美术 | `art_fx_mallet`（+ 砸 2～3 帧约定） | 暖棕木+铜箍；搁姿可同图旋转落点 |
| SFX | `lb_sfx_hammer_hit` / `lb_sfx_hammer_rest` | 敲木 ≈80～120ms / 轻顿或静默；禁 beep；禁旧 flip/launch 冒充 |

## 4. 失败短句

| ID | 失败短句 | lb_str_* | 说明 |
|----|----------|----------|------|
| S19-1 | **质疑无锤砸** | `lb_str_challenge_no_act` | 点质疑（或调试·质疑锤）后无抬砸，仅左上字变 |
| S19-2 | **相信无锤搁** | `lb_str_believe_no_act` | 点相信（或调试·相信锤）后无搁置态 |
| S19-3 | **锤仅自己见** | `lb_str_choice_act_self_only` | 正式路径他座不见谁的锤（调试本地可豁免全员） |
| S19-4 | **砸与搁不可辨** | `lb_str_choice_act_same_pose` | 两态同姿仅换色 / 落点不分槽 |
| S19-5 | **锤挡池或手** | `lb_str_choice_act_blocks` | 砸轨或搁位置压 `lb_cmp_pool` / 手牌行 / 烛 |
| S19-6 | **调试锤走了业务** | `lb_str_debug_hammer_has_logic` | 点调试锤却揭牌/扣烛/改轮转 |

## 5. 边界

- 正式锤与调试锤 **同一套** 视觉/SFX；调试只跳过权威与业务。
- 飞词辅读 **P0 可后置**；有飞词时禁挡池（另票）。
- GAP=24% / 禁抬 padB / 开牌 1000/3000：**不动**。
