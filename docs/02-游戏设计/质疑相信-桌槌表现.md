## 1. 写死

| 项 | 锁 | 禁（=失败） |
|----|----|-------------|
| **常驻** | 每座头像旁空位可见一把木槌（够大） | 无常驻；过小 |
| **朝向** | 见 §1.2：锤头**朝荷官**四向 | 四座同朝左写死；锤头背离荷官 |
| **SELF 落点** | **金框右空**（自机底座旁） | 飘荷官右；压手 |
| **相信** | 槌不动（保持该座朝向搁姿） | 相信还在动 |
| **质疑** | 就地抬砸→回搁；**砸向按座** | 四座同一朝左砸动画 |

### 1.1 四座旁空（沿用 v0.3.3）

| 座 | 落点 | 禁 |
|----|------|----|
| **SELF** | **金框右空** / 底座旁空 | 飘荷官右；压手 → S19-10/12 |
| **左座 L** | 头像右空（朝桌） | 硬外偏；压池 |
| **右座 R** | 头像左空（朝桌） | 硬外偏；空位无槌 |
| **TOP** | 头像左旁空 | 挡脸 → S19-10 |

### 1.2 锤头朝荷官（本批重锁）

荷官≈桌心。搁姿与砸姿锤头均朝荷官：

| 座 | 锤头方向（指向荷官） | 示意 |
|----|----------------------|------|
| **TOP** | **↓** 向下 | 上座锤头朝桌心下 |
| **SELF** | **↑** 向上 | 自机锤头朝桌心上 |
| **LEFT** | **→** 向右 | 左座锤头朝桌心右 |
| **RIGHT** | **←** 向左 | 右座锤头朝桌心左 |

质疑抬砸：**短位移沿该座朝向**（砸向荷官/桌心一侧），再回搁。**禁**四座共用同一「朝左砸」写死动画。
