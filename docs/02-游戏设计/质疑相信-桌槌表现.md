## 1. 写死

| 项 | 锁 | 禁（=失败） |
|----|----|-------------|
| **常驻** | 每座头像旁**空位**始终可见一把木槌（够大） | 无常驻；过小；右座无槌 |
| **落点原则** | **头像旁空白**朝桌，非硬外偏 | 贴屏缘 |
| **四座旁空** | 见 §1.1 | TOP 挡脸；SELF 飘荷官右；压牌 |
| **相信** | 槌不动 | 相信还在动 |
| **质疑** | 放置点就地抬砸→回搁 | 砸点贴牌心 |

### 1.1 四座旁空（含 Rebuild 位姿钉）

| 座 | 落点 | 禁（本批打回） |
|----|------|----------------|
| **自机 SELF** | **底座旁空**（优先头像右侧空带）；紧贴该座底座可读区 | **飘荷官右**；压手牌行 → S19-10 / S19-12 |
| **左座 L** | 头像**右空**（朝桌） | 硬左外；压池 |
| **右座 R** | 头像**左空**（朝桌） | 硬右外；空位无槌 |
| **上座 TOP（老千）** | 头像**左旁空**（不挡脸） | **槌挡脸**；贴牌堆顶 → S19-10 |

禁区仍锁：手牌行 / 池 / 烛 / 脸（TOP）。具体 vp 认 UI 17a；本岗锁语义。
