## 1. 写死

| 项 | 锁 | 禁（=失败） |
|----|----|-------------|
| **常驻** | 每座头像旁空白带**始终可见**一把木槌（搁置姿） | 无常驻、用时才出现 |
| **尺寸** | 槌须一眼可读（头像旁主道具感）；过小不过 | **槌过小** |
| **落点原则** | **头像旁空白**（朝桌可读空带），**不是**硬外偏到屏边 | 硬贴外缘；压牌/池/烛 |
| **四座旁空** | 见 §1.1；**各写各的** | 三把偏同侧；右座锤仍在头像右外当「硬外」 |
| **相信** | 槌**不动** | 相信还在动 |
| **质疑** | 放置点附近就地抬砸→回搁 | 砸点贴牌心 / 飞进池 |
| **外形** | 一眼木槌 | 法庭玩具/木勺 |

### 1.1 四座旁空（纠锁写死）

| 座 | 落点（相对该座头像） | 禁 |
|----|----------------------|----|
| **自机 self** | 头像旁空白（优先**右侧空**；不压手牌行） | 压手牌；飞进池 |
| **左座 L / p1** | 头像**右空**（朝桌内侧空白） | **硬左外**；压池 |
| **右座 R / p2** | 头像**左空**（朝桌内侧空白） | **硬右外**；锤仍在头像右当主读 |
| **上座 对家 / p3** | 头像旁空（优先**左侧空**；不压牌堆） | 贴牌堆顶 |

禁区仍锁：手牌行 / 池 / 烛。具体 vp 认 UI 17a；本岗锁**旁空语义**（废 v0.3.0「左左外/右右外」）。

## 2. 时序

1. 进桌：四座槌已在搁置姿（常驻、尺寸可读、旁空正确）。
2. 正式 **质疑 ACK**：就地抬砸 + `lb_sfx_hammer_hit` → 回搁；HOLD **0.8～1.2s**。
3. 正式 **相信 ACK**：不播锤动画；静置可见。
4. **调试**二键：只播本地座；零业务。
