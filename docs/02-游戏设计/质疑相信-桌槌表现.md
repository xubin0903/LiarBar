### 1.1 砸拍（写死）

1. **抬**：放置点附近上抬（短位移）+ **scale 放大**（可读「离桌」）。
2. **砸**：回落贴桌 + **scale 缩小回搁姿** + 阴影一顿；同起 `lb_sfx_hammer_hit`。
3. **回搁**：回该座搁姿与朝向；HOLD 可读 0.8～1.2s。
4. 砸向仍**按座朝荷官**（旋座结果锁）；但位移主读是 **垂直感/远近感**，不是左右横扫。

## 2. 时序

进桌常驻 → 质疑 ACK：2.5D 抬砸 + hit → 回搁 → 相信静置。调试本地零业务。
