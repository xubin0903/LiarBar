## 1. 写死（再打回锁）

| 项 | 锁 | 禁（=失败） |
|----|----|-------------|
| **常驻** | 每座头像旁空白带**始终可见**一把木槌（搁置姿） | 无常驻、用时才出现 |
| **尺寸** | 槌须一眼可读（头像旁主道具感）；过小不过 | **槌过小**（像饰品/木勺点） |
| **四座锚方向** | 见 §1.1；**各写各的**，禁一套坐标复用 | 三把偏左；右座锤在头像左 |
| **相信** | 槌**不动**（搁置静置） | 相信还在动 / 播 rest 动画 |
| **质疑** | 放置点附近就地抬起→砸下→回搁；短位移 | 砸点贴牌心 / 飞进池 |
| **外形** | 一眼木槌（暖棕木+铜箍/圆柱头可读） | 法庭玩具/木勺/看不清 |

### 1.1 四座锚方向（写死）

| 座 | 锚方向（相对该座头像） | 禁 |
|----|------------------------|----|
| **自机 self** | **右侧空** | 压手牌行；落到头像左 |
| **左座 L / p1** | **左外**（头像左侧外侧空白） | 贴池/贴中线；落到头像右 |
| **右座 R / p2** | **右外**（头像右侧外侧空白） | **锤在头像左**；贴池 |
| **上座 对家 / p3** | **左侧空**（头像左侧空白带） | 贴牌堆；落到头像右当主读 |

禁区仍锁：手牌行 / 池 / 烛。具体 vp 认 UI 17a 分锚表；本岗锁**方向语义**。

## 2. 时序

1. 进桌：四座槌已在搁置姿（常驻、尺寸可读）。
2. 正式 **质疑 ACK**：该座就地抬砸（短震 + `lb_sfx_hammer_hit`）→ 回搁置；HOLD 可读认 **0.8～1.2s**。
3. 正式 **相信 ACK**：**不播**锤动画；静置可见（可轻 `lb_sfx_hammer_rest` 或静默）。
4. **调试** `lb_btn_debug_hammer_doubt` / `believe`：只播本地座；质疑=抬砸；相信=确认静置；**零业务**。
