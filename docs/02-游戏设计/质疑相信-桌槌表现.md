## 1. 写死（打回锁）

| 项 | 锁 | 禁（=失败） |
|----|----|-------------|
| **常驻** | 每座头像旁空白带**始终可见**一把木槌（搁置姿） | 无常驻、用时才出现；锤压在手牌/池/烛上 |
| **四座锚** | self / L / R / 对家 **各写各的** 落点 | 一套坐标四座复用 |
| **相信** | 槌**不动**（保持头像旁搁置） | 相信还在动 / 播 rest 动画 |
| **质疑** | 在**该座放置点附近**就地抬起→砸下→回搁置；短位移 | 砸点贴牌心 / 飞进池；抬砸后不回搁 |
| **外形** | 一眼木槌（暖棕木+铜箍可读） | 法庭玩具/木勺/看不清贴图 |

## 2. 时序

1. 局内进桌：四座槌已在搁置姿（常驻）。
2. 正式 **质疑 ACK**：该座就地抬砸（短震 + `lb_sfx_hammer_hit`）→ 回搁置；定格可读认锤 HOLD **0.8～1.2s**（实现可 ≈1000ms）。
3. 正式 **相信 ACK**：**不播**锤动画；该座槌保持静置可见即可（可轻 `lb_sfx_hammer_rest` 或静默）。
4. **调试** `lb_btn_debug_hammer_doubt` / `believe`：只播**本地座**；质疑=抬砸；相信=确认静置（零位移）；**零业务**。

## 4. 失败短句

| ID | 失败短句 | lb_str_* | 说明 |
|----|----------|----------|------|
| S19-1 | **质疑无锤砸** | `lb_str_challenge_no_act` | 质疑 ACK / 调试质疑锤后无抬砸 |
| S19-2 | **相信无常驻锤** | `lb_str_believe_no_act` | 相信路径下该座头像旁无搁置槌（语义改：非「无搁动画」） |
| S19-3 | **锤仅自己见** | `lb_str_choice_act_self_only` | 正式路径他座不见谁的锤（调试本地豁免全员） |
| S19-4 | **砸与搁不可辨** | `lb_str_choice_act_same_pose` | 抬砸与搁置姿难辨 |
| S19-5 | **锤挡池或手** | `lb_str_choice_act_blocks` | 常驻或砸轨压池/手/烛 |
| S19-6 | **调试锤走了业务** | `lb_str_debug_hammer_has_logic` | 调试键揭牌/扣烛/改轮转 |
| **S19-7** | **锤压在牌上** | `lb_str_hammer_on_cards` | 常驻落点压在手牌行或池叠上 |
| **S19-8** | **相信还在动** | `lb_str_believe_hammer_moves` | 相信路径仍播 rest/位移动画 |
| **S19-9** | **砸点贴牌心** | `lb_str_hammer_smash_on_pool` | 质疑砸位移落到牌心/池心，非放置点附近空白 |

## 5. 边界

- 正式与调试同一套视觉；调试只跳过权威与业务。
- 开牌 1000/3000、GAP=24%、禁抬 padB、人模：**不动**。
- 左上荷官句仍为播报，不当事主读。
