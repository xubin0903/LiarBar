## 1. 写死

| 项 | 锁 | 禁（=失败） |
|----|----|-------------|
| **常驻** | 每座头像旁空位可见一把木槌（够大） | 无常驻；过小 |
| **朝向结果** | 锤头朝荷官：TOP↓ / SELF↑ / LEFT→ / RIGHT← | 四座同朝左写死；锤头背离荷官 |
| **真源路径** | 美术 **单朝主轴 +X**；client **按座旋转** 到 §1.2 | 先烤 12 张分向帧当 P0；四座同贴图无旋转 |
| **SELF 落点** | **金框右空** | 飘荷官右；压手 |
| **相信** | 槌不动（保持该座朝向搁姿） | 相信还在动 |
| **质疑** | 就地抬砸→回搁；砸向=该座朝荷官 | 四座同一朝左砸动画 |

### 1.1 四座旁空

| 座 | 落点 | 禁 |
|----|------|----|
| **SELF** | **金框右空** / 底座旁空 | 飘荷官右；压手 → S19-10/12 |
| **左座 L** | 头像右空（朝桌） | 硬外偏；压池 |
| **右座 R** | 头像左空（朝桌） | 硬外偏；空位无槌 |
| **TOP** | 头像左旁空 | 挡脸 → S19-10 |

### 1.2 锤头朝荷官（结果锁）

| 座 | 锤头方向 | client 旋座（相对真源 +X） |
|----|----------|---------------------------|
| **RIGHT** | **←** | 视资源约定（常 ≈180° 或镜像；以锤头朝桌心为准） |
| **LEFT** | **→** | 真源 +X 可接近 0°（锤头朝右=朝荷官） |
| **SELF** | **↑** | 约 −90° / 270°（锤头朝上） |
| **TOP** | **↓** | 约 +90°（锤头朝下） |

> 角度数字认 UI/鸿蒙实测；本岗锁 **结果朝向** 与 **单朝+X→旋座** 路径。禁四座共用无旋转的同一朝左动画。
