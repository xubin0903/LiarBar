# 《谎馆》对局互动方案

| 项 | 内容 |
|----|------|
| 版本 | v0.1 Demo · 第2批 |
| 状态 | 待人工审核 |
| 与 GDD 关系 | **表现与社交层详规**；胜负规则以 [GDD](./GDD.md) 为准 |
| 默认桌规 | 社交桌（动作不改牌真假） |

---

## 1. 设计目标

把「说谎」从点两个按钮，升级为四层同时在骗：

```
系统节奏层：倒计时 / 灯光 / 实况窗
社交施压层：起哄 / 点名 / 站队
动作暗示层：表情 / 手势 / 握姿
牌面操作层：出牌 / 质疑
        ↓
AI 荷官解读层：记录 · 播报 · 复盘
```

**一句话**：我演给你看，你猜我是不是在骗。

---

## 2. 设计约束（写进答辩也成立）

| 约束 | 说明 |
|------|------|
| 可见非对称 | 牌私有，表演公开 |
| 可伪装 | 紧张/淡定信号可被主动伪造 |
| 可误读 | 读错是玩法一部分 |
| 默认可关数值影响 | 社交桌默认；演技桌可选 |
| 无摄像头可玩 | 手动表情轮盘 ≡ FaceAR 枚举 |
| 防刷屏 | 每回合动作次数上限 |

**对外口径**：动作是社交语言，不是透视外挂。

---

## 3. 阶段化互动（焊进流程）

### 3.1 入座开张（约 30s）

| 互动 | 玩家行为 | 全桌反馈 | MVP |
|------|----------|----------|-----|
| 入座姿态 | 端坐/瘫坐/前倾 | 头像姿态 | P1 |
| 亮相表情 | 拍 1s 或选表情 | 动态头像框 | P1（手动选 P0） |
| 开局宣言 | 选台词模板 | 弹幕一闪 | P0 模板即可 |

### 3.2 看牌（隐私核心局）

| 互动 | 设计 | MVP |
|------|------|-----|
| 窥牌手势 | **长按牌背揭开，松手收回** | P0 |
| 防窥绑定 | 揭开瞬间启动隐私防窥 | P0 |
| 看牌演技 | 揭开同时可选：挑眉/面瘫/苦笑/吞咽 | P0 轮盘 |
| 全桌可见 | 只见表情符号，不见牌 | P0 |
| 假动作 | 「装惊喜」「装绝望」快捷 | P0 |

**单手**：智感握姿左握时，表情快捷键挪到右侧（P1）。

### 3.3 出牌包（Play Bundle）

```
出牌包 = 选牌(1~3) + 出牌方式 + 桌面话术 + 微动作/点名
```

#### 3.3.1 出牌方式（P0 至少 3 种）

| 方式 ID | 操作 | 全桌信号 | 常见解读（可反用） |
|---------|------|----------|-------------------|
| SOFT | 短滑轻推 | 平稳入池 | 像真 |
| SLAM | 快速上滑 | 砸桌+轻震 | 装狠/心虚 |
| HESITATE | 拖拽停顿>0.8s | 牌角发抖 | 强心虚（可伪造） |
| PIN（P1） | 双指按下再出 | 用力扣 | 认真施压 |
| BLIND（P1） | 不看牌确认 | 闭眼标记 | 疯狗 |

强表演方式每局次数上限：见数值文档。

#### 3.3.2 带话与点名（P0）

| 类型 | 示例 | 备注 |
|------|------|------|
| 装真 | 「整整齐齐」 | 模板 |
| 挑衅 | 「你敢开？」 | 模板 |
| 点名 | @某人 | 头像烛火盯梢；对方实况窗/震动提示 |
| 跳过 | 无话 | **跳过本身也是信息** |

自定义：≤12 字（可 P1）。

#### 3.3.3 加注谎（P1）

- 口气 Normal / Raise  
- 默认不影响扣命，只影响动画与战报标签  

### 3.4 非回合观战（防挂机）

| 动作 ID | 触发 | 可见性 | 每回合上限 | MVP |
|---------|------|--------|------------|-----|
| KNOCK | 双击桌面区 | 全桌音效波纹 | 2 | P0 |
| TOAST | 点酒杯 | 全桌 | 1 | P1 |
| STARE | 长按头像 1s | 被盯者强提示 | 1 | P0 |
| SIGN_OK | 对某人画 ✓ | 全桌 | 2 | P0 |
| SIGN_NO | 对某人画 ✗ | 全桌 | 2 | P0 |
| HECKLE | 选「假的吧/稳/开他」 | 弹幕 | 2 | P0 |
| WHISPER | 邻座 6 字 | 双方（可选荷官窃听） | 1 | P2 |

**倒计时集体催促（P0）**：剩余 <5s，全桌可点「催」；压力仅表现层（微抖/鼓点），静默局关闭。

### 3.5 信任温度（表现层，P1）

- 每人头像周缘冷蓝↔热红  
- 输入：被盯、被✗、犹豫出牌等  
- **禁止**写成“说谎值”文案，只做氛围  

### 3.6 质疑三拍（P0 高潮）

```
拍1 指控（约 0.8s）：质疑者姿态 + 台词
拍2 对峙（约 1.2s）：被质疑者反应表情；旁观押 TRUE/FAKE
拍3 翻牌（约 1.5s+）：逐张翻；可砸杯加重音；结果定格
```

| 角色 | 可做 |
|------|------|
| 质疑者 | 拍桌指控 / 举杯轻问 / 指人怒斥（三选一姿态） |
| 被质疑者 | 死撑 / 破防 / 反嘲 |
| 旁观+幽灵 | 押真假、砸杯 |
| 系统 | 光感切红、实况窗“翻牌中” |

押面子：**不改谁扣命**，只改面子分与战报徽章。

### 3.7 惩罚与出局

| 事件 | 互动 |
|------|------|
| -1 命 | 泼酒 UI；可选认罚表情 |
| 出局 | **遗言 ≤8 字** + 可选“我怀疑谁”烙印 |
| 幽灵 | 可 KNOCK/SIGN/HECKLE/押面子；不可见他人手牌 |

### 3.8 局间关系（P1）

- 仇敌：本局成功质疑你的人，下局红名一闪  
- 酒友：连续两局未恶性互狙，生成标签  
- 卡片文案复用战报

## 4. 动作暗示三通道

### 4.1 通道 A：表情（FaceAR 或轮盘）

统一枚举（写入日志）：

| 枚举 | 符号呈现（酒馆化，不裸奔人脸） | 可伪造 |
|------|--------------------------------|--------|
| SMILE | 酒面微波 | 是 |
| SMIRK | 烛火斜跳 | 是 |
| FROWN | 酒面结霜 | 是 |
| BROW_UP | 烛芯一挑 | 是 |
| AVERT | 面具侧过 | 是 |
| STARE_NOD | 面具正对 | 是 |
| PANIC | 面具裂痕（破防定格用） | 是 |

### 4.2 通道 B：屏幕手势暗语（教程必教）

| 手势 | 含义 | MVP |
|------|------|-----|
| 双击自己头像 | 「我这手真」 | P0 |
| 三连点桌 | 「有人在骗」 | P0（与 KNOCK 合并规则需统一：建议三连=KNOCK 强化） |
| 左滑自己 | 「别质疑我」 | P1 |
| 右滑自己 | 「来开我」 | P1 |
| 对他人 ✓ / ✗ | 挺他 / 他假 | P0 |

### 4.3 通道 C：智感握姿（P1）

| 状态 | 表现 |
|------|------|
| 左/右单手 | 操作热区改对侧 |
| 未握持 | 偏观战，起哄按钮放大 |
| 换手 | 触发一次“重整衣领”全桌可见动画 |

### 4.4 新手动作词典（四套，教学用）

```
装真：轻推 + SMILE + 双击自己
装疯：甩出 + 右滑自己 + 点名最稳者
带节奏：敲桌 + 画✗ + 起哄「开他」
死撑：扣拍/轻推 + STARE_NOD + 不带话
```

---

## 5. 演技桌（档位 C，默认关）

仅软压力，**永不改牌真假**：

| 检定 | 效果方向 |
|------|----------|
| 众怒（≥3 人同时 ✗） | 其出牌时限 -2s |
| 破绽组合（犹豫+FROWN） | 荷官多一句公开阴阳 |
| 镇定演出 | 减少公开尴尬动画（纯表现） |

---

## 6. AI 在互动中的义务

| 时机 | 行为 |
|------|------|
| 出牌后 | 10%～30% 概率短评模板 |
| 集体催 | 可跟风 HECKLE |
| 质疑对峙 | AI 双方出姿态/表情 |
| 全程 | 低频 KNOCK / SIGN_NO |
| 局后 | 基于日志生成读心句 |

人机演示：**AI 必须会用 P0 互动**，否则桌面假死。

## 7. 40 秒互动密度样例（演示分镜可直接用）

```
00:00  小A 长按看牌（防窥）→ 苦笑面具
00:08  小B 画✗；小C 敲桌
00:12  小A 点名小B + 甩出两张
00:18  实况窗质疑倒计时；旁观押真假
00:22  小B 拍桌质疑
00:24  小A 死撑；砸杯
00:26  翻出假牌 → 扣命 → 破防定格
00:32  荷官：「面具裂了。」
00:35  进入下一宣称 / 或战报预告
```

## 8. 优先级与静默局

### P0（互动立住）

1. 长按看牌 + 防窥  
2. 出牌方式 ≥3  
3. 带话模板 + 点名  
4. 敲桌、✓✗、催  
5. 质疑三拍 + 押真假  
6. 手动表情轮盘  
7. 荷官模板短评 + 战报含动作一句  

### P1

FaceAR、握姿、加注谎/盲出、温度条、表情对比卡、卡片  

### P2

私语窃听、演技桌、语音怒斥  

### 静默局开关

关闭：强震动、鼓点催促、公开嘲讽音效、弹幕起哄密度降为 0。

---

## 9. 风险

| 风险 | 对策 |
|------|------|
| 表情噪声 | 酒馆符号化；只教 4 套 |
| 刷屏 | 回合上限 |
| 社死 | 静默局 |
| 公平性质疑 | 默认社交桌写进一页纸与 PPT |

---

## 10. 审核焦点问题

1. 旁观押面子是否默认开？（GDD 建议开）  
2. 出牌是否强制带话？还是可跳过？（建议可跳过）  
3. P0 是否砍掉“点名”降工作量？（不建议砍，社交核）  
4. 质疑三拍总时长上限？建议 ≤4s 可跳过动画
