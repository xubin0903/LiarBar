## 2. 与 GDD §6.1 对齐（散文）

§6.1 已锁、本文不改字：

1. 阶段 `TURN` 且轮到自己，选 1～`MAX_PLAY` 张（默认 **3** = `max_play_cards`）。  
2. 记录出牌方式（至少枚举；桌上主路径默认 `SOFT`，见 15）。  
3. 牌从手牌入本手扣牌区，对外牌背。  
4. 带话可跳过；点名 P0 可选——走次路径 `lb_sheet_play`，**不在本线重做**。  
5. 出牌后轮转下家；本手可被质疑；**第一手不可质疑**。

桌上 UI 态（与 15 §2 同名，不另造引擎阶段）：

```
Idle → PeekSelected → MultiSelected → ConfirmReady → Playing → Settle → Idle
```

| UI 态 | GDD | 合法时 |
|-------|-----|--------|
| Idle | `TURN` | 己回合可点一张进 PeekSelected |
| PeekSelected / MultiSelected | `TURN` | 已选 1～`cap`；`cap = min(MAX_PLAY, 手牌数)` |
| ConfirmReady | `TURN` | 选择合法 → 条出现，点 `lb_btn_play_confirm` |
| Playing | `PLAY_REVEAL_SELF` | 提交；方式默认 SOFT |
| Settle | 回 `TURN`（下家）或 AUTO_PLAY | 条隐、余牌回 Idle |

**取消（与 15 写死一致）：** 点空白 → 全清回 Idle；再点同牌 → 取消该张。不提交、不进 `PLAY_REVEAL_SELF`。

**合法性（不改配置键）：**

```
legal(n) = 己回合 且 未出局 且 阶段允许 PLAY
           且 hand_count ≥ 1
           且 min_play_cards ≤ n ≤ min(MAX_PLAY, hand_count)
```

手牌 0：GDD §10.1 仅质疑窗或自动跳过。**本线不扩质疑。** 复用已锁 `lb_str_hand_empty`（没有牌了，只能质疑）。

超时仍认 GDD `AUTO_PLAY`。本线不改超时公式。

## 3. 控件与确认条（只引用 15）

**`lb_*` 以 15 / 02 v0.1.3 为准**（#100 已登记）：

| id | 角色 |
|----|------|
| `lb_cmp_hand` | 手牌条 |
| `lb_cmp_card_{0-4}` | 单张；点按翻面 + 多选 |
| `lb_cmp_play_confirm_bar` | 确认条；仅合法选中出现 |
| `lb_btn_play_confirm` | 主提交 |
| `lb_btn_play` / `lb_sheet_play` | 锁名不废；**次路径**（方式 / 带话 / 点名） |

两确认钮不得同时可点出两套规则。新用例点 `lb_btn_play_confirm`（F15-10）。

**确认条：** 仅合法选中时出现（15 推荐；非法不挂灰钮）。可点 = `_enabled`。Playing 可短暂 `_disabled` 防连点。文案复用 `lb_str_play`「出牌」。

**可点优先、不绑贴底硬修：** 条近底安全区上沿，拇指够得着——这是 UX，**不是** 11 手牌贴底硬修。不改 `padB` / `HAND_RING_GAP` / flush 闸（15 硬闸三句 · F15-11）。

翻面 vs 抬起的时序窗、连点打断、peek 阈值：**认 15 §3**。本文不重写毫秒与 vp。策划只要求：点选必须看见正面，选中须保持正面；取消沿原路径收回。

SFX 槽认 15 §7：`lb_sfx_card_flip` / `lb_sfx_card_select` / `lb_sfx_play_confirm`。本 PR 不交真源。

## 4. 失败短句（对齐 F15-* + 规则向）

线框闸 **抄 15 §8**。规则向短句与 15 §4 口播锁字一致。合入 ≠ 终验。

| ID | 短句 | 对齐 | 不过 / 桌内 |
|----|------|------|-------------|
| F15-1 | **单张不翻面** | 15 | 点一张不见正面 |
| **S15-1** | **未翻面就想出** | 语义补 | 牌背或翻转中途进 Playing。桌内可：**先翻开再出。** |
| F15-2 | **多选无效** | 15 | 不能选到 `cap` |
| F15-3 | **取消无效** | 15 | 点空白 / 再点同牌仍选中（=「点空白未取消残留选中」） |
| F15-4 | **超选仍选中** | 15 | 第 `cap+1` 张进组。桌内：**超选**（`lb_str_play_over_select`） |
| F15-5 | **非己回合能出** | 15 | 别人回合能选并能交。桌内：**非己回合**（`lb_str_play_not_your_turn`） |
| F15-6 | **张数不符仍出** | 15 | 0 张或超帽进 Playing。桌内：**张数不符**（`lb_str_play_illegal_count`） |
| **S15-2** | **未选牌点确认** | 语义补：F15-6/8 | 0 张（含只长按看过）仍能交。条应不出现 |
| F15-7 | **合法无确认条** | 15 | 已选合法、己回合，条不在 |
| F15-8 | **非法仍亮出牌** | 15 | 非法却 `_enabled` 且能交 |
| F15-9 | **终稿仍是系统灰钮** | 15 | 系统灰/蓝当完成 |
| F15-10 | **顶钮仍是唯一主路径** | 15 | 只能靠旧 `lb_btn_play` / 半屏才能出 |
| F15-11 | **绑了贴底硬修** | 15 | 为条改 `padB` / 环-手 / 重开 flush |
| F15-12 | **扩了质疑** | 15 | 本线做出质疑窗 / 四拍 |
| **S15-3** | **无手牌仅质疑窗口却走出牌** | §10.1 边界 | 桌内复用 **没有牌了，只能质疑。** 不因此解冻质疑 |

长按揭全手 ≠ 已选中。S15-1 与 S15-2 不合并。
