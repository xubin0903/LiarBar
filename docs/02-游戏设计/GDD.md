## 1. 游戏概述

### 1.1 品类

虚张声势 / 心理博弈（规则内核对齐大众「骗子酒吧」类：宣称花色、扣牌出、质疑翻验、淘汰制）。

### 1.2 一局体验一句话

> 你用真牌或假牌推进宣称，用表情和姿态骗人，在被质疑的翻牌瞬间决定谁掉命。

### 1.3 设计支柱（3 条）

| 支柱 | 含义 | 设计推论 |
|------|------|----------|
| 信息差 | 手牌私有，表演公开 | 防窥看牌；动作全桌可见 |
| 可伪装 | 任何“心虚信号”都可演 | 禁止系统透视真假 |
| 全员热 | 非行动者也参与 | 旁观敲桌/站队/押面子 |

### 1.4 体验目标

| 指标 | 目标 |
|------|------|
| 单局时长 | 3～8 分钟（4 人 3 命） |
| 学会上手 | ≤60 秒教学可进行第一局 |
| 高潮密度 | 平均每 40～90 秒一次质疑相关紧张点 |
| 演示友好 | 90 秒内可走到一次完整质疑结算 |

## 2. 对局结构

### 2.1 人数

| 模式 | 人数 | MVP |
|------|------|-----|
| 标准桌 | 4 人 | ✅ 默认 |
| 小桌 | 3 人 | ✅ |
| 大桌 | 5～6 人 | P1（规则兼容，AI 与 UI 次优先） |

人不足时由 **AI 牌友** 补位（可关，但关后人数不足不能开局）。  
**MVP 形态：只人机 + 本地。**

### 2.2 生命

- 默认每人 **3 命**  
- 命归零 → 出局，成为 **幽灵旁观**（可起哄/押面子，不可看他人手牌，不可出牌质疑）  
- 场上仅剩 1 人有命 → 该人胜利，进入战报  

可选（非 MVP）：虚拟“酒量条”代替命，归零同出局。

### 2.3 座位与回合顺序（已锁定）

- 座位固定环形  
- 出牌按顺时针  
- 开局第一行动者：AI 荷官随机指定，或“房主左手边”  
- **新一轮宣称开始时：由上一轮受罚者（扣命者）的下家先出；若受罚者已出局，则其下家先出**  
- 本条为**正式规则**，不再保留「MVP 可随机简化」的摇摆表述

## 3. 牌与牌堆

### 3.1 牌面定义

| 牌 | 说明 |
|----|------|
| 普通牌 | 符号：`A` / `K` / `Q` |
| 万能牌 Joker | **永远算作符合当前宣称** |

> MVP 使用 **符号牌**（非完整 52 张扑克）。  
> 宣称形如：“本轮必须出 **A**”。  
> 牌面只有：`A` `K` `Q` `JOKER` 四种。

### 3.2 为何简化

- 教学快、UI 好做、AI 好写  
- 答辩 10 秒能讲清  
- 与“骗子酒吧”精神一致，不绑死某一商业产品牌表  

### 3.3 发牌（默认 4 人桌，详见数值文档）

| 参数 | 默认建议 |
|------|----------|
| 每人手牌 | 5 张 |
| 牌堆构成 | A×8，K×8，Q×8，JOKER×4（共 28，发 20，余牌废弃或作展示） |
| 发牌后 | 余牌不进入本局（防数牌过深，保持轻量） |

3 人桌、5～6 人桌参数见 [数值与牌堆配置](./数值与牌堆配置.md)。

### 3.4 手牌私密性

- 仅本人可见  
- UI：默认牌背；**长按/按住** 揭示；松开隐藏  
- 揭示期间触发 **隐私防窥**（系统能力）  
- 他人不可通过任何合法 UI 看到你的手牌

## 4. 核心循环

```
开局发牌
  → 荷官公布本轮宣称（如“出 A”）
  → 轮到玩家：出牌 或（若非本轮第一手）质疑上家
  → 若出牌：牌扣入中央池，轮转下家
  → 若质疑：翻上家本手牌 → 结算 → 扣命 → 清空本轮池 → 新宣称（若多人存活）
  → 直至仅一人存活
  → 战报
```

### 4.1 阶段枚举（逻辑名，供程序对齐）

| 阶段 ID | 名称 | 可执行操作 |
|---------|------|------------|
| LOBBY | 等待开局 | 配置、准备 |
| DEAL | 发牌表演 | 自动 |
| CLAIM | 公布宣称 | 自动 + 短播报 |
| TURN | 回合决策 | 出牌 / 质疑（条件见下） |
| PLAY_REVEAL_SELF | 自己确认出牌 | 选牌、方式、话术（手牌仍防窥） |
| CHALLENGE_RITUAL | 质疑仪式 | 三拍 + 旁观押注 |
| JUDGE | 结算 | 自动翻验 |
| PENALTY | 惩罚演出 | 掉命/出局 |
| RECAP | 战报 | 再来、分享 |
| END | 结束 | 回首页 |

## 5. 宣称（Claim）

### 5.1 定义

每轮开始，AI 荷官从符号集合中选一个 **本轮合法目标**，例如：

- “这一轮，出的都得是 **A**（Joker 算 A）”

### 5.2 选取规则（MVP）

- 在 `A/K/Q` 中 **均匀随机**（**Joker 不作宣称目标**）  
- 连续两轮避免同一宣称（若可能）  

### 5.3 玩家不能改宣称（MVP）

- 降低复杂度；进阶可做“加注谎”只加口气不改花色（见 §6.3）

## 6. 玩家行动详规

### 6.1 出牌（PLAY）

**合法条件**：当前阶段为 TURN，且轮到自己。

**必须**：

1. 选择手牌 1～`MAX_PLAY` 张（默认 MAX_PLAY=3）  
2. 选择 **出牌方式**（见互动方案；逻辑上至少记录枚举）  
3. 将牌从手牌移入 **本手扣牌区**（对他人不可见）  

**可选**：

4. 带话（模板/点名/短自定义）——**可跳过**  
5. 点名一位玩家（施压标记）——**P0**  

**出牌后**：

- 轮到下一位存活玩家  
- 上家本手牌成为“可被质疑对象”  
- 本轮第一手 **不可被质疑**（因无上家本手）；仅可出牌  

手牌触摸选牌、翻面与确认条：参见 [手牌触摸出牌-交互方案](./手牌触摸出牌-交互方案.md)。  

### 6.2 质疑（CHALLENGE）

**合法条件**：

- 轮到自己  
- 本轮已存在“上家本手扣牌”  
- 自己未出局  

**效果**：

1. 进入质疑仪式（表现层；总长 ≤4s，可跳过）  
2. 翻开上家 **刚刚那一手** 的全部扣牌（不是历史所有）  
3. 判定：  

| 结果 | 条件 | 惩罚 |
|------|------|------|
| 质疑成功 | 存在至少 1 张 **既非宣称符号、也非 Joker** | 上家（被质疑者）-1 命 |
| 质疑失败 | 全部为宣称符号或 Joker | 质疑者 -1 命 |

4. 本轮结束：中央本手与本轮历史扣牌清空（或弃置）  
5. 全体未出局玩家 **不补牌**（MVP；手牌打光规则见 §10.1）  
6. 若仍 ≥2 人存活 → 新宣称 + 新一轮（出牌权见 §2.3）  
7. 若有人 0 命 → 出局演出 → 继续或结束  

### 6.3 加注谎（P1，可选规则开关）

- 出牌时可声明“口气等级”Normal / Raise  
- Raise：被抓时额外公开嘲讽动画，或 -1 额外“面子”不改命（推荐不改命，只动画）  
- **默认关闭**，免平衡争议  

### 6.4 盲出（P1）

- 未揭牌状态直接确认出牌  
- 标记“盲出”，全桌可见  
- 仍遵守 1～3 张与手牌数约束

## 7. 互动系统（逻辑摘要）

> 表现与手势详规以 [互动方案](./互动方案.md) 为准。GDD 只锁 **对规则/日志的影响**。

### 7.1 桌规档位

| 档位 | 名称 | 动作对胜负 |
|------|------|------------|
| S | 社交桌（**默认**） | **无影响**，只影响信息、舆论、战报 |
| C | 演技桌（可选） | 只影响时限/播报等软压力，**永不改牌真假** |

### 7.2 必须进入对局日志的事件（供战报）

- PLAY（张数、方式、是否点名、不写牌面）  
- CHALLENGE（谁查谁）  
- JUDGE（成功与否、假牌张数）  
- EMOTE（表情枚举）  
- TABLE_ACT（敲桌、画✓✗、押真假）  
- LIFE_CHANGE / OUT  

### 7.3 旁观押面子（默认开）

- 窗口：**嵌在质疑仪式拍 2（对峙）**；旁观（含幽灵）选 TRUE（全真）/ FAKE（有假）  
- **关闭条件（先到先关）**：拍 3 翻牌开始 **或** 满 `challenge_bet_seconds`（默认 **2s**）  
- 押对：+面子分；**押错：0**（不扣分）  
- **不改变扣谁命**  

### 7.4 表情与手势

- 映射为枚举写入日志  
- FaceAR 与手动轮盘 **同一枚举空间**  
- 教程必须包含 4 套“装真/装疯/带节奏/死撑”  
- **三连点桌 = KNOCK 强化**（同一动作 ID：`KNOCK`）

## 8. AI 设计

### 8.1 AI 荷官（强制）

| 职责 | 实现 |
|------|------|
| 洗牌发牌 | 确定性随机（可记 seed 便于复现演示） |
| 公布宣称 | 规则随机 |
| 推进回合 | 状态机 |
| 超时处理 | 见 §10 |
| 质疑结算 | **纯规则，禁止 LLM** |
| 播报 | 模板句；可选 LLM 润色，失败回落模板 |
| 战报 | 统计日志 + 模板/LLM 一句话 |

### 8.2 AI 牌友（MVP 三人格）

| ID | 名 | 出假倾向 | 质疑倾向 | 表演倾向 |
|----|----|----------|----------|----------|
| AI_TIMID | 怂货 | 低 | 低 | 少敲桌 |
| AI_SHARK | 老千 | 中高 | 中 | 爱甩出、假笑 |
| AI_KAREN | 杠精 | 中 | 高 | 爱画✗、爱催 |

决策：**概率表 + 手牌启发式**（见数值文档），不要求完美最优。

伪逻辑示例（出牌）：

```
if 手牌中符合宣称的数量 >= 要出的张数:
    以 P_truth 出真
else:
    必须出假或掺假
质疑：if 上家连续出牌次数高 or 随机 < P_challenge: 质疑
```

### 8.3 AI 必须会的互动

- 出牌方式不全是“轻推”  
- 会点名、敲桌、画✗（低频率）  
- 被质疑时出反应表情  
→ 保证 **1 真人 3 AI 演示不冷场**

## 10. 异常与边界规则

| 情况 | 处理 |
|------|------|
| 手牌为 0 仍轮到你 | 见 **§10.1**（已锁定可执行版） |
| 手牌 < 想出张数 | UI 禁止选择超出 |
| 回合超时 | AUTO_PLAY：随机出 1 张合法优先真牌；若无牌可出则按 §10.1 |
| 质疑超时 | 默认不自动质疑；仅出牌超时自动出；挑战-only 窗口超时视为跳过 |
| 只剩 2 人 | 规则不变，更易演示 |
| 玩家强退 | 人机：转 AI 接管；联网（P2）：托管 |
| 断网 | 人机无影响 |
| 拒绝摄像头 | 手动表情，功能完整 |
| 静默局 | 关闭催促抖动、公开嘲讽音效、强弹幕（**要做**） |

### 10.1 手牌耗尽细则（方案 A 可执行版 · 已锁定）

替换旧「手牌多者胜」含糊终局。**禁止**以手牌多寡直接判胜。

1. **无手牌且可质疑**（存在上家本手、且非本轮第一手语境下轮到自己）：  
   - **仅开放质疑**，不开出牌  
   - 时限：`challenge_only_seconds`（默认 **8**）  
   - 不质疑 / 超时 → **跳过**，轮转下家  

2. **无手牌且不可质疑**：  
   - **自动跳过**  

3. **连续一圈无人出牌/质疑推进**（存活座位走完一圈，本轮无有效 PLAY/CHALLENGE）：  
   - **本轮结束，不扣命**  
   - 对所有**存活**玩家：按 `hand_size_default`，从**完整牌堆**重建 → 洗牌 → 重发  
   - 荷官公布**新宣称**  
   - 先手：由**上次扣命受罚者**的下家先出；若本局尚**无受罚记录**，则荷官随机指定先手  

4. 胜负仍只认：**命归零出局，场上仅剩 1 人有命者胜**。

## 11. 教学模式（60 秒）

**强制脚本（已锁定）**：

1. **AI 先出本轮第一手**（示范出牌；本轮第一手不可质疑，见 §6.1 / G-Q6）  
2. **再教玩家质疑**（玩家作为下家，对 AI 本手发起质疑）  
3. **禁止**在本轮第一手（尚无上家本手）时教质疑——否则与规则冲突，会教错  

| 步 | 内容 | 玩家动作 |
|----|------|----------|
| 1 | 宣称是什么 | 看 |
| 2 | 长按看牌 + 防窥 | 做一次 |
| 3 | **AI 出本轮第一手**（示范出牌方式；第一手不可质疑） | 看 |
| 4 | **教质疑**：对 AI 上家本手发起质疑 | 点质疑 |
| 5 | 翻牌结果 + 结算简述 | 看 |
| 6 | 动作词典四套（图示） | 跳过可 |

可跳过；设置中可重进。

## 14. 状态机索引（供第4批展开）

主路径：

```
LOBBY → DEAL → CLAIM → TURN
TURN → (PLAY_REVEAL_SELF → 提交) → TURN(下家)
TURN → CHALLENGE_RITUAL → JUDGE → PENALTY
PENALTY → (存活≥2 ? CLAIM : RECAP) → END
TURN（无牌）→ 仅质疑窗口或自动跳过（§10.1）
一圈无推进 → 重建发牌 → CLAIM
```

事件：`onTimeout` `onOut` `onAllButOne` `onEmote` `onTableAct` `onHandEmptyStall`

完整转移表与数据结构 → 第4批 `05-技术/状态机与规则引擎.md`。
