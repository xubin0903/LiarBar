## 1. 游戏概述

### 1.1 品类

虚张声势 / 心理博弈（规则内核对齐大众「骗子酒吧」类：宣称花色、扣牌出、质疑翻验、**左轮淘汰**）。

### 1.2 一局体验一句话

> 你用真牌或假牌推进宣称，用表情和姿态骗人，在被质疑的翻牌瞬间决定谁扣扳机——实弹出局，最后幸存者胜。

### 1.3 设计支柱（3 条）

| 支柱 | 含义 | 设计推论 |
|------|------|----------|
| 信息差 | 手牌私有，表演公开 | 防窥看牌；动作全桌可见 |
| 可伪装 | 任何“心虚信号”都可演 | 禁止系统透视真假 |
| 全员热 | 非行动者也参与 | 旁观敲桌/站队/押面子 |

### 1.4 体验目标

| 指标 | 目标 |
|------|------|
| 单局时长 | 3～8 分钟（4 人左轮桌） |
| 学会上手 | ≤60 秒教学可进行第一局 |
| 高潮密度 | 平均每 40～90 秒一次质疑/开枪紧张点 |
| 演示友好 | 90 秒内可走到一次完整质疑→开枪 |

## 2. 对局结构

### 2.1 人数

| 模式 | 人数 | MVP |
|------|------|-----|
| 标准桌 | 4 人 | ✅ 默认 |
| 小桌 | 3 人 | ✅ |
| 大桌 | 5～6 人 | P1（规则兼容，AI 与 UI 次优先） |

人不足时由 **AI 牌友** 补位（可关，但关后人数不足不能开局）。  
**MVP 形态：只人机 + 本地。**

### 2.2 胜负与淘汰（左轮 · **废 3 命主胜负**）

> **§2.2 旧「每人 3 命 / 命归零出局 / 打光=本轮胜→RoundWin→RedealAll」已全部废止。**  
> 现锁认 [左轮对局-状态机](./左轮对局-状态机.md) R3 / R9 / R10。

- **左轮手枪**：6 膛 **1 实弹**（其余空膛）。任意须开枪者扣扳机一次；枪膛顺序推进。
- **实弹** → 该玩家 **出局 / 淘汰**（幽灵旁观：可起哄/押面子，不可看他人手牌，**不发牌 / 不质疑 / 不出牌 / 不开枪**）。
- **空膛** → 惊吓演出后继续；该玩家仍存活。
- **整局胜**：场上 **仅剩 1 名存活者** → MatchEnd / RankSettle。
- **废止**：3 命扣命主胜负；打光 = RoundWin→RedealAll（#160/#163）；打光入整局名次 / 坐穿。

可选（非 MVP）：虚拟“酒量条”等表现层替代物 **不得** 恢复 3 命扣命公式。

生命主读：**烛 + 熄灭**。左轮 HUD/SFX 可留作开枪反馈，**不得**当生命计数 UI。语义为「存活 / 已出局」，**不**再表示 3 命数字。参见 [14a](../04-设计/14a-生命显示-语义与文案.md)；**不**把旧 3 命当现行规则。

### 2.3 座位与回合顺序（仍锁）

- 座位固定环形  
- 出牌按顺时针  
- 开局第一行动者：AI 荷官随机指定，或“房主左手边”  
- **新一轮宣称开始时：由上一轮开枪者（实弹或空膛均算）的下家先出；若开枪者已出局，则其下家先出**  
- 本条为**正式规则**

## 3. 牌与牌堆

### 3.1 牌面定义

| 牌 | 说明 |
|----|------|
| 普通牌 | 符号：`A` / `K` / `Q` |
| 万能牌 Joker | **永远算作符合当前宣称**（Joker 除外于「假牌」判定） |

> MVP 使用 **符号牌**（非完整 52 张扑克）。  
> 宣称形如：“本轮必须出 **K**”。  
> 牌面只有：`A` `K` `Q` `JOKER` 四种。

### 3.2 为何简化

- 教学快、UI 好做、AI 好写  
- 答辩 10 秒能讲清  
- 与“骗子酒吧”精神一致，不绑死某一商业产品牌表  

### 3.3 发牌（默认 · **PM 锁**）

| 参数 | 锁定值 |
|------|--------|
| 牌堆构成 | **20 张 = 6K + 6Q + 6A + 2Joker** |
| 每人手牌 | **5 张** |
| 发牌后 | 余牌不进入本局（4 人发 20，余 0；3 人发 15，余 5 废弃或展示） |

> **废止**旧表「A×8，K×8，Q×8，JOKER×4（共 28，发 20）」。  
> 3/5/6 人桌若需调表，另开数值票；**不得**静默改回 28 张。详见 [数值与牌堆配置](./数值与牌堆配置.md)（须跟钉到 20 张）。

### 3.4 手牌私密性

- 仅本人可见  
- UI：默认牌背；**长按/按住** 揭示；松开隐藏  
- 揭示期间触发 **隐私防窥**（系统能力）  
- 他人不可通过任何合法 UI 看到你的手牌

## 4. 核心循环

```
开局 Deal5（每人 5）
  → Designate 公布本轮宣称（K / Q / A）
  → Play：出 1～3 张（可虚张）
  → 下家：Trust（相信=续对，不揭） | Challenge（质疑=揭本手）
  → 正常揭牌：真 → 质疑者开枪；假 → 上家（被质疑者）开枪
  → 任意开枪 → CollectRedeal（收牌重发）+ 新宣称
  → 实弹出局；仅剩 1 存活 → MatchEnd
  → hand==0 → HandEmptyGate（§10.1 / 左轮 §2.6：≥3 / =2）
```

主链与 U 表 / mermaid：**只认** [左轮对局-状态机](./左轮对局-状态机.md)。

### 4.1 阶段枚举（逻辑名，供程序对齐）

| 阶段 ID | 名称 | 可执行操作 |
|---------|------|------------|
| LOBBY | 等待开局 | 配置、准备 |
| DEAL | 发牌表演（Deal5） | 自动 |
| CLAIM | 公布宣称（Designate） | 自动 + 短播报 |
| TURN | 回合决策 | 出牌 / 相信 / 质疑（条件见下） |
| PLAY_REVEAL_SELF | 自己确认出牌 | 选牌、方式、话术（手牌仍防窥） |
| TRUST_OR_CHALLENGE | 相信或质疑窗 | Trust / Challenge |
| JUDGE | 揭牌裁定 | 自动翻验 |
| SHOOT | 开枪演出 | 扣扳机 / 实弹或空膛 |
| COLLECT_REDEAL | 收牌重发 | 存活者重发 + 新宣称 |
| HAND_EMPTY_GATE | 打光门 | ≥3 / =2 分支（§10.1） |
| RECAP | 战报 | 再来、分享 |
| END | 结束（MatchEnd） | 回首页 |

> 旧 `PENALTY`（-1 命）已废；改为 `SHOOT`。旧 `RoundWin→RedealAll` 已废；任意开枪走 `COLLECT_REDEAL`，打光走 `HAND_EMPTY_GATE`。

## 5. 宣称（Claim / Designate）

### 5.1 定义

每轮开始，AI 荷官从符号集合中选一个 **本轮合法目标**，例如：

- “这一轮，出的都得是 **K**（Joker 算 K）”

### 5.2 选取规则（MVP）

- 在 `K/Q/A` 中 **均匀随机**（**Joker 不作宣称目标**）  
- 连续两轮避免同一宣称（若可能）  

### 5.3 玩家不能改宣称（MVP）

- 降低复杂度；进阶可做“加注谎”只加口气不改花色（见 §6.3）

## 6. 玩家行动详规

### 6.1 出牌（PLAY）

**合法条件**：当前阶段为 TURN，且轮到自己，且手牌 ≥1。

**必须**：

1. 选择手牌 **1～3** 张（`MAX_PLAY=3`，可虚张）  
2. 选择 **出牌方式**（见互动方案；逻辑上至少记录枚举）  
3. 将牌从手牌移入 **本手扣牌**（对他人不可见；**表现落点 = 中央 `lb_cmp_pool`**）  

**可选**：

4. 带话（模板/点名/短自定义）——**可跳过**  
5. 点名一位玩家（施压标记）——**P0**  

**出牌后**：

- 若 `hand > 0` 且非本轮第一手语境下的下家决策：进入 **Trust | Challenge**  
- 若 `hand == 0`：进 **HandEmptyGate**（§10.1），**禁止**走旧 RoundWin→RedealAll  
- 本轮第一手 **不可被质疑**（因无上家本手）；仅可出牌；下家只出牌  

手牌触摸选牌、翻面与确认条：参见 [手牌触摸出牌-交互方案](./手牌触摸出牌-交互方案.md)。  
飞出 / 落池表现数字仍可参见旧出牌扣牌文（已 SUPERSEDED 规则段）；**规则分流以左轮为准**。

### 6.2 相信 / 质疑（Trust | Challenge）

> **入口 UI（PM reject 2026-09-14）**：前台二键 = **质疑** \| **相信**；锁 `lb_str_challenge_doubt`/`believe` · `lb_btn_challenge_doubt`/`believe` · `art_btn_challenge_doubt`/`believe`；SFX=`lb_sfx_challenge_enter`/`commit`（commit 仅质疑）。**废**真/假/pass 作入口；**废**草稿文案键 commit/trust（免撞 SFX）。true/false **保留**（reveal only）。  
> **真 / 假** 只作揭牌裁定结果（谁开枪）。见 [质疑入口-状态机](./质疑入口-状态机.md) v0.2.5 / [左轮](./左轮对局-状态机.md) v1.1.3。  
> **裁定与开枪**只认本节 + [左轮对局-状态机](./左轮对局-状态机.md) §1.1。

**合法条件**：

- 轮到自己（或打光门下的下家）  
- 本轮已存在“上家本手扣牌”（池上可见）  
- 自己未出局  
- 非本轮第一手（G-Q6）  

**效果**：

1. **Trust（相信）**：入口键文案「相信」；不揭牌；轮转继续对上家该手之后的流程（下家出牌）。**禁止**相信路径进揭牌；**禁止**相信后仍不可出。  
2. **Challenge（质疑）**：入口键文案「质疑」；ack 后揭开上家 **刚刚那一手** 的全部扣牌。**禁止**质疑未揭牌（权威已接受后）。  
3. **正常揭牌判定**（Joker 除外＝Joker 永远算符合宣称）：  

| 结果 | 条件 | 开枪 |
|------|------|------|
| 宣称为真（全符合） | 全部为宣称符号或 Joker | **质疑者开枪** |
| 宣称为假（有掺假） | 存在至少 1 张 **既非宣称符号、也非 Joker** | **上家（被质疑者 / 出牌者）开枪** |

4. **任意开枪** → **CollectRedeal**（收齐牌堆、存活者重发 5 张）+ **新宣称**。  
5. 实弹 → 出局；仅剩 1 存活 → MatchEnd。  
6. **废止**「质疑成功/失败 → ±1 命」旧表。

### 6.3 加注谎（P1，可选规则开关）

- 出牌时可声明“口气等级”Normal / Raise  
- Raise：被抓时额外公开嘲讽动画（**不**改开枪公式）  
- **默认关闭**  

### 6.4 盲出（P1）

- 未揭牌状态直接确认出牌  
- 标记“盲出”，全桌可见  
- 仍遵守 1～3 张与手牌数约束

## 7. 互动系统（逻辑摘要）

> 表现与手势详规以 [互动方案](./互动方案.md) 为准。GDD 只锁 **对规则/日志的影响**。

### 7.1 桌规档位

| 档位 | 名称 | 动作对胜负 |
|------|------|------------|
| S | 社交桌（**默认**） | **无影响**，只影响信息、舆论、战报 |

- 映射为枚举写入日志  
- FaceAR 与手动轮盘 **同一枚举空间**  
- 教程必须包含 4 套“装真/装疯/带节奏/死撑”

## 10. 异常与边界规则

| 情况 | 处理 |
|------|------|
| 手牌为 0 | 见 **§10.1 HandEmptyGate**（左轮 §2.6） |
| 手牌 < 想出张数 | UI 禁止选择超出 |
| 回合超时 | AUTO_PLAY：随机出 1 张合法优先真牌；若无牌可出则按 §10.1 |
| 质疑/相信超时 | 默认按 Trust（过）处理（窗长认入口规格）；打光 =2 强制质疑除外 |
| 只剩 2 人 | 打光走 =2 强制质疑；其余规则不变 |
| 玩家强退 | 人机：转 AI 接管；联网（P2）：托管 |
| 断网 | 人机无影响 |
| 拒绝摄像头 | 手动表情，功能完整 |
| 静默局 | 关闭催促抖动、公开嘲讽音效、强弹幕（**要做**） |

### 10.1 手牌耗尽 / 打光门（HandEmptyGate · **废 RoundWin**）

> **§10.1 旧「打光=本轮胜→RoundWin→RedealAll / 仅质疑窗 / 3 命相关句」已全部废止。**  
> 现锁 **一字不改** 认 [左轮对局-状态机 §2.6](./左轮对局-状态机.md)（PM 群锁 · **Joker 除外**）：

| 存活 | 打光者 | 下家 | 开枪 |
|------|--------|------|------|
| **≥3** | 本轮安全 | 不质疑你=跳过续对上家(不揭其最后一手)；质疑你=揭最后一手 | 仅被质疑且假→打光者开枪；真→质疑者开枪；不质疑→本轮胜等他人打完→下一轮 |
| **=2** | — | 强制质疑最后一手 | 真→质疑者开枪；假→打光者开枪 |

- **任意开枪 → CollectRedeal**（收牌重发 + 新宣称）。  
- **废 RoundWin。** 打光本身 **不是** 旧「本轮胜→全员重发」触发器；只有开枪（或 ≥3 不质疑后的本轮胜等待结束切入下一轮 CollectRedeal）才收牌重发。  
- **Joker 除外**：揭验时 Joker 永远算符合宣称，不得判假。  
- **禁止**：≥3 仍强制质疑；=2 仍可跳过；打光仍走 RoundWin；未被质疑却让打光者开枪（≥3 且下家选择不质疑时）。

失败短句索引：左轮 §4（S18-1～S18-12）。

## 11. 教学模式（60 秒）

**强制脚本（已锁定，跟左轮）**：

1. **AI 先出本轮第一手**（示范出牌；本轮第一手不可质疑）  
2. **再教玩家质疑**（玩家作为下家，对 AI 本手发起质疑）

## 14. 状态机索引（**主真源 = 左轮**）

**程序与会签只认** [左轮对局-状态机](./左轮对局-状态机.md) v1.1.3：

- 主链：`Deal5→Designate→Play→Trust|Challenge→Reveal→Shoot→CollectRedeal`  
- `hand==0→HandEmptyGate`（§2.6 ≥3/=2）  
- 完整 **U 转移表**、**mermaid**、失败短句 S18-*  

GDD 逻辑阶段对照（摘要）：

```
LOBBY → DEAL(Deal5) → CLAIM(Designate) → TURN(Play)
TURN → TrustOrChallenge → (Trust → 下家 Play) | (Challenge → Reveal → Shoot → CollectRedeal)
Play ∧ hand==0 → HandEmptyGate（≥3 EmptySafe3 / =2 ForceChallenge2）
Shoot 实弹 → Eliminated；仅剩 1 → MatchEnd
CollectRedeal → Designate（多人仍存活）
```
