## 1. 游戏概述

### 1.1 品类

虚张声势 / 心理博弈（规则内核对齐大众「骗子酒吧」类：宣称花色、扣牌出、质疑翻验、**烛命淘汰**）。

### 1.2 一局体验一句话

> 你用真牌或假牌推进宣称，用表情和姿态骗人，在被质疑的翻牌瞬间决定谁熄一支烛——烛尽出局，最后幸存者胜。

### 1.3 设计支柱（3 条）

| 支柱 | 含义 | 设计推论 |
|------|------|----------|
| 信息差 | 手牌私有，表演公开 | 防窥看牌；动作全桌可见 |
| 可伪装 | 任何“心虚信号”都可演 | 禁止系统透视真假 |
| 全员热 | 非行动者也参与 | 旁观敲桌/站队/押面子 |

### 1.4 体验目标

| 指标 | 目标 |
|------|------|
| 单局时长 | 3～8 分钟（4 人对局桌） |
| 学会上手 | ≤60 秒教学可进行第一局 |
| 高潮密度 | 平均每 40～90 秒一次质疑/揭牌熄烛紧张点 |
| 演示友好 | 90 秒内可走到一次完整质疑→揭牌熄烛 |

## 2. 对局结构

### 2.1 人数

| 模式 | 人数 | MVP |
|------|------|-----|
| 标准桌 | 4 人 | ✅ 默认 |
| 小桌 | 3 人 | ✅ |
| 大桌 | 5～6 人 | P1（规则兼容，AI 与 UI 次优先） |

人不足时由 **AI 牌友** 补位（可关，但关后人数不足不能开局）。  
**MVP 形态：只人机 + 本地。**

### 2.2 胜负与淘汰（**3 烛 · 揭牌直接-1 · 废左轮**）

> **§2.2 旧「左轮 6 膛 1 实 / 真弹即死 / 开枪轮盘」与旧「打光=RoundWin→RedealAll」已全部废止。**  
> 现锁认 [对局-状态机](./对局-状态机.md) R3 / R7 / R8 / R9 / R10。

- **开局命数**：每人 **3 烛**（`lives_default=3`）。  
- **揭牌罚**：裁定后 **骗子**（假牌出牌者）或 **错质疑者**（质疑为真时）**直接熄 1 烛**（PenaltyExtinguish1）。**无**气缸、**无**真弹/空膛随机、**无**开枪轮盘。  
- **淘汰**：烛数降至 **0** → 该玩家 **出局**（幽灵旁观：可起哄/押面子，不可看他人手牌，**不发牌 / 不质疑 / 不出牌**）。  
- **整局胜**：场上 **仅剩 1 名存活者** → MatchEnd / RankSettle。  
- **结算后续**：任意 PenaltyExtinguish1 完成后 → **CollectRedeal**（收牌重发 + 新宣称；名可留，**不**绑枪）。  
- **废止**：左轮开枪结算；`lives_default=1`；真弹即死；打光 = RoundWin→RedealAll（#160/#163）。

生命主读：**烛 + 熄灭**（14a）。左轮 HUD/SFX（`art_revolver_*` / `sfx_revolver_*` / `RevolverGun`）**冻结**，不得当结算或命数主读。EmptySafe「你/上家」键可留。

### 2.3 座位与回合顺序（仍锁）

- 座位固定环形  
- 出牌按顺时针  
- 开局第一行动者：AI 荷官随机指定，或“房主左手边”  
- **新一轮宣称开始时：由上一轮揭牌罚承受者（熄烛座）的下家先出；若该座已出局，则其下家先出**  
- 本条为**正式规则**

## 3. 牌与牌堆

### 3.1 牌面定义

| 牌 | 说明 |
|----|------|
| 普通牌 | 符号：`A` / `K` / `Q` |
| 万能牌 Joker | **永远算作符合当前宣称**（Joker 除外于「假牌」判定） |

> MVP 使用 **符号牌**（非完整 52 张扑克）。  
> 宣称形如：“本轮必须出 **K**”。  
> 牌面只有：`A` `K` `Q` `JOKER` 四种。

### 3.2 为何简化

- 教学快、UI 好做、AI 好写  
- 答辩 10 秒能讲清  
- 与“骗子酒吧”精神一致，不绑死某一商业产品牌表  

### 3.3 发牌（默认 · **PM 锁**）

| 参数 | 锁定值 |
|------|--------|
| 牌堆构成 | **20 张 = 6K + 6Q + 6A + 2Joker** |
| 每人手牌 | **5 张** |
| 发牌后 | 余牌不进入本局（4 人发 20，余 0；3 人发 15，余 5 废弃或展示） |

> **废止**旧表「A×8，K×8，Q×8，JOKER×4（共 28，发 20）」。  
> 3/5/6 人桌若需调表，另开数值票；**不得**静默改回 28 张。详见 [数值与牌堆配置](./数值与牌堆配置.md)（须跟钉到 20 张）。

### 3.4 手牌私密性

- 仅本人可见  
- UI：默认牌背；**长按/按住** 揭示；松开隐藏  
- 揭示期间触发 **隐私防窥**（系统能力）  
- 他人不可通过任何合法 UI 看到你的手牌

## 4. 核心循环

```
开局 Deal5（每人 5）
  → Designate 公布本轮宣称（K / Q / A）
  → Play：出 1～3 张（可虚张）
  → 下家：Trust（相信=续对，不揭） | Challenge（质疑=揭本手）
  → 正常揭牌：真 → 质疑者熄 1 烛；假 → 上家（骗子）熄 1 烛
  → PenaltyExtinguish1 → CollectRedeal（收牌重发）+ 新宣称
  → 烛尽出局；仅剩 1 存活 → MatchEnd
  → hand==0 → HandEmptyGate（§10.1 / 对局 §2.6：≥3 / =2）
```

主链与 U 表 / mermaid：**只认** [对局-状态机](./对局-状态机.md)。

### 4.1 阶段枚举（逻辑名，供程序对齐）

| 阶段 ID | 名称 | 可执行操作 |
|---------|------|------------|
| LOBBY | 等待开局 | 配置、准备 |
| DEAL | 发牌表演（Deal5） | 自动 |
| CLAIM | 公布宣称（Designate） | 自动 + 短播报 |
| TURN | 回合决策 | 出牌 / 相信 / 质疑（条件见下） |
| PLAY_REVEAL_SELF | 自己确认出牌 | 选牌、方式、话术（手牌仍防窥） |
| TRUST_OR_CHALLENGE | 相信或质疑窗 | Trust / Challenge |
| JUDGE | 揭牌裁定 | 自动翻验 |
| PENALTY_EXTINGUISH | 揭牌罚熄烛 | 输家直接熄 1 烛 |
| COLLECT_REDEAL | 收牌重发 | 存活者重发 + 新宣称（不绑枪） |
| HAND_EMPTY_GATE | 打光门 | ≥3 / =2 分支（§10.1） |
| RECAP | 战报 | 再来、分享 |
| END | 结束（MatchEnd） | 回首页 |

> 旧 `SHOOT`（左轮开枪）已废；改为 `PENALTY_EXTINGUISH`（揭牌直接熄1）。旧 `RoundWin→RedealAll` 已废；揭牌罚后走 `COLLECT_REDEAL`，打光走 `HAND_EMPTY_GATE`。`lives_default=3`。

## 5. 宣称（Claim / Designate）

### 5.1 定义

每轮开始，AI 荷官从符号集合中选一个 **本轮合法目标**，例如：

- “这一轮，出的都得是 **K**（Joker 算 K）”

### 5.2 选取规则（MVP）

- 在 `K/Q/A` 中 **均匀随机**（**Joker 不作宣称目标**）  
- 连续两轮避免同一宣称（若可能）  

### 5.3 玩家不能改宣称（MVP）

- 降低复杂度；进阶可做“加注谎”只加口气不改花色（见 §6.3）

## 6. 玩家行动详规

### 6.1 出牌（PLAY）

**合法条件**：当前阶段为 TURN，且轮到自己，且手牌 ≥1。

**必须**：

1. 选择手牌 **1～3** 张（`MAX_PLAY=3`，可虚张）  
2. 选择 **出牌方式**（见互动方案；逻辑上至少记录枚举）  
3. 将牌从手牌移入 **本手扣牌**（对他人不可见；**表现落点 = 中央 `lb_cmp_pool`**）  

**可选**：

4. 带话（模板/点名/短自定义）——**可跳过**  
5. 点名一位玩家（施压标记）——**P0**  

**出牌后**：

- 若 `hand > 0`（**含本轮第一手**）：下家进入 **Trust | Challenge**（质疑\|相信）  
- 若 `hand == 0`：进 **HandEmptyGate**（§10.1），**禁止**走旧 RoundWin→RedealAll  
- 本轮第一手落地后 **可被质疑**（下家须过质疑\|相信）；**仅**在尚无人出牌时无可质疑靶  

手牌触摸选牌、翻面与确认条：参见 [手牌触摸出牌-交互方案](./手牌触摸出牌-交互方案.md)。  
飞出 / 落池表现数字仍可参见旧出牌扣牌文（已 SUPERSEDED 规则段）；**规则分流以对局-状态机为准**。

### 6.2 相信 / 质疑（Trust | Challenge）

> **入口 UI（仍锁）**：前台二键 = **质疑** \| **相信**；锁 `lb_str_challenge_doubt`/`believe` · `lb_btn_challenge_doubt`/`believe` · `art_btn_challenge_doubt`/`believe`；SFX=`lb_sfx_challenge_enter`/`commit`（commit 仅质疑）。**废**真/假/pass 作入口；**废**草稿文案键 commit/trust（免撞 SFX）。true/false **保留**（reveal only）。  
> **真 / 假** 只作揭牌裁定结果（谁熄烛）。见 [质疑入口-状态机](./质疑入口-状态机.md) v0.2.5 / [对局-状态机](./对局-状态机.md) v2.0.0。  
> **裁定与熄烛**只认本节 + [对局-状态机](./对局-状态机.md) §1.1。

**合法条件**：

- 轮到自己（或打光门下的下家）  
- 本轮已存在“上家本手扣牌”（池上可见）  
- 自己未出局  
- 本轮已有上家本手（G-Q6：含第一手落地）  

**效果**：

1. **Trust（相信）**：入口键文案「相信」；不揭牌；轮转继续对上家该手之后的流程（下家出牌）。**禁止**相信路径进揭牌；**禁止**相信后仍不可出。  
2. **Challenge（质疑）**：入口键文案「质疑」；ack 后揭开上家 **刚刚那一手** 的全部扣牌。**禁止**质疑未揭牌（权威已接受后）。  
3. **正常揭牌判定**（Joker 除外＝Joker 永远算符合宣称）：  

| 结果 | 条件 | 罚 |
|------|------|----|
| 宣称为真（全符合） | 全部为宣称符号或 Joker | **质疑者熄 1 烛** |
| 宣称为假（有掺假） | 存在至少 1 张 **既非宣称符号、也非 Joker** | **上家（骗子 / 出牌者）熄 1 烛** |

4. **PenaltyExtinguish1** 完成后 → **CollectRedeal**（收齐牌堆、存活者重发 5 张）+ **新宣称**。  
5. 烛尽（0）→ 出局；仅剩 1 存活 → MatchEnd。  
6. **废止**：左轮开枪 / 真弹空膛轮盘 / `lives_default=1` / 真弹即死；**现行**即「揭牌输家直接 -1 烛」（与旧「±1 命表」形似但无左轮）。

### 6.3 加注谎（P1，可选规则开关）

- 出牌时可声明“口气等级”Normal / Raise  
- Raise：被抓时额外公开嘲讽动画（**不**改开枪公式）  
- **默认关闭**  

### 6.4 盲出（P1）

- 未揭牌状态直接确认出牌  
- 标记“盲出”，全桌可见  
- 仍遵守 1～3 张与手牌数约束

## 7. 互动系统（逻辑摘要）

> 表现与手势详规以 [互动方案](./互动方案.md) 为准。GDD 只锁 **对规则/日志的影响**。

### 7.1 桌规档位

| 档位 | 名称 | 动作对胜负 |
|------|------|------------|
| S | 社交桌（**默认**） | **无影响**，只影响信息、舆论、战报 |
| C | 演技桌（可选） | 只影响时限/播报等软压力，**永不改牌真假** |

### 7.2 必须进入对局日志的事件（供战报）

- PLAY（张数、方式、是否点名、不写牌面）  
- TRUST / CHALLENGE（谁信/查谁）  
- JUDGE（真/假、假牌张数）  
- PENALTY（谁熄烛、剩余烛数）  
- ELIMINATED / MATCH_END  
- EMOTE / TABLE_ACT  

### 7.3 旁观押面子（默认开）

- 窗口：嵌在质疑对峙拍；旁观（含幽灵）选 TRUE（全真）/ FAKE（有假）  
- **关闭条件（先到先关）**：翻牌开始 **或** 满 `challenge_bet_seconds`（默认 **2s**）  
- 押对：+面子分；**押错：0**（不扣分）  
- **不改变谁开枪**  

### 7.4 表情与手势

- 映射为枚举写入日志  
- FaceAR 与手动轮盘 **同一枚举空间**  
- 教程必须包含 4 套“装真/装疯/带节奏/死撑”  
- **三连点桌 = KNOCK 强化**（同一动作 ID：`KNOCK`）

## 10. 异常与边界规则

| 情况 | 处理 |
|------|------|
| 手牌为 0 | 见 **§10.1 HandEmptyGate**（对局 §2.6） |
| 手牌 < 想出张数 | UI 禁止选择超出 |
| 回合超时 | AUTO_PLAY：随机出 1 张合法优先真牌；若无牌可出则按 §10.1 |
| 质疑/相信超时 | 默认按 Trust（过）处理（窗长认入口规格）；打光 =2 强制质疑除外 |
| 只剩 2 人 | 打光走 =2 强制质疑；其余规则不变 |
| 玩家强退 | 人机：转 AI 接管；联网（P2）：托管 |
| 断网 | 人机无影响 |
| 拒绝摄像头 | 手动表情，功能完整 |
| 静默局 | 关闭催促抖动、公开嘲讽音效、强弹幕（**要做**） |

### 10.1 手牌耗尽 / 打光门（HandEmptyGate · **废 RoundWin · 废左轮开枪**）

> **§10.1 分支条件（≥3/=2）与入口仍锁；结算由开枪改为熄烛。**  
> 认 [对局-状态机 §2.6](./对局-状态机.md)（PM 群锁 · **Joker 除外**）：

| 存活 | 打光者 | 下家 | 揭牌结算 |
|------|--------|------|----------|
| **≥3** | 本轮安全 | 不质疑你=跳过续对上家(不揭其最后一手)；质疑你=揭最后一手 | 仅被质疑且假→打光者熄1烛；真→质疑者熄1烛；不质疑→本轮胜等他人打完→下一轮 |
| **=2** | — | 强制质疑最后一手 | 真→质疑者熄1烛；假→打光者熄1烛 |

- **PenaltyExtinguish1 → CollectRedeal**（收牌重发 + 新宣称）。  
- **废 RoundWin。废左轮开枪。** 打光本身 **不是** 旧「本轮胜→全员重发」触发器；只有揭牌罚（或 ≥3 不质疑后的本轮胜等待结束切入下一轮 CollectRedeal）才收牌重发。  
- **Joker 除外**：揭验时 Joker 永远算符合宣称，不得判假。  
- **禁止**：≥3 仍强制质疑；=2 仍可跳过；打光仍走 RoundWin；未被质疑却让打光者熄烛；仍走左轮开枪。

失败短句索引：对局 §4（S18-1～S18-19）。
