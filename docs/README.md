## 审核怎么提意见

请在对应文档末尾「审核记录」表追加一行，或写入 `docs/审核意见.md`：

```
| 日期 | 文档 | 问题位置 | 意见 | 提议修改 | 提出人 |
```

**改文档原则**：先锁 GDD 规则与 MVP 边界，再改产品和特性，最后改答辩材料。  
**v0.2**：规则已锁定；变更须走制作人审核（见工作流文档）。日常 PR 合入 `develop`，合 `main` 仅负责人。
