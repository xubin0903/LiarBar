# 《谎馆》项目一页纸

| 项 | 内容 |
|----|------|
| 项目名 | 谎馆（英文工作名：LiarBar） |
| 赛道 | 华为高校创新赛 · 应用创新 |
| 形态 | HarmonyOS 原生应用（手机优先） |
| 品类 | 轻量社交博弈 · 虚张声势（骗子酒吧规则内核） |
| 文档版本 | v0.1 Demo · 第1批 |
| 状态 | 待人工审核 |

---

## 1. 一句话定位

> 不用真人主持、手牌防偷窥、熄屏也能盯回合的鸿蒙「骗子酒吧」——用动作演、用舆论压、用 AI 荷官控场。

---

## 2. 解决什么问题

| 痛点 | 线下/现有线上 | 谎馆 |
|------|----------------|------|
| 缺人当庄 | 要有人控流程 | AI 荷官全自动 |
| 凑不齐人 | 开不起局 | AI 牌友补位 |
| 手牌被瞄 | 社交社死/作弊感 | 隐私防窥 + 长按揭牌 |
| 回合靠吼 | 节奏乱 | 实况窗倒计时 + 群体催促 |
| 线上只剩按钮 | 没“演”的空间 | 出牌姿态 / 表情 / 点名 / 旁观站队 |

---

## 3. 目标用户

- **主**：高校学生（寝室、社团、饭局 3～6 人）
- **次**：朋友小局、线下聚会用手机辅助庄家
- **场景**：课间、宿舍夜谈、聚餐等待（单局 3～8 分钟）

---

## 4. 核心卖点（答辩可直接念）

1. **AI 荷官**：发牌、宣称、结算、播报，规则引擎裁判，不靠 LLM 判胜负  
2. **系统级防窥手牌**：看牌瞬间防偷窥，贴合博弈本质  
3. **对局互动不只按钮**：出牌包（姿态+话术+点名）+ 质疑仪式 + 旁观押面子  
4. **鸿蒙自然融合**：防窥、实况窗、互动卡片、智能填充、沉浸光感、智感握姿（可选）  
5. **小而美**：单机/人机可完整体验，不依赖多设备与 3D  

---

## 5. 明确不做（防范围膨胀）

| 不做 | 原因 |
|------|------|
| 应用接续 / 全场景跨端主流程 | 开发与设备成本高，与核心玩法弱相关 |
| 3D 场景 / 3DGS / 空间建模 | 过重，非本局必要 |
| 碰一碰组队作为必选项 | 可后置；演示不依赖 |
| 复杂技能板、成长数值养成 | 破坏骗子酒吧纯心理内核 |
| LLM 直接判定牌真假/胜负 | 不可控、不公平 |
| 真金赌博 / 抽奖付费赌 | 合规风险 |
| 首版强制语音房 | 技术与审核成本；文字+表情优先 |

---

## 6. 成功标准（MVP）

- [ ] 1 真人 + 3 AI 可完整打完一局并出战报  
- [ ] 看牌防窥可演示（侧拍对比）  
- [ ] 实况窗显示回合/倒计时  
- [ ] 出牌方式 ≥3、质疑三拍、旁观敲桌/画✓✗ 可用  
- [ ] PPT 可勾选 ≥3 个鸿蒙特性 + AI 融合说明  
- [ ] 3 分钟演示脚本可稳定跑通  

---

## 7. 关键假设（审核时重点打）

1. 默认 **社交桌**：动作/表情只影响信息与舆论，不改牌真假  
2. 手机单端优先；联网好友房可第二阶段  
3. FaceAR 为增强，**手动表情轮盘**必须可完全替代  
4. 单局目标时长 3～8 分钟，适合答辩演示半局
