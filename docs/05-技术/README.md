## 1. 本目录解决什么问题

把已锁定的规则翻译成程序能落地的三件事：

1. **工程怎么起**：DevEco + ArkTS 目录、配置表、**引用 UI 已锁 `lb_` id**、分支（见 `01`）  
2. **对局怎么转**：阶段枚举、转移表、数据字典（见 `02`，展开 GDD §14）  
3. **课设演什么鸿蒙能力**：≥3 个可演示特性、验收一句、不做边界（见 `03`）

**明确不做（本批 + MVP 工程）**：商业化、反作弊、联网房、LLM 判胜负、全场景接续主流程、3D。
