## 2. 四座分锚表（线框真源 · 禁止一套坐标复用）

头像位认 [11 §2.2](./11-局内横屏与自适应布局.md)。槌锚 **另写**，不抄 11 的座位像素，也不抄 self 公式去套 p1/p2/p3。

**原则：** 槌落在 **该座头像旁、朝桌可读的空白带**。旁缝 8～16vp 仅参考缝宽；**主闸是失败句**（§8），不是缝宽本身。

```
        [p2 槌] 头像左侧旁空（离脸 · 禁盖脸）
   [p3 槌]                              [p1 槌]
   头像右侧空（朝桌心）                    头像左侧空（朝桌心）
              荷官 + lb_cmp_pool
   [self 槌] 贴底座金框头像旁（底带内 · 禁飘桌心）
              lb_cmp_hand
```

| 座 | 角色 | 头像控件 | 头像位（认 11） | 槌常驻锚（本线 · 各写各的） | 砸 | 硬禁 |
|----|------|----------|----------------|----------------------------|----|------|
| **p3** | 杠精 | `lb_cmp_seat_p3` | **左边竖直中**（上家；不贴顶） | 头像 **右侧** 空（**朝桌心**）。落在左座头像与桌心之间的空白带。**不**用 self / p1 公式 | 就在 p3 空白带就地抬砸→回搁 | 禁离开头像—桌心空白带。禁朝桌心收到 `lb_cmp_pool` 里。禁压 `lb_cmp_life_seat_p3` / 头像本体 / 手牌行 |
| **p1** | 怂货 | `lb_cmp_seat_p1` | **右边竖直中**（下家；不贴顶） | 头像 **左侧** 空（**朝桌心**）。落在右座头像与桌心之间的空白带。**必须看得见**。**不**抄 p3 / self 公式 | 就在 p1 空白带就地抬砸→回搁 | 禁离开头像—桌心空白带（看不见 = **右座无槌**）。禁朝桌心收到 `lb_cmp_pool` 里。禁压 `lb_cmp_life_seat_p1` / 头像本体 / 手牌行 |
| **p2** | 老千 | `lb_cmp_seat_p2` | **上沿中**（对家；顶栏下） | 头像**左侧旁空 / 侧空**（§2.2）。槌右缘在 **44vp** 脸槽左外缘外 **8～16vp**，水平偏左。**勿**叠脸 bbox | 就在 p2 左空就地抬砸→回搁 | **禁盖脸**：槌心 / 槌体贴进脸框 = **对家槌盖脸**（S19-10）。仍禁下移进 `lb_cmp_pool` / 荷官 bust / 顶栏主读 / `lb_cmp_life_seat_p2` |
| **self** | 发发发 | `lb_cmp_seat_self`（`selfDock` 金框内 **40vp** 脸槽） | 底带 **左侧独立槽**；与 `lb_cmp_hand` 不同轴、不压牌 | **贴底座头像旁**（§2.2）。金框内 / 贴框：脸右旁或脸上沿旁缝。须一眼仍是「头像旁」 | 就在该头像旁短弧抬→砸→回搁。砸点=该放置点附近空白 | **禁飘桌心**：上漂荷官 / `lb_cmp_pool` / 桌心安全带、贴屏左缘、金框外左缘当旁空 = **自机槌飘桌心**（S19-10）。压 `lb_cmp_hand` = S19-12 |

| 总闸 | 锁 |
|------|-----|
| 常驻 | 四座进桌即各搁一把；始终可见搁置姿 |
| 复用 | **禁止**一套 `x,y` / 一套 `INWARD_PCT` 朝池插值四座共用。**禁止**抄左座公式套右座 |
| 废主锚 | 「二键簇上沿外 8～16vp」/「环–手带之间」不再作任何一座主锚 |
| 空白带 | 槌只落 **该座头像旁、朝桌可读空带**。左/右座仍=头像与桌心之间。v0.2.1 对 TOP/SELF 的空「旁空」读法以本版为准 |
| 层 | 仍 `lb_cmp_choice_act`；HitTest None；全员同轨 |

**不过（挂点口径 · 交叉策划键 · 不另造 `lb_str_*`）：**  
**对家槌盖脸** — p2 槌心 / 槌体贴进老千脸 bbox（含现帧 DX=−56 切进 44vp 脸槽）。交叉 **S19-10** `lb_str_hammer_not_in_blank`。  
**自机槌飘桌心** — self 槌离开底座金框头像旁（上漂荷官 / 池心安全带 / 贴屏左缘 / 金框外当旁空）。交叉 **S19-10**。压手牌另交叉 **S19-12** `lb_str_hammer_presses_cards`。  
**右座无槌** — p1 头像左侧空（朝桌心）看不见常驻槌（含抄左座公式飞走）。可交叉 S19-2 / S19-10。  
**三把全偏左** — 三座（或四座）槌都挤在画面左侧 / 都抄左座落点；右座空白带空着。  
**贴屏幕外缘** — 槌贴屏缘（含自机把屏左缘当旁空）。可交叉策划已锁 **S19-11** `lb_str_hammer_on_screen_edge`（本票非主闸）。  
锚压头像本体 → S19-5 / TOP 盖脸走 S19-10。锚进手牌行 / 常驻压牌 → S19-5 / **S19-7** / **S19-12**。砸飞出放置点 / 砸点贴牌心或池心 → **S19-9**。

## 2.2 TOP / SELF 数字锚（v0.2.2 · 对照真机截图 · 主闸=失败句）

数字是**建议区间**。过关看失败句，不看缝宽是否刚好 12vp。坐标默认 = 控件左上（与现帧 `choiceActPosOf` 同构）。显示边长认 §2.1；client 现帧 **112** 在 96～120 窗内，**本版不改尺**。

### p2 对家（老千 · 上沿中）

真机：槌已在头像左侧一带，但槌体贴进脸——**左侧对、离脸不对**。

| 项 | 锁 |
|----|-----|
| 脸槽 | 圆裁 **44vp**（client `seatAvatar` TOP / `art_ai_shark_idle`） |
| 锚 | 头像**左侧旁空**（或明确「侧空」）。水平偏左，留在上沿带 |
| 缝 | 槌**右缘** ≥ 脸**左外缘**外 **8～16vp**（主读 8～12） |
| 建议 DX | 相对**脸槽**左上：`−(显示边长 + 8～16)`。client 112 → **−120～−128**（与右座 `origin − MALLET − 缝` 同构） |

| **禁** | 槌心或槌体贴进脸 bbox。盖脸 = 不过。**勿**把「在头像左侧一带」当成已离脸 |

### self 自机（发发发 · 底带左槽）

真机：槌离开金框圆脸，飘在屏左 / 框外上空，读成荷官侧道具——**不是头像旁**。

## 3. 相信 = 槌不动

| 项 | 锁 |
|----|-----|
| 姿 | 该座常驻槌保持 **平放搁置**，头像旁可见 |
| 动 | **不动**。禁任何 rest / 搁置位移动画。**废「相信也播搁置动画」** |
| SFX | 可轻 `lb_sfx_hammer_rest` 或静默；禁强制 `hammer_hit` / `challenge_commit` |
| 正式 ACK | 相信座 **保持静置可见即可**（不播锤动画） |
| 调试·相信锤 | 确认本地座静置（零位移）；不另播搁动画 |
| 美术 | `art_fx_mallet` 搁姿（一眼木槌；暖棕木+铜箍） |

## 4. 质疑 = 就地砸

| 项 | 锁 |
|----|-----|
| 位 | 该座 **常驻槌已在** §2 该座放置点 |
| 轨迹 | **就地**抬起→砸下（短位移）→**回搁置**。落点仍在 **本座空白带** |
| **禁** | 飞牌心 / 飞 `lb_cmp_pool` 池心；从桌心/键簇另起飞砸；砸完漂到别座；抬砸后不回搁 |
| 主读定格 | 砸落后可读 **0.8～1.2s** 再回搁（HOLD=1000 已在窗内） |
| 收 | Reveal 起势前须已回搁（不得拖进 18 `DRAW_TO_FLIP`） |
| SFX | `lb_sfx_hammer_hit`（敲木 ≈80～120ms；禁 beep / flip / launch / land / enter / commit / reveal_* 冒充） |
| 美术 | `art_fx_mallet_up` → `art_fx_mallet_hit`（抬砸）；回 `art_fx_mallet` |
| 尺 | 抬砸帧与常驻 **同画幅**（§2.1）；禁砸时缩回 72 |

**不过：** 无抬砸 = **质疑无锤砸**（S19-1）。砸位移落到牌心/池心 = **砸点贴牌心**（S19-9）。
