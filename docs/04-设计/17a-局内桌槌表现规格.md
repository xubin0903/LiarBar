## 0. 写死 / 不动

| 锁 | 本线 |
|----|------|
| 常驻 | 进桌后 **每座** 头像旁空白带 **始终可见** 一把搁置木槌。禁用时才出现 |
| 锚 | **self / p1 / p2 / p3 各写各的**（§2）。贴该座头像外缘旁空白，**不进头像本体** |
| 质疑 | 该座常驻槌在 **本座放置点** 就地抬起→砸下（短位移）→**回搁置**。禁飞牌心/池心；禁从桌心/键簇另起飞砸 |
| 相信 | **槌不动**。保持头像旁搁置可见。**废**相信播搁置 / rest 动画 |
| 禁区 | `lb_cmp_hand` 手牌行 / `lb_cmp_pool` / 烛 `lb_cmp_life_*`。自机勿压手牌；AI 勿贴牌堆 |
| 命名 | 对外 **桌槌/酒槌**；资源 id `mallet` / `hammer` 均可；文案 **禁「法槌」** |
| 全员同轨（F2） | 正式 **ACK** 后全员见该行动座锤（自机=AI 同轨）。质疑座播砸；相信座保持静置可见即可 |
| 调试 | 立刻只播 **本地玩家座位**；质疑=抬砸；相信=确认静置（零位移）；**零业务** |
| 左上荷官句 | = 规则播报，不抢锤主读。无徽只改左上字 = 不过（S19-1 / S19-2） |
| 中顶（R6） | **只** `lb_txt_timer`。锤不占中顶 |
| 开牌 | `DRAW_TO_FLIP=1000` / `REVEAL_HOLD=3000` **不动**。Reveal 起势前砸拍须已回搁 |
| 布局 | `HAND_RING_GAP=24%` / 禁抬 `padB` **不动** |
| 入口 | 身前二键 / 超时=相信 / 质疑≠相信 **一字不改**（认 17） |

## 2. 四座分锚表（线框真源 · 禁止一套坐标复用）

头像位认 [11 §2.2](./11-局内横屏与自适应布局.md)。槌锚 **另写**，不抄 11 的座位像素，也不抄 self 公式去套 p1/p2/p3。

旁缝 **8～16vp** 仅参考（头像外缘外旁缝）；**主闸是空白带**。

```
        [p2 槌] 头像旁空白（上沿中 · 不朝下贴池）
   [p3 槌]                              [p1 槌]
   左边竖直中 · 外侧/下侧空白            右边竖直中 · 外侧/下侧空白
              荷官 + lb_cmp_pool
   [self 槌] 底带左槽头像旁空白 · 不进手牌行
              lb_cmp_hand
```

| 座 | 头像控件 | 头像位（认 11） | 槌常驻锚（本线 · 各写各的） | 砸 | 硬禁 |
|----|----------|----------------|----------------------------|----|------|
| **self** | `lb_cmp_seat_self`（`selfDock`） | 底带 **左侧独立槽**；与 `lb_cmp_hand` 不同轴、不压牌 | 自机头像 **外缘旁空白**（建议头像 **右侧或上侧** 旁缝，仍在底带左槽族）。贴头像外缘，不进头像本体 | 就在该空白带短弧抬→砸→回搁。砸点=该放置点附近空白 | **自机勿压手牌**：禁进 `lb_cmp_hand` / 确认条 / `lb_cmp_life_self` / 头像本体。禁飞向池心 |
| **p1** | `lb_cmp_seat_p1` | **右边竖直中**（下家 / 怂货；不贴顶） | p1 头像 **外缘旁空白**（建议头像 **右侧外侧或下侧** 旁缝，贴边空白带）。**不**用 self 的 Bottom / `SELF_SIDE_VP` | 就在 p1 空白带就地抬砸→回搁 | **AI 勿贴牌堆**：禁朝桌心 / `lb_cmp_pool` 内收。禁压 `lb_cmp_life_seat_p1` / 头像本体 / 手牌行 |
| **p2** | `lb_cmp_seat_p2` | **上沿中**（对家 / 老千；顶栏下） | p2 头像 **外缘旁空白**（建议头像 **左侧或右侧** 水平旁缝，留在上沿带）。**不**朝下插向池/荷官 | 就在 p2 空白带就地抬砸→回搁 | **AI 勿贴牌堆**：禁砸点下移进 `lb_cmp_pool` / 荷官 bust。禁压顶栏主读 / `lb_cmp_life_seat_p2` / 头像本体 |
| **p3** | `lb_cmp_seat_p3` | **左边竖直中**（上家 / 杠精；不贴顶） | p3 头像 **外缘旁空白**（建议头像 **左侧外侧或下侧** 旁缝，贴边空白带）。**不**镜像抄 p1 的右缘公式，也不抄 self | 就在 p3 空白带就地抬砸→回搁 | **AI 勿贴牌堆**：禁朝桌心 / `lb_cmp_pool` 内收。禁压 `lb_cmp_life_seat_p3` / 头像本体 / 手牌行 |

| 总闸 | 锁 |
|------|-----|
| 常驻 | 四座进桌即各搁一把；始终可见搁置姿 |
| 复用 | **禁止**一套 `x,y` / 一套 `INWARD_PCT` 朝池插值四座共用 |
| 废主锚 | 「二键簇上沿外 8～16vp」/「环–手带之间」不再作任何一座主锚 |
| 层 | 仍 `lb_cmp_choice_act`；HitTest None；全员同轨 |

**不过：** 锚压头像本体 → S19-5。锚进手牌行 / 常驻压牌 → S19-5 / **S19-7**。砸飞出放置点 / 砸点贴牌心或池心 → **S19-9**。

## 3. 相信 = 槌不动

| 项 | 锁 |
|----|-----|
| 姿 | 该座常驻槌保持 **平放搁置**，头像旁可见 |
| 动 | **不动**。禁任何 rest / 搁置位移动画。**废「相信也播搁置动画」** |
| SFX | 可轻 `lb_sfx_hammer_rest` 或静默；禁强制 `hammer_hit` / `challenge_commit` |
| 正式 ACK | 相信座 **保持静置可见即可**（不播锤动画） |
| 调试·相信锤 | 确认本地座静置（零位移）；不另播搁动画 |
| 美术 | `art_fx_mallet` 搁姿（一眼木槌；暖棕木+铜箍） |

**不过：** 该座头像旁无搁置槌 = **相信无常驻锤**（S19-2）。相信路径仍播 rest/位移 = **相信还在动**（S19-8）。抬砸与搁置难辨 = **砸与搁不可辨**（S19-4）。

## 4. 质疑 = 就地砸

| 项 | 锁 |
|----|-----|
| 位 | 该座 **常驻槌已在** §2 该座放置点 |
| 轨迹 | **就地**抬起→砸下（短位移）→**回搁置**。落点仍在 **本座空白带** |
| **禁** | 飞牌心 / 飞 `lb_cmp_pool` 池心；从桌心/键簇另起飞砸；砸完漂到别座；抬砸后不回搁 |
| 主读定格 | 砸落后可读 **0.8～1.2s** 再回搁（HOLD=1000 已在窗内） |
| 收 | Reveal 起势前须已回搁（不得拖进 18 `DRAW_TO_FLIP`） |
| SFX | `lb_sfx_hammer_hit`（敲木 ≈80～120ms；禁 beep / flip / launch / land / enter / commit / reveal_* 冒充） |
| 美术 | `art_fx_mallet_up` → `art_fx_mallet_hit`（抬砸）；回 `art_fx_mallet` |

**不过：** 无抬砸 = **质疑无锤砸**（S19-1）。砸位移落到牌心/池心 = **砸点贴牌心**（S19-9）。

## 5. 时序（挂 17 / 18 · 不另造 phase）

```
进桌 → 四座常驻槌已在各自 §2 空白带（搁置姿）
按下质疑|相信 → 本地键反馈 ≤120ms（认 17；本层不改热区）
正式 ACK：
  质疑座 → 就地砸 → 回搁 → 18 RevealDraw（1000 不动）
  相信座 → 保持静置可见（不播锤动画）→ 续出
调试：立刻本地座（质疑=抬砸；相信=确认静置）→ 零业务
```
