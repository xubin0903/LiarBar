## 0. 写死 / 不动

| 锁 | 本线 |
|----|------|
| 质疑 | 该座木槌 **抬起→砸下** = 叫破。禁同锤仅换色；禁动人模骨骼 / 换座贴图 |
| 相信 | **同槌平放搁置** 键旁/座旁（静止或极轻一顿）= 放过。与砸态 **落点分槽**，一眼可辨 |
| 命名 | 对外 **桌槌/酒槌**；资源 id 用 `mallet` / `hammer` 均可；文案 **禁「法槌」** |
| 全员同轨（F2） | 正式路径：权威 **Commit / Trust ACK** 后 **全员**播该行动座锤（自机=AI 同轨）。禁锤仅行动座私有层 |
| 调试 | 立刻播 **本地玩家座位**；**零业务**（不揭牌、不扣烛、不要求轮到你） |
| 左上荷官句 | = **规则播报**，不抢锤主读。无徽只改左上字 = **不过**（对表 S19-1 / S19-2） |
| 中顶（R6） | **只**倒计时 `lb_txt_timer`。锤 **不**占中顶 |
| 飞词 | `lb_str_choice_doubt_call`=「不信！揭开！」/ `lb_str_choice_believe_call`=「过。下一家。」· **P0 可后置**；若做 **禁挡池** |
| 开牌 | `DRAW_TO_FLIP=1000` / `REVEAL_HOLD=3000` **不动**。Reveal 起势前锤须收 / 淡出 |
| 布局 | `HAND_RING_GAP=24%` / 禁抬 `padB` **不动** |
| 入口 | 身前二键 / 超时=相信 / 质疑≠相信 **一字不改**（认 17） |

## 1. 层序（`lb_cmp_choice_act`）

| 项 | 锁 |
|----|-----|
| id | **`lb_cmp_choice_act`** |
| 家 | **全员桌面层**（table-wide shared overlay；**不是**行动座私有层） |
| HitTest | **`HitTestBehavior.None`**（可短暂盖手牌行/确认条的**字**，**不挡点**） |
| z | **池叠 `lb_cmp_pool` 之上**；人模贴图之上（贴图本身零改）；**不得**压过顶栏主读（宣称 / 法官句 / `lb_txt_timer`） |
| 正式路径 | **Commit / Trust ACK** 后全员播该行动座锤 |
| 调试路径 | **立刻**播本地座；跳过权威与业务 |

```
底  桌布 / 座框 / 人模静态贴图（零改）
    lb_cmp_pool（本手堆）
    lb_cmp_choice_act（锤 · HitTest None · 全员层）
    手牌行 / 确认条（可短暂盖锤字；锤不挡其点）
    lb_cmp_challenge_entry（身前二键 · 可点）
    顶栏：claim / judge / dealerLine（左上）+ lb_txt_timer（中顶专席）
调  lb_btn_debug_open → lb_cmp_debug_life（仅 DebugBuild）
```

**禁：** 锤压 `lb_cmp_pool` / 手牌主行 / 烛（`lb_cmp_life_*`）= **锤挡池或手**（S19-5）。

## 2. 质疑 = 砸

| 项 | 锁 |
|----|-----|
| 锚 | **行动座身前**。自机：环–手带之间、入口二键簇 **上沿外 8～16vp**。侧家 / 对家：**镜像 seat 锚**（该座身前安全区，不抄自机 Bottom 像素） |
| 轨迹 | **短弧抬→砸**；落点在该座安全区内 |
| 主读定格 | 砸落后可读 **0.8～1.2s**，再收 / 淡出 |
| 收 | **Reveal 起势前须收**（不得拖进 18 `DRAW_TO_FLIP`） |
| SFX | `lb_sfx_hammer_hit`（敲木 ≈80～120ms；禁 beep；禁 flip / launch / land / enter / commit / reveal_* 冒充） |
| 触感 | 短震可叠（认策划；静默局关） |
| 美术 | `art_fx_mallet` **2～3 帧抬砸** |

**不过：** 点质疑（或调试·质疑锤）后无抬砸，仅左上字变 / 无徽 = **质疑无锤砸**（S19-1 `lb_str_challenge_no_act`）。

---

## 3. 相信 = 搁

| 项 | 锁 |
|----|-----|
| 姿 | **同槌平放搁置**（可同图旋转落点；**禁**同姿仅换色） |
| 槽 | 键簇旁 **外侧分槽**（与砸态落点 **分槽**，一眼可辨） |
| 自机 | **BottomEnd / 键旁**（仍在身前族，不挡二键热区） |
| 侧 / 对家 | **seat 角**（该座安全区外侧，不进池 / 手 / 烛） |
| 动 | **静止或极轻一顿** |
| 主读 | 搁住可读后收 / 淡出；续出前不得挡下家确认条点 |
| SFX | `lb_sfx_hammer_rest`（轻顿或静默；禁强制 `lb_sfx_challenge_commit` / `hammer_hit`） |
| 美术 | `art_fx_mallet` **搁姿**（可同图旋转） |

**不过：** 点相信（或调试·相信锤）后无搁置态 = **相信无锤搁**（S19-2 `lb_str_believe_no_act`）。两态同姿仅换色 / 落点不分槽 = **砸与搁不可辨**（S19-4 `lb_str_choice_act_same_pose`）。

## 4. 时序（挂 17 / 18 · 不另造 phase）

```
按下质疑|相信 → 本地键反馈 ≤120ms（认 17 入口；本层不改热区）
正式：权威 Commit / Trust ACK → 全员 lb_cmp_choice_act 播该座锤
  质疑砸 → 收锤 → 18 RevealDraw（DRAW_TO_FLIP=1000 不动）
  相信搁 → 收锤 → 续出（不揭）
调试：点调试锤 → 立刻本地座锤 → 零业务
```

| 拍 | 锤 |
|----|----|
| 入口未 ACK | **不**播正式锤（本地键反馈 ≠ 锤主读） |
| ACK 后 | 全员播 |
| Reveal 起势 | 锤已收 / 淡出 |
| 调试 | 可在任意局内拍立刻播本地座；**不得**因此进 18 / 熄烛 / 改轮转 |

## 5. 调试二键（与生命调试同族）

挂现有局内调试面板，与 `lb_btn_debug_open` / `lb_cmp_debug_life` **同族**。**不**另开第五主屏，**不**桌面叠字条。

| id | 类型 | 文案键 | 可见字 |
|----|------|--------|--------|
| `lb_btn_debug_hammer_doubt` | 按钮 | `lb_str_debug_hammer_doubt` | **调试·质疑锤** |
| `lb_btn_debug_hammer_believe` | 按钮 | `lb_str_debug_hammer_believe` | **调试·相信锤** |

| 锁 | 说明 |
|----|------|
| 作用 | **只**触发 **本地玩家座位** 锤表现（砸 / 搁各走正式同一套视觉 + SFX） |
| 零业务 | **不**揭牌、**不**扣烛、**不**要求轮到你、**不**发 Commit/Trust |
| 正式包 | `DebugBuild` **隐入口=零入口**（与 `lifeDecShown` / 14b R-LIFE-5 同闸）。release 看见 = **正式包露出调试**（认 14b，不另造 key） |
| 豁免 | 调试本地锤 **可豁免**「全员可见」（S19-3 正式路径才打 **锤仅自己见**） |

**不过：** 点调试锤却揭牌 / 扣烛 / 改轮转 = **调试锤走了业务**（S19-6 `lb_str_debug_hammer_has_logic`）。
