## 3. 相信 = 静置

| 项 | 锁 |
|----|-----|
| 姿 | **同槌平放搁置**（可同图旋转；**禁**同姿仅换色） |
| 位 | 同槌在该座锚点 **静置**（搁在该放置点；**不**另开键簇外侧分槽当主位） |
| 动 | **静止或极轻一顿**；**禁长距位移** |
| 主读 | 搁住可读后收 / 淡出；续出前不得挡下家确认条点 |
| SFX | `lb_sfx_hammer_rest`（轻顿或静默；禁强制 `lb_sfx_challenge_commit` / `hammer_hit`） |
| 美术 | `art_fx_mallet` **搁姿**（可同图旋转） |

**不过：** 点相信（或调试·相信锤）后无搁置态 = **相信无锤搁**（S19-2 `lb_str_believe_no_act`）。两态同姿仅换色 = **砸与搁不可辨**（S19-4 `lb_str_choice_act_same_pose`）。**同锚不构成不可辨**（静置 vs 就地砸须姿/动可辨）。

---

## 4. 质疑 = 就地砸

| 项 | 锁 |
|----|-----|
| 位 | 槌 **出现在该放置点**（与相信同一锚安全区） |
| 轨迹 | **就地抬砸**：短弧抬→砸；落点仍在 **同一锚安全区** |
| **禁** | 从桌心 / 池心 / 键簇 **另起飞砸**；砸完再漂到别处；长距飞砸轨迹 |
| 主读定格 | 砸落后可读 **0.8～1.2s**，再收 / 淡出（client `HOLD_MS=1000` 已在窗内） |
| 收 | **Reveal 起势前须收**（不得拖进 18 `DRAW_TO_FLIP`） |
| SFX | `lb_sfx_hammer_hit`（敲木 ≈80～120ms；禁 beep；禁 flip / launch / land / enter / commit / reveal_* 冒充） |
| 触感 | 短震可叠（认策划；静默局关） |
| 美术 | `art_fx_mallet` **2～3 帧抬砸** |

**不过：** 点质疑（或调试·质疑锤）后无抬砸，仅左上字变 / 无徽 = **质疑无锤砸**（S19-1 `lb_str_challenge_no_act`）。砸飞出放置点 = **锤挡池或手**（S19-5 `lb_str_choice_act_blocks`）。

## 5. 时序（挂 17 / 18 · 不另造 phase）

```
按下质疑|相信 → 本地键反馈 ≤120ms（认 17 入口；本层不改热区）
正式：权威 Commit / Trust ACK → 全员 lb_cmp_choice_act 播该座锤
  质疑就地砸 → 收锤 → 18 RevealDraw（DRAW_TO_FLIP=1000 不动）
  相信静置 → 收锤 → 续出（不揭）
调试：点调试锤 → 立刻本地座锤 → 零业务
```

| 拍 | 锤 |
|----|----|
| 入口未 ACK | **不**播正式锤（本地键反馈 ≠ 锤主读） |
| ACK 后 | 全员播 |
| Reveal 起势 | 锤已收 / 淡出 |
| 调试 | 可在任意局内拍立刻播本地座；**不得**因此进 18 / 熄烛 / 改轮转 |
