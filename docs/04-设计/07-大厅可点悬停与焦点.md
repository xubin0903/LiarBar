#### 实现建议（PM「1 帧」· **不是**验收门）

鸿蒙落地时，**首帧**即可把描边 / 高光 opacity 切到目标（或 `animateTo` **≤16ms**），再可选 80～120ms EaseOut 收到位。这样手感更「可点」，且 **80～120ms 内必可见**，与 R2 测试表不冲突。

| 层 | 口径 | 测试怎么勾 |
|----|------|------------|
| **验收** | R2：**80～120ms 内**铜边或高光已能看见 | 只勾 [06 R2a–R2c](./06-开场大厅v3-打回加严.md)。未在 80～120ms 内亮 = 不过 |
| **实现建议** | 首帧瞬切描边 / opacity，或 ≤16ms 到位，再可选 EaseOut | **不另开验收句**。未做瞬切、但 80～120ms 内已亮 = **仍过 R2** |

禁止写成「1 帧严于并覆盖 R2」。300ms+ 才亮仍失败（R2 原禁）。

## 1. 三态优先级（所有本表控件）

| 优先级 | 态 | 谁触发 | 视觉 | 音频 |
|--------|-----|--------|------|------|
| 最高 | **pressed** | 指针按下 / 手指 `TouchType.Down` | 沿用 #27 §E 的 scale；盖过 hover | CTA / peek 仍走 `lb_sfx_cta_tap`（静默关） |
| 中 | **hover 或 focus** | 鼠标进入 **或** 键盘 / TV / 无障碍焦点（R2：二者都算） | **铜边或高光闪**（R2）；示意「可点」 | **无**。悬停出 `sfx_cta_tap` = R2 不过 |
| 低 | **idle** | 离开且失焦 | 回 #27 §F.2 稳态（主 CTA 微光；peek / 设置卡不动） | — |

重叠规则：

1. **pressed > hover/focus > idle 微光**。按下时不要叠出「悬停 × 按下」。scale **一律相对 idle 基准 1.0**。  
2. **悬停主信号是铜边 / 高光，不是再放大。** R2 / H2：只用按钮 `scale` 或按压 `0.96` 冒充悬停 = 不过。hover / focus 全程 **≤1.01**。  
3. 主 CTA 进入 hover / focus 时：**压过或暂停** v3 §3.4 稳态微光。悬停高光 Δ 须 **≥0.15**（R2），不能和微光糊成同一种呼吸。  
4. **到达 / 离开验收抄 R2：80～120ms。** 实现可首帧瞬切描边 / opacity（或 ≤16ms）再可选 EaseOut；**验收仍只认 80～120ms 内可见**。禁止 300ms+。  
5. 静默局（`lb_tog_silent == on`）：**视觉仍播**；悬停 **不**调 `lb_sfx_cta_tap`；按下亦关击打音与强震（R2c / #27）。

## 2. `lb_btn_quickstart`（主 CTA · R2a）

对照 [06 §3.2](./06-开场大厅v3-打回加严.md) + #27 §E / §F.2。热区高 ≥56vp；独立于设置卡（03 已锁）。

| 态 | 视觉 | 时长 | 音频 | 禁止 |
|----|------|------|------|------|
| hover | **铜边或高光**（R2）：`tavern_brass` `#C4A46A` 或 `tavern_accent` `#F0C14B` 描边 / 外发光；**或** 高光层相对常态 **Δ ≥ 0.15**。若叠 scale：**≤1.01**，**不能只靠 scale** | **验收：80～120ms 内可见**；离开 80～120ms 收回。实现建议：首帧瞬切或 ≤16ms | **不**出 `sfx_cta_tap` | 用按压 0.96 冒充；1.04+；整屏闪白；300ms+ 才亮 |
| focus | **与 hover 同触发、同窗**：至少 2vp accent / brass 环。无鼠标时必须靠这条过 R2a | 同左（80～120ms） | **不**出 `sfx_cta_tap` | 只做 PC hover；系统蓝环在褐底上看不见 |
| pressed | **保持** #27：`scale 1→0.96`，按下 **≤80ms**；抬起 **100～120ms** 回 1 | 同 #27 | `lb_sfx_cta_tap` ≤80ms（静默关） | 改按压数字、当悬停交差 |
| idle | #27 §F.2 稳态微光：4.0～5.0s，高光 `0.92↔1.00` 或铜边极弱；**scale 峰值 ≤1.01** | 入场 stagger 结束后才开 | 无周期性 UI 音 | 悬停时仍叠微光抢同一条弱呼吸 |

## 5. 真机兜底（R2 已写「无键鼠时 focus」）

R2a：无键鼠时把 **focus** 落到主钮（Tab / 无障碍），先不要激活。只写 `.onHover` = R2 失败。

| 输入 | 必须看见 | ArkUI 提示（会签后落 `feat/client-*`，本 PR 不写） |
|------|----------|--------------------------------------------------|
| PC 鼠标 | hover，**80～120ms** 内铜边或高光 | `.onHover` |
| 键盘 / TV / 无障碍 | **focus** 同套闪、同窗 | `.focusable(true)` + `.onFocus` / `.onBlur`。主 CTA、peek、静默开关、昵称框、填上次（若在）都能吃到焦点 |
| 手机手指 | **pressed** 仍示意可点（#27 scale）；能 Tab/无障碍时仍要 focus | 主 CTA / peek 已有 `.onTouch`，保持 |
| 模拟器 | 有指针走 hover；无指针走 focus | 两条都要过 |

```
有指针 → hover（R2 80～120ms）
有焦点 → focus（与 hover 同材质、同窗）
按下   → pressed（#27，盖过上两者；勿冒充 R2）
都没有 → idle
```

ArkUI（验收仍认 80～120ms）：可先首帧切描边 / 高光 opacity（或 `duration ≤16`），再 `animateTo({ duration: 80～120, curve: Curve.EaseOut })` 收到位。不要新控件、不要 `lb_btn_hover_*`。
