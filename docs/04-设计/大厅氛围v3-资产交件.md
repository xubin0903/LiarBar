## 4. 制作口径

- 荷官四态：**只派生** `art_dealer_bust_idle`。禁止另绘一张脸再冒充实动作。  
- 烛 / 尘：透明 overlay，色锁定板 `tavern_candle` / `tavern_shadow` / `tavern_paper`。  
- 音频：分层合成（低弦 + 拨弦 + 厅响 + 杯模态），**禁止**一条短 beep 填五槽。  
- 口播：拟人 TTS，锁句自然语速；句尾留气口。  
- 脚手架 `scripts/gen_scaffold_assets.py` / `gen_lobby_sfx.py` **不要**盖本表文件。

重出图：`python3 scripts/gen_lobby_v3_art.py`  
重出声：先备口播源再 `python3 scripts/gen_lobby_v3_audio.py`
