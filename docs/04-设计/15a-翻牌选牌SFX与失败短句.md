**硬闸：**

1. **翻牌槽 = `lb_sfx_card_flip`**，**只属 S15-4** 手牌翻面。**合法提前** = 己回合未选中触点 Down 起声，与按下→翻面重叠盖缓冲地板。**耳听与翻面同起**，不得动画完才响 / **翻完才响** / **半秒后才响**。熄灭起势 **禁止** 复用本槽（#112 / 14a §3a）。  
2. **禁止**只 log、系统咔哒 / beep 冒充终稿。  
3. **静默局**画面在、翻牌槽关 = 过。  
4. **听闸 = 与动效同起（翻牌允许合法提前）。** 熄灭认 14a：`lb_sfx_life_extinguish` **起势/首帧同播**，禁止后挂灭序末帧。**半秒后才响** 认 S15-5 / 14a S14-13。**禁止**把翻牌起声挪到 T2 / 末帧。  
5. **预热闸：** `lb_sfx_card_flip` / `lb_sfx_life_extinguish` 两槽须预热到 **`loadComplete` 之后**才允许 play。`pending` 当同步 / 未预热先排队再补播 = **预热未完成不得当过**。  
6. **翻牌 Down 起声；`playFlip` 复用、不二播。** 视觉仍 `CardFace.playFlip` / `animateTo`；T2 仍视觉拍。熄灭仍禁 `card_flip`、不提前。音量 `VOL_FLIP=0.95` 另项。  
7. **调试（已有 · #131）：** 调试窗 **`lb_btn_debug_sfx_arm`** 可切 **早起** / **同起**（默认早起）。正式包不验此钮。不另造 id。

## 2. 失败短句（测试可抄）

合入 ≠ 终验。不替代 F15-1～12 / S15-1～3。

| ID | 短句 | 不过 / 听验 |
|----|------|-------------|
| **S15-4** | **翻牌无声 / 像文字游戏** | 点翻面应响 `lb_sfx_card_flip` 却未真播、只 log、系统咔哒 / beep 冒充（**静默局除外**） |
| **S15-5** | **翻牌声晚于翻面 / 像延迟** | 非静默已真播 `lb_sfx_card_flip`，但晚于翻面起势 / **翻完才响** / 动画完才响 / **半秒后才响**（**静默局除外**） |
| **S15-6** | **预热未完成不得当过** | 翻牌当拍槽未到 `loadComplete` 仍勾过；或 `pending` 当同步补播（**半秒后才响** 另认 S15-5） |
| **S15-7** | **起声未贴触点 / 早起未生效** | Down 未起声或仍等视觉拍才播（缓冲地板未盖）（**静默局除外**）。**半秒后才响** / **翻完才响** 另认 S15-5 |
| **S15-8** | **二次起声叠响** | Down 起声后又在 `playFlip` 再播一次（**静默局除外**） |

熄灭无声 / 无过程 / 硬切 / **晚于灭序**：抄 [14a S14-8 / S14-9 / S14-13 / S14-14](./14a-生命显示-语义与文案.md)，槽是 `lb_sfx_life_extinguish`（**起势/首帧同播**；须 `loadComplete` 后才准 play）。14b R-LIFE-4 听闸随 14a 本票改同起，UI 另票补丁。

**静默局（写死）：** 画面在（翻面仍可见），`lb_sfx_card_flip` 关 = **过**。熄灭同理。
