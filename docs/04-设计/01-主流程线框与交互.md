## 0. 本文边界

**写什么**：开桌 → 看牌 → 出牌包 → 质疑仪式（四拍） → 战报/结算 的信息架构、一指主操作、关键态、ArkUI 建议、动效占位。

**不写什么**：规则判定、数值默认值改写、色板、3D、联网房、商业化、反作弊。

**已对齐测试 PR#6 / 工程 PR#7。** 路由级主屏仅四个：`lb_scr_lobby`（含冷启动/首页开桌）/ `lb_scr_table` / `lb_scr_challenge` / `lb_scr_report`。  
废止主屏：`lb_scr_home`、`lb_scr_peek`、`lb_scr_play`、`lb_scr_recap`。看牌 = 桌面遮罩 `lb_cmp_peek_mask`；出牌包 = `lb_sheet_play`（测试点 `lb_cmp_packet` / `lb_btn_play`）。  
质疑四拍必须独立：`lb_challenge_windup` / `lb_challenge_standoff` / `lb_challenge_reveal` / `lb_challenge_result`（拍2 不得并进 reveal）。口播可仍写「起势→揭牌→结果」。  
测试步骤只写 `lb_*`；核对资源写 `art_*`；禁 `lb_art_*`。

阶段 id 沿用 GDD §4.1，不另造规则状态：

```
LOBBY → DEAL → CLAIM → TURN
TURN → PLAY_REVEAL_SELF → TURN(下家)
TURN → CHALLENGE_RITUAL → JUDGE → PENALTY
PENALTY → (存活≥2 ? CLAIM : RECAP) → END
```

## 1. 总则（所有画面共用）

### 1.1 信息分层（对齐 GDD §9.1）

| 层级 | 放什么 | 放哪里 |
|------|--------|--------|
| 永远可见（常驻） | 当前宣称、轮到谁、各自剩余命、倒计时 | 顶栏 / 座位环，不进弹层 |
| 强提示（瞬时） | 被点名、被画✗、质疑窗口、荷官短句 | Toast / 头像角标 / 全屏仪式，2s 内可消失 |
| 私有 | 手牌正面 | 仅长按揭开；松手收回 |
| 弱化 | 面子分、历史轮次 | 战报为主；对局中最多小徽章 |

**不展示**：他人手牌、AI 内部概率、未公开的本手牌面。

### 1.2 一指原则（演示友好）

- 主路径每个决策 **一个拇指热区**（底部中央或底部右主按钮），直径建议 ≥ 56vp。
- 演示不依赖双指、摄像头、语音、第二部手机。
- 带话、表情、点名、三拍动画 **均可跳过**；跳过本身合法（对齐互动方案：带话可跳过、三拍可跳过）。
- 出牌方式：手势识别（SOFT/SLAM/HESITATE）是完整体验；演示允许改点 **方式芯片** 一指提交。

### 1.3 反馈四态（所有可点控件）

| 态 | 后缀 | 体感 | 动效占位 |
|----|------|------|----------|
| 默认 | `_idle` | 可点 | 无 |
| 按下 | `_press` | 立即缩小/压暗 | **≤80ms** 缩放；操作反馈 <100ms（PRD §7） |
| 成功 | `_success` | 收起面板或进入下一阶段 | **200～300ms** 位移/淡出 |
| 失败 / 非法 | `_fail` | 不进阶段；控件复位 | **150ms** 轻抖；静默局关震动 |
| 不可用 | `_disabled` | 不响应；需可见原因 | 无动画；旁注一行文案 |

震动 / 音效：**只占位，不写死素材**。静默局（PRD F-13）关闭强震动、鼓点催促、嘲讽音效。

### 1.4 实况窗常驻字段（P0，F-08）

对局中同步到实况窗，不另开页面：

| 字段 | 文案示例 |
|------|----------|
| 阶段 | 轮到你出牌 / 轮到「老千」 / 质疑倒计时 / 翻牌中 |
| 剩余秒 | `12` |
| 宣称简称 | 本轮出 A |

锁屏只读，不提供出牌/质疑操作。

## 2. 演示路径（一指可达 · 约 90s）

对齐一页纸成功标准、数值 `demo_seed_enabled=true` / `demo_seed_value=20260906`、GDD §11 教学脚本。

```
[lobby] 点「快速开桌」
    → 默认 4 人桌 / 3 命 / 3 AI 入座（可跳过入座动画）
[桌面·看牌] 长按手牌区 1 次（防窥开启）→ 松手
    → 荷官公布宣称（自动）
    → AI 先出本轮第一手（教学/演示种子；第一手不可质疑）
[出牌包] 点 1 张牌 → 点方式芯片「轻推」→ 点「出牌」（带话默认跳过）
[质疑] 下一次轮到自己且已有上家本手：点「质疑」
[质疑] 默看完 windup→standoff→reveal→result（口播：起势→揭牌→结果）；随时可点「跳过」（总长 ≤4s）
[战报] 局结束后点「再来一局」或「回 lobby」
```

**教学强制顺序**（GDD §11 / 互动方案 §4.4）：**禁止**在本轮第一手教质疑。UI 在第一手把「质疑」置 `_disabled`，旁注「第一手还没人出过牌」。

旁观押面子：演示者自己发起质疑时是质疑者，押注窗给另外 3 个 AI + 日后旁观；演示者不被强迫点押注。

| 分区 | 常驻 | 瞬时 |

### 5.2 一指主操作（轮到自己时）

| 条件 | 主按钮 | 次操作 |
|------|--------|--------|
| 有牌，可出牌 | **点手牌** 打开出牌包（画面 D） | 长按看牌 |
| 非第一手，可质疑 | 底栏右侧 **【质疑】** | 同上 |
| 无牌且可质疑（GDD §10.1） | 只留 【质疑】，时限 8s | 手牌区空态文案「没有牌了，只能质疑」 |
| 无牌且不可质疑 | 无主按钮，自动跳过 | 荷官一句「过」 |
| 别人的回合 | 无出牌/质疑 | 双击桌面 KNOCK；点头像画✓✗ |

第一手：`lb_btn_challenge` = `_disabled`。

### 5.3 关键态

| 控件 | 何时 disabled | 失败反馈 |
|------|---------------|----------|
| 质疑 | 本轮第一手；自己已出局；无上家本手 | 点 disabled 不抖；旁注一句 |
| 催 | 剩余 ≥5s；静默局 | 不出现，不是置灰 |
| KNOCK | 本回合已用满 2 次 | 第三次双击无波纹，Toast「这轮敲够了」 |
| SIGN_OK / SIGN_NO | 各已 2 次 | 同上 |

轮到自己：自己头像描边 + 底栏主按钮亮起。  
轮到别人：手牌仍可长按看，但不能打开出牌包。

### 5.4 ArkUI 与动效占位

| 区域 | 建议组件 |
|------|----------|
| 整桌 | `Stack`：桌面 `Image` 为底，上层 `Column` |
| 顶栏 | `Row`：宣称 `Text`、倒计时 `Text`（或 `Progress` 细条）、荷官位 |
| 对手 | 三角座位用 `Stack` 绝对偏移；每座 `Column(Image, Row命点, Text名)` |
| 中央池 | `Stack` 叠牌背 `Image`，张数 `Badge` / `Text` |
| 手牌 | 横向 `List`（`List.ListDirection.Horizontal`）或 `Row`；项为 `Stack` 牌背 |
| 底栏 | `Row`：左次按钮、右主 `Button` |
| 荷官句 | `Text` overlay，`bindSheet` 不需要 |
| 手势 | 桌面区 `TapGesture({count:2})`→KNOCK；`TapGesture({count:3})`→KNOCK 强化（同一 ID） |
| ✓✗ | 长按头像出两点 `Button`，或对头像 `PanGesture` 画符（MVP 用两点按钮更稳） |

| 动效 | 量级 | 震动 | 音效 |
|------|------|------|------|
| 倒计时 <5s | 数字 200ms 脉冲 | 可选微震；**静默局关** | 鼓点占位 `lb_sfx_hurry` |
| KNOCK 波纹 | 300ms 圆扩 | 无 | `lb_sfx_knock`；三连用 `lb_sfx_knock_heavy` |
| 被点名 | 头像烛火 400ms | 被点名者短震 | `lb_sfx_callout` |
| AI 思考 | 头像 400～1200ms 微动（数值 `ai_think_ms`） | 无 | 无 |

### 5.5 与互动方案对齐

- §3.4 KNOCK / STARE / SIGN / HECKLE / 催。
- §4.2 三连点桌 = `KNOCK` 强化，不另立按钮。
- §8 静默局：关催促抖动与起哄密度。

## 6. 画面 C · 看牌

**对齐**：互动方案 §3.2；PRD F-03 / F-07；GDD §3.4。

叠在 `lb_scr_table` 上，控件 id = `lb_cmp_peek_mask`。**禁止**写成独立主屏。松手必须回到牌背。

### 6.1 信息架构

```
┌─────────────────────────────┐
│ （顶栏仍在，宣称/倒计时常驻）│
│        ░ 防窥遮罩 ░         │  ← 除手牌区外降曝光
│                             │
│   对手只见：面具符号        │  ← 他人不可见牌面
│                             │
├─────────────────────────────┤
│  [挑眉][面瘫][苦笑][吞咽]   │  ← 表情轮盘（可一点，可忽略）
│  [装惊喜] [装绝望]          │  ← 假动作快捷
│ ┌──┬──┬──┬──┬──┐            │
│ │A │K │Q │J │A │  ← 仅此时正面
│ └──┴──┴──┴──┴──┘            │
│     按住看牌 · 松手收起      │
└─────────────────────────────┘
```

| 分区 | 常驻 | 瞬时 |
|------|------|------|
| 顶栏 | 宣称、倒计时 | 不变 |
| 遮罩 | 防窥开启期间 | 进入/退出 150ms |
| 手牌正面 | 按住期间 | 松手立即牌背 |
| 表情条 | 按住期间可点 | 选中后全桌只见表情符号 |

### 6.2 一指主操作

**长按手牌区任意位置**（不必精确点中某一张）→ 揭开全部自己的手牌。  
松手 → 收回。  
演示只要做一次长按再松开。

表情：按住同时可用同一拇指点轮盘；不点也不挡看牌。无摄像头完整可用（F-07）。

### 6.3 关键态

| 态 | 行为 |
|----|------|
| `_idle`（未按） | 牌背；防窥关 |
| `_press`（按住） | 牌面；防窥开；表情条出现 |
| 松手 success | 150ms 翻回牌背；防窥关；表情条消失 |
| 轮到别人仍可看 | 允许，避免忘牌 |
| 出牌包打开时 | 看牌仍可用：按住已选牌区揭开确认（手牌仍防窥，GDD PLAY_REVEAL_SELF） |
| 质疑仪式中 | **不允许**看自己的牌挡仪式；长按无效 |

失败：无「看牌失败」。不可用仅在三拍全屏时。

### 7.2 一指主操作（演示最短）

1. 点 1 张牌（选中）。  
2. 方式保持默认「轻推」（进入面板即默认 SOFT）。  
3. 带话保持「不带话」。  
4. 点 **【出牌】**。

| 方式 ID | 手势（从手牌区滑向中央池） | 阈值（引用数值，不改） |
|---------|----------------------------|------------------------|
| SOFT | 滑速 ≤ `soft_max_velocity`（1200 px/s） | 平稳入池 |
| SLAM | 滑速 ≥ `slam_min_velocity`（2800 px/s） | 砸桌+轻震 |
| HESITATE | 拖拽停顿 ≥ `hesitate_dwell_ms`（800ms） | 牌角发抖 |

带话：点模板或「不带话」。自定义 ≤12 字为 P1，MVP 不做输入框。

| 点名 | 可点 | 压下 | 目标头像烛火 | — | 自己；已出局者 |

## 8. 画面 E · 质疑仪式（四拍锁名）

**对齐**：互动方案 §3.6；GDD §6.2 / §7.3；PRD F-05 / F-06；工程 PR#7。  
规则层仍是：拍1 指控 → 拍2 对峙（嵌押注）→ 拍3 翻牌 → 定格。口播可说 **起势 → 揭牌 → 结果**。  
**程序 / 测试 / 文档必须用四个独立 id**（拍2 = `standoff`，不得并进 reveal）：

| 锁名 id | 口播 | 互动方案 | 时长（可跳过） | 玩家是否必须操作 |
|---------|------|----------|----------------|------------------|
| `lb_challenge_windup` | 起势 | 拍1 指控 | 约 0.8s | 质疑者可选姿态；不选用默认「拍桌指控」 |
| `lb_challenge_standoff` | （对峙，口播「揭牌」之前） | 拍2 对峙 + 押注窗 | 约 1.2s；押注窗 ≤2s | 旁观押真假；质疑者可只看 |
| `lb_challenge_reveal` | 揭牌 | 拍3 逐张翻 | 约 1.5s+ | 只看 |
| `lb_challenge_result` | 结果 | 定格 → JUDGE 文案 | 含在仪式总长内 | 无操作，只看谁扣命 |

**总长 ≤ `challenge_ritual_max_seconds`（4s）**。任意时刻右上角 **【跳过】** → 直接进结果定格（仍要播判定，不许跳过扣谁命）。

押注窗关闭（GDD §7.3，先到先关）：**拍 3 翻牌开始** 或 满 `challenge_bet_seconds`（2s）。

**`lb_challenge_result`（定格）**

| 跳过 | 切到本 id（或直接 JUDGE）；牌一次全翻 + 同一定格，总 200ms，仍出对错 |
