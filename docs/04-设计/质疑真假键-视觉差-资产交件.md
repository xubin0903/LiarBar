## 2. 双通道规则（色盲安全）

禁止只靠红 / 绿或只靠色温。真 / 假必须 **形 + 色温** 双通道可分：

| 通道 | 真 `*_true` | 假 `*_false` |
|------|-------------|--------------|
| **形** | 高圆角 **pill**；左边浅 **勾** | **更尖**圆角（≈14px）；更厚暗描边；左边 **斜撇** + 细横 |
| **色温** | 暖：烛金 `#E8B86D` / 铜 `#C4A46A` / accent | 冷：钢青 / teal-copper，压红抬蓝绿 |
| **ON** | 烛金洗 + 铜边更亮 | 冷 teal 洗 + 钢边；**不是**暖金的色相双胞胎 |

色盲（含红绿）仍须靠 **轮廓（pill vs 尖角）+ 勾/撇** 分清真假。

## 3. 禁令（ban list）

| 禁 | 原因 |
|----|------|
| 仅色相对调的双胞胎（同形同描边只换 hue） | 色盲不可分；违反双通道 |
| 系统灰 `Button` / HarmonyOS 默认灰铬 | 与确认铬同一禁；酒馆风 |
| 系统强调蓝当假 / 系统绿当真 | 非酒馆 token；易被读成系统控件 |
| 只靠红=假 / 绿=真 | 红绿色盲失效 |
| 烤死「真」「假」大字占满中心 | 客户端要叠 `Text`；本批只留左侧轻符 |
| 改 `.ets` / 抬 `padB` / 改 `HAND_RING_GAP` | 本 PR 零 ets、零布局 |
| 新音频 / 改 `lb_sfx_challenge_*` | 零音频；SFX 认既有 enter/commit |
| 用押注 `art_bet_*` / `lb_btn_bet_*` 顶替入口 | 17 写死禁 |
