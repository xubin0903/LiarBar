## 2. 开场时间轴挂点（请 @UI 对拍）

同一路由 `lb_scr_lobby`，默认总长 ~2.0s（clamp 1.5～2.5s）。**本 PR 不改时间轴 ets**；合入后现挂槽立刻换真图，静帧槽请 UI 在 `feat/client-lobby-v2` 挂上。

| 拍 | 时刻 | 画面 | 挂本批哪张 |
|----|------|------|------------|
| T0 黑场 | 0 | 全屏 `tavern_bg` `#1A120E` | 程序色，不是图 |
| T0→静帧淡入 | 0～0.35s | 独立启动静帧，无闪白 | **`art_splash_still`** |
| 加载暗示 | 0.35～0.9s | 静帧上转圈 / 细条 | 程序 `Progress`；条色 `tavern_candle` |
| 荷官亮相 | 0.9～1.3s | 胸像淡入；idle→announce **交叉淡化** | `art_dealer_bust_idle` → `art_dealer_bust_announce` |
| 大厅底显现 | 随 0.9～1.7s | 静帧之下（或切过）露出景深 | **`art_lobby_bg`** |
| 分区 stagger + CTA | 1.3～2.0s | 设置卡 → 主 CTA →「进桌看看」 | `art_input_field` · `art_btn_primary` / `_on` |
| 对局桌（轴外） | 点 `lb_btn_quickstart` 后 | 局内底；规则不变 | `art_table_bg` + `art_dealer_bust_announce` |

分层验收（对照色板 token，不是「屏幕上有这些色就过」）：

| 层 | 应能指认 | token |
