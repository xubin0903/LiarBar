## 1. 开桌加载轴（L1）

### 1.1 用户路径（锁名）

```
lb_scr_lobby（冷启动轴已结束，CTA 可点）
  → 点 lb_btn_quickstart（文案「快速开桌」）
  → 按下反馈仍走大厅已锁：≤80ms 缩放 + sfx_cta_tap（本篇不改 R2 / CTA）
  → 立刻盖上加载叠层（仍在 lb_scr_lobby 路由内，不新开第五主屏）
  → 播 sfx_match_open + 桌布/牌堆画面
  → 轴结束 → 进 lb_scr_table
  → 进入已有阶段 DEAL（开局发牌，见 §2）
```

`lb_btn_start`（改桌规后「开打」）**走同一加载轴**，避免两条入桌。  
这不是重做大厅，只是 **入桌闸**。人数 / 命数 / AI 补位 / 静默开关逻辑不变（F-01 / F-13）。

### 1.2 时长

| 项 | 口径 |
|----|------|
| **默认总长** | **1100ms**（从叠层盖上到允许切 `lb_scr_table`） |
| **验收窗** | **800～1500ms**（不得短于 800，不得长于 1500） |
| **MVP 跳过** | **不可跳过**（课设演示要稳；禁止「再点一次秒进桌」） |
| **起算点** | 主钮抬起且叠层第一帧可见。大厅 CTA 击打音仍按已锁 ≤80ms，**不计入**本 1100ms |
| **失败** | 点完无叠层、或总长 <800ms 就看见可操作桌面 = L1 不过 |

P1（本批不做）：可跳过、进度条拖拽、联网匹配转圈。

### 1.3 拍表（UI 抄常量；拍内可微调，**L-4 必须落在 800～1500ms，默认 1100**）

叠层 id（**本批锁名**）：`lb_ovl_match_load`。  
不得升格为 `lb_scr_*` 第五主屏。

| 拍 | 时刻（默认 1100ms） | 看什么 | 听什么 | 点什么 |
|----|---------------------|--------|--------|--------|
| L-0 | 0ms | 叠层盖住大厅；`lb_btn_quickstart` 进入 `_disabled`（防连点再开一桌） | 大厅 `sfx_cta_tap` 可已在响（已锁，不改） | **不要再点**。误点不得开第二桌、不得关叠层 |
| L-1 | 0～200ms | 桌布 / 毡面从牌桌锚点展开或铺开（语义：桌子铺好了） | `sfx_match_open` **同起**（±40ms） | 不点 |
| L-2 | 200～750ms | 牌堆在荷官 / 中央锚点码齐（语义：牌来了）。座位剪影可依次亮，但不发牌 | `sfx_match_open` 尾响自然落；**无**第二记 CTA | 不点 |

| 语义 | 建议怎么做 | 禁止 |
|------|------------|------|
| 桌布展开 | 毡面或桌布从中心或近景铺开，接到已有 `art_table_bg` 色感 | 只整屏 fade、或大厅五分区再播一遍 |

加载暗示（转圈或底沿细条）可以有，但 **不能代替** 桌布 / 牌堆语义。禁止单转圈交差。

## 2. 发牌时序（D1）

规则权威：[GDD §3.3](../02-游戏设计/GDD.md) / [§10.1](../02-游戏设计/GDD.md) / [数值表 §1–§2](../02-游戏设计/数值与牌堆配置.md)。  
**下列规则数字只引用，不改：**

| 键 / 条文 | 已锁值 | 本篇用法 |
|-----------|--------|----------|
| `default_players` | **4** | MVP 默认桌；快速开桌 |
| `hand_size_default` | **5** | 每存活座发 5 张 |
| 4 人牌堆 | A×8 K×8 Q×8 JOKER×4（28） | 开局发 20，余 8 弃置本轮不用 |
| §10.1 重建 | 完整牌堆洗牌，只给 **存活** 座按 `hand_size_default` 重发 | 不扣命；禁止手牌多者胜 |
| 3 人桌 | 每人仍 5 张（发 15） | 张数按座缩放，单张时长不另发明 |

### 2.1 谁先拿到 · 发给谁

| 项 | 口径 |
|----|------|
| 牌堆锚点 | 中央偏上：`lb_cmp_dealer` 手边或 `lb_cmp_pool` 上方。所有牌 **从同一锚点飞出** |
| 座序 | **顺时针**，与 GDD §2.3 / 座位环一致 |
| **开局第一张** | **写死**从 **真人** `lb_cmp_seat_self`（引擎 `seatId=0` / `viewerSeatId`）起，再 `p1 → p2 → p3` |
| 每座张数 | **5**（`hand_size_default`） |
| 一轮怎么发 | **写死一张一张绕桌**：第 1 张给 self，第 2 张给下家……绕满 5 圈。禁止「先给一人发完 5 张再下一位」 |
| 幽灵 | **不发**（§10.1 只对存活） |
| 3 人桌 | 仍从真人起顺时针，发 15 张 |
| 先手出牌 | **不是**发牌第一张的那个人。先手仍按 GDD §2.3 / 状态机 §3.1（荷官随机或房主左手边；重建则受罚者下家） |

「一张一张绕桌」是 **开局/重建的画面顺序（写死）**：全桌一起热，避免一人先满手、三人干看。  
逻辑层可以一次发完 20 张；**画面必须按上表顺序飞**。

### 2.2 单张与总长（开局）· stagger 写死

公式（4 座开局，`N=20`）：

```
T_card     = 220ms          // 窗 180～260；课设演示必须用默认
T_stagger  = 55ms           // 窗 40～70；从上一张落地起算
T_deal     = N × T_card + (N − 1) × T_stagger
           = 20 × 220 + 19 × 55
           = 5445ms
```

| 参数 | 窗（验收夹取） | **默认（写死，演示用这个）** | 禁止 |
|------|----------------|------------------------------|------|
| 单张飞行 `T_card` | **180～260ms** | **220ms** | 0ms 闪现；改手牌张数来凑时长 |
| 张间 stagger `T_stagger` | **40～70ms** | **55ms** | 按「起飞重叠」算间隔 |
| 间隔算法（开局） | — | **串行**：上一张 **落地后** 再隔 `T_stagger` 起飞下一张 | 开局用重叠；用座间长停冒充串行 |
| 4 座开局总长 `T_deal` | **4000～6000ms** | **5445ms** | <4000ms 快进；用加载 1100ms 加进本段 |

验收认 **第一张起飞 → 最后一张落地** 的墙钟。**不要**把加载 1100ms 算进 `T_deal`。  
相邻两张还要能单独量：`落地(i) → 起飞(i+1)` ∈ **40～70ms**（默认 55）。量不到这条 = stagger 没写进实现，**D1g 失败**。

落座稳态：牌背落入该座手牌条（真人 = `lb_cmp_hand` / `lb_cmp_card_{0-4}`；AI = 座位旁小叠）。落座后可有 ≤80ms 轻压，**不要翻面**。自己手牌稳态仍是牌背；**对手始终背**。揭面只认长按 peek / 出牌包选牌。

### 2.3 重建发牌（GDD §10.1 · 手牌耗尽）

触发只认已锁 T17：连续一圈无人 PLAY/CHALLENGE → 本轮结束 **不扣命** → 完整牌堆重建 → `DEAL`。  
荷官字幕已锁：`一圈没人推进。不扣命，重新发牌。`（`lb_str_dlr_redeal`）。**不要**说成流局判负、不要比手牌。

| 项 | 口径 |
|----|------|
| 发给谁 | 仅 `ALIVE`；张数仍 `hand_size_default`（5） |
| 座序 | 仍顺时针；**仍从真人起**（与开局同一套） |
| **总长** | **写死下限**：`T_rebuild ≥ 0.60 × 本局开局实测 T_deal`。目标落在 **60%～75%**；低于 60% = D1e 失败 |
| 怎么缩短 | 单张取窗下限 **180ms**；stagger 取 **40ms**；仍 **串行**；取消加载轴、取消桌布重铺、取消荷官口型 |
| 4 存活默认 | `20×180 + 19×40 = 4360ms`（相对 5445ms ≈ **80%**，满足 ≥60%） |
| 存活 <4 | 按实际张数串行；不要给幽灵飞牌 |
| 仍须有 | 牌背飞行 + 每张 `sfx_deal_card`（静默则无声，画面仍播） |
| 之后 | `DEAL_DONE` → `CLAIM` 新宣称；先手按 §10.1（有受罚记录＝受罚者下家，否则荷官随机） |

重建 **不再走** §1 开桌加载。人已在 `lb_scr_table`。

### 2.4 发牌期间桌面停顿（体验，不改规则）

| 可 | 不可 |
|----|------|
| 看座位、看牌飞、看荷官字幕「发牌。每人 5 张。」 | 打开出牌包、点 `lb_btn_challenge`、长按看牌（手牌未齐；齐了也等 `CLAIM` 后再教看牌） |
| 静默时看同一套动画 | 用跳过切走 `DEAL`（MVP） |

第一手宣称与出牌：**必须等发牌动画结束**（§4）。这与 GDD「本轮第一手不可质疑」是两件事：先发完，再公布宣称，再进入第一手。

## 3. 音效语义

分层与大厅 v3 相同：**文件 stem = `sfx_*` / `vo_*`；程序调用点 = `lb_sfx_*` / `lb_vo_*`。禁止 `lb_art_*`。**  
本批 **只新增两槽**。不改 `sfx_cta_tap` / `sfx_boot_hit` / `bgm_lobby_night`。

### 3.1 槽位与调用点

| 文件 stem（给音频 / 美术） | 程序 id | 何时 | 时长建议 | 循环 |
|---------------------------|---------|------|----------|------|
| `sfx_match_open` | `lb_sfx_match_open` | 加载 L-1 与叠层同起 | **0.6～1.1s**（含尾响）；须能盖住默认 1100ms 的前半 | 否 |
| `sfx_deal_card` | `lb_sfx_deal_card` | **每一张**起飞或出手瞬间（±20ms） | **≤0.18s** 本体；可带极短纸声尾 | 否（每张重触发） |

旧线框占位 `lb_sfx_deal_in`：**废止当完成**。开桌听 `lb_sfx_match_open`；单张听 `lb_sfx_deal_card`。

建议 rawfile 路径（会签后音频交件，**本 PR 不放文件**）：

```
rawfile/audio/sfx/sfx_match_open.wav
rawfile/audio/sfx/sfx_deal_card.wav
```

### 3.2 分层听感（给美术 / 音频，验收用耳朵）

| 槽 | 听什么（须能指认） | 不要做成 |
|----|--------------------|----------|
| `sfx_match_open` | **一层布面 / 毡面铺开** + **一层牌摞落桌**（可叠极轻杯沿）。像夜馆里把桌子摆好，不是系统叮 | 方波 beep；大厅 `sfx_cta_tap` 再播一遍；`sfx_boot_hit` 招牌灯亮复用 |
| `sfx_deal_card` | **短纸声 + 指尖拨牌**；每张能数得清。4 座 20 张是一串密而匀的「啪、啪、啪」，不是一条长垫 | 一张长 sweep 冒充 20 张；与开桌槽同一条短波；金属敲击当扑克 |

开局 20 张会密触发：相邻两记至少隔 **40ms**，不要混成一团。重建同样每张一记，只是总长更短。

### 3.3 静默局（对齐已锁 · 写死）

权威口径：[GDD §10 静默局](../02-游戏设计/GDD.md) · [PRD F-13](../01-产品/PRD.md) · 大厅 v3 H3（字幕在、声/震关、画面仍播）。  
本批只补两句，**不重开**大厅五层声场讨论：

| 项 | `lb_tog_silent == on` |
|----|------------------------|
| `lb_sfx_match_open` | **不调播放器** |
| `lb_sfx_deal_card` | **不调**（20 张全静） |
| `lb_hpt_*` / 发牌触感 | **不调** |
| 大厅 CTA `sfx_cta_tap` | 仍按已锁：**关** |
| 桌布 / 牌堆 / 飞牌画面 | **照播**（静默不是冻画面） |
| 荷官字幕 | **仍出**「发牌。每人 5 张。」/ 重建句 |
| 口播 | 本批本就不作硬门槛；静默下 **更不许** 用 VO 冒充完成 |

禁止「静默只把开桌音压到 −24 dB 还留着」。

## 4. 状态机挂点（给鸿蒙）

权威阶段枚举：[GDD §4.1](../02-游戏设计/GDD.md) · [状态机草图 §1](../05-技术/02-回合状态机草图.md) · `entry/.../engine/Phase.ets`。  
十态 **不得另起别名**。日志 / 实况窗只报已有 ID。

### 4.1 加载要不要独立 `MATCH_LOADING`？

| 结论 | 口径 |
|------|------|
| **引擎** | **不要**新增 `MATCH_LOADING`。加载期间阶段 **写死仍是 `LOBBY`**（尚未 `START_MATCH`） |
| **表现层** | UI 子状态名可用 `MATCH_LOADING`（给 `Lobby` 叠层），**不写进** `Phase` 枚举、不写进战报 |
| **T01 时机（写死）** | **先播完加载轴（1100ms），再 `START_MATCH`（T01），再 `toTable`。** 禁止「一点就 T01 + 切桌」 |

现挂是「一点就 `START_MATCH` + 切桌」。会签后 **必须**改成：

```
点 lb_btn_quickstart
  → UI: MATCH_LOADING 叠层（阶段仍 LOBBY）
  → 轴 1100ms 结束（夹取 800～1500）
  → T01 START_MATCH → 引擎进入 DEAL
  → 切 lb_scr_table
  → 播发牌动画（引擎保持 DEAL；挡住 PLAY / CHALLENGE）
  → T02 DEAL_DONE → CLAIM → T03 → TURN
```

**禁止**先 `START_MATCH` 再播加载：现挂同步塌缩会在叠层期就变成 `TURN`，第一手会提前开放（D1b / D1d 失败）。日志在 `LOBBY` 叠层期与 `DEAL` 期都 **不得**报「轮到你出牌」。

### 4.2 发牌要不要独立 `DEALING`？

| 结论 | 口径 |
|------|------|
| **不要**新阶段 `DEALING` | 已有 **`DEAL` = 发牌表演**（GDD 原文）。重建发牌也回 `DEAL`（T17） |
| `DEAL` **挡住玩法** | 不可 `INTENT_PLAY` / `INTENT_CHALLENGE`；`lb_btn_challenge` `_disabled`；不打开 `lb_sheet_play` |
| 第一手宣称 | **只在发牌动画完成之后**。对应已有 **T02 `DEAL_DONE` → `CLAIM`**，再 T03 → `TURN` |
| 现挂缺口 | `dealFresh()` 里立刻把 `phase` 写成 `CLAIM`，`announceClaim()` 再写成 `TURN`。会签后须 **把表演窗拆开**：逻辑手牌可先写入私有 `Hand`，公开阶段保持 `DEAL` 直到最后一张落地 |

实况窗阶段用词（已有话术，不新造规则）：发牌中用「重新发牌」/「发牌」；**不要**在 `DEAL` 写「轮到你出牌」。

### 4.3 转移对照（已有事件，不发明规则）

| 草图 | 体验挂点 |
|------|----------|
| T01 `LOBBY` + `START_MATCH` → `DEAL` | **写死**放在加载轴结束（1100ms，窗 800～1500）之后，不得提前 |
| T02 `DEAL` + `DEAL_DONE` → `CLAIM` | **写死**放在最后一张落地后 **≤250ms**（收束含在内，不得先 CLAIM 再飞完） |
| T03 `CLAIM` + `CLAIM_ANNOUNCED` → `TURN` | 宣称播报；此时才允许第一手出牌。第一手仍不可质疑（G-Q6） |
| T17 `STALL_CHECK` → `DEAL` | §10.1 重建；**跳过** §1 加载；走 §2.3 短轴后再 T02 |

教学局（GDD §11）同一套：先加载、再发牌、再宣称；**禁止**在第一手教质疑。教学蒙层等 `TURN` 再叠。

### 4.4 挡住表（写死 · 给鸿蒙抄）

| 公开阶段 | 路由 / 叠层 | `INTENT_PLAY` | `INTENT_CHALLENGE` | 长按看牌 | 实况窗阶段词 |
|----------|-------------|---------------|--------------------|----------|--------------|
| `LOBBY` + 加载叠层 | `lb_scr_lobby` + `lb_ovl_match_load`（**本批锁名**） | 否 | 否 | 否 | 不得写「轮到你出牌」 |
| `DEAL` | `lb_scr_table` | **否** | **否**（`lb_btn_challenge` `_disabled`） | **否** | 「发牌」/「重新发牌」 |
| `CLAIM` | `lb_scr_table` | 否 | 否 | 否 | 宣称播报 |
| `TURN` 且 `playIndexInRound==0` | `lb_scr_table` | 是（有牌） | **否**（G-Q6 第一手） | 是 | 「轮到你出牌」此时才合法 |

`DEAL` 未 `DEAL_DONE` 之前，任何出牌 / 质疑意图 **忽略**（与草图「非法，忽略」一致）。

## 5. 可勾验收句

每行 **听 / 看 / 点** 三件套。映射 **L1 = 加载**，**D1 = 发牌**。  
未审构建 **不得勾通过**。大厅 R1–R4 / 冷启动 3.8s **不在本表**。

### 5.1 L1 开桌加载

| ID | 点什么 | 看什么 | 听什么 | 失败短句 |
|----|--------|--------|--------|----------|
| **L1a** | 大厅轴已结束，点 `lb_btn_quickstart` | **先**出现加载叠层（桌布展开和/或牌堆码齐），**不是**瞬间 `lb_scr_table` | 非静默：按下仍可有已锁 `sfx_cta_tap`；叠层同起 **`sfx_match_open`**（布面/牌摞，不是 beep） | 一点就进桌；无叠层 |
| **L1b** | 叠层出现后 **再点屏幕 / 再点主钮**（故意连点） | 叠层不关；不切桌；不第二局 | 无第二记开桌音抢戏 | 连点跳过；或开了两桌 |
| **L1c** | **不点**，只盯轴 | 墙钟 **800～1500ms** 内切到 `lb_scr_table`；课设包默认应落在 **1100ms ±100ms** | `sfx_match_open` 不是 CTA 复读、不是 boot 招牌 | <800ms 闪进桌；或 >1500ms 还停在转圈 |
| **L1d** | 改桌规后点 `lb_btn_start` | **同一套**加载，不秒进桌 | 同一 `sfx_match_open` | 只有快速开桌有动画、「开打」秒切 |
| **L1e** | 先开 `lb_tog_silent`，再点 `lb_btn_quickstart` | 桌布 / 牌堆 **照播**；仍不可跳过 | **无** `sfx_match_open`、**无** CTA、**无**触感 | 静默无画面；或静默还在响 |

### 5.2 D1 发牌（开局 + 重建）

| ID | 点什么 | 看什么 | 听什么 | 失败短句 |
|----|--------|--------|--------|----------|
| **D1a** | 加载结束后 **手离开**。不点出牌 / 质疑 | 牌从 **同一牌堆锚点** 飞出；**顺时针从真人起**；每人 **5** 张；**飞行与落座稳态都是牌背**（自己不自动翻面）；**对手始终背** | 非静默：每张一记 **`sfx_deal_card`**（纸/拨牌，能数张） | 闪现满手；一次 5 张砸给一人；或落座后自己翻成明牌 |
| **D1b** | 发牌未完时点 `lb_btn_challenge` / 点手牌 | 按钮不可用或无效；**不**打开出牌包；**不**进质疑 | 无出牌/质疑音 | 没发完就能出第一手 |
| **D1c** | **不点**，看墙钟 | 4 座开局：第一张起飞→最后一张落地 **4～6s**（默认约 5.4s） | 20 记能分开，不是一条长 sweep | 总长 <4s 的「快进发牌」；或 >7s 拖死演示 |
| **D1d** | 发完仍 **不点** | 先出宣称（`lb_txt_claim` / 荷官句），**然后** 才进入可出牌的第一手；质疑仍 `_disabled` | 宣称句按已锁模板；无提前「轮到你」抢在飞牌期 | 飞牌期就公布宣称并开放出牌 |
| **D1e** | 构造或打到 §10.1 一圈无推进（可用调试，**禁止**改成手牌多者胜） | 字幕「一圈没人推进。不扣命，重新发牌。」；**无**开桌加载；存活座再飞 5 张牌背；幽灵不发 | 非静默：每张仍 `sfx_deal_card`；总长 **≥ 开局发牌的 60%** | 重建闪现；或重建又走 1100ms 开桌叠层 |
| **D1f** | 静默局走到开局发牌（及若能走到重建） | 飞牌 / 落座 **照播** | **无** `sfx_deal_card`、**无**触感；字幕仍在 | 静默无动画；或静默仍啪啪响 |
| **D1g** | **不点**。对任意相邻两张量 `落地(i) → 起飞(i+1)` | 间隔落在 **40～70ms**（默认能感到 55ms 一拍）；不是两张同时飞 | 两记 `sfx_deal_card` 能分开 | stagger 按起飞重叠；或间隔量不到 / >70ms 连成一条 |

### 5.3 失败短句速查（H4）

勾不通过时，测试只准用下表原句（或等价），不要写成「体验差一点」。

| ID | 失败短句（写死） |
|----|------------------|
| L1a | 一点就进桌；无叠层 |
| L1b | 连点跳过；或开了两桌 |

| L1d | 只有快速开桌有动画、「开打」秒切 |

| D1a | 闪现满手；一次 5 张砸给一人；或落座后自己翻成明牌 |
| D1b | 没发完就能出第一手 |
| D1c | 总长 <4s 的「快进发牌」；或 >7s 拖死演示 |
| D1d | 飞牌期就公布宣称并开放出牌 |

### 5.4 本表不验（写明，避免误勾）

- 大厅烛火融合、CTA 悬停闪、夜馆 BGM、招呼口播（R1–R4 / v3）
- 质疑四拍光效、砸杯、押面子
- 牌面正面是否精美（美术另票；本批飞行/落座稳态牌背齐即可勾 D1）。C1 揭面可读性见质量清单，**≠** 落座明牌
- 口播是否有人声（本批非硬门槛）
