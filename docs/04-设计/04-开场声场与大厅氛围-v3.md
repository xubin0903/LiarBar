## 2. 开场声场与时间轴（冷启动）

同一路由 `lb_scr_lobby` 内播完，**不另开启动页**（废止 `lb_scr_home` 仍成立）。

### 2.1 目标听感

进的是 **夜深还开着的酒馆**，不是提示音包。层次必须能分开指认：

| 层 | 媒体文件名（已定） | 听感 | 出现拍 |
|----|-------------------|------|--------|
| BGM | `bgm_lobby_night` | 低、慢、暖；像馆里一直在响的夜曲，不抢口播 | T2 淡入 → 大厅稳态一直循环 |
| 环境底噪 | `sfx_amb_tavern` | 极轻：远处杯沿一碰、模糊人声、木梁轻响。单听应像「房间」，不像音效按钮 | T2 淡入 → 稳态循环 |
| 开场击点 | `sfx_boot_hit` | **一记**有空间的招牌 / 灯亮（铜撞 + 短厅响），不是 beep、不是系统叮 | T1 静帧亮到七八成时 |
| CTA 点按 | `sfx_cta_tap` | 短木面 / 铜钉；按下 80ms 内必须听到 | **仅用户按下之后**（轴内禁止预播） |
| 荷官招呼 | `vo_dealer_greet` | 锁句口播，拟人、近距、略沙。必须是人声轨道 | T4 与字幕同起 |

**禁止单 beep 冒充完成（H2）**：三发方波 / 正弦 tip / 同一条 wav 改音量重挂，**验收直接不过**。BGM、环境、击点、口播必须是 **四条不同材质**；CTA 是第五条短反馈。单条 beep 填五个槽 = 未完成。

现挂 `rawfile/sfx/sfx_boot.wav` · `sfx_lobby_amb.wav` · `sfx_cta.wav`（#23/#25）= **v2 占位**，v3 **不得**当交件。会签后换槽，**旧文件名废止、不留别名**（已选定）。

### 2.2 加长冷启动默认轴（3.8s）

| 常量建议 | 值 | 说明 |
|----------|----|------|
| `BOOT_MS_TOTAL` | **3800** | 默认轴 |
| `BOOT_MS_MIN` | **3000** | 可调下限（再短 = 又「太快」） |
| `BOOT_MS_MAX` | **4500** | 可调上限 |
| 缩轴规则 | 画面拍按比例压 | **不得删**黑场、静帧、加载、荷官、stagger、稳态、声场起层任一段 |
| 口播 | **禁止变速 / 禁止剪句** | 锁句按自然语速 1.8～2.4s（默认 **2.1s**）。缩轴时允许口播溢入稳态，**T6 到点必须可点** |
| 拉长轴 | 只拉 T2 加载 + T3 亮相 | 不把口播拉成慢放 |

「跳过开场」仍 = **P1**，本批不强制。轴未到 T6 前，`lb_btn_quickstart` **不可点**。

#### 2.2.1 默认 3.8s 拍表

时刻按 **3800ms** 书写。调到 3.0s / 4.5s 时 **拍顺序不变**，只按比例伸缩画面段。

| 拍 | 时刻 | 时长 | **点什么** | **看什么** | **听什么** | 静默局（§2.6 写死） |
|----|------|------|------------|------------|------------|---------------------|
| T0 黑场 | 0.00～0.08s | 80ms | **不点**。从桌面点过图标后手离开 | 全屏 `tavern_bg` `#1A120E`，无按钮 | **无声**。禁止预滚 BGM | 同样无声 |
| T1 静帧淡入 | 0.08～0.60s | 520ms | **不点** | **独立** `art_splash_still` 从黑场淡入，无闪白 | **`sfx_boot_hit` @ ~0.18s**（招牌 / 灯亮，有厅响）。**不是 beep**。此拍还没有 BGM / 环境满额 | **关击点**；画面照播 |
| T2 加载 + 声场起 | 0.60～1.40s | 800ms | **不点** | 静帧仍在；中央或底沿细进度 / 转圈 | **`sfx_amb_tavern` 0.60s 起、淡入 400ms**；**`bgm_lobby_night` 0.80s 起、淡入 600ms**。两层能分开指认 | **BGM / 环境 / 击点全关** |
| T3 底 + bust | 1.40～2.20s | 800ms | **不点**。误点 `lb_btn_quickstart` **不应**开桌 | 静帧切过 / 露出 `art_lobby_bg`（须能看出不是同一张褐金底）；`lb_cmp_dealer` idle 胸像淡入 | BGM + 环境已在，保持。此拍 **不**接口播、不另加击打 | 全关；画面照播 |
| T4 招呼 | 2.20s 起 | 口播 1.8～2.4s（默认 2.1s） | **不点**。眼看 `lb_cmp_dealer` | idle→**announce** 交叉淡化（350ms，禁硬切闪白）；字幕打出锁句 | **`vo_dealer_greet` 与字幕同起**；BGM **duck −6～−9dB**（200ms 压下） | **关口播、关强震、关 BGM/环境/击打**；**字幕必须仍出**同一句 |
| T5 分区 stagger | 2.50～3.30s | 800ms | **不点** | 顶栏 → 设置卡 → 主 CTA →「进桌看看」错开（间隔 90～110ms）；`opacity 0→1` + `translateY 12→0` + `scale 0.96→1` | **无新击打**。禁止为 stagger 加占位 beep | 无声；动效与字幕仍播 |
| T6 稳态可点 | 3.30～3.80s | 500ms | 轴走到 3.80s 后才允许点 `lb_btn_quickstart`（本拍先看整屏，**先不点**） | 五分区可辨；荷官开始从 announce **回 idle**（若口播未完，回切等到口播结束 +0.25s，见 §3.5） | 口播未完则继续；口播结束后 BGM **200ms 回稳态音量**。环境保持 | 全静；字幕按 §2.4 再留 0.4s |

**可点规则**：总轴播完（默认 3.8s，允许落在 3.0～4.5s）必须可点。口播可以溢到 2.20+2.40=**4.60s**（上限语速），**不挡** T6 可点。

T5 与 T4 重叠是故意的：人在说话时，卡和按钮才错开进来，像「位子给你留着」的同时把桌摆上，而不是先播完广告再出 UI。

#### 2.2.2 分区 stagger 顺序（T5，默认 2.50～3.30s）

每层间隔约 90～110ms，单层动画 240～280ms：

1. 顶栏  
2. 荷官区补位（胸像已在 T3；本拍只补字幕条若尚未出）  
3. 设置卡（`lb_cmp_nick_field` / 人数 / `lb_tog_silent`）  
4. 主 CTA `lb_btn_quickstart`  
5. 次级「进桌看看」

量级与 v2 相同，**禁止**改成大弹跳。

### 2.3 音源规格表

路径建议（鸿蒙 rawfile，**不要**写成 `art_*`，更 **禁止** `lb_art_*`）：

```
entry/src/main/resources/rawfile/audio/
  bgm/bgm_lobby_night.ogg
  sfx/sfx_amb_tavern.ogg
  sfx/sfx_boot_hit.wav
  sfx/sfx_cta_tap.wav
  vo/vo_dealer_greet.wav
```

| 文件 | 类型 | 格式 | 声道 / 采样 | 时长上限 | 循环 | 淡入 / 淡出 | 相对响度 | 来源 | 静默 |
|------|------|------|-------------|----------|------|-------------|----------|------|------|
| `bgm_lobby_night` | BGM | **ogg**（Vorbis） | 立体声 48 kHz | 循环体 **16～32s**（不要 2s 短 loop 听出接缝） | **是**。循环点避开强拍；交叉淡化 ≥400ms 或无缝 loop | 开场淡入 **600ms**；离厅 / 静默淡出 **400ms** | 开场目标 **−12 dB**（相对 0 dBFS 峰值参考，见下）；稳态再低 **2 dB**（约 −14 dB） | 库素材或自制配乐 **可**。禁止单振荡器 | **关（写死）** |
| `sfx_amb_tavern` | 环境 | **ogg** | 立体声 48 kHz | 循环体 **8～16s** | **是**。loop 点在气息最低处 | 淡入 **400ms**；淡出 **300ms** | 比 BGM 再低 **6 dB**（约 −18 dB）。单听杯碰不得超过 BGM 存在感 | 库素材 **可**，须去识别广告感 | **关（写死）** |
| `sfx_boot_hit` | 开场击点 | **wav** 16-bit | 单声道或立体声 48 kHz | **≤0.70s**（含尾响） | 否 | 文件内自带 10ms 起音；尾响自然落到 −40 dB | 峰值约 **−6 dB**；比口播略让、比 BGM 明显 | 拟音 / 库 **可**。必须有厅响，禁止纯 beep | **关** |
| `sfx_cta_tap` | UI 反馈 | **wav** 16-bit | 单声道 48 kHz | **≤0.18s** | 否 | 起音 <8ms | 峰值约 **−10 dB**。次级「进桌看看」**同文件 −3 dB** 再播，不另出条 | 拟音 / 库 **可** | **关** |
| `vo_dealer_greet` | 口播 | **wav** 16-bit | **单声道** 48 kHz | **1.8～2.4s**（锁句自然语速；默认按 2.1s 做轴） | 否 | 句首 <40ms；句尾留 80～120ms 气口 | 对白参考 **−8 dB** 峰值 / 响度明显高于 BGM。口播时 BGM duck **−6～−9 dB** | **必须真人录或拟人声**（TTS 须过审听感）。禁止蜂鸣、机器人默认音 | **关口播**；字幕仍在 |

**相对 dB 怎么用**：上表是 **混音目标关系**，不是文件内必须写成这些峰值。验收用耳朵：口播最前、击点第二、CTA 短而清、BGM 托底、环境几乎「感觉有房间」。任一层盖住口播 = 不过。

| 必须真人 / 拟人 | 可程序合成 / 库素材 |
|-----------------|---------------------|
| `vo_*`（本批仅 `vo_dealer_greet`） | `sfx_*` · `bgm_*` |

**禁止**：

- 用一条短 beep 当 boot / amb / cta 三个槽  
- 把 BGM 做成循环 1s 电子垫，听出接缝  
- 环境里出现可辨清的闲聊内容、商标、其他游戏原声  
- 口播改字、加字、叠混响到听不清锁句  
- 未审先落正弦 / 方波「占位完成」

### 2.4 招呼锁句 + 口播 / 字幕对齐

| 项 | 口径 |
|----|------|
| **锁句** | **夜深了，位子给你留着。** |
| 文案 key | `lb_str_dlr_lobby_greet`（v2 已给，**不改字**） |
| 口播文件 | `vo_dealer_greet` |
| 调用点 | `lb_vo_dealer_greet`（程序 id，不是文件名） |
| 控件 | 字幕挂 `lb_cmp_dealer` 旁或下方（v2 已锁）。**不动** `lb_cmp_dealer_banner` |
| 入座满句 | `lb_str_dlr_lobby_full`「本桌四人，酒已满。」**仍只给出座满**；禁止拿来冒充进场招呼 |

### 3.2 荷官 idle 循环动作（呼吸以外 · H2 硬门槛）

#### 3.2.1 动作表

| 动作 | 建议资源 | 时长 | 幅度 | 触发 | 权重（加权随机） |

### 3.5 `announce` 与招呼的关系

大厅只用已锁两态：`art_dealer_bust_idle` / `art_dealer_bust_announce`（#22 已交）。招呼是 **大厅唯一自动切 announce 的理由**。

| 阶段 | 姿态 | 持续 | 回 idle |
|------|------|------|---------|
| T3 亮相 | idle 淡入 | 至 T4 | — |
| T4 招呼起 | **350ms** 交叉到 announce | 口播全程（静默局按 2.1s 虚拟口播钟） | — |
| 口播结束 + **0.25s** | 保持 announce | 0.25s | **400ms** 交叉回 idle |
| 回 idle 后 | idle + §3.2 循环 | 直到下一次进场 / 离开大厅 | 循环自己切状态图，**不再占 announce** |

离开大厅再回来（从桌返回）：**不**重播整段 3.8s 冷启动（冷启动只冷启动一次）。回大厅走 **0.4s 短入**（已选定）：未静默则 BGM/环境 400ms 淡入到稳态；**不**重播 `sfx_boot_hit`；**不**重播 `vo_dealer_greet`（避免每次回大厅都「夜深了」）；**不再出**招呼字幕。静默则短入也全静（§2.6）。

**先看后点。** 任一条失败即 v3 未通过。  
**H1**：下表每一行都写清 **点什么 / 看什么 / 听什么**。缺一列不得拿去会签。  
画面分层、独立静帧、五分区、锁句文字仍对齐 [03 §7](./03-开场与大厅交互-v2.md) / [#24 清单](../06-质量/开场与大厅验收勾选清单.md)；**时刻与听感以本表为准**（#24 的 1.5–2.5s **不再作为 v3 时长门槛**）。

冷启动总长必须落在 **3.0～4.5s**（默认 3.8s）。

### 7.1 前置（仍写三件套）

| # | **点什么** | **看什么** | **听什么** | 过 |
|---|------------|------------|------------|----|
| P0 | **不点**厅内。确认构建是会签后的包，不是热重载 | 锁名能对上：`lb_scr_lobby` / `lb_btn_quickstart` / `lb_cmp_dealer` / `lb_tog_silent` / `art_splash_still` | 未开验前不应有厅内循环声抢跑 | [ ] |
| P1 | 从 **桌面点图标** 冷启（不要热重载冒充） | 进的是同一路由 `lb_scr_lobby`，不是 `lb_scr_home` | 冷启瞬间无残响、无上一局 BGM | [ ] |
| P2 | **不点** Table / 质疑 / 战报当本表验收 | 局内 / `demo_seed` / TC-19 **不扩验** | 本表不验收局内任何音 | [ ] |

**未审占位音 / 仅缩放不得拿来勾下面任何一行通过（H2）。**

### 7.3 大厅稳态（停 ≥8s）

| # | **点什么** | **看什么** | **听什么** | 过 |

| 9b | **不点** | 近景烛焰在闪（焰，不是整屏闪）；远景烟或光尘微动（P0 允许程序尘） | 无额外 FX 音。禁止为烛光加 beep | [ ] |

| # | **点什么** | **看什么** | **听什么** | 过 |
|---|------------|------------|------------|----|
| 10 | 回大厅后 **点 `lb_tog_silent` 打开** → 杀进程 → **从桌面再点图标**重开（再走 3.0～4.5s） | 招呼 **字幕仍在**，句为「夜深了，位子给你留着。」荷官真动作与烛光 **仍在** | **全静**：口播关、强震关、开场击点关、CTA 击打关、**BGM 关、环境关**。无「留低音量」备选 | [ ] |
| 10b | 静默重开、轴结束后 **再点 `lb_btn_quickstart`** | 整钮仍缩放；仍进默认开桌（规则不变） | **无** `sfx_cta_tap`、**无**强震 | [ ] |

### 7.5 失败短句

出现任一条，v3 不过：

- 验收句缺 **听 / 看 / 点** 任一列（H1）。  
- 总轴短于 3.0s 或长于 4.5s；或删了拍。  
- **单 beep 冒充完成**；三槽同一条短波；无分层 BGM/环境/口播（H2）。  
- 大厅 **仅缩放交差**；无眨眼 +（点头/抬杯/面具）真动作循环（H2）。  
- 口播与字幕不同起，或改锁句。  
- 静默局仍有 BGM / 环境 / 击打 / 口播 / 强震；或字幕没了（H3）。  
- 未审先落占位音 / 占位动效当通过。  
- 改了局内 / 规则 / 锁名 / `lb_art_*`。
