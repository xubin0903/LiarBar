## 2. 分区线框（横屏桌 · 过 X1 / X2）

画板按 **手机横屏**（宽 > 高）。数字是 **比例 / 约束**，不是 px 终值。

### 2.1 常驻底（无叠层）

```
← 宽（长边）→
┌──────────────────────────────────────────────────────────┐
│ 宣称 A │ 12s │ 阶段          荷官短句（可空）              │  ← 顶栏 ≤12% 高
├────┬───────────────────────────────────────────────┬─────┤
│    │                    p2                         │     │
│ p3 │                                               │ p1  │
│    │              荷官                             │     │  ← 座位环 + 桌心
│    │         dealPileAnchor / 池                   │     │     ≥52% 高（含安全区后）
│    │                    self                       │     │
├────┴───────────────────────────────────────────────┴─────┤
│  [背][背][背][背][背]     手牌 5                         │  ← lb_cmp_hand 18～24% 高
├──────────────────────────────────────────────────────────┤
│  [催]                         【质疑】  【出牌】          │  ← 底栏 CTA ≤14% 高
└──────────────────────────────────────────────────────────┘
```

| 分区 | 锁名 | 几何（约束，非像素） | 常驻 | 对齐 10 |
|------|------|----------------------|------|---------|
| 顶栏 | `lb_cmp_topbar` · `lb_txt_claim` · `lb_txt_timer` | 高 **≤ 12%** 窗口高；左右避开刘海 | 宣称、倒计时、阶段 | X1 宣称；LY1 安全区。**荷官胸像不进顶栏** |
| 座位环 | `lb_cmp_seat_self` / `_p1` / `_p2` / `_p3` | 见 §2.2 | 轮到描边、命 | X1 四座；禁止再排成一条 `Row`（O1 不过） |
| 荷官 | `lb_cmp_dealer` | 桌心偏上，**占位 ≤ 桌心区 28% 短边** | 胸像可缩小；口播走字幕 | X2：不挡池、不挡宣称、不挡 p2 |
| 中央牌堆 | `dealPileAnchor` + `lb_cmp_pool` | 桌心：dealer 手边 / 池上（08 §2.1 / 09 §1.2） | 本手背+张数 | 语义在此；**像素归票 B** |
| 己方手牌 | `lb_cmp_hand` · `lb_cmp_card_{0-4}` | 底栏之上一条；高 **18～24%**；牌用已锁 56×78 档 | 默认牌背（10 §6 / 09 C1） | X1 手牌；不得被 CTA / 回开桌挤出屏 |
| 底栏 CTA | `lb_btn_challenge` + 出牌入口 | 高 **≤ 14%**（含手势条 padding）；主钮 ≥56vp | 质疑 / 出牌；催仅 <5s | X1 CTA；**禁止**再垫通栏「回开桌」（X4） |

3 人桌：缺座留空，**不**把剩下三座收成一排。

**X1 几何推论（10 补句）：** 横屏一帧内指认四块；禁止靠竖向 `Scroll` 把座位或 CTA 推到屏外。手牌 5 张可横向微移，**整桌**不得靠滑才露出宣称或主按钮。

### 2.2 座位环（self / p1 / p2 / p3）

顺时针与 09 发牌序一致：**self → p1 → p2 → p3**。几何是「环」，不是「工具条」。

| 座 | 锁名 | 环上位置（相对桌心区） | 朝向 |
|----|------|------------------------|------|
| 自己 | `lb_cmp_seat_self` | **下沿中**，贴手牌上沿 | 头像+命；手牌本身在 `lb_cmp_hand` |
| 下家 | `lb_cmp_seat_p1` | **右沿中** | 头像下沿内侧小叠（牌背） |
| 对家 | `lb_cmp_seat_p2` | **上沿中**，顶栏下 | 同上 |
| 上家 | `lb_cmp_seat_p3` | **左沿中** | 同上 |

建议用 `RelativeContainer` `alignRules` 或四向 `Flex`，**不要** `.position({ x: 24, y: 128 })`（LY1）。  
桌心区 = 顶栏下沿 ～ 手牌上沿，左右再减安全 inset。

### 2.3 出牌包 `lb_sheet_play`（过 X3）

10 X3 写死：盖住面积 **< 50%** 横屏可视；高度建议 **≤ 短边 40%**；顶栏宣称与四座仍可指。

```
┌─ 顶栏宣称仍可见 ─────────────────────────────────────────┐
│ ░ 座位环仍可辨（压暗，不卸） ░     ┌─ 出牌包 ─────────┐ │
│         池 / 荷官                  │ 已选 n/3 · 取消    │ │
│                                    │ 手牌多选（可横滑） │ │
│                                    │ 方式芯片           │ │
│                                    │ 【出牌】           │ │
└────────────────────────────────────┴────────────────────┘
```

| 要（过 X3） | 不要 |
|-------------|------|
| **默认右侧栏**：宽使盖住面积 **< 50%**（建议 ≤36% 窗口宽，留余量） | 全宽 Column 插进主 `Column`；`bindContentCover` 挡宣称 |
| 若改底栏：高 **≤ 短边 40%**，且面积仍 **< 50%** | 01 竖屏半屏 sheet 原样搬进横屏（10 已禁） |
| 顶栏宣称 + 四座 **仍可指**；`lb_btn_play` 与方式芯片同屏 | 再滑一层才看见提交 |
| 点包外 / 取消 = 不提交（01 已锁） | 把「回开桌」放进包当主按钮（X4） |

`bindSheet` 若用：横屏走 **侧栏 / 中等 detent** + `constraintSize({ maxHeight: '40%' })`。禁止默认半屏当完成。

## 3. 约束 / 百分比 / 断点（过 LY1）

终局方案只认 **约束 / 百分比 / Flex / RelativeContainer / 断点**。  
**禁止**把写死像素坐标（`position x/y`、`seatXs[]`、`flyX=152`）当交件。

| 手段 | 用在 | 禁止当终局 |
|------|------|------------|
| 百分比宽高 | 顶栏 / 手牌带 / CTA / sheet 封顶 | `height(340)` 手牌起点 |
| `layoutWeight` / `Flex` | 桌心吃剩余高；底栏两 CTA 均分 | 固定 `Column` 把环挤出屏 |
| `RelativeContainer` `alignRules` | 四座+荷官+池 | 四座 `Row` + 魔法数 x |
| `constraintSize` `{ min, max }` | 胸像、牌、sheet | 胸像 72×96 写死还进顶栏 |
| `onAreaChange` → 锚点 | `dealPileAnchor`、飞牌落点 | 默认 `pileX=152, pileY=210` 当「桌心」（票 B） |
| 断点（§4.2） | 小屏收胸像、折叠加边 | 一套 px 打天下 |

**允许**的分量（不是屏幕坐标）：牌 56×78 / peek 80×112（09）；热区 ≥56vp（01）。

飞牌：位移 = 锚点 A→槽心 B（运行时量），时长仍 08/09。横屏只换 A/B。

## 4. 安全区 · 断点 · 桌布横裁

### 4.1 刘海 / 手势条（LY1）

横屏刘海多在 **左或右短边**；手势条在 **底长边**。10：**`lb_txt_claim`、`lb_cmp_hand`、`lb_btn_challenge` / 出牌主 CTA 不得被刘海或底条裁掉、挡到点不到。**

| 区 | 要 | 不要 |
|----|----|------|
| 顶栏宣称 / 倒计时 | 加上沿 + **左/右 cutout**；文字收进安全矩形 | 宣称画进挖孔 |
| 左座 p3 / 右座 p1 | 头像中心在安全矩形内 | 头像一半在刘海里 |
| 手牌 / CTA | 底边 = 手势条 inset + 约束边距；CTA 高仍 ≥56vp | 质疑钮沉到横条手势区 |
| 出牌侧栏 | 贴右减右 inset | sheet 顶满到物理边缘 |

读窗口 `avoidArea`（cutout / navigation indicator / system）换成 vp。**不要**用「左右各 48px」冒充安全区（LY1）。

### 4.2 小屏与折叠（宽高比阈值）

以 **窗口** `W/H`（横屏 > 1）和短边 vp 分档。不要按机型名分支。

| 档 | 条件（同时满足） | 布局 | 失败若误用 |
|----|------------------|------|------------|
| **L-phone**（主验收） | `W/H ≥ 1.60` 且短边 ≥ 320vp | §2 标准环；荷官小 bust | — |
| **L-small** | `W/H ≥ 1.60` 且短边 **< 320vp** | 隐/再缩荷官 bust（只留字幕）；手牌仍 5 槽 | 仍塞大胸像进顶栏 |
| **L-fold**（展开内屏） | `1.20 ≤ W/H < 1.60` 且短边 ≥ 360vp | 环仍在；桌心可加 **百分比** 边距（如 8%） | 当平板重做第五屏 |
| **非目标** | `W/H < 1.20`（仍竖） | **不应出现**在 table 稳态 = O1 取向锁失败 | 「竖屏自适应」交差 10 |

折叠外屏按 L-phone / L-small。平行视窗 **不进完成态**。大厅 / 战报 / 质疑 **不套** 上表（10：质疑冻；战报非 X1–X4 硬门槛）。

### 4.3 桌布横裁安全区（`art_table_bg`）

现挂 `art_table_bg` = **竖构图 1080×2340**（清单 / 大厅 P0）。横屏窗口用 `ImageFit.Cover` 时，**只露出竖图中段一条横带**（按宽铺满，上下被裁）。

本 PR **不交新媒体**。10：美术默认不新出图；本文开口要 **裁切说明**（不是新文件名）。

| 项 | 口径 |
|----|------|
| 资源 | 继续 `$r('app.media.art_table_bg')`。**禁止** `lb_art_*`、禁止本票发明 `art_table_bg_land` |
| 裁法 | `Cover`；锚 **桌心毡面**（竖图垂直中段），不要锚顶烛或底木边 |
| 可见带（约） | 源图高 2340 里，横屏 16:9 约中段 **~600px**；更长屏（≈19.5:9）约中段 **~500px**。关键毡纹 / 桌心必须落在这条带 |
| 控件安全 | 宣称、四座、手牌、CTA 画在 **窗口安全矩形**，不要假设桌布顶/底装饰还在 |
| 挖孔 | 左右刘海压在桌布裁切边上即可；**主信息不画进 cutout**（LY1） |
| 新图 | 仅当 Cover 中段毡面空/花、X2 认不出桌心时，**另票**美术出横构图。未开口 = 继续竖底横裁 |

装饰（烛、木饰）被裁掉 **可以**。宣称被桌布高对比纹吃掉、或毡心裁没只剩边框 = 线框失败，先改 `objectFit` 锚点 / 分区，再考虑新图。

|-------|------------|-------------|
| O1 | 进桌横屏；大厅仍竖 | 局内仍竖；或大厅被逼成必须横 |

| **页级**锁：进入 `pages/Table` 对主窗口 `setPreferredOrientation` → `LANDSCAPE` 或 `AUTO_ROTATION_LANDSCAPE` | 只改 `module.json5` `"orientation": "landscape"`（大厅也会横，O1 不过） |
| 离开 table **恢复 `PORTRAIT`**（或 `AUTO_ROTATION_PORTRAIT`） | 锁横后不恢复 |
| Ability 启动仍竖，服务冷启动大厅 | 启动即横再闪回竖 |
| 折叠内屏走 §4.2 L-fold，取向仍锁横 | `unspecified` 让系统转回竖桌 |

`module.json5` 全局建议 **保持 portrait**。横屏只靠窗口 API。
