| 可牺牲 | **左右木饰**、竖图顶/底装饰边。被 Cover 裁掉可以 |
| 不烤进底 | **荷官 bust**、**牌背** 是叠在桌上的控件（`lb_cmp_dealer` / `lb_cmp_pool` / `lb_cmp_card_*`），禁止 bake 进 `art_table_bg` |
| 控件安全 | 宣称、四座、手牌画在 **窗口安全矩形**，不要假设桌布顶/底装饰还在 |
| 挖孔 | 左右刘海压在桌布裁切边上即可；**主信息不画进 cutout**（LY1） |
| 新图 | **本批不新出横底。** 仅当 30%～70% 带内毡面空/花、X2 认不出桌心时，**另票**再议 |

宣称被桌布高对比纹吃掉、或毡心裁出 30%～70% 带 = 线框失败，先改 `objectFit` 锚点 / 分区，再考虑另票。

## 5. 验收对照（不另起闸）

### 5.1 本版布局验收（对照 10 · 线框加严 · 不冒充 10 闸号）

**10 X1 锁句（一字不改，本 PR 不改 10）：**  
「一眼看清四座+手牌+宣称+质疑/出牌。」

**与 X1 的关系（写死）：** 完整出牌 / 质疑 **流程闸** 仍听策划短文 / 10（常驻大双钮不是本批布局必选项）。本版 **布局验收** 以这些句为准，不另起冒充 10 的闸号：

1. **荷官+牌堆** —— bust 在 `dealPileAnchor` / `lb_cmp_pool` 上或旁，能指认；不得只剩槽。  
2. **手牌沉底留空**（R-LAND-3 **#59 再加严**）—— 贴**底安全区上沿**；上沿与 `dealPileAnchor` / `lb_cmp_pool` 有一眼能指的明显空隙；**手牌偏上贴中堆** = 失败。#58 裁半 / 半张出屏仍不过。  
3. **手牌水平中线锚**（11 挂点，挂在 R-LAND-3 / X1，**不另起闸号**）—— `lb_cmp_hand` 中线 = 桌面水平中线；5 张与 1～2 张中心点重合；左右对称余量肉眼接近；`selfDock` 不得挤成右偏。  
4. **稳态无大双 CTA** —— 不常驻大块「质疑」「出牌」双钮；垂直空间给手牌。

演示 **3～5 分钟**可读：竖厅 → **立刻锁横 + 加载** → 稳态横桌 →（可选）peek。出牌包 / 质疑入口本批可弱或暂隐；打开后的 X3 几何仍按 §2.3。失败短句：**10 §4 原句继续用于 10 闸**；下表是 **11 布局加严** 专用短句。

## 6. ArkUI 建议（只建议，零 ets）

### 6.1 Orientation / 窗口横屏锁定（O1 · 本版加严）

| 要 | 不要 |
|----|------|
| **点开桌当下**（进 `pages/Table` **同拍或更早一拍**）对主窗口 `setPreferredOrientation` → `LANDSCAPE` 或 `AUTO_ROTATION_LANDSCAPE` | 先 `toTable` 露出竖桌，再在 `aboutToAppear` 里拧横（**先进桌再拧横**） |
| `lb_ovl_match_load` 叠在 **已锁横** 的窗口上（仍复用该 id；可挂 lobby 路由内，但窗口取向已横） | 加载层在竖窗口播完再转；或加载时仍竖 |
| 离开 table **恢复 `PORTRAIT`**（或 `AUTO_ROTATION_PORTRAIT`） | 锁横后不恢复；或大厅也被锁横 |
| Ability 启动仍竖，服务冷启动大厅 | 启动即横再闪回竖 |
| 折叠内屏走 §4.2 L-fold，取向仍锁横 | `unspecified` 让系统转回竖桌 |

`module.json5` 全局建议 **保持 portrait**。横屏只靠窗口 API。禁止整应用 `"orientation": "landscape"`（大厅也会横，O1 不过）。

### 6.2 分区组件树

```
Stack  .id('lb_scr_table')
  Image art_table_bg          // Cover + 桌心锚（§4.3）
  Column  安全 padding（avoidArea → vp）
    Row     lb_cmp_topbar     // 宣称 + 倒计时 + 弱回开桌；可选弱入口；无大 bust
    RelativeContainer / Flex   layoutWeight(1)
        seat p2 / p3 / p1     // self 不进桌心环中轴；见底带左槽
        lb_cmp_dealer         // 默认 Visible；紧贴池上/旁；禁 None/0×0
        lb_cmp_pool + dealPileAnchor（量到的中心，不是 152,210）
        // 桌心下沿 ～ 手牌上沿 = 可见空隙（禁手牌偏上贴中堆）
    Stack / 底带
        selfDock              // 底带左侧独立槽；不进 hand 的 layoutWeight
        Row     lb_cmp_hand   // 贴底安全区上沿；水平中线=桌面中线；张数只左右伸缩
    // ※ 稳态不要再垫 Row CTA（旧 ≤14% 双钮删）
    // ※ 禁止 selfDock 与 hand 同一 Row + layoutWeight 挤成整排右偏
  PeekMaskOverlay             // Stack 顶，不占流
  lb_ovl_match_load           // 进桌轴内；横屏窗口；轴完卸
  // 出牌（后续）：bindSheet 侧栏 / Stack 右栏；面积 <50%
```

飞牌层坐标来自锚点测量（票 B）。Stub 不要插在桌心与手牌之间（会吃掉空隙）。
