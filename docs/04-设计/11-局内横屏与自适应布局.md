## 4. 安全区 · 断点 · 桌布横裁

### 4.1 刘海 / 手势条（LY1）

横屏刘海多在 **左或右短边**；手势条在 **底长边**。10：**`lb_txt_claim`、`lb_cmp_hand`、主 CTA（若露出）不得被刘海或底条裁掉、挡到点不到。**  
本版手牌 **贴底安全区** = 手势条 inset + **极小约束缝**（几乎齐平），不是贴物理底边；其下不允许大块空带。

| 区 | 要 | 不要 |
|----|----|------|
| 顶栏宣称 / 倒计时 | 加上沿 + **左/右 cutout**；文字收进安全矩形 | 宣称画进挖孔 |
| 左座 p3 / 右座 p1 | 头像中心在安全矩形内 | 头像一半在刘海里 |
| 手牌 | 底缘贴 **底安全区上沿**（手势条 inset + **极小约束缝**，几乎齐平）；环-手空隙 **24%** 窗口高（`HAND_RING_GAP`，**数字不动**）只吃心→牌，**不垫手下**；上沿与 `dealPileAnchor` / `lb_cmp_pool` 留一眼能指的大空隙；整带水平中线 = 桌面中线；`selfDock` 不压最左牌；self **仅** `art_player_idle` + 圆裁；bust+池在屏幕/桌面正中、仍贴池旁/上 | 沉到手势条下；或为避手势条 / 加大 `padB` 把整带顶进桌心（**手牌偏上贴中堆** / **加大 padB 顶高手牌**）；或底缘下剩大块空带 / 把 24% 垫手下（**手牌悬空偏高** / **底缘离底过大** / **手牌底缘离底过大**）；或为腾空隙把 bust 挤上顶边或顶离屏心（**荷官被挤上顶边** / **荷官离开桌心牌堆**）；或被 `selfDock` 挤成整排右偏 / **盖住叠住手牌**；或 **selfDock 叠铜框** |
