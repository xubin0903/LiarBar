## 5. 制作口径（相对 #28 的修补）

- 烛：只留暖色发光。棋盘灰 / 黑底 **不得**以高 alpha 出图。可略大于 256 留光晕。  
- BGM：低弦 + 慢拨 + 木，禁止单振荡垫。峰值守 −12 dBFS。  
- 环境：房间感；杯碰不得盖过 BGM。  
- 口播：拟人、近距、轻混响；句中逗号气口保留；禁干巴 TTS。  
- 脚手架 `gen_scaffold_assets.py` / `gen_lobby_sfx.py` **不要**盖本表文件。

重出烛：放好 `scripts/art_src/src_fx_candle.jpg` 后 `python3 scripts/gen_lobby_v3_art.py --candle-only`  
重出声：`python3 scripts/gen_lobby_v3_audio.py --polish`（需 `edge-tts`）
