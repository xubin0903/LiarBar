## 2. 色板依据（只抄风格板，不另发明色）

| Token | Hex | 用在本批 |
|-------|-----|----------|
| `tavern_bg` | `#1A120E` | 底、衣帽暗部 |
| `tavern_felt` | `#2C1814` | 桌心毡 |
| `tavern_panel` | `#3D241C` | 木框、招牌、按钮常态底 |
| `tavern_candle` | `#E8B86D` | 径向烛光、焰芯、描边高光 |
| `tavern_brass` | `#C4A46A` | 铜线、铆钉、帽带 |
| `tavern_paper` | `#F3E6C8` | 领/手套/招牌字 |
| `tavern_shadow` | `#0E1A22` | 四角冷暗、输入槽内凹 |
| `tavern_accent` | `#F0C14B` | 主按钮边 / 按下填充 |
| `tavern_danger` | `#C23A3A` | 领结点缀、吧台瓶（装饰，不改规则） |

制作手法：平涂 + 1 级暗面 + 径向烛光 + 木纹/铜线 + 轻噪点。bust / 按钮皮四角为真透明（straight alpha）。
