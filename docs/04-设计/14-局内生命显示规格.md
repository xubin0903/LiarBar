### 0.2 现挂缺口（对照，不改码）

现 `lb_scr_table` 座位旁生命是 **裸数字**（`Text(lives)`）。风格板与清单已预留酒杯/筹码皮，**未接到独立生命组件**。  
本线目标：酒馆 / 虚张声势皮的生命 **主读**；数字只作 **次读**（可藏、可旁注，不得再当唯一主信息）。

## 1. 目的

把「3 / 2 / 1 / 0」换成 **一眼能感到还剩几口气** 的酒馆生命显示。

- 主读：符号组（烛 / 筹 / 杯 / 牌记 —— **美术候选，UI 不点终稿**）。  
- 次读：阿拉伯数字，仅核对 / 无障碍，不得单独交差。  
- 三态必须可辨：**满血 / 残血 / 濒死**。可选第四态 **幽灵/出局**。  
- 自己与对手 **层级不同**；横屏小档仍须可读。

生命 **语义**（何为扣命、何为出局、何为胜）仍认 GDD §2.2。策划并行会签措辞；UI **不另写胜负规则**。

## 2. 信息层级

### 2.1 自己 vs 对手

| | 自己 `lb_cmp_life_self` | 对手 `lb_cmp_life_seat_pN` |
|--|------------------------|---------------------------|
| 位置 | 底带 / `selfDock` 近旁；**下手身份条**，不进手牌行 | 各座框近旁（头像下沿或内侧），不进桌心 |
| 体量 | **主生命**：符号更大、间距更松 | **次生命**：同构缩小，三态仍可指 |
| 数字 | 允许次读（如「2」旁注） | 默认不挂大号数字；小档可省略数字 |
| 动效 | 掉命反馈可略强（仍轻、短） | 同构更弱，避免抢宣称 / 荷官 |
| 禁区 | **不得**压 `lb_cmp_hand` 最左牌、不得进 hand 水平中线 | **不得**压 bust / 池 / 宣称 |

一眼验收：评委能指「这是我的命、那是他的命」，不靠读座位名才能分清。

### 2.2 三态（+ 可选幽灵）

规则仍是 3 命整数。UI 把剩余命 **映射** 成表现态。策划可改口播用词；映射表本线锁定给测试。

| 表现态 | 剩余命（GDD） | 主读意图 | 次读数字 |
|--------|---------------|----------|----------|
| **满血** | 3 | 三枚符号都「还在」；暖、稳 | `3` 可选 |
| **残血** | 2 | 一枚已灭/空/裂；还能撑 | `2` 可选 |
| **濒死** | 1 | 只剩一枚在喘；危，但不写成「已死」 | `1` 可选 |
| **幽灵/出局**（可选） | 0 | 符号全灭或去饱和；叠座位 `_ghost` | `0` 可藏 |

禁止只用红/绿换色交差三态。必须靠 **枚数 + 形变**（灭烛 / 空杯 / 裂筹 / 牌记翻面等，题材由美术会签）。

0 命行为仍认 GDD：出局 = 幽灵旁观，不可出牌 / 质疑。本线只画外观，**不扩旁观 UX**。

### 2.3 横屏小档可读

对照 11 L-small：环座已缩小。生命不得先被卸掉。

| 档 | 自己符号建议 | 对手符号建议 | 数字 |
|----|--------------|--------------|------|
| 常档横屏 | 单枚 **≥ 20vp**；三枚总宽约 72～96vp | 单枚 **≥ 14vp** | 自己可 12～14fp |
| L-small | 自己单枚 **≥ 16vp**；对手 **≥ 12vp** | 可收成贴座一列 | 对手数字可关；自己数字尽量留 |

失败：小档只剩看不清的细线点、或生命被卸成空。

## 3. 线框槽位（`lb_scr_table`）

横屏桌。生命是 **环上饰件**，不是底栏通栏。不改 11 手牌贴底数字。

```
┌─ 顶栏宣称 / 倒计时 ──────────────────────────────────────┐
│                          [p2 老千]                         │
│                         life_p2                            │
│                                                            │
│  [p3 杠精]          荷官 bust + 池          [p1 怂货]      │
│  life_p3            （禁挡）                 life_p1        │
│                                                            │
│  selfDock + life_self          ← 底带左槽，不压最左牌      │
│            ┌──── lb_cmp_hand ────┐                         │
│            │ 背 背 背 背 背      │  ← 生命不得伸进此带     │
└────────────┴─────────────────────┴─────────────────────────┘
```

| 槽 | 控件 | 锚 | 不得挡 |
|----|------|----|--------|
| 自己 | `lb_cmp_life_self` | `selfDock` / `lb_cmp_seat_self` **近旁**（头下或名旁）；底带左槽内 | `lb_cmp_hand`、最左 `lb_cmp_card_0`、确认条（见 15） |
| p1 | `lb_cmp_life_seat_p1` | `lb_cmp_seat_p1` 框下沿或内侧 | 荷官、池、顶栏 |
| p2 | `lb_cmp_life_seat_p2` | `lb_cmp_seat_p2` 框下沿（顶栏下，座仍上沿中） | 宣称、bust |
| p3 | `lb_cmp_life_seat_p3` | `lb_cmp_seat_p3` 框下沿或内侧 | 荷官、池、顶栏 |

3 人桌：缺座不挂生命。不把三座收成一排。

**叠层建议（只建议，零 ets）：** 生命跟座位同组，不进 `lb_cmp_hand` 的 `layoutWeight` 链，不进桌心 `tableHeart`。

**贴底硬修搁置：** 本线 **不** 用生命条去「垫高 / 沉底」手牌，**不** 改 `HAND_RING_GAP` / `padB`。确认条近底安全区上沿的可点口径只认 [15](./15-局内手牌触摸出牌规格.md)，**不**回绑 11 flush 闸。

## 5. 状态表与掉命反馈

### 5.1 稳态

| 态 | 自己 | 对手 | 可点？ |
|----|------|------|--------|
| 满血 | 三枚「在」；暖、稳 | 同构缩小 | 否（生命不是按钮） |
| 残血 | 两枚在、一枚灭/空 | 同上 | 否 |
| 濒死 | 一枚在；可微闪，不抢宣称 | 同上，闪更弱 | 否 |
| 幽灵/出局 | 全灭或去饱和；座位 `_ghost` | 同上 | 否；不挡旁观（旁观 UX 本线不扩） |

回血 / 加命：**本线不做**。不写治愈动画。

### 5.2 掉命轻反馈（只写意图 + 时序窗）

触发：`PENALTY` 已按 GDD 扣 1 命之后。本线 **不改** 扣谁、扣几命。

| 意图（题材会签后择一或组合） | 时序窗 | 说明 |
|------------------------------|--------|------|
| 摇 | **120～200ms** 轻位移；振幅小 | 自己略强于对手 |
| 灭（烛/焰） | **180～280ms** 收光 | 被扣的那一枚 |
| 裂（杯/筹/牌记） | **150～240ms** 裂纹或碎边 | 不要整桌抖 |

| 要 | 不要 |
|----|------|
| 只动被扣那一枚 + 所属座位 | 全屏闪红（质疑仍冻，不借惩罚做质疑皮） |
| 静默局：画面在、强震关 | 强震当唯一反馈 |
| 结束后落到新稳态（残血或濒死或幽灵） | 反馈后仍显示旧命数 |

音效：可复用已锁惩罚向槽（清单 / [13](./13-局内声场与伴奏规格.md) 结算向）；**本线不新造音频文件**。掉命专用 SFX 若要另开，走音频票，不进本 PR。

## 6. 无障碍

| 项 | 建议 |
|----|------|
| 色盲 | 三态靠 **枚数 + 形变**；禁止只靠红/绿 |
| 对比 | 符号相对桌布对比建议 **≥ 3:1**；次读数字用风格板 `tavern_paper`，不用灰贴灰 |
| 最小尺寸 | 见 §2.3；热区不是按钮，但评委须能 **指认**，不能小于建议 vp |
| 屏幕朗读（可选） | 组名「自己生命 / 怂货生命」+ 剩余整数；不读题材昵称当规则 |
| 静默局 | 不关生命画面 |

## 7. 失败短句（测试可抄）

合入 ≠ 终验。未会签勿按短句改 ets。

| # | 短句 | 不过 |
|---|------|------|
| F14-1 | **生命仍是纯数字** | 主读仍是裸 `3/2/1`，无符号组 |
| F14-2 | **三态不可辨** | 满血/残血/濒死靠色盲或凑近才分清；或 2 与 1 同形 |
| F14-3 | **挡手牌或荷官** | 生命压 `lb_cmp_hand` / 最左牌 / `lb_cmp_dealer` / `lb_cmp_pool` |
| F14-4 | **自己与对手层级混淆** | 四座生命同大、分不清谁是自己 |
| F14-5 | **小档生命不可读** | L-small 卸生命或缩成无法指认的点 |
| F14-6 | **数字当唯一完成** | 卸符号只留数字交差 |
| F14-7 | **改了命数规则** | 出现 ≠3 的默认命、回血、第 4 格当规则 |
| F14-8 | **绑了贴底硬修** | 为生命改 `padB` / `HAND_RING_GAP` / 重开 11 flush 闸 |

质疑入口被生命挡住、或生命票顺带做质疑四拍 = 一并打回（质疑仍冻）。
