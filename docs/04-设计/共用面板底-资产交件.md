### 3.1 画法

- 4× 超采绘制 → LANCZOS 缩 256。
- 铜边：竖向渐变 `tavern_candle` → `tavern_brass` → `tavern_mute`，圆角 mask。
- 木纹：`tavern_panel` ↔ `tavern_felt` 横向噪声（SEED_FINAL）；边缘 vignette 混 `tavern_bg`。
- 内细线：`tavern_candle` alpha 110。
- 配方与 `gen_art_drafts_23.py` 的 `panel()` 同族；**独立脚本**，不改 draft 生成器 / `draft_*`。

### 3.2 九宫

客户端：`Image.resizable({ slice: { left: 48, top: 48, right: 48, bottom: 48 } })`（API 由鸿蒙确认）。竖屏大厅宽 92%、横屏局内宽 36%～64% 同一张（22:109-110）。

## 4. 设置遮罩加浓（程序色，不出图）

对照 22:106 基线 `tavern_bg`（`#1A120E`）**55%～65%** 不透明。登录 §4.2：设置打开时再加浓一档、正文/滑条对比度不降。

| 场景 | 建议不透明 | 备注 |
|------|------------|------|
| 暂停 / 确认 / 快进 / 战绩 / 规则 等共用遮罩 | **55%～65%**（沿用 22:106；实现可取中值 **60%**） | 下层桌面仍可读「已暂停」 |
| **设置面板**打开时的遮罩 | **70%～75%**（推荐锁 **72%** = alpha ≈ 184/255） | 只加浓遮罩，**不**改 `art_panel_base` / 正文色；滑条与 `tavern_paper` 对比度保持 |

验收：「明显比现状更浓、控件仍可读」（登录 §4.2）。色值写在 23；22 线框由 UI 下次改版顺手回填一行即可（本岗不改 22）。

## 5. 生成

```bash
python3 scripts/gen_art_panel_base.py
```

依赖 Pillow（本次 12.3.0）；读感条标注字体 DejaVu Sans Bold（`/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf`，**Bitstream Vera 字体许可**（DejaVu 自己的改动属公有领域），**不是 OFL**；只用在 docs 读感条，media 不含文字）。Noto CJK 本脚本未用。脚本写 1 张 media + 读感条，并打印尺寸 / 字节 / sha256。不读不写任何其它 media、rawfile、`string.json`；不碰 `gen_art_drafts_23.py` 与 `draft_*`。
