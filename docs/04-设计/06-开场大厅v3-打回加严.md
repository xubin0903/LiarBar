## 3. 加严验收表（可勾选 · H1 三件套）

**先看后点。** 在 v3 §7 原表之外另勾。任一条失败 = **v3 过关仍暂停**。  
冷启动仍从 **桌面点图标**；不要热重载冒充。局内 / `demo_seed` / TC-19 **不扩验**。

### 3.1 R1 烛火融合（看）

叠层资源：`art_fx_candle`。只缩放焰，不缩放 `art_lobby_bg`、不缩放整屏（v3 §3.3 仍在）。

| # | **点什么** | **看什么** | **听什么** | 过 |
|---|------------|------------|------------|----|
| R1 | **不点**。停在 `lb_scr_lobby` 稳态 ≥3s，眼看近景烛（荷官区旁 / 景深近烛位） | 焰有 **软边 alpha**：边缘溶进 `art_lobby_bg`，读不出硬矩形。四角 / 画板外沿须透到底（能看见酒馆底，不是一块卡纸）。焰芯 `opacity` 在闪；**只焰层** `scale 1.00↔1.06` | 本条 **不听** 新 FX。禁止为烛加 beep | [ ] |

**失败（看见任一条即不过）：**

- 方砖 / 正方形贴片 / 能描出的硬矩形外框  
- 白底或黑底不透明板（纸板贴纸感）  
- 整块 overlay 不透明、挡死背景木纹 / 桌沿  
- 拿整屏或整张 `art_lobby_bg` 去做 `scale` 冒充焰动  

**给美术的切图底线（会签后出图，本 PR 不出资产）：** PNG 透明底；建议仍 256×256 内焰；画板四角 alpha=0；焰边用软擦，不要实心方罩。色仍锁 `tavern_candle` `#E8B86D`。挂点不变：`$r('app.media.art_fx_candle')`。

### 3.2 R2 悬停 / 焦点闪（看 / 点）

只验 **hover / focus**，**不要**用按下缩放交差。按压仍走 v3 §3.7 / 05 §E（主钮 `1→0.96` ≤80ms）。

控件（不新造）：

| 入口 | 已锁 / 已建议 id | 文案 |
|------|-----------------|------|
| 主 CTA | `lb_btn_quickstart` | 「快速开桌」 |
| 次级 | 热区建议 `lb_btn_peek_table`（03 / v3 已建议，**不是**本批新锁） | 「进桌看看」（`lb_str_nav_peek`） |

#### 给 UI / 鸿蒙的规格（按此实现）

| 项 | 口径 | 禁止 |
|----|------|------|
| 触发 | ArkUI **hover**（键鼠 / 预览器指针进入热区）**或** **focus**（`.focusable(true)` 后焦点落入） | 只做 press；只做 §3.4 那条 4～5s 稳态微光 |
| 到达 | 进入 hover / 获得焦点后 **80～120ms** 内高亮到可见 | 拖到 300ms+ 才勉强亮；或根本不亮 |
| 材质 | **铜边**（`tavern_brass` `#C4A46A` 或 `tavern_accent` `#F0C14B` 描边 / 外发光）**或** 高光层 `opacity` 闪到相对常态 **Δ ≥ 0.15**（例如常态 0.00→0.20，或 0.70→0.88） | 整钮闪白；整屏闪；换一张无关图 |
| scale | hover / focus 全程 **≤1.01** | 放到 1.04+ 冒充「有反馈」 |
| 离开 | 指针离开 / 失焦后 **80～120ms** 收回 | 卡住高亮不回 |
| 次级 | 「进桌看看」**同样要有**可见闪，可弱于主钮（铜边更细或 Δopacity 略小），但必须能看出来 | 主钮有、次级死静 |
| 静默 | `lb_tog_silent` 打开后：**视觉仍播**；**不**调 `lb_sfx_cta_tap`；**无**强震 / 触感 | 静默后连铜边也关；或悬停却出击打音 |
| 轴未完 | T6 前主钮仍 disabled，可不响应 hover 开桌；若可见，悬停闪允许做，**不得**因此 enabled | 轴未完悬停把桌开了 |

ArkUI 挂法（接口提示，不是新 id）：`onHover` + `focusable(true)` / `onFocus` / `onBlur`；用 `animateTo({ duration: 80～120, curve: Curve.EaseOut })` 改描边或高光 opacity。不要新控件、不要 `lb_btn_hover_*`。

| # | **点什么** | **看什么** | **听什么** | 过 |
|---|------------|------------|------------|----|
| R2a | 预览器 / 键鼠：指针移入 `lb_btn_quickstart` 热区（**先不要按下**）。无键鼠时：把焦点落到该钮（Tab / 无障碍焦点），**先不要激活** | **80～120ms** 内出现铜边或高光闪，scale ≤1.01。移出 / 失焦同样收回 | 非静默：**无必须音**（悬停不是 CTA 击打）。若误出 `sfx_cta_tap` = 与按压耦死，本条不过 | [ ] |
| R2b | 同样方式悬停或聚焦次级「进桌看看」（不要点成主 CTA） | 可见弱于主钮的同族闪（铜边或高光），不是死按钮 | 同上：悬停不应出击打音 | [ ] |
| R2c | 点 `lb_tog_silent` 打开 → 再做 R2a（悬停或聚焦，**不按下去**） | 铜边 / 高光 **仍在** | **无** SFX、**无**触感 | [ ] |

**失败（看见任一条即不过）：** 悬停 / 焦点完全无视觉变化；只用按下 `scale` 冒充本条；静默后视觉也没了；悬停就播 `lb_sfx_cta_tap`。

R2 正文只锁两钮。设置卡可点控件（`lb_tog_silent` / `lb_cmp_nick_field` / `lb_str_fill_last`）的感知展开见 [07](./07-大厅可点悬停与焦点.md)。**验收数字仍抄本表 R2**（07 的「1 帧」只是实现建议，不覆盖本窗）。

### 3.3 R3 BGM + 环境（听）

文件 / 调用点仍是 v3 已定：`bgm_lobby_night` → `lb_bgm_lobby_night`；`sfx_amb_tavern` → `lb_sfx_amb_tavern`。不新造槽。

| # | **点什么** | **看什么** | **听什么** | 过 |
|---|------------|------------|------------|----|
| R3 | **打开 App**（桌面点图标）。手离开，**不点**厅内按钮。听到 T2 起层后停在大厅稳态再听 ≥4s | 画面走到大厅即可，本条不验构图。确认未开静默 | 必须感到 **夜里还开着的酒馆房间**（分层的暖），不是一层瘦电子垫。须能 **分开指认**：垫乐（低弦 / 慢拍夜曲）≠ 房间（杯沿 / 木梁 / 极远模糊人声 至少一种）。两层都在，房间不是「几乎没有」 | [ ] |

**失败（听见任一条即不过）：**

- 薄电子垫 / 单振荡 loop，没有馆的温度  
- 房间层几乎听不见，或关到只剩一条垫

## 4. 失败短句（测试可直接抄）

出现任一条，**v3 不得过关**：

- R1：烛火是方砖 / 硬矩形 / 白黑底板，或整屏缩放冒充焰。

- R3：薄垫、房间几乎没有、两层不能分开指认、打回包原 loop。  
- R4：口播干 / 无演 / 复读机；或改了锁句。  
- 验收句缺听 / 看 / 点（H1）；单 beep 或仅缩放（H2）；静默馆里还响或字幕没了（H3）。  
- 未审落 ets / rawfile / 占位资产当通过。  
- 改了局内 / 规则 / 已锁控件名 / `lb_art_*`。
