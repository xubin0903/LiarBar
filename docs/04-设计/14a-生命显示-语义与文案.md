## 1. 主隐喻拍板：烛火

生命 = 桌上那簇火。满则旺，残则矮，濒死将灭，出局火灭。

| 剩余命（GDD，不改） | 14 表现态 | 本文口播档 | 挂在（**14 锁名**） |
|---------------------|-----------|------------|---------------------|
| 3 | 满血 `_full` / `_life_3` | **燃** | `lb_cmp_life_self` · `lb_cmp_life_seat_p1` `p2` `p3` |
| 2 | 残血 `_hurt` / `_life_2` | **弱** | 同上；单枚可用 `lb_cmp_life_pip_{0-2}` |
| 1 | 濒死 `_dying` / `_life_1` | **将灭** | 同上 |
| 0 | 幽灵 `_life_0` / `_ghost` | **灭** | 同上 + 座位 `_ghost` |

当面 **不挂** 辅读数字（**R-LIFE-1**：卸 `lb_txt_life_self` 主路径 / 禁止 `showDigit` 当面完成）。无障碍可读剩余整数。口播/字幕仍可说「还剩 2」，那不是座旁数字。枚数必须等于剩余命。

**art 认 14b：** 终验主读 `art_life_candle_body` / `flame_*` / `extinguish_*`。旧 `art_life_candle_{full,hurt,dying}` **暂留兼容一句**，终验认新分层。杯 / 筹仍备选，措辞仍说「火 / 燃 / 弱 / 将灭 / 灭」，不说 HP、生命值、血条。

## 2. 自己 vs 对手 · 语气

控件认 14：自己 = `lb_cmp_life_self`（近 `lb_cmp_seat_self`）；对手 = `lb_cmp_life_seat_pN`。

| | 自己 | 对手 |
|--|------|------|
| 层级 | **强提示** | **弱化**（14：同构缩小） |
| 语气 | 对你说：你的火、你还剩 | 陈述：那头、{昵称} 的火 |
| 掉命 | 可短字幕，贴自己生命组 | 座位闪一下，不占屏心、不大字喊命 |
| 将灭 | 「就剩芯了」可以更紧 | 仍弱，不恐吓 |

禁止层级颠倒（对齐 F14-4）：自己弱成看不清、对手大字「还剩 n 命」。  
禁止系统腔。面子分仍弱化，不当第二套命。

## 3. 掉命局内提示（样例）

**不改、不覆盖**已锁裁定句：

- `lb_str_dlr_judge_success`：有假。{被质疑者} 掉 1 命。  
- `lb_str_dlr_judge_fail`：全真。{质疑者} 掉 1 命。  
- `lb_str_dlr_penalty_life`：{昵称} 还剩 {命} 命。  
- `lb_str_dlr_penalty_out`：{昵称} 出局，旁观看戏。

氛围句在裁定之后或不挡裁定。静默局口播可关、字幕仍在。质疑仍冻：不写四拍新词。

| 对象 | 掉完后 | key 建议 | 样例（酒馆虚张声势，不油腻） |
|------|--------|----------|------------------------------|
| 自己 | 2 | `lb_str_life_self_2` | 你的火矮了一截。还剩 2。 |
| 自己 | 1 | `lb_str_life_self_1` | 就剩芯了。看住。 |
| 自己 | 0 | — | 走已锁出局句 |
| 对手 | 2 | `lb_str_life_other_2` | {昵称} 的火晃了晃。 |
| 对手 | 1 | `lb_str_life_other_1` | {昵称} 那头只剩芯。 |
| 对手 | 0 | — | 走已锁出局句 |

不要：「亲，生命值只剩一滴～」「加油哦」。不要惨叫长文。  
对手句不重复念数字。裁定句与氛围句禁止同时抢屏心。

常驻主读：自己 / 对手都只留烛枚数（自己更大）。**禁止**再叠可见 `lb_txt_life_self`（R-LIFE-1）。

## 3a. 熄灭（0 命瞬间 · 对齐 R-LIFE-4）

**0 命 = 灭**（§1 已有口播档，本节省「瞬间」）。不覆盖已锁裁定句：

- `lb_str_dlr_judge_success` / `lb_str_dlr_judge_fail` / `lb_str_dlr_penalty_life`  
- **`lb_str_dlr_penalty_out`：{昵称} 出局，旁观看戏。** ← 0 命仍走这句，不另造胜负

**熄灭瞬间（写死，时序认 14b）：** 被扣的那一枚从「将灭」收成「灭」；枚数 = **0**。座位进幽灵观感（14 `_life_0` / `_ghost`）。走 `art_life_candle_extinguish_*` 短序列，总窗 **180～320ms**，**禁 0ms 硬切**（R-LIFE-4）。非静默：起势复用 `lb_sfx_card_flip`，灭尽播 **`lb_sfx_life_extinguish`**（14b §2.3；本补刀 SFX **仅此两槽**）。

| 要 | 不要 | 对齐 |
|----|------|------|
| 最后一枚收光；组上再无燃 / 弱 / 将灭主读 | 0 命座位仍挂旺火 / 半烬 / 将灭芯 | S14-4 · R-LIFE-4 |
| 灭与出局同步：火灭 = 幽灵旁观 | 火灭了座位未进幽灵，或反过来 | S14-5 |
| 烛身＞焰（柱是主体） | **火苗比烛身还高** / 焰压烛 | R-LIFE-2 |
| 有收光过程 + `lb_sfx_life_extinguish` | 只切图假；熄灭无过程 / 无声（静默局除外） | S14-8 / S14-9 · R-LIFE-4 |
| 氛围句在裁定之后或不挡裁定 | 用氛围句替换 `lb_str_dlr_penalty_out` | — |
| 自己略紧、对手仍弱（同 §2） | 自己无句、对手全屏喊「死了」 | S14-3 |

氛围样例（酒馆虚张声势，不油腻；**在已锁出局句之后**，可关）：

| 对象 | key 建议 | 样例 |
|------|----------|------|
| 自己 · 熄灭 | `lb_str_life_self_out` | 你的火灭了。坐下看。 |
| 自己 · 熄灭（更紧） | 同上，备选 | 芯也收了。 |
| 对手 · 熄灭 | `lb_str_life_other_out` | {昵称} 那头灭了。 |
| 对手 · 熄灭（更弱） | 同上，备选 | {昵称} 的火收了。 |

不要：「亲，生命值归零啦～」「加油哦还能复活」。  
**不改 3 命。不发明回血。不挡手牌 / 荷官。** 调试 −1 见 **附录 A** 与 [14b R-LIFE-5](./14b-局内生命显示-打回加严.md)。

对齐既有 **S14 / F14 / R-LIFE**，勿另起胜负规则。剩 1 人有命 → 胜，仍认 GDD §2.2。

## 附录 A · 调试扣血（文案 / 短句 · 对齐 R-LIFE-5）

> **用途：** 开发 / 展示 / Rebuild 用「强制 −1 命」。**不是**正式局内玩法。  
> **默认隐藏。** 打开后选座位扣 **1 滴**，立刻走 [14b R-LIFE-4](./14b-局内生命显示-打回加严.md) 熄灭时序 + `lb_sfx_life_extinguish`。  
> 线框 / 选座交互认已合 [14b §3](./14b-局内生命显示-打回加严.md)。本文只锁文案与失败短句。  
> 禁改 3 命。质疑仍冻。合入 ≠ 终验。

### A.1 硬闸（对齐 14b）

1. **只扣 1。** 选一座、确认一次 = −1，不连扣、不加命。  
2. **立刻走熄灭**（§3a + **R-LIFE-4**：`extinguish_*` · 180～320ms · 禁硬切）。落到 0 = **灭**、枚数 = 0、幽灵同步。  
3. **SFX 仅两槽：** 起势 `lb_sfx_card_flip`，灭尽 `lb_sfx_life_extinguish`（14b §2.3）。静默局画面在、两槽关 = 过。  
4. **禁改 `lives_default`。** 映射：3 **燃** / 2 **弱** / 1 **将灭** / 0 **灭**。  
5. **质疑仍冻。**  
6. **正式包默认不露**（R-LIFE-5 只打调试包）。

### A.2 锁名与文案（写死 · 认 14b）

| 项 | 锁 |
