## 1. 语义拍板

### 1.1 主隐喻：烛火（已拍板）

生命 = 桌上自己的那簇火。命还在，火还在；命掉，火矮；出局，火灭。

| 剩余命 | 隐喻档 | 口播 / 辅读用词 | 控件态（已有，不新造） |
|--------|--------|-----------------|------------------------|
| 3 | **燃** | 三簇都旺 / 火还满 | `_life_3` |
| 2 | **弱** | 矮了一截 / 两簇 | `_life_2` |
| 1 | **将灭** | 就剩芯了 | `_life_1` |
| 0 | **灭** | 火灭了（出局 / 幽灵） | `_life_0` / `_ghost` |

**辅读必须保留数字。** 隐喻是主感觉，数字是「还剩几命」的硬可读。禁止做成只有气氛、数不清剩余命。

GDD §9.1：各自剩余命 = **永远可见**。本线只规定怎么说、怎么分层，不把命藏进二级页。

### 1.2 备选「杯盏」（一句带过）

现挂资源有 `art_life_cup_full` / `art_life_cup_empty`（02 映射）。**杯盏（满 / 残 / 空）仅作备选视觉槽**，兼容已有切图；**语义主锁烛火**。本 PR 不改 `art_*`、不强制本轮换资产。UI [14](./14-局内生命显示规格.md) 把烛/筹/杯/牌记列为美术候选、不点终稿——**措辞以本文烛火为准**；14 的 `lb_cmp_life_*` 槽位与三态表仍认。

桌上已有 `art_fx_candle` / `art_fx_candle_stare`（点名盯梢）。生命隐喻与烛火家族同语，避免再发明「血条 / HP / 爱心」。

## 2. 自己 vs 对手 · 信息层级

| | 自己（`lb_cmp_seat_self`） | 对手（`lb_cmp_seat_p1` / `p2` / `p3`） |
|--|---------------------------|----------------------------------------|
| 层级 | **强提示** | **弱化** |
| 常驻 | 烛火档 + **数字紧挨着**，一眼能答「我还剩几」 | 小焰 / 小点 + 数字作辅，不抢宣称与荷官 |
| 语气 | 对你说话：你的火、你还剩 | 陈述别人：那头、{昵称} 的火；不喊「小心他只剩 1 条命！」大字幕 |
| 掉命 | 自己一侧更亮、更近、可短字幕 | 座位上闪一下即可，不占屏心 |
| 将灭 | 允许更强提示（芯还在，看住） | 仍弱：小焰将灭，不弹全屏恐吓 |

**禁止层级颠倒**：自己只剩一个看不清的小点、对手头上挂大字「还剩 3 命」。  
**禁止**用「HP-1 / 生命值」系统腔。正式名仍是 **谎馆**，按钮不写「骗子酒馆」。

面子分继续弱化（GDD §9.1），不要做成第二套命。

## 3. 局内提示短句（掉命 · 酒馆虚张声势，不油腻）

荷官 **裁定句已锁**，本线不得润色、不得替换：

- `lb_str_dlr_judge_success`：有假。{被质疑者} 掉 1 命。  
- `lb_str_dlr_judge_fail`：全真。{质疑者} 掉 1 命。  
- `lb_str_dlr_penalty_life`：{昵称} 还剩 {命} 命。  
- `lb_str_dlr_penalty_out`：{昵称} 出局，旁观看戏。

下列是 **氛围层**（字幕条 / 生命旁注 / 可选荷官第二句），在裁定句之后或不挡裁定句。静默局：口播可关，**字幕仍在**（与荷官规格 C7 一致）。质疑仍冻：本线不写质疑四拍新台词。

### 3.1 自己掉命

| 掉完后剩余 | key 建议 | 字幕（写死样例） |
|------------|----------|------------------|
| 2（燃→弱） | `lb_str_life_self_2` | 你的火矮了一截。还剩 2。 |
| 1（弱→将灭） | `lb_str_life_self_1` | 就剩芯了。看住。 |
| 0 | 不另造 | 走已锁 `lb_str_dlr_penalty_out`（自己出局时 {昵称}=你） |

不要：「亲，你的生命值只剩一滴啦～」「加油哦」。不要惨叫、不要破防长文。

### 3.2 对手掉命（弱化）

| 掉完后剩余 | key 建议 | 字幕（写死样例） |
|------------|----------|------------------|
| 2 | `lb_str_life_other_2` | {昵称} 的火晃了晃。 |
| 1 | `lb_str_life_other_1` | {昵称} 那头只剩芯。 |
| 0 | 不另造 | 已锁出局句 |

对手句 **不重复念数字**（数字在座位辅读上已经在）。需要硬信息时让位给已锁「{昵称} 还剩 {命} 命。」——氛围句与裁定句二择一叠、或裁定在先、氛围在座位，禁止两句同时抢屏心。

### 3.3 常驻辅读（非掉命瞬间）

| 对象 | key 建议 | 默认中文 |
|------|----------|----------|
| 自己 | `lb_str_life_self_aux` | 你 · {命} |
| 对手 | `lb_str_life_other_aux` | {命} |

常驻自己带「你」，对手只留数字（或极小焰）。UI 14 可把 `{命}` 做成 3/2/1 点，但 **点的数量必须等于剩余命**，不能只有燃/弱/将灭的颜色差、数不清几簇。

## 4. 文案约束（一句即可）

**生命显示不得挡住手牌条（`lb_cmp_hand`）与荷官位（`lb_cmp_dealer`）。**  
自己的强提示放在 self 座位一带，不压手牌正面、不盖宣称、不盖荷官胸像。对手弱化贴座位，不向屏心抢位。横屏贴底硬修本轮搁置，本文不借「生命要贴底」重开 11/12。

不改每人 3 命；不把命写成酒量条玩法（GDD 可选非 MVP，本线不做）。

## 5. 失败短句（给测试抄 · 写死）

| ID | 失败短句（测试标题 / 打回用语） | 判定 |
|----|--------------------------------|------|
| L1 | **只剩数字无隐喻** | 生命区只有阿拉伯数字或「HP」，没有任何烛火 / 燃弱将灭的酒馆读法（含文案或约定视觉档）。杯盏占位若完全当进度条、无火的说法，也算 |
| L2 | **看不出还剩几命** | 4 秒内指认不出某座还剩 3 / 2 / 1 / 0。只有颜色气氛、簇数与数字对不上 |
| L3 | **自己与对手层级颠倒** | 自己弱、对手强：自己数不清，对手大字喊命；或自己掉命无强提示、对手掉命全屏喊 |

过关：自己常驻能读出数字 + 燃/弱/将灭之一；对手能弱读出剩余命；掉命不盖手牌 / 荷官；裁定句未被本线改字。
