### 3.1 补句（写死）

**R-LAND-1 · 进桌立刻横：** 「立刻」= 主钮抬起后叠层第一帧已横，中间不得插入可操作竖桌。禁止整应用 `module.json5` 一刀切横。加载不可跳过、毫秒窗、连点 = **复用 L1 加载**（仍勾 L1a–L1e），不要在本表重验一遍数字。  
过关再加严：**进桌后横屏稳定不闪**；朝向只在进桌/离桌设置，禁止稳态轮询反复 `setPreferredOrientation`；禁止 200ms 级无差别 State 全树刷导致可见闪。进桌后桌面闪烁 / 朝向或布局反复跳动 = 失败。根因 ②③（手牌未沉底 / 中心漂移；self 压牌）已由 **R-LAND-3** + [11](./11-局内横屏与自适应布局.md) **self 不压牌**覆盖，**不另起闸、不重写那两句**。

**R-LAND-2 · 荷官+牌堆：** 只用已有 **`art_dealer_bust_idle` / `art_dealer_bust_announce`** 胸像裁切放桌心。装饰可缩小，**不可卸掉**、**不新出全身**。空 `Image` / 占位框 / 只有 `lb_cmp_pool` 无荷官 = 不过。`dealPileAnchor` 仍叠在荷官手边或池上（08 §2.1）。11 小屏「隐 bust 只留字幕」对本批 = 失败。池旁张数（工程现挂 `poolText`）须贴 `lb_cmp_pool` / 锚点旁或上，**不得**落到 `lb_cmp_hand` 下；bust 在但池空、张数文案下手牌带 = 仍打回本条。

**R-LAND-3 · 手牌沉底留空 + 水平中线锚（对齐 11 §2.1.2 两闸 · 不另起闸）：** 「空隙」用眼睛能插进一根指头的缝即可，**不写死 px**（LY1）。过关写死：**手牌贴底安全区**（再沉至底安全区上沿）；**水平中心锚固定；张数变化只左右伸缩，中心不漂**（中线 = 屏幕/桌面水平中线；**不被 `selfDock` 挤走**）。手牌仍靠近桌心 / 未沉底 = 失败。整排相对屏幕中线右偏（张数变中心漂移）= 失败。`selfDock` 与 hand 同一权重链把牌排挤右 = 仍打回本条。11 等价短句可打回：**手牌偏上贴中堆** / **手牌整排右偏**。手牌贴池、或被大底栏顶到池边 = 与 R-LAND-4 一并打回。稳态手牌须 **整张** 落在底边安全区内；被底边裁成半张 / 半张出屏 = 失败（不只「贴中堆」）。

**R-LAND-4 · 稳态无大双 CTA：** 加严的是 **稳态桌**。打开 `lb_sheet_play` 仍走 X3（面积 < 50%），本批不重做。`lb_btn_challenge` / `lb_btn_play` **锁名保留**；可弱、可收进溢出，**不可**再占一条大双底栏。不得用本条要求重做质疑四拍。

**R-LAND-5：** 媒体 id **一字不改**：`art_ai_timid_idle` · `art_ai_shark_idle` · `art_ai_karen_idle`。挂点只认 `lb_cmp_seat_p1` / `_p2` / `_p3`（映射见 §0.1）。源 **256×256 透明方**（本批锁；清单旧 216 让位）。过关：三 id 对得上人格 **且** 不是方块减号。工程在美术未到前也 **禁止**方块减号当完成。`*_hold` / `*_break` **本批不交、不验**（质疑仍冻）。禁止为分人去扩桌布 / 牌面 / 四拍图。  
**环位写死（对照 11 §2.2 · 不另起闸）：** 左 `p3` karen 杠精 · 上 `p2` shark 老千 · 右 `p1` timid 怂货 · **下手 `lb_cmp_seat_self`**。老千不见 / self 跑到中上 / 占位黑块减号头像 = 不过。
