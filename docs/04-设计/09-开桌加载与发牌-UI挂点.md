## 2. L1 加载层（写死 · 对照 08 §1.2 / §1.3）

控件：**`lb_ovl_match_load`**。

### 2.1 常量

| 常量 | 值 (ms) | 对照 08 | 禁止 |
|------|---------|---------|------|
| `MATCH_LOAD_MS_DEFAULT` | **1100** | 默认总长 | 「约 1 秒」交差 |
| `MATCH_LOAD_MS_MIN` | **800** | 验收下限 | <800 闪进桌 |
| `MATCH_LOAD_MS_MAX` | **1500** | 验收上限 | >1500 还停在转圈 |
| 跳过 | **不可跳过**（MVP） | H1 / L1b | 再点一次秒进桌 |

起算点（08）：主钮抬起且叠层第一帧可见。大厅 CTA 击打 ≤80ms **不计入** 1100ms。  
课设包默认应落在 **1100ms ±100ms**，且必须落在 800～1500。

### 2.2 衔接与防闪白

```
lb_btn_quickstart press（05 §E，不改）
  → 立刻盖上 lb_ovl_match_load（仍在 lb_scr_lobby）
  → L-0～L-4（默认 1100ms）
  → T01 + 切 lb_scr_table
  → DealFx.play(opening)
```

| 要 | 不要 |
|----|------|
| overlay 底 `tavern_bg` `#1A120E` | **1 帧闪白**；默认白 `Navigation` |
| **先盖后切**（08：叠层在 lobby 内播完再 `toTable`） | 先看到空桌再盖层；一点就 T01 |
| 桌布 / 牌堆语义（L-1 / L-2） | **单转圈**交差；大厅五分区再播一遍 |
| 轴内 CTA `_disabled`，连点不开关层、不开第二桌 | 「再点一次秒进桌」 |

### 2.3 拍表 L-0～L-4（对照 08 §1.3 · 默认 1100ms）

拍内可微调；**L-4 必须落在 800～1500ms，默认 1100**。

| 拍 | 时刻（默认 1100ms） | 看 | 听 | 点 |
|----|---------------------|----|----|----|
| **L-0** | 0ms | `lb_ovl_match_load` 盖住大厅；`lb_btn_quickstart` `_disabled` | 大厅 `sfx_cta_tap` 可已在响（05 已锁） | **不要再点**。误点不得开第二桌、不得关叠层 |
| **L-1** | 0～200ms | 桌布 / 毡面从牌桌锚点展开（语义：桌子铺好了） | `sfx_match_open` → **`lb_sfx_match_open`** 同起（±40ms） | 不点 |
| **L-2** | 200～750ms | 牌堆在荷官 / 中央锚点码齐（语义：牌来了）。座位可亮，**不发牌** | `lb_sfx_match_open` 尾响自然落；**无**第二记 CTA | 不点 |
| **L-3** | 750～1100ms | 可选荷官口型 / 轻点头（口播非硬门槛）。叠层开始让出桌面 | 无新击打。可选 `vo_*` **不验收** | 不点 |
| **L-4** | 1100ms | 切 `lb_scr_table`；座位 / 牌堆 / 手牌空位可辨 | 无进桌 beep | 仍不可出牌、不可质疑 |

### 2.4 ArkUI（加载层）

| 要 | 不要 |
|----|------|
| `Stack` 全屏；`.id('lb_ovl_match_load')` | 新 `NavDestination` / `lb_scr_*` |
| 底 `tavern_bg`；装饰 `tavern_candle` / `tavern_brass` | 白底系统圈 |
| 盖上：首帧已不透明，或短 `animateTo` EaseOut | 等路由完成再淡入 |
| **`TransitionEffect`：** 仅 overlay **自身** opacity | 整页共享转场（易闪白） |
| `hitTestBehavior` 挡住下层 | 穿透连点开第二桌 |

## 3. D1 发牌（写死 · 对照 08 §2）

开局与重建 **复用同一 `DealFx`**。

### 3.1 常量（抄表）

```
T_card     = 220ms          // 窗 180～260；课设演示必须用默认
T_stagger  = 55ms           // 窗 40～70；从上一张落地起算
T_deal     = N × T_card + (N − 1) × T_stagger
           = 20 × 220 + 19 × 55
           = 5445ms         // 窗 4000～6000
```

| 常量 | 默认（写死） | 窗 | 禁止 |
|------|--------------|-----|------|
| `T_card` / `DEAL_CARD_MS_DEFAULT` | **220ms** | **180～260** | 0ms 闪现；改张数凑时长 |
| `T_stagger` / `DEAL_STAGGER_MS_DEFAULT` | **55ms** | **40～70** | 按起飞重叠算间隔 |
| 间隔算法 | **串行**：上一张 **落地后** 再隔 `T_stagger` 起飞下一张 | — | 开局用重叠；座间长停冒充串行 |
| `T_deal` | **5445ms** | **4000～6000ms** | <4000 快进；把 L1 1100 加进本段 |
| 可量间隔（08 D1g） | 落地(i)→起飞(i+1) ∈ **40～70**（默认 55） | 同左 | 量不到 / >70ms 连成一条 |

验收墙钟 = **第一张起飞 → 最后一张落地**。**不要**把加载 1100ms 算进 `T_deal`。

### 3.2 路径与座序（写死）

```
dealPileAnchor（桌心：dealer 手边 / pool 上）
    → 顺时针、从真人起、一张一张绕桌
         第 1 张 self → 第 2 张 p1 → 第 3 张 p2 → 第 4 张 p3 → … 绕满 5 圈
```

| 座 | 锁名 | 落点 | 朝向 |
|----|------|------|------|
| 自己 | `lb_cmp_seat_self` + `lb_cmp_hand` | `lb_cmp_card_0` … `lb_cmp_card_4` | **牌背**；落座可 ≤80ms 轻压，勿自动翻面 |
| 下家 | `lb_cmp_seat_p1` | 头像下沿内侧小叠 | 只背 |
| 对家 | `lb_cmp_seat_p2` | 同上 | 只背 |
| 上家 | `lb_cmp_seat_p3` | 同上 | 只背 |

禁止「先给一人发完 5 张再下一位」。幽灵 **不发**。3 人桌仍从真人起，发 15 张（单张时长不另发明）。  
先手出牌 **不是**发牌第一张的人（规则已锁，本文不改）。

### 3.3 单张 transform

飞行中同时：位移（锚点→槽心）+ 旋转（落地收回）+ 缩放（从小到槽；自己满槽、对手紧凑背）。  
`animateTo({ duration: T_card, curve: Curve.EaseInOut })`。禁止 spring 大弹跳、禁止整桌 `scale` 冒充发牌。  
**发牌不用 `TransitionEffect`。**

### 3.4 Z-order

正在飞的那张最高（建议 `zIndex = 1000 + dealIndex`）；同槽后到在上。L1 在发牌前已卸。

### 3.5 重建（写死下限）

| 项 | 口径 |
|----|------|
| 组件 | **同一 `DealFx`**；`mode=rebuild` |
| L1 | **不重走** |
| 座序 | 仍从 self 起顺时针一张一张绕；只给存活 |
| 总长 | **`T_rebuild ≥ 0.60 × 本局开局实测 T_deal`**（目标 60%～75%） |
| 建议缩短 | `T_card=180`、`T_stagger=40`，仍串行。4 存活默认 `20×180+19×40=4360ms`（相对 5445 ≈ 80%，满足 ≥60%） |
| 仍须有 | 牌背飞行 + 每张 `lb_sfx_deal_card`（静默无声、画面仍播） |

### 3.6 发完

最后一张落地 → **≤250ms** 内 `DEAL_DONE` → `CLAIM`。飞牌期不得公布宣称、不得开放出牌（08 D1d）。
