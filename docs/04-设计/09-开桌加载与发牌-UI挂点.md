## 2. L1 加载层接口（骨架）

控件：`lb_ovl_match_load`。与大厅 CTA **按下之后**衔接。

```

  → 立刻盖上 lb_ovl_match_load（仍在 lb_scr_lobby；对照 08）
  → L1 轴（时长 **未锁，等 08**）
  → 切 lb_scr_table
```

### 2.1 必须具备（与毫秒无关）

| 要 | 不要 |
|----|------|
| overlay 底 `tavern_bg` `#1A120E`（可叠毡面，仍是褐黑） | **1 帧闪白**；默认白 `Navigation` |

| 进度 / 循环可作暗示，**不能代替**桌布/牌堆 | 白底转圈 |
| 轴内主钮 `_disabled`，连点不开关层、不开第二桌 | 「再点一次秒进桌」（08：MVP 不可跳过，**待 08 校准是否维持**） |

### 2.2 拍表骨架（时刻栏 = 对照 08，未锁）

## 3. 发牌动效接口（骨架）

开局与重建 **复用同一 `DealFx`**（程序本地名，不是新控件 id）。

### 3.1 单张 transform（属性锁 · 时长未锁）

飞行中同时做三件事（缺一 = 路径不可见）：

| 属性 | 接口 |
|------|------|
| 位移 | `dealPileAnchor` → 目标槽心 |
| 旋转 | 飞行中有倾角，落地收回（自己手牌可留极小扇角） |
| 缩放 | 从小到槽尺寸；自己满槽、对手紧凑背 |

曲线建议：`animateTo` + `Curve.EaseInOut`。**禁止** spring 大弹跳、禁止整桌 `scale` 冒充发牌。  
**单张毫秒窗：待策划 08 D1 校准。****未锁，等 08。**

### 3.2 Stagger（算法对照 08 · 数字未锁）

| 项 | 09 接口 | 数字 |
|----|---------|------|
| 开局序 | 一张一张绕桌：self → p1 → p2 → p3，发满 `hand_size_default`（只引用，不改 5） | — |
| 开局间隔算法 | **对照 08：串行**——上一张 **落地后** 再隔 stagger 起飞下一张 | **stagger 毫秒：未锁，等 08。** 对照 08：40～70，默认 55 |
| 实现 | 每张独立 `animateTo`，轴时刻错开 | 不要一条动画串完当「有 stagger」 |
| 重建 | 同一组件、同一序；跳过 L1；缩短参数 | **倍数未锁，等 08。** 对照 08：≥ 开局实测 × 0.60 |

**不要**把「起飞重叠、总长约 1s」写成 09 完成口径——那是 08 D1c 对照失败句。最终是否维持串行 / 4～6s，**等 08 校准**。

### 3.3 Z-order

| 层 | 规则 |
|----|------|
| 桌底 / 座位 / 池 | 低于飞行牌 |
| 正在飞的那张 | 最高（建议 `zIndex = 1000 + dealIndex`） |
| 已落入同一槽 | 后到的在上 |
| L1 overlay | 发牌开始前已卸；不要盖死路径 |

### 3.4 发完

- 事件对照：最后一张落地 → `DEAL_DONE` → `CLAIM`（08 D1d）。
- 自己手牌默认 **牌背**；揭开仍是长按 `lb_cmp_peek_mask`（对照 08：发牌期不教看牌）。
- 中央池本手仍空，直到第一手出牌。

### 3.5 ArkUI（发牌）

| 问题 | 建议 | 不要 |
|------|------|------|
| 单张怎么动 | 每张 `animateTo({ curve: Curve.EaseInOut })` 写 translate / rotate / scale | 用 `TransitionEffect` 做弧线（控不了路径 / z） |
| stagger | 轴时刻或 `setTimeout`；**按 08 校准后的落地后再隔** | 起飞重叠却当 D1 完成（08 对照失败） |
| 落点 | `getRectangleById('lb_cmp_card_0')` 等；对手用 `lb_cmp_seat_p*` | 与锁名无关的魔法数 |
| 重建 | `DealFx.play({ mode: 'rebuild' })` | 复制一份 `RedealFx.ets` |
| `TransitionEffect` | **发牌不用** | 整页共享转场 |

时长参数名可先占位（值等 08）：`DEAL_MS_CARD` / `DEAL_MS_STAGGER` / `DEAL_REBUILD_SCALE`。  
**未锁，等 08。** 对照 08 §7：`220` / `55` / `0.60`。
