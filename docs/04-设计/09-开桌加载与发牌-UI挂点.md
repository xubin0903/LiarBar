## A. 与大厅 CTA 的衔接（按下 → L1，禁止闪白）

对照 [05 §E](./05-开场大厅v3-UI动效挂点.md)：`lb_btn_quickstart` 按下 `scale 1→0.96` **≤80ms**，非静默出 `lb_sfx_cta_tap`。  
**本文从按下被接受、开桌逻辑成立之后写起。** 不改 05 的 80ms / R2。

```
lb_btn_quickstart press（05 §E，≤80ms）
  → 同一手势内：lb_ovl_match_load 已盖上（tavern_bg，opacity 到 1）
  → 再切 lb_scr_table（或 table 在 overlay 底下预挂）
  → L1 窗走完（默认 1100ms，clamp 800～1500）
  → overlay 淡出
  → D1 发牌（同一 DealFx）
```

| 入口 | 是否走 L1 | 备注 |
|------|-----------|------|
| `lb_btn_quickstart` | **是** | 主路径；与 05 按压衔接 |
| `lb_btn_start`（改桌规后开打） | **是** | 同一覆盖层，不另造 overlay id |
| `lb_btn_again`（再来一局） | **是** | 开桌类入口；不要闪一下空桌 |
| `REDEAL_STALL` 重建发牌 | **否** | 已在 `lb_scr_table`；只走缩短 D1 |
| 大厅「进桌看看」 | **否** | 桌预览；局内不在本文验收（05 已锁） |

**禁止 1 帧闪白**（失败即打回）：

| 要 | 不要 |
|----|------|
| overlay 底 = `tavern_bg` `#1A120E`（可叠极弱毡面，仍是褐黑） | 默认白页 / 系统白 `Navigation` 露一帧 |
| **先盖后切**或 **table 首帧已带 overlay opacity=1** | 先看到空 `lb_scr_table` 再盖层 |
| 进度 / 循环叠在褐底上 | 白底转圈、闪一下 lobby 再闪 table |
| 淡入 ≤80ms 或首帧已满不透明 | 用会露白底的 `TransitionEffect` 整页共享转场 |

01 §4.4「切到发牌 300ms 桌面放大」仍是线框占位。**防闪白以本层 overlay 为准**，不要用那 300ms 切白页冒充 L1。  
01 入座 0.4～0.8s（可跳）**不替代** L1。入座可在 overlay 下播或跳过；用户看见的开桌等待 = 本层。

## B. 程序常量（给 `DealFx` / 加载层抄）

08 未合。会签后若 08 L1/D1 数字不同，**只改本表**，不要在业务 PR 里另写一套。

### B.1 L1 加载层

| 常量 | 值 (ms) | 对照 | 禁止 |
|------|---------|------|------|
| `LOAD_MS_MIN` | **800** | 策划窗下限（08 L1 未合） | 短于 800 当完成（会闪切） |
| `LOAD_MS_MAX` | **1500** | 策划窗上限 | 拖成冷启动 3.8s |
| `LOAD_MS_DEFAULT` | **1100** | PM 默认建议 | 写死 0 / 1 帧 |
| `LOAD_MS_FADE_IN` | **80** | 与 CTA 按压同级；首帧满不透明也合法 | 等路由完成再淡入 |
| `LOAD_MS_FADE_OUT` | **180** | 露出已就位的桌 | 淡出时露白 |
| `LOAD_MS_LOOP` | **700** | 进度 / 循环一拍建议 | 整屏闪白呼吸 |

缩 / 拉轴：只在 **800～1500** 内缩进度循环，**不得删**覆盖层本身（删层 = 闪白风险）。

### B.2 D1 发牌（开局）

| 常量 | 值 | 对照 | 禁止 |
|------|-----|------|------|
| `DEAL_MS_CARD` | **220**（合法窗 **180～280**） | 单张位移+旋转+缩放 | 瞬切出现；>400ms 一张 |
| `DEAL_MS_STAGGER` | **50**（合法窗 **40～70**） | 张与张错开 | 20 张同时弹出 |
| `DEAL_DEG_FLIGHT` | **±12～±28°** | 飞行中旋转，落地收回 | 整圈空翻当 MVP |
| `DEAL_SCALE_START` | **0.55** | 相对目标槽 | 从 0 弹 bounce |
| `DEAL_SCALE_END_SELF` | **1.0** | 对 `lb_cmp_card_*` 槽 | 落到槽外 |
| `DEAL_SCALE_END_AI` | **0.42** | 对手座下沿紧凑牌背 | 对手亮正面 |
| `DEAL_Z_FLYING` | `1000 + dealIndex` | 在飞的那张最上 | 后发的牌钻到桌底 |
| `DEAL_COUNT_DEFAULT` | **5** / 座 | `hand_size_default`（只读，不改规则） | 改发牌张数 |

默认 4 座 × 5 张 = 20 张。建议序：**绕桌轮发** `self → p1 → p2 → p3` 循环，不要一座发完再下一座（路径更可见）。

默认轴：`stagger×19 + card = 50×19+220 = 1170ms`（落在观感约 1.2s）。08 D1 若给总窗，按总窗反推 stagger，**顺序不变**。

### B.3 D1 重建（同组件 · 缩短）

| 常量 | 值 | 说明 |
|------|-----|------|
| `DEAL_REBUILD_TIME_SCALE` | **0.65** | 乘在 `DEAL_MS_CARD` / `DEAL_MS_STAGGER` 上 |
| `DEAL_REBUILD_SKIP_L1` | **true** | 不重走加载层 |
| 组件 | **同一 `DealFx`** | 只换参数 / `mode=opening\|rebuild`，禁止第二套发牌实现 |

重建触发仍是规则已锁的 `REDEAL_STALL`（GDD §10.1 / 状态机 T17）：存活座从**完整牌堆**重发。本文只缩短表演，**不改**谁活、发几张、先手。

```
opening:  L1(default 1100) → DealFx(card=220, stagger=50)
rebuild:  DealFx(card=220*0.65, stagger=50*0.65)   // ≈143 / 33
```

## C. L1 加载层拍表（`lb_ovl_match_load`）

同一 overlay id，开桌类入口复用。进度与循环 **必须可见**（不要空等）。

### C.1 默认轴（1100ms）

时刻按 **1100ms** 书写。clamp 到 800 / 1500 时 **拍顺序不变**。

#### L0 盖上 · 0～80ms（可与 CTA 按压重叠）

| 项 | 接口 |
|----|------|
| 窗 | `0 ～ LOAD_MS_FADE_IN`（80ms）；**允许首帧 opacity=1** |
| 可见层 | 全屏 `lb_ovl_match_load`：底 `tavern_bg`。可见细进度或循环（LoadingProgress / 底沿条） |
| 音频 | 非静默：**`sfx_match_open` → `lb_sfx_match_open`** 一记（开桌击打，不是 CTA 木钉的重复预播）。静默：**不调** |
| 交互 | **不点**。盖住大厅误点；桌面主按钮此时不应可点 |
| 静默 | **关击打**；进度 / 循环 **照播** |

#### L1 循环等待 · 80～920ms（默认轴）

| 项 | 接口 |
|----|------|
| 窗 | 默认 `80 ～ (LOAD_MS_DEFAULT − 180)` |
| 可见层 | 进度 0→约 0.85 **或** 循环 `opacity 0.70↔1.0`，周期 `LOAD_MS_LOOP`。可加一句弱文案（可选，不作硬锁） |
| 音频 | **无第二记击打**。禁止为进度加 beep / `sfx_load_*` |
| 交互 | **不点** |
| 静默 | 无声；动效仍在 |

#### L2 揭桌 · 最后 180ms

| 项 | 接口 |
|----|------|
| 窗 | 默认 `920 ～ 1100`（`LOAD_MS_FADE_OUT`） |
| 可见层 | overlay `opacity 1→0`；底下 `lb_scr_table` 已就位（座位锁名在、手牌槽空或占位不可见） |
| 音频 | 无 |
| 交互 | 仍不点出牌 / 质疑（阶段仍是 `DEAL`） |
| 静默 | 画面照淡出 |

### C.2 状态机

```
ctaAccepted (quickstart / start / again)
  → show lb_ovl_match_load   // 先于或同步于 toTable
  → t in [800, 1500], default 1100
  → fadeOut 180ms
  → hide overlay
  → DealFx.play(opening)
```

热重载 / 已在桌上的重建：**不进本状态机**。

### C.3 ArkUI（加载层）

| 要 | 不要 |
|----|------|
| `Stack` 全屏盖一层；`.id('lb_ovl_match_load')` | 新 `NavDestination` / 新 `lb_scr_*` |
| 底色 `tavern_bg`；`Progress` 或旋转环用 `tavern_candle` / `tavern_brass` | 系统白 `LoadingProgress` 衬在白底 |
| 盖上：首帧已不透明，**或** `animateTo({ duration: 80, curve: Curve.EaseOut })` | 依赖默认页面转场（易闪白） |
| 揭桌：`animateTo({ duration: 180, curve: Curve.EaseIn })` 把 overlay opacity→0 | 整页 `TransitionEffect` 若会先卸 lobby 再挂白底 table |
| `hitTestBehavior` 挡住下层 | 穿透点到已半挂的 table |

**`TransitionEffect`：** 仅 overlay **自己的** `opacity` 进出可用。  
**不要**用共享元素 / 整页 `TransitionEffect` 做 lobby→table——现挂路由一切，白底风险高于收益。发牌路径见 §D，不用 `TransitionEffect`。

## D. 发牌动效（对照 D1）

开局发牌与重建发牌 **复用同一组件**（建议程序名 `DealFx`，本地枚举，不是新控件 id）。

### D.1 路径

```
dealPileAnchor（桌心：dealer 下 / pool 上）
    → 各座位手牌槽
         自己：lb_cmp_seat_self 下的 lb_cmp_hand / lb_cmp_card_{0-4}
         对手：lb_cmp_seat_p1 / p2 / p3 下沿内侧紧凑牌背（可暂无独立手牌 List）
```

| 座 | 锁名 | 落点 | 落地朝向 |
|----|------|------|----------|
| 自己 | `lb_cmp_seat_self` + `lb_cmp_hand` | `lb_cmp_card_0` … `lb_cmp_card_4` 槽心 | 牌背；略扇或平铺（对现挂横向 `Row`） |
| 下家 | `lb_cmp_seat_p1` | 头像下沿内侧，叠 5 张背 | 只背，不揭 |
| 对家 | `lb_cmp_seat_p2` | 同上 | 只背 |
| 上家 | `lb_cmp_seat_p3` | 同上 | 只背 |

现挂工程对手还没有独立手牌条：**先落到座位控件几何**，不要因此新锁 `lb_cmp_hand_p*`。日后拆槽，路径终点改坐标，id 仍是座位 + 自己这边的 `lb_cmp_card_*`。

### D.2 单张 transform

每张飞行中同时做三件事（缺一 = 路径不可见）：

| 属性 | 开局 | 重建（×0.65 时长） |
|------|------|-------------------|
| 位移 | 锚点 → 目标槽心 | 同路径 |
| 旋转 | 飞行 `DEAL_DEG_FLIGHT`，落地 0°（自己手牌可保留极小扇角 ≤8°） | 同，可减旋转幅度 |
| 缩放 | `0.55 →` 自己 1.0 / 对手 0.42 | 同 |

曲线：`Curve.EaseInOut`（飞出稍快、落入稍收）。**禁止** spring 大弹跳、禁止整桌 `scale` 冒充发牌。

### D.3 Stagger

| 项 | 开局 | 重建 | 禁止 |
|----|------|------|------|
| 间隔 | 40～70ms（建议 50） | 约 26～46ms（建议 33） | 同时弹出 |
| 序 | 轮发 self→p1→p2→p3 | **同一序** | 重建改成随机喷 |
| 实现 | 每张独立 `animateTo`，`setTimeout` / 轴时刻错开 | 同函数不同 gap | 一条动画串 20 张 |

### D.4 Z-order

| 层 | 规则 |
|----|------|
| 桌底 / 座位 / 池 | 低于飞行牌 |
| 正在飞的那张 | `DEAL_Z_FLYING` 最高 |
| 已落入同一槽的牌 | 后到的在上（`dealIndex` 更大） |
| overlay L1 | 发牌开始前已卸；发牌时 **不要**再盖死路径 |

验收：能指出「从桌心飞向四座」，不是手牌区突然多五张背。

### D.5 发完

- 阶段仍交引擎：`DEAL` → `CLAIM`（荷官句 / 宣称按 03 策划规格，本文不改词）。
- 自己手牌默认 **牌背**（01 / GDD §3.4）；揭开仍是长按 `lb_cmp_peek_mask`，**不是**发牌结束自动翻面。
- 中央池本手仍空，直到第一手出牌。

## E. 牌面组件（正 / 背 · 角标安全区）

### E.2 媒体（只这些 · 禁 `lb_art_*`）

对照 [关键资源规格清单 §2.4](./关键资源规格清单.md)：源图 **240×336**（逻辑约 80×112，5:7）。现挂 `card_w`/`card_h` = 56×78vp，是缩小手牌；**角标按牌高比例绘制，缩放后仍须可读**。

| rank / 态 | `$r` | 何时 |
|-----------|------|------|
| 背 | `art_card_back` | 默认手牌、飞行中、对手槽、池中未翻 |
| A | `art_card_a` | 仅本人揭开 / 选中确认 / 仪式翻开 |
| K | `art_card_k` | 同上 |
| Q | `art_card_q` | 同上 |
| Joker | `art_card_joker` | 同上；**不作宣称目标**（规则已锁） |

不要出完整扑克花色。不要 `lb_art_card_*`。清单已有 `art_card_privacy_mask` / `art_card_glow` 仍挂看牌 / 质疑，本批不改。

### E.3 角标安全区（须美术会签）

**硬门槛：角标高度 ≥ 22% 牌高。**

| 量 | 源图像素 (240×336) | 逻辑 80×112vp | 现挂手牌 56×78vp |
|----|-------------------|---------------|------------------|
| 22% 牌高 | **≥74px** | **≥25vp** | **≥17vp** |
| 建议区 | 左上 + 右上各一块；宽约 28% 牌宽 | 符号居区中，不贴裁切边 | 缩到 56vp 宽仍能认 A/K/Q/Joker |

清单已有「四周各留 16px」安全边。角标 **画在安全边之内**，高度仍 ≥22% 牌高（22% 是符号块，不是把 16px 边算进去）。

| 要 | 不要 |
|----|------|
| 角标是高对比符号（风格板纸色 / 烛金），缩到现挂手牌仍可辨 | 只靠牌心大图、角标细线 |
| 圆角在 **组件** `borderRadius` clip（清单：源图可直角） | 源图把角标画进会被 clip 掉的圆角外 |
| 背与面角标区对齐，翻面不跳 | 背面角落装饰吃掉安全区 |

**请 @LiarBar美术 会签本表。** 未会签 = 鸿蒙可用色块占位联调，**不得**当牌面完成。

### E.4 缩放手牌仍可读

| 场景 | 最小可读 |
|------|----------|
| 自己手牌（现挂 56×78 或日后 80×112） | 角标 rank 一眼可认 |
| 对手紧凑背（约 0.42） | 只认「是牌背、张数」，不认 rank |
| 飞行中（0.55→1） | 认背即可 |

验收：侧看自己揭开的 5 张，A/K/Q/Joker **不靠牌心大符号也能从角标读出**。

## H. ArkUI 建议（发牌）

| 问题 | 建议 | 不要 |
|------|------|------|
| 单张怎么动 | 每张 `animateTo({ duration: DEAL_MS_CARD, curve: Curve.EaseInOut })` 写 `translate` + `rotate` + `scale` | `TransitionEffect` 做自定义弧线（控不了 stagger / z） |
| stagger | `setTimeout` / 轴时刻；每张一个动画 | 一个 `animateTo` 里 for 循环期望自动错开 |
| z-order | 飞行层独立 `Stack`；改 `.zIndex(DEAL_Z_FLYING)` | 靠 DOM 顺序碰运气 |
| 落地对齐 | `componentUtils.getRectangleById('lb_cmp_card_0')` 等取槽心；对手用 `lb_cmp_seat_p*` | 写死一套与现布局无关的魔法数还不跟 id |
| 重建 | 同一 `DealFx.play({ timeScale: 0.65, skipLoad: true })` | 复制一份 `RedealFx.ets` |
| 与 overlay | L1 结束后再 `play`；或 L2 淡出后 0ms 接第一张 | overlay 还在时把牌飞在层下看不见 |

**`TransitionEffect` 结论：**

- 加载层：可用 **自身** opacity；不要整页共享转场。
- 发牌： **不用** `TransitionEffect`；用 `animateTo` + 坐标。
