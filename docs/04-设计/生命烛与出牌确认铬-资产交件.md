## 2. 线 A · 烛火三态（形变，不只换色）

对齐 14 §2.2 / 14a：枚数 = 剩余命；三态靠 **焰形 + 柱高**，禁止只靠红绿。

| 态 | 口播 | 形 | 色 |
|----|------|----|----|
| 满 / `_full` | 燃 | 高泪滴焰，蜡柱完整 | 暖烛金 `#E8B86D` + 焰芯纸色 |
| 残 / `_hurt` | 弱 | **明显更矮**的焰，蜡柱仍在 | 焰偏铜 / mute，可带细裂 |
| 濒 / `_dying` | 将灭 | **无泪滴焰**：短蜡桩 + 圆残芯 + 烟缕 | 芯仍暖，烟 `tavern_mute` |

色盲仍须靠轮廓分清满 / 残 / 濒。幽灵 / 0 命由 #103 组透明度 + `_ghost` 处理，**本批不另出灭烛图**。

酒杯 `art_life_cup_*` **仍在清单**，不作本线主读。14 题材本批锁 **烛**。
