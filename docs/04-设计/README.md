# 04-设计

本目录是 **UI 线框** 与 **美术规格** 的交汇处，不改玩法规则。  
规则仍以 `docs/02-游戏设计/`、`docs/01-产品/PRD.md` 的 v0.2 锁定稿为准。

> 分工：**UI 管交互与 `lb_*`；美术管夜半酒馆与 `art_*`。**  
> **禁止** `lb_art_*`。媒体 / `$r` 只认 `art_*`；组件 / 路由 / 用例只认 `lb_scr_*` `lb_cmp_*` `lb_btn_*`。  
> 对齐表见 [关键资源规格清单.md §7](./关键资源规格清单.md)。四主屏 + 四拍与测试 PR#6 / 工程 PR#7 一致。

测试步骤只写 `lb_*`；核对资源写 `art_*`。

- **美术**（`feat/art-*`）：视觉风格、默认皮肤、表情与符号规范、资源规格清单

- **策划 / 音频向**（`feat/design-*`）：开场声场与大厅氛围 v3（只写 docs；不改规则、不改局内）；开桌加载与发牌体验（只写 docs；不改规则数字、不动大厅 v3 / R1–R4）；局内横屏可读性（只写 docs；大厅可竖、进桌强制横；L1/C1/D1 终验暂停至可读 + 牌堆锚点）；局内横屏打回加严（[12](./12-局内横屏打回加严-验收.md) **v0.1.5**：#50/#57/#59 五门；R-LAND-1 进桌后横屏稳定不闪；R-LAND-3 再沉底 + 水平中线锚；与 11 对照词互核）
