| 通道 | 你 `*_you` | 上家 `*_prev` |
|------|------------|---------------|
| **形** | 高圆角 **pill**；近身自指剪影 + **内箭头** | **更尖**圆角（≈12px）；厚暗描边；斜向回指 + **回撤 chevron** |
| **色温** | 暖：烛金 / 铜 / accent | 冷：钢青 / teal-copper |
| **ON** | 烛金洗 + 铜边更亮 | 冷 teal 洗 + 钢边；**不是**暖金色相双胞胎 |
