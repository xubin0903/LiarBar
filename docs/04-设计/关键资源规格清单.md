## 1. 目录与密度

```
entry/src/main/resources/
├── base/media/          ← 默认：@3x 源图（头像 216、图标 144）
├── mdpi/media/          ← 1x 导出（头像 72、图标 48）   【可后补】
├── ldpi/media/          ← 1.5x 导出（头像 108、图标 72） 【可后补】
└── xldpi/media/         ← 2x 导出（头像 144、图标 96）   【可后补】
```

**MVP 验收**：`base/media/` 放齐 P0 文件即可跑通；多密度为加分，不挡联调。

| 类型 | 逻辑尺寸 (vp) | @3x 源 (px) | 导出档（若做多密度） | 格式 | 透明底 |
|------|---------------|-------------|----------------------|------|--------|
| 头像 / 胸像裁切 | 72 | **216×216** | 72 / 108 / 144 | PNG | 是 |
| 荷官半身占位 | 108×144 | **324×432** | 108×144 / 162×216 / 216×288 | PNG | 是 |
| 牌面 | 80×112（5:7） | **240×336** | 80×112 / 120×168 / 160×224 | PNG | 是 |
| 小图标 | 32 | **96×96** | 32 / 48 / 64 | PNG | 是 |
| 标准图标 | 48 | **144×144** | 48 / 72 / 96 | PNG | 是 |
| 桌面竖屏切片 | 全屏 | **1080×2340** | 可只出 1 张 + 纯色底 | PNG / 说明见 §5 | 否（底图） |
| 惩罚/翻牌高光切片 | 按切片 | 见表 | — | PNG | 是 |

- **文件名**：仅小写、数字、下划线；**不含** `@3x` 后缀（密度靠目录）。  
- **资源 ID**：与文件名去扩展名一致，例 `art_card_a`。  
- 校园皮（P1）：同名文件放 `dark` 不适用；用 `base/media/skin_canteen/` 或运行时换 `art_canteen_*`（本表暂不展开文件行）。
