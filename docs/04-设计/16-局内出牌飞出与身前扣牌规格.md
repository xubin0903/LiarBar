## 1. 拍表（给鸿蒙 · 不是新引擎阶段）

逻辑阶段仍是 GDD：`TURN` → `PLAY_REVEAL_SELF` → `TURN`（下家）。  
下表是 **桌上出牌 UI 拍**，挂在 15 的 ConfirmReady 之后，**不另造引擎阶段**。鸿蒙实现 `PlayLaunch` / `PlayLanded` / `onPlayRollback` **只认本表数字**。

```
ConfirmReady → PlayLaunch（点确认即飞 + launch SFX）→ PlayLanded（扇形成形 + land SFX）
                 ↑ 乐观 · 不等 ack                         ↑ 满 320ms 窗
                      ↘ 权威拒 → onPlayRollback（pile+hand 回滚）
PlayLanded → AwaitChallenge     ← 飞未满窗不得进；第2节写质疑入口
PlayLanded → 打光胜利层         ← 末手权威已胜：扇必须先成形；飞中禁胜利 UI/SFX
```

```mermaid
stateDiagram-v2
  [*] --> ConfirmReady: 15 已选合法
  ConfirmReady --> PlayLaunch: 点 lb_btn_play_confirm\n立刻飞 · confirmBusy
  PlayLaunch --> PlayLanded: 飞满窗 · 扇形成形
  PlayLaunch --> PlayRolledBack: 权威拒 · onPlayRollback
  PlayRolledBack --> ConfirmReady: 牌回手 · 张数已纠正
  PlayLanded --> AwaitChallenge: 满窗后才准\n第2节
  PlayLanded --> WinPresent: 末手已胜 · 扇先成形
  PlayLaunch --> PlayLaunch: 窗内禁再交一手
  PlayLaunch --> PlayLaunch: 飞中禁胜利层 / 胜SFX
```

| UI 拍 | GDD 阶段 | 画面 | 玩家能做什么 |
|-------|----------|------|--------------|
| **ConfirmReady** | `TURN` | 15：条在、钮 `_enabled`；`confirmBusy=false` | 点 `lb_btn_play_confirm`。取消仍认 15 |
| **PlayLaunch** | `PLAY_REVEAL_SELF`（UI 已飞；引擎 ack **可后到**） | 已选牌从手牌位飞向该座身前锚；**`lb_sfx_play_launch` 与飞出同一 onset** | **不可改选、不可再交**。`confirmBusy=true`。条 `_disabled` 或收起（认 15 Playing） |
| **PlayLanded** | 回 `TURN`（下家）或仍在本手展示；末手打光则权威可在 **落地帧** 判胜 | 身前扇形 **已成形**；牌背；HitTest None；**`lb_sfx_play_land` 贴落地** | 本手第1节飞出完成。`confirmBusy` 解除。`AwaitChallenge` **仅此之后**。打光胜利层 **只在扇成形之后**（§6.3） |
| **PlayRolledBack** | 仍 `TURN`（本座） | 身前扇卸掉；牌回手原位（不 flush）；口播/短句走 **单一** key `lb_str_play_rollback` = **出牌未生效 / 张数已纠正** | 可再选再确认（认 15）。**不得**留下「已出成功」的身前扇 |
| **AwaitChallenge** | （第2节） | 飞已满窗；身前仍是 **这一手** | 第2节写入口。本线只锁：**飞未完不得进**；禁与旧四拍/弱 CTA 双轨 |

**写死：** `PlayLaunch` / `PlayLanded` / `AwaitChallenge` 是 **UI 拍名**，给鸿蒙对表。日志 / 实况窗仍报 GDD 阶段，不得把这三拍写成新的 `phase` 枚举。v0.1.0 的 `ChallengeAwait` **更名为** `AwaitChallenge`（同一后节，不是第二套）。

**乐观（写死）：** 点确认 **即** 进 `PlayLaunch`，**不等** T20 / `SUBMIT_PLAY` ack。ack 后到只用于确认或触发 `onPlayRollback`，不得把「等 ack」做成无位移纯切图。

**`confirmBusy`（写死）：** `PlayLaunch` 全程 `true`（推荐满 **320ms**，不得短于窗下沿 280ms 就放开）。Busy 期间：确认条不可再点；第二次 `confirm` **丢弃**；不得再选再飞。Busy 在 `PlayLanded` 或 `onPlayRollback` 完成时才落 `false`。飞中途放开 busy 又能交 = **动画未完又出一手**。

超时 AUTO_PLAY 仍认 GDD：自动 1 张也走同一乐观飞出 → 身前单张落点，不另走路。AUTO_PLAY 同样满窗后才准 `AwaitChallenge`。

## 2. 线框数字（本版闸 · 会签前当锁）

评委 / 鸿蒙 / 测试 **只认下表**。窗口是实现容差；**推荐值**是对表数。  
**本版不改** ° / 露边 / 落点 / Z / `padB` / GAP — 与 v0.1.0 同一套数。

### 2.1 飞出时长（不可跳过）

| 项 | 锁 |
|----|-----|
| 推荐 | **320ms** |
| 窗口 | **280～400ms** |
| 缓动 | ease-out（与 15 翻/抬同族，不另造曲线名） |
| 起点 | 该张在 `lb_cmp_hand` 的选中位（抬起态可当起点） |
| 终点 | 该座身前锚（§2.3） |
| 途中 | 牌背（他人永远不见面）；可用已有 `art_card_back` |
| 听感 | **飞出视觉起势与 `lb_sfx_play_launch` 同 onset**（见 §5） |
| 不可跳过 | **必须播完本窗** 才进 `AwaitChallenge` / 才解除 `confirmBusy`（回滚除外） |
| 飞中确认 | **禁止**；`confirmBusy` 吞第二次确认 |

短于 280ms 闪现、长于 400ms 拖沓，或无位移纯切图 = **无飞出纯提交**。  
未满窗就开质疑 / 跳过飞出 = **飞出被跳过进质疑**。

### 2.2 扇形 ° / 露边（张数闸）

**禁止**当面 `Text` / Badge 写「1」「2」「3」。张数只靠 **牌背扇** 读。`lb_txt_play_count` 是 15 次路径包内「已选 n/3」，**不**挂到身前扣牌。

| 张数 | 转角 | 露边 | 锚 |
|------|------|------|----|
| **1** | **不扇**（0°） | — | **该座身前正中** |
| **2** | **±8°** | 邻牌露边 **10vp** | 以身前正中为轴，左右对称 |
| **3** | **−12° / 0° / +12°** | 邻牌露边 **10vp** | 中张 0° 压轴；左右对称 |

露边 **10vp** = 上一张（或下一张）至少露出 **10vp** 牌背边，一眼能数。重叠到只剩一条缝 = **张数不可读**。

扇形朝向：指向桌心 / 环内，不是朝屏幕外翻。左右座、对家 **镜像** 该座朝心方向（§2.3）。

牌档建议沿用手牌 56×78 或略缩一档；**缩尺不得**靠抬 `padB` 或改 `HAND_RING_GAP` 腾空。本线不锁新 `art_*`。

```
1 张（不扇）          2 张（±8° / 露边 10vp）       3 张（−12°/0°/+12° / 露边 10vp）

      [背]                  [背]  [背]                 [背] [背] [背]
       │                    ╲      ╱                    ╲   │   ╱
     身前正中                 身前正中                     身前正中
```

### 2.3 落点（self / 左 / 右 / 对家）

**Self：** 落在 **自己座位之上 / 身前**（下手 `lb_cmp_seat_self` / `selfDock` 身前空位），在手牌主行 **之上**、桌心 **之下** 的环-手带里。

| 要 | 不要 |
|----|------|
| 身前、贴自己座；1 张居中 | 飞进桌心池 / 荷官 bust 当完成 |
| **不得抬 `padB`** | 加大 `padB` / 底 padding 给扇形腾空 |
| **不得盖手牌主行** | 扇叶压住 `lb_cmp_hand` 牌心或热区 |
| **不得盖生命烛** | 压 `lb_cmp_life_self` / 对手 `lb_cmp_life_seat_pN` |
| 左右座 / 对家 **镜像** 各座锚 | 四座共用一个桌心落点 |

**镜像（写死）：**

| 座 | 锁名 | 身前锚 |
|----|------|--------|
| 自己 | `lb_cmp_seat_self` | 底带身前、手牌主行之上、水平近该座 / 桌面中线身前 |
| 右 · 怂货 | `lb_cmp_seat_p1` | 右侧座 **内侧 / 身前**（朝桌心），边竖直中口径仍认 11 |
| 对家 · 老千 | `lb_cmp_seat_p2` | 上沿座 **身前（靠桌心一侧）** |
| 左 · 杠精 | `lb_cmp_seat_p3` | 左侧座 **内侧 / 身前**（朝桌心） |

11 的 p3/p1 边竖直中、self / p2 上沿 **本轮不改**。身前锚是 **座内侧空位**，不是把座框挪走。

AI 出牌走同一套 ° / 露边 / 时长 / 乐观飞，只换该座锚。AI 手被权威拒同样 `onPlayRollback`（测试可抄同一短句）。

### 2.4 Z 序与命中

| 层 | 谁 | Z | 命中 |
|----|-----|---|------|
| 下 | 桌心 bust / 池 / 牌堆锚 | 低 | 仍认 11（本线不改） |
| 中 | `lb_cmp_play_fly`（飞）→ `lb_cmp_play_front_pile`（落后） | **高于桌心，低于确认条** | **落后 HitTest None**（不得挡手牌） |
| 上 | `lb_cmp_play_confirm_bar` | 最高可点层之一 | Busy 时不可点；PlayLaunch 起 `_disabled` / 收起 |

确认条 **继续** 15 / 工程口径：`Stack` **BottomEnd overlay**，与 `handPin` **兄弟**，**禁止**进 `handPin`（进 pin 会撑 hug、抬手牌，等于变相抬 `padB`）。

飞出层在 PlayLaunch 窗内可挡误点；**PlayLanded 之后** 身前堆必须 `HitTestMode.None`（或等价），手牌主行 / 余牌点按不被扇形吞掉。

## 3. 控件 id（草案 · 已回写 02）

| id | 类型 | 何时 | 说明 |
|----|------|------|------|
| `lb_cmp_play_fly` | 组件 | PlayLaunch | 飞出层 / 在途牌。窗尽即卸或切到 pile。回滚时中途卸，牌回手 |
| `lb_cmp_play_front_pile` | 组件 | PlayLanded 起 | **只持本轮这一手** 1～3 张牌背扇。**无**张数 Text。质疑 / 揭牌后清空（第2/3节） |

子实例不必另锁第三套前缀。需要自动化点单张时，用 pile 下标 `0..2`（左→右或逆时针朝心），**不要**发明 `lb_art_*`。

牌面资源：`art_card_back`（02 §5.3 已有）。本 PR **不交** PNG / rawfile。

余牌仍是 `lb_cmp_card_*`。**本线不 flush**：飞走的下标位可空着，不把右边牌滑过来。flush 后节。回滚后牌回到原下标，**仍不 flush**。

### 3.1 身前堆生命周期（本轮一手 · 坟场后开）

GDD §6.1 / §6.2：本手扣牌区是 **刚刚那一手**；质疑翻的也是上家 **刚刚那一手**，不是历史所有。

| 时点 | `lb_cmp_play_front_pile` | 不要 |
|------|--------------------------|------|
| `PlayLanded` | 换上 **这一手** 扇（1/2/3） | 把上一手扇留在底下再叠一层 |
| 下家再出（本轮未质疑） | **该座** 仍只显示自己这一手；不得把四座牌堆成桌心坟 | 跨座、跨手无限堆 |
| 权威拒 / `onPlayRollback` | **立刻卸** 这一手；手牌张数回到提交前 | 拒了还留扇 = **出牌未生效** |
| 质疑 / 揭牌之后 | **清空** 该手扇 | 揭完仍留旧扇冒充坟场 |
| 新一轮宣称 | 各座 pile **空** | 上一轮扇还在 = **身前跨轮堆叠** |

**坟场 / 弃置堆本线不开。** 清空之后牌去哪、是否另挂 id，**第2/3节** 写。本线只锁：pile **不是** 无限跨轮栈。

## 4. 不做（本线写死）

| 不做 | 说明 |
|------|------|
| 手牌 flush | 余牌收缝 / 重排 / 改 `HAND_RING_GAP` **搁置** |
| 抬 `padB` | 禁加大 inset 给扇形或条腾空 |
| 改 GAP / tip | `HAND_RING_GAP=24%` 数字不动；不重开删 tip |
| 等 ack 才飞 | 乐观已锁；不得把「等 T20」做成 **无飞出纯提交** |
| 飞中再确认 | `confirmBusy` 必须吞第二次；不得两手叠飞 |
| 跳过飞进质疑 | 未满 320ms 窗不得进 `AwaitChallenge` |
| 飞中出胜利层 | PlayLaunch / 飞中禁胜 UI、`lb_sfx_result_win`、战报抢切；打光表现必须等扇成形（§6.3） |
| 身前跨轮堆 | pile 只本轮一手；坟场后开 |
| 质疑双轨 | 旧四拍全屏 + 新局内质疑弱 CTA / 大双底栏 **禁并存**（第2节） |

## 5. SFX（双槽交叉 · 不交文件）

出牌飞出 **只认双槽**，与 13 的 soft/slam/hesitate **方式槽** 不是同一对：

| 调用点 | 何时 | 本线交文件？ |

| `lb_sfx_soft` / `_slam` / `_hesitate` | 13 方式槽（SOFT/SLAM/HESITATE）；**不替代** launch/land 双槽 | **否** |

- PlayLaunch / PlayLanded / 出牌飞出路径播 **`lb_sfx_card_flip`**（翻牌槽只属 S15-4）。

- land：耳 onset 贴 **扇形成形 / 落锚**。

## 6. 乐观飞 + 回滚（PM 已锁 · 废「未决」）

v0.1.0 §6「乐观飞 vs ack 策划未决」**作废**。本版锁 **乐观**。

| 项 | 锁 |
|----|-----|
| 起飞 | 点 `lb_btn_play_confirm`（或 AUTO_PLAY 触发）**立刻** `PlayLaunch` |
| 不等 | **不等** T20 / `SUBMIT_PLAY` ack / 权威回包 |
| 落点 | 仍是该座身前锚（§2.3）；不得改飞进桌心 |
| 权威接受 | 飞继续 → `PlayLanded` → 满窗后才 `AwaitChallenge` |
| 权威拒绝 | **立刻** `onPlayRollback`（飞中或已落都要回） |

实现不得用「等 ack」当借口做成 **无飞出纯提交**。

### 6.1 `onPlayRollback`（权威拒）

引擎 / 权威拒（非法张数事后发现、座位不同步、本手未成立等）→ 鸿蒙必须调 `onPlayRollback`（UI 拍名；不是新 `phase`）。

**必须同时：**

1. **卸** `lb_cmp_play_fly` 在途牌（若还在飞：中断位移，不做到达）。  
2. **卸** `lb_cmp_play_front_pile` 这一手扇（若已落）。  
3. **手牌回滚** 到提交前：牌回原下标；可见张数 = 提交前张数。**不 flush**。  
4. `confirmBusy=false`。条按 15 回到可再选。  
5. 出口播 / 测试短句走 **单一** 文案 key（02）：  
   `lb_str_play_rollback` = **出牌未生效 / 张数已纠正**  
   （两句写在 **一个** key 里，中间用「 / 」；**禁止**再拆 `lb_str_play_not_applied` / `lb_str_play_count_corrected`。）

语义仍是两半、同屏一次出齐：

- **出牌未生效** — 本手不算；身前不得留「已出成功」。  
- **张数已纠正** — 手牌可见张数已回到权威；禁止仍少 N 张像已经打出去。

缺半句、或拆成两个 key 交差 = 同一回滚不过（F16-5 / F16-6 都可抄；锁词仍是这两句）。

| 要 | 不要 |
|----|------|
| pile + hand **都**回 | 只回手不卸扇 / 只卸扇不回手 |
| 一个 key 两句都在 | 无声成功吞掉、只 toast「失败」、或拆两个 key |
| 回滚后可再选（15） | 回滚后死锁 `confirmBusy` / 条永不回 |
| 回滚不改 `padB` / GAP | 借回滚重排手牌当 flush |

15 客户端预检仍先挡：未进 `PlayLaunch` 的非法选认 **张数不符** / **非己回合** / **超选**，**不**改叫本 key。  
`lb_str_play_rollback` 只用于 **已经起飞（或已落）之后** 的权威拒。

### 6.2 质疑已解冻 · 禁双轨（指针第2节）

**废止** v0.1.0「质疑仍冻 / 挑战等待后节再写（不扩）」里的 **仍冻**。  
**质疑已解冻。** 飞满窗后的等待拍名 = `AwaitChallenge`。

第2节（本文后续节，**本 PR 不写满**）必须锁：

- 新局内质疑在 `lb_scr_table` 上接 `AwaitChallenge`（入口 / 可点窗 / 与身前这一手的关系）。  
- **禁止**与旧轨并行：旧 `lb_scr_challenge` 四拍全屏仪式 + 底栏/顶栏 **弱 CTA**（R-LAND-4 时代可弱可藏的 `lb_btn_challenge` / `lb_btn_play` 大双底栏）**不得**和新局内质疑两套同时可点。  
- 见双轨 = **质疑双轨并存**。  
- 揭牌只翻 **这一手**（GDD §6.2）；pile 清空时序落第2/3节。  
- 第一手不可质疑 **仍认 GDD**（无上家本手 → 入口 `_disabled` + `lb_str_challenge_disabled_first`）。这是规则，不是「仍冻」。

本线（第1节）只验到：飞未满窗不能进质疑；文档与线框 **不得再写「质疑仍冻」**。

### 6.3 打光胜利层（表现在落地之后）

对齐 Aron「**牌打完即胜**」：末手权威成功时，**判定**可以落在 `PlayLanded` **落地帧**（引擎/权威已可记胜）。**表现**必须在扇形成形 **之后**。

| 时点 | 判定（权威） | 胜利 / 战报 / 名次层 |
|------|----------------|----------------------|
| `PlayLaunch` / 飞中 | 可 internally 已知道将胜 | **禁止** 胜利遮罩、名次条、`lb_scr_report` 抢切、`lb_sfx_result_win` |
| `PlayLanded` 扇 **已成形** | 落地帧可落胜 | **这之后** 才许胜利层 / 胜 SFX / 进战报 |

**写死：**

1. 末手打光、权威已接受：必须先走满飞出窗，**身前扇成形**（1 张居中 / 2 张 ±8° / 3 张 −12°/0°/+12°，露边 10vp，与 §2 同一套数）。  
2. 扇未成形就盖胜利遮罩、切战报、或先响胜 SFX = **胜利遮未成形扇形**。  
3. 飞中出胜层 **不得** 用「牌打完即胜」当借口跳过 `PlayLaunch`（那是判定，不是表现）。  
4. 本条不改扇形数字、不改 `padB` / GAP、不改双槽 SFX、不改质疑已解冻。
