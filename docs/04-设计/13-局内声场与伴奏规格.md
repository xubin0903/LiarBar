## 1. 目标听感（一句话）

进桌后：夜半酒馆里 **有人在弹、有人在压气氛**——低弦垫底、节奏点到为止、高音点缀不抢宣称/口播；操作一下一响，材质能分开指认（木 / 纸 / 铜 / 布），不是同一个 tip 改音量。

---

## 2. 与大厅声场的区分（硬闸）

| | 大厅 `bgm_lobby_night` | 局内 `bgm_table_bluff`（本规格） |
|---|---|---|
| 功能 | 冷启动 / 等开桌氛围 | **对局张力**伴奏；虚张声势 |
| 密度 | 疏、慢、暖，少鼓点 | 中等密度：有 **可感知编曲层次**（垫底 + 律动 + 点缀） |
| BPM | 偏慢氛围（约 60–72） | **78–92 BPM**（默认目标 **84**）；可稳可微推，禁止 trance 连打 |
| 听感关键词 | 夜馆一直在响 | **算计 / 盯梢 / 压注**；像酒吧角落小乐队，不像电子游戏默认 battle |
| 循环体 | 16–32s | **24–40s**（禁止 ≤8s 听出接缝的干 loop） |
| 切换 | 离厅淡出 | 进桌：大厅 BGM **400ms 淡出** → 局内 BGM **600ms 淡入**；回大厅反向 |

**禁止**：局内直接复用 `bgm_lobby_night` 改音量；禁止一条振荡器刷两槽。

## 3. 局内 BGM 规格 · `bgm_table_bluff`

### 3.1 情绪与曲风

- **曲风**：暗爵士 / 慢速 noir lounge × 轻微东方木感（可选古筝拨片点缀，勿成民族表演曲）
- **情绪弧**：稳态「盯着你出牌」；宣称抬张时可程序 duck，**不要**整曲切战斗版（本批不做多段变奏文件）
- **调性建议**：小调或多利亚；避免大调欢快通关感

### 3.2 编曲层次（必须能单听拆开）

| 层 | 角色 | 建议乐器 / 材质 | 相对响度（相对 0 dBFS 峰值参考） |
|---|---|---|---|
| A 垫底 | 持续气场 | 低弦 / 低合成垫 / 极轻厅响噪声 | 约 −16～−14 dB |
| B 律动 | 伴奏感来源 | 刷镲极轻 + 木箱/指弹低音；或慢拨吉他 | 约 −14～−12 dB |
| C 动机 | 可记忆短句 | 钢琴/电钢琴 2～4 小节动机，稀疏 | 约 −12～−10 dB |
| D 点缀 | 酒馆色 | 杯沿远处一碰 / 木梁（**融进曲，不是独立 SFX 槽**） | 低于 B 约 6 dB |

验收句：**关掉画面只听 10s，能指认「至少两层在动」（垫底 ≠ 律动/动机）**；不是单音循环。

### 3.3 技术参数

| 项 | 规格 |
|---|---|
| 文件 | `rawfile/audio/bgm/bgm_table_bluff.ogg` |
| 格式 | Vorbis · **立体声 48 kHz** |
| 时长 | 循环体 **24～40s** |
| 循环 | **是**；接缝避开强拍与动机句尾；交叉淡化 **≥500ms** 或无缝 loop |
| 淡入 / 淡出 | 进桌淡入 **600ms**；回大厅 / 静默淡出 **400ms** |
| 稳态响度 | 峰值约 **−14～−12 dBFS**；须让位宣称 UI 与（若有）口播 |
| Duck | 荷官短口播 / 关键 VO 时 duck **−6～−9 dB**（200ms）；本批若无新 VO 则仅预留接口 |
| 静默局 | **关**（与大厅写死一致：字幕可在，轨全关） |

### 3.4 不合格（直接打回）

- 2～8s 干 loop、接缝可听见「咔一下」
- 纯白噪声 / 单正弦 / 手机铃声感
- 与大厅 BGM 频谱几乎相同（听不出进桌换曲）
- 鼓点过密盖过发牌纸感

## 5. 关键 SFX 清单（可验收）

### 5.1 已有（本规格 **不重做**，换绑验收引用）

| 文件 | 场景 | 时长 / 峰值（已交） | 调用建议 |
|---|---|---|---|
| `sfx_match_open.wav` | 开桌 / 进桌一记 | ~0.78s · ≈−10 dBFS | `lb_sfx_match_open` |
| `sfx_deal_card.wav` | 单张发牌（可叠播） | 主体 ≤120ms · ≈−10 | `lb_sfx_deal_card` |
| `sfx_deal_whoosh.wav` | 可选走牌气声 | ~0.14s · ≈−14 | `lb_sfx_deal_whoosh` |

### 5.2 本规格 **新建**（会签后生成）

| 文件 | 场景 | 格式 | 时长 | 峰值建议 | 材质要点 | 调用建议 |
|---|---|---|---|---|---|---|
| `sfx_claim_set.wav` | 荷官/系统锁定本轮宣称（如「本轮出 A」） | wav 48k 单声道 | **0.20～0.45s** | −12～−8 | 短铜铃 + 木桌一触；**非 beep** | `lb_sfx_claim_set` |
| `sfx_play_soft.wav` | 软出牌（对应 play soft） | wav 单声道 | **≤0.20s** | −12～−10 | 轻纸落桌 | `lb_sfx_play_soft` |
| `sfx_play_slam.wav` | 甩出 / 重出 | wav 单声道 | **≤0.28s** | −10～−8 | 掌心拍桌 + 纸；比 soft 明显更「狠」 | `lb_sfx_play_slam` |
| `sfx_play_hesitate.wav` | 犹豫出（可选） | wav 单声道 | **≤0.22s** | −14～−12 | 纸摩擦半下又停 | `lb_sfx_play_hesitate` |
| `sfx_turn_tick.wav` | 轮到谁（弱提示） | wav 单声道 | **≤0.12s** | −16～−14 | 极短木击；勿吵 | `lb_sfx_turn_tick` |
| `sfx_named_stare.wav` | 被点名盯梢（烛火挂点时） | wav 单声道 | **0.25～0.50s** | −12～−10 | 烛火「hoo」+ 低频聚焦；可与 `art_fx_candle_stare` 同拍 | `lb_sfx_named_stare` |
| `sfx_result_win.wav` | 结算胜 | wav 立体声可 | **0.6～1.2s** | −10～−8 | 低弦收束 + 轻杯碰；**禁止** 8-bit 胜利 fanfare | `lb_sfx_result_win` |
| `sfx_result_lose.wav` | 结算负 / 罚酒感 | wav | **0.6～1.2s** | −10～−8 | 闷木 + 酒液短响；勿惨叫 | `lb_sfx_result_lose` |

**三条出牌材质必须可盲听区分**（soft / slam / hesitate）。

## 6. 混音与路由（给鸿蒙）

| 规则 | 说明 |
|---|---|
| 总线 | BGM 床 / SFX 床 /（预留）VO 床；静默 = 三床全关 |
| 进桌 | `sfx_match_open` 可与 BGM 淡入重叠；开桌击点峰值短暂允许压过 BGM |
| 发牌 | `sfx_deal_card` 可叠播；单次不超过 BGM 存在感太多（约 ≤ +4 dB 感） |
| 出牌 | soft/slam 跟动画峰值对齐；slam 可 duck BGM **−3 dB · 120ms** |
| 禁止 | 同一 `AudioPlayer` 用一条 wav 改 pitch 填多槽交差 |

路径约定（与大厅一致）：

```
rawfile/audio/
  bgm/bgm_table_bluff.ogg
  sfx/sfx_claim_set.wav
  sfx/sfx_play_soft.wav
  sfx/sfx_play_slam.wav

  sfx/sfx_turn_tick.wav
  sfx/sfx_named_stare.wav
  sfx/sfx_result_win.wav

  （已有）sfx_match_open / sfx_deal_card / sfx_deal_whoosh
```

## 7. 验收句（测试可抄）

**BGM**

1. 进桌 1s 内能感到 **换曲**（不是大厅那条变小声）。  
2. 稳态循环 **≥20s** 听不出硬接缝。  
3. 闭眼 10s：能说出「垫底 + 至少一层律动/动机」。  
4. 静默局：局内 BGM/SFX **全无**。

**SFX**

5. 开桌一记仍是桌布/铜钉感（沿用已交 `sfx_match_open`）。  
6. 发牌纸感可叠、非 beep（沿用已交）。  
7. soft / slam **盲听可分**；turn_tick 不抢戏。  
8. 结算 win/lose 非 8-bit fanfare、非惨叫。  
9. 质疑四槽 **本批未挂真源** 不算失败（占位文档即可）。

**不合格**：单响循环、纯朗读感、方波 tip、与大厅无法区分。
