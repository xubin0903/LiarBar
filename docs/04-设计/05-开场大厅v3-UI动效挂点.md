### A.3 默认可点与 disabled 状态机


## B. 分区 stagger 接口（T5）

默认窗 **2500～3300ms**。缩轴时 **先后顺序不变**。

### B.1 层序（禁止改序）

| # | 层 | 锁名 / 文案 | 备注 |
|---|----|-------------|------|
| 1 | 顶栏 | `lb_str_app_title` · `lb_btn_records`（可后挂） | 第一层 |
| 2 | 荷官字幕补位 | 挂在 `lb_cmp_dealer` 旁 / 下 | 胸像已在 T3；本拍只补字幕条（若尚未出） |

| 5 | 「进桌看看」 | `lb_str_nav_peek`（热区建议 `lb_btn_peek_table`） | 最后一层；弱入口 |

### B.2 数字

| 项 | 值 | 禁止 |
|----|-----|------|
| 层间隔 | **90～110ms**（建议常量 100） | 改成同时弹出 |
| 单层动画 | **240～280ms**（建议常量 260） | 拉成 >400ms 或弹性过冲 |
| 属性 | `opacity 0→1` + `translateY 12→0` + `scale 0.96→1` | **禁止 bounce / spring 大弹跳** |
| 曲线 | EaseOut（与 03 ArkUI 提示一致） | 禁止为 stagger 加击打音 |

五层用默认 100ms 间隔 + 260ms 层动画时：第 5 层约 `2500+400` 起、`3160` 收，落在 3300 窗内。

ArkUI：各层独立 `animateTo({ duration: layerMs, curve: Curve.EaseOut })`，用 `setTimeout` / 轴时刻错开 `gapMs`，**不要**一条动画串弹性。

## C. 荷官 idle 循环接口（H2 — 禁止仅缩放）

对照 v3 §3.2 / §3.2.1。底层呼吸可留，**仅呼吸 / 仅 `scale` = 验收失败**。

循环在 **T6 结束之后**，或 **announce→idle 回切完成之后**，**取晚者** 自动开。无需玩家点 `lb_cmp_dealer`。

### C.1 状态机（ArkUI 面向）

```
                    ┌─────────────────────────────┐
                    │  announce（§D，不占本循环）  │
                    └──────────────┬──────────────┘
                                   │ 400ms 回 idle
                                   ▼
                         ┌─────────────────┐
              ┌─────────►│   idle_base     │◄──────────┐
              │          │ breath 仍走     │           │
              │          └────────┬────────┘           │
              │                   │ 加权抽             │
              │     ┌─────────────┼──────────────┐     │
              │     ▼             ▼              ▼     │
              │  blink          nod            mask    │
              │  (可叠 nod)   (可叠 blink)      │     │
              │     │             │              │     │
              └─────┴──────┬──────┴──────────────┘     │
                           │ 抽到 cup                  │
                           ▼                           │
                         cup  ──期间禁止 cup / nod─────┘
```

| 状态 | 资源槽 | 时长 | 冷却 | 权重 | 幅度 |
|------|--------|------|------|------|------|
| `idle_base` | `art_dealer_bust_idle` | 一直在 | — | — | 底层呼吸 `scale 1.00↔1.02`，周期 **1.6s**，位移 ≤2vp |
| `blink` | `art_dealer_idle_blink` | **0.16～0.22s** | **2.8s** | **0.40** | 眼缝闭合再睁；头不动 |
| `nod` | `art_dealer_idle_nod` | **0.55～0.70s** | **7s** | **0.25** | 下颌点一次回正；不超过 bust 框 4vp |
| `cup` | `art_dealer_idle_cup` | **1.10～1.40s** | **12s** | **0.20** | 持杯手抬到下颌高再放下；可伴面具微侧 |
| `mask` | `art_dealer_idle_mask` | **0.70～0.90s** | **6s** | **0.15** | 面具 / 帽檐偏 2～4° 再回 |

资源规格（v3 §3.8.1）：四张皆 **324×432 PNG、透明底**。挂同一 `lb_cmp_dealer`，**不改控件 id**。眨眼 **单张交叉**（已选定），不做三帧序列。

### C.2 抽取与互斥规则（必须实现）

| # | 规则 |
|---|------|
| 1 | 下一次动作按权重加权随机：blink 0.40 / nod 0.25 / cup 0.20 / mask 0.15 |
| 2 | **两次大动作（nod / cup）不得连抽**（nod 后下一抽不能是 cup，cup 后下一抽不能是 nod；也不能 cup→cup） |
| 3 | **blink 可与 nod 重叠**（点头过程中允许再切一次 blink） |
| 4 | **cup 期间禁止再 cup / nod**（抬杯是互斥大动作） |
| 5 | 冷却未到的动作从候选里剔除后再归一化权重；若只剩 blink，就眨眼 |
| 6 | 循环自己切状态图，**不再占 announce** |
| 7 | 停大厅 ≥8s：至少一次 **眨眼** +（点头 **或** 抬杯 **或** 面具）其中之一 |

建议内部枚举名（程序本地，**不是**新控件 id）：`DealerIdleState = idle_base | blink | nod | cup | mask`。  
announce 是另一对图（`art_dealer_bust_idle` / `art_dealer_bust_announce`），见 §D，不要把 idle 四态写进 banner。

### C.3 ArkUI 做法（MVP · 已选定）

| 要 | 不要 |
|----|------|
| `Stack` 叠 `Image`：底图 `art_dealer_bust_idle` + 当前动作帧 | Live2D / Spine / 骨骼 |
| 切态 `opacity` 交叉 **120～180ms**（与现 idle/announce 同槽） | 整 bust 12 帧硬切闪白 |
| 眨眼也可改为 **眼层 1 张** 叠在 idle 上（更省，可选） | 用 `scale` 假装点头 / 抬杯 |
| 呼吸只挂在 `idle_base` 容器，动作帧相对 bust 对齐 | 动作期间把整屏拿去呼吸放大 |

### C.4 可选验收参考：16s 示范序列（v3 §3.2.2）

实现可用随机；联调 / 会签可用下列定序对照（从 **回 idle 底图、呼吸已在** 起算）：

| 时刻 | 动作 |
|------|------|
| 0.0s | `idle_base`；呼吸已在 |

## D. announce ↔ idle 切换（对照 v3 §3.5）

大厅只用已锁两态：`art_dealer_bust_idle` / `art_dealer_bust_announce`。招呼是 **大厅唯一自动切 announce 的理由**。局内 banner 切 announce **本批不改**。

| 阶段 | 姿态 | 时长 / 条件 | 鸿蒙要点 |
|------|------|-------------|----------|
| T3 亮相 | idle 淡入 | 至 T4（1400～2200） | 只出 `art_dealer_bust_idle`，**先不要**切 announce |
| T4 招呼起 | **350ms** 交叉到 announce | 口播全程 | `lb_vo_dealer_greet` 与字幕 **同起 ±40ms** |
| 口播结束 + **0.25s** | 保持 announce | 250ms hold | 不要口播一停立刻切 |
| 回 idle | **400ms** 交叉回 idle | hold 之后 | 回切完成 → 才允许 §C 循环 |
| 回 idle 后 | idle + §C | 直到离开大厅 | 循环不再占 announce |

### D.1 默认定时（口播 2.1s）

```
T4_AT = 2200
voEnd = T4_AT + voDuration          // 默认 4300；静默用 2100 虚拟钟
holdEnd = voEnd + 250               // 默认 4550
idleBackEnd = holdEnd + 400         // 默认 4950
idleLoopStart = max(clickableAt, idleBackEnd)
```

默认轴上：CTA 在 **3800** 可点，idle 循环约 **4950** 才开（取晚者）。口播溢到 4.60s 时：`voEnd=4600` → `idleLoopStart=5250`，**仍不回滚** CTA enabled。

### D.2 静默

- 不调 `lb_vo_dealer_greet`。
- 仍切 announce、仍出字幕。
- **虚拟口播钟 = 2100ms**（v3 写死）。
- 字幕残留：口播钟结束后再留 **0.4s**，淡出 **200ms**。至少停到 `T4_AT + 2500`。

缺 `vo_dealer_greet` 文件：fail-soft 只出字幕 + 虚拟钟切态；**不算 v3 通过**，也 **不得**用 beep 替代。

### D.3 从桌返回（短入 0.4s）

| 做 | 不做 |
|----|------|
| `BOOT_MS_RETURN_ENTER=400` 短入到稳态五分区 | **不**重播 3.8s 冷启动 |
| 未静默：BGM / 环境 **400ms** 淡入到稳态音量 | **不**重播 `lb_sfx_boot_hit` |
| 静默：短入也全静（§A.4） | **不**重播 `lb_vo_dealer_greet`、**不再出**招呼字幕 |
| 荷官直接 `idle_base` + 立刻（或短入结束后）开 §C | 不走 T4 announce |

冷启动只冷启一次（进程冷启）。

## E. CTA 按压接口（对照 v3 §3.7）

热区高 ≥56vp；主 CTA **独立于设置卡**（03 已锁，不改）。

| 入口 | 按压 scale | 时长 | 音频 | 静默 |
|------|------------|------|------|------|
| `lb_btn_quickstart`「快速开桌」 | `1 → 0.96` | 按下 **≤80ms**；抬起 **100～120ms** 回 1 | `lb_sfx_cta_tap` 在按下 **≤80ms** 内出声 | **无 sfx、无强震 / 触感**；**scale 仍在** |
| 「进桌看看」 | `1 → 0.98` | 弱于主钮；不要整屏闪 | **同一** `lb_sfx_cta_tap`，音量 **−3 dB** | 同上：无声无震，scale 仍在 |

可选：主钮按下闪一次烛（不作硬验收）。  
逻辑：主钮 = 默认开桌（规则不变）；次级 = 桌预览（**局内画面不在本文验收**）。

轴内 **禁止**预播 CTA 音。未到 T6 终点：主钮 disabled，按压缩放与 sfx 都不走开桌。

**悬停 / 焦点 ≠ 按压。** 真机已打回「无按钮闪」。材质 / scale 帽抄 [06 §3.2](./06-开场大厅v3-打回加严.md)。**移入须 1 帧内可见、无鼠标 focus/pressed 等价、静默动效仍在且无击打音**，抄 [07 PM 硬口径](./07-大厅可点悬停与焦点.md)。不要用本节 `scale 0.96` 冒充悬停，也不要用 80～120ms 动画当「亮起来」。

## F. 烛光 / 尘微动 + CTA 稳态微光

v3 **作废** v2「呼吸 **或** 烛光」的 OR：烛光 / 远景微动 **和** 荷官真动作循环 **都要有**。

### F.1 烛光 / 尘（对照 v3 §3.3）

| 层 | 资源 | 循环 | 量级 |
|----|------|------|------|
| 近景烛 | `art_fx_candle` | 焰芯 `opacity 0.70↔1.0`，周期 **0.55～0.85s**；焰 **`scale 1.00↔1.06`**（只缩放焰，不缩放整屏） | 极轻；禁整屏闪白 |
| 远景烟 / 光尘 | `art_fx_dust` | `translateY` 慢移 **8～14s** 一轮 + `opacity 0.20↔0.45` | 更轻；不挡 CTA |

缺 `art_fx_candle` 时：v2 程序色烛罩（`tavern_candle`）可 fail-soft；有真图后验收只认图 + 微动。  
`art_fx_dust`：P0 允许程序尘（不影响 H1–H3）。  
**禁止**为烛 / 尘加 beep 或独立 Foley。

静默：这两层 **仍播**。

### F.2 CTA 稳态微光（对照 v3 §3.4）

| 谁 | 稳态 | 禁止 |
|----|------|------|
| 主 CTA | 4.0～5.0s 一轮，高光 `opacity 0.92↔1.00`（或铜边极弱）；**scale 峰值 ≤1.01** | 上下弹跳、呼吸放大到 1.04+ |
| 设置卡 | 默认 **不动** | 整卡漂浮 |
| 顶栏 | 可选 6s 一轮 `opacity 0.96↔1.00` | 标题跳动 |
| 「进桌看看」 | **不动** | 做成第二个主 CTA 动效 |

入场 stagger 结束后才开本表微光，避免和 T5 `scale 0.96→1` 抢同一条属性。
