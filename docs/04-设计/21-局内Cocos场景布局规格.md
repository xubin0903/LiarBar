## 1. 设计分辨率与适配

### 1.1 场景取向

| 场景 | 取向 | 说明 |
|------|------|------|
| `Table.scene`（局内） | **强制横** | 对齐 11 O1 / R-LAND-1：进桌立刻横；大厅仍竖（ArkUI 壳，不进本场景） |
| 宿主 | ArkUI `Table.ets` + `XComponent` | Mode 2 嵌入（见 05 引擎重写方案）；本文只管 Cocos 内布局 |

### 1.2 Canvas 设计分辨率（推荐锁）

| 项 | 锁（v0.1.0） | 说明 |
|----|--------------|------|
| 设计分辨率 | **1280 × 720**（宽 × 高 · 设计单位） | 横屏 16:9 基准；**禁止**写死屏幕像素当终局（对齐 11 LY1） |
| 坐标系 | 原点默认屏幕中心或左下按 Creator 工程统一；**相对锚**用百分比 / Widget | 环心、手牌、池用相对桌面框，不用魔法数 px 方案 |
| 安全区 | 刘海 / 手势条 inset 由宿主或 Widget 吃；`padB` **只**消化底 inset | **禁止**加大 `padB` 顶高手牌（11） |

### 1.3 适配策略（FIT 选择）

局内关键几何（`HAND_RING_GAP=24%` 窗口高、手牌贴底安全区上沿）**以高度百分比为主**。

| 策略 | 选用 | 理由 |
|------|------|------|
| **`FIT_HEIGHT` = true** | **主选（本版锁）** | 高度铺满设计高；24% GAP、贴底缝、顶栏 ≤12% 相对高稳定；宽边可留左右 letterbox / 扩展桌布 Cover |
| `FIT_WIDTH` = false（默认关） | 与上配套 | 单开 FIT_WIDTH 会压扁高度，易把手牌顶高或挤 bust |
| `SHOW_ALL` / 双 fit | **备选**（折叠 / 极端比） | 完整可见优先；黑边可接受；仍须满足贴底 + 24% 只吃心→牌 |
| 竖构图桌布 | 继续 `art_table_bg` Cover；安全带竖图 **30%～70% 高**（11 §4.3） | **不新出**横底图 |

**写死：** L-small（短边 <320 设计单位等价）只 **缩小** bust，**禁止**隐 bust（R-LAND-2）。断点比例抄 11 §4.2 / `TableBreakpoints`（`L_PHONE_RATIO=1.60` 等），用窗口 W/H，不按机型名。

## 3. 相对几何（对照 11 / TableLayout / 17 / 18）

数字一律 **相对量 / 已锁 vp 窗**；终局禁止魔法屏幕像素方案。

### 3.1 常量对照表（冻结 · 本版不改）

| 常量 | 值 | 真源 |
|------|-----|------|
| `HAND_RING_GAP` / `HAND_RING_GAP_PCT` | **24%** 窗口/设计高 | 11 · `TableLayout.HAND_RING_GAP_PCT` |
| GAP 落点 | **只**在桌心(荷官+池)下沿 → 手牌上沿 | 11 §2.1.2 · **禁止**垫手下 |
| `padB` | **只**底安全区 inset | 11 · **禁加大 padB 顶高手牌** |
| 手牌沉底 | 底缘贴底安全区上沿；其下仅 inset + 极小约束缝 | 11 |
| 荷官 + 池 | `lb_cmp_dealer` + `lb_cmp_pool` **须屏/桌正中**；bust 贴池旁或上 | 11 R-LAND-2 |
| 顶栏高 | **≤12%** 设计高 | 11 |
| 手牌带宽 | 建议 **18～28%**（空隙优先于吃满） | 11 |
| self 槽宽 | 约 **16%**（`SELF_SLOT_PCT`）左独立；不进 hand 权重链 | `TableLayout` |
| 左右座 | p3 左 / p1 右 = **边竖直中**；p2 上沿中；self 底带左槽 | 11 §2.2 |
| 开牌舞台 | 池中心 **下 56vp**（窗 **48～64**）；牌 **0.90×**（0.85～0.95） | **18 一字不改** |
| 暗场 | 压暗 **0.40** · 模糊 **6vp** · 只糊背景 | **18** |
| 抽→翻 / 持面 | `DRAW_TO_FLIP=1000ms`（800～1200）· `REVEAL_HOLD=3000ms`（2.5～3.5s） | **18 v0.1.6** |
| 开牌安全距 | 头像 ≥24 · 烛 ≥20 · 手 ≥16 · 底栏 ≥12（vp） | **18** |
| 质疑入口 | 自位身前；热区各 ≥44vp；不盖手/烛/池/宣称 | **17** |
| 池上张数 | AwaitChallenge 本手牌背可见；张数=`lastPlay.count` | **17 R5** |
| 左上 / 中顶 | 宣称+tip+法官句 → 左上；中顶 **仅** `lb_txt_timer` | **11 R6 / 17 R6** |

### 3.2 线框（横 · 与 11 ASCII 同口径）

```
← 宽 1280 设计 →
┌──────────────────────────────────────────────────────────┐
│ 宣称+法官句（左上） │  timer（中顶唯一） │ 弱 home        │  ≤12% 高
├────┬───────────────────────────────────────────────┬─────┤
│    │                    p2                         │     │
│ p3 │     dealer + pool（须屏心；bust 贴池旁/上）    │ p1  │  边竖直中
│    │         池上本手牌背 · 张数可见                 │     │
│    │         ░░ GAP 24%（只吃心→牌；禁垫手下）░░    │     │
├────┴───────────────────────────────────────────────┴─────┤
│ selfDock │        [背][背][背][背][背]  ← 中线=桌面中线  │  贴底缝
└──────────────────────────────────────────────────────────┘
     ※ 开牌：lb_cmp_reveal_stage 在池正下 56vp（认 18）
     ※ 质疑|相信：lb_cmp_challenge_entry 自位身前（认 17）
```

### 3.3 Cocos 落点注意（对标 ArkUI 踩坑）

| 要 | 不要（失败短句） |
|----|------------------|
| GAP 节点 **在** `tableHeart` 与 `lb_cmp_hand` **之间** | 把 24% 空白垫在手牌节点下面（**加大 padB 顶高手牌** / **手牌底缘离底过大**） |
| bottom band Widget 贴底 + 子节点 Bottom 对齐 | 仅 hug 高度却 Top 对齐 → 手牌飞到桌心 |
| `tableHeart` 真正居中 | bust+池偏上偏左（**荷官离开桌心牌堆**） |
| 压缩环腾 GAP 时 bust 仍贴池 | **荷官被挤上顶边** |
| `lb_txt_timer` 独占中顶 | 中顶叠宣称/法官句（**中顶仍叠宣言** · S18-28） |

## 4. z-order（建议锁）

数值越大越靠上。同层内按表序。

| z | 节点族 | 说明 |
|---|--------|------|
| 0 | `lb_cmp_table_bg` | 桌布 |
| 10 | `lb_cmp_safe_frame` 内：环 / 桌心 / GAP / 底带 / 手牌 / 烛 / self | 稳态桌 |
| 20 | `lb_cmp_topbar` 文案与 timer | 须压过桌心装饰，但低于开牌暗场牌面可读性冲突时以 18 为准（牌面最上） |
| 30 | `lb_cmp_challenge_entry` / `lb_cmp_empty_target_choice` / `lb_cmp_play_confirm_bar` | 可点入口 |
| 40 | 飞牌 Tween 层 | 临时 |
| 50 | `lb_cmp_peek_mask` / `lb_sheet_play` | 叠层 |
| 60 | `lb_cmp_reveal_dim` | 暗场 · **不得**盖住舞台牌面（牌面另挂更高） |
| 70 | `lb_cmp_reveal_stage` | 开牌牌面最上清晰层（18 §2.5） |
| 80 | `lb_cmp_npc_challenge_bubble` | 短气泡 · 不抢点 |
| 90 | `lb_ovl_match_load` | 进桌加载最顶（轴内） |

**写死：** `lb_cmp_reveal_stage` = **桌级共享**，禁止挂在行动座私有节点下（F2 / **揭牌仅自己见**）。

## 6. 状态后缀（控件层 · 抄 02 §3）

节点可见态用后缀或同名子状态机；**共享主名、只换后缀**。

| 后缀 | 用于 |
|------|------|
| `_idle` / `_press` / `_disabled` | 可点钮、牌 |
| `_selected` | 手牌多选 |
| `_empty` | 手牌 0 |
| `_turn` | 当前行动座描边 |
| `_life_3` … `_life_0` / `_ghost` | 生命 / 幽灵 |
| `_win` / `_lose` | 局末 / 质疑结果呈现（非入口文案） |

入口仍锁 **质疑\|相信**（`lb_btn_challenge_doubt` / `_believe`）；**禁止**入口真/假/过三键。开牌 faceUp = 真 `lastPlayRanks`（认 18）。

## 7. 失败短句对照（S18-24～28 + 布局）

合入 ≠ 终验。打回优先 S18 短句；布局短句挂 11，不冒充新闸号。

### 7.1 S18-24～28（对局 / 17 / 18 · 一字不改）

| 码 | 短句 | 键 | 本场景看点 |
|----|------|-----|------------|
| **S18-24** | **开牌假面** | `lb_str_reveal_claim_face` | `lb_cmp_reveal_stage` faceUp ≠ 真出 / claim 填充 |
| **S18-25** | **开牌过快** | `lb_str_reveal_too_fast` | DRAW&lt;800ms 或 HOLD&lt;2.5s / 仍锁 3500\|5000 主读 |
| **S18-26** | **质疑窗不见上家本手张数** | `lb_str_challenge_no_pile_count` | AwaitChallenge 池上无本手牌背或张数≠`lastPlay.count` |
| **S18-27** | **法官句未全左上** | `lb_str_judge_not_top_start` | 法官/荷官句未落 TopStart |
| **S18-28** | **中顶仍叠宣言** | `lb_str_center_top_claim_stack` | 中顶除 timer 外仍叠宣称/法官句 |

### 7.2 布局短句（11 · Cocos 同等适用）

| 短句 | 不过 |
|------|------|
| **手牌未沉底** / **手牌悬空偏高** / **手牌底缘离底过大** | 底缘未贴底安全区上沿；手下大块空带 |
| **间隙不足 24%** / **手牌偏上贴中堆** | 心→牌空隙 &lt;24% 或认不出；GAP 垫手下 |
| **加大 padB 顶高手牌** | 用底 padding 抬牌带 |
| **荷官被顶飞** / **荷官被挤上顶边** / **荷官离开桌心牌堆** | bust 离池或离屏心 / 挤顶 |
| **手牌整排右偏** | 中线被 selfDock 挤走 |
| **selfDock 盖住/叠住手牌** | 最左牌被挡 |
| **环位偏高** / **左右座贴顶** | p3/p1 未边竖直中 |
| **宣言不在左上** | claim/tip 不在 TopStart |
| **开牌无位** / **开牌挡脸·烛** / **开牌看不清** | 认 18 F18-1～3 |
| **揭牌仅自己见** | 舞台非桌级共享（S18-23 交叉） |
