## 2. 布局原则（**LY1**）

终稿布局 **只认** 下列手段，互相可组合：

| 要 | 不要（当终稿） |
|----|----------------|
| 约束：`Flex` / `Row`+`Column` 权重 / `RelativeContainer` / 锚到已锁 id | `position({ x: 152, y: 210 })`、座位 `seatXs[]` 像素数组当完成 |
| 百分比：宽高 `'100%'` / `layoutWeight` / 短边比例 | 把一张参考机的 px 抄进全机 |
| 断点：按短边 / 宽高比压字号、CTA 行高、sheet 高 | 只做一种分辨率「刚好」 |
| 安全区：刘海、胶囊、手势条、圆角用系统 safe area / padding **百分比或约束** | 写死 `47px` 顶垫当终稿；宣称或 CTA 伸进不安全区 |

**安全区（写死）：** `lb_txt_claim`、`lb_cmp_hand`、`lb_btn_challenge` / 出牌主 CTA **不得**被刘海或底条裁掉、挡到点不到。装饰可进边，主信息不行。

**牌堆锚点（票 B · 只引用）：** 视觉落点仍是 08 §2.1 / 09 §1.2：`dealPileAnchor` 叠在 `lb_cmp_dealer` 手边或 `lb_cmp_pool` 上方；所有牌从 **同一锚点** 飞出。现挂绝对坐标 **偏了** = 票 B 修，本篇不给补丁步骤。锚点未过 = **D1 终验不得开**（§5）。

01 竖屏「半屏 `bindSheet`」**不得**原样搬进横屏（见 **X3**）。

## 3. 可读性验收（课设 3～5 分钟 · 听 / 看 / 点）

对象：评委 **一眼看清四座+手牌+宣称+质疑/出牌**（PM 锁句，一字不改口径）。  
墙钟：进 `lb_scr_table` 之后的稳态桌（`CLAIM` / `TURN`，发牌飞牌期另走 D1，本表不替 D1）。  
任一条失败 = **本批局内可读不过**，不得用「功能能点通」交差。

| ID | 听 | 看 | 点 | 失败短句 |
|----|----|----|----|----------|
| **O1** | 本条不听 | 进桌后画面是 **横屏桌**；四座沿桌展开，不再是竖屏一条座位 `Row` 顶满 | 竖持须转到横。不点「再转回竖还能打完整桌」当过 | 局内仍竖；或大厅被逼成必须横 |
| **LY1** | 本条不听 | 分区随安全区/短边收缩，主信息不进刘海、不贴手势条 | 不点。量的是约束，不是某一台的绝对 px | 硬编码像素当终稿；或宣称/CTA 被刘海裁掉 |
| **X1** | 本条不听（宣称口播非本批门槛） | **一眼看清四座+手牌+宣称+质疑/出牌**：`lb_cmp_seat_*` + `lb_cmp_hand` + `lb_txt_claim` + `lb_btn_challenge` / 出牌 CTA；**不滚动** | **不要滑整桌** 才找齐上述块。热区可点、可指给评委 | 要滑才找齐；或缺座/手牌/宣称/CTA 认不出 |
| **X2** | 本条不听 | 荷官 `lb_cmp_dealer`、中堆 `lb_cmp_pool` / 牌堆锚点、自己手牌、CTA 四区语义可指，**无致命互盖**（挡到认不出或点不到） | 主 CTA 与手牌长按区可点，不误触成另一区 | 荷官/中堆/手牌/CTA 致命互盖，点不到或认不出 |
| **X3** | 本条不听 | 打开 `lb_sheet_play`：盖住面积 **< 50%** 横屏可视；高度建议 **≤ 短边 40%**。顶栏宣称与四座仍可指 | 能点选牌 + `lb_btn_play`；点遮罩外/取消仍不提交。禁止再滑一层才看见提交 | 出牌包吃掉半屏或以上；或盖住宣称/四座 |
| **X4** | 本条不听 | 「回开桌」（`lb_str_home`）**弱于** 质疑/出牌。评委第一眼先看到桌与主 CTA，不是调试回大厅 | 3～5 分钟主路径 **不经过** 回开桌。可留在顶栏次级 / 溢出 / 调试角 | 回开桌抢主 CTA；或比质疑/出牌更显眼 |

**X1 补句（写死）：** PM 锁句 **「一眼看清四座+手牌+宣称+质疑/出牌」** = 横屏一帧内指认这四块，禁止靠竖向 `Scroll` 把座位或 CTA 推到屏外。手牌 5 张可横向微移（peek 区），**整桌**不得靠滑才露出宣称或主按钮。

**X2 补句：** 装饰轻叠（烛光、毡面）可过。牌堆锚点盖住手牌条、荷官盖住宣称、CTA 盖住牌堆飞线落点 = 致命，不过。票 B 锚点若仍飘在屏外/座位脸上，**X2 与 D1 一并不过**。

**X3 补句：** 01 竖屏「半屏出牌包」在横屏会吞掉桌。横屏用压缩底栏或侧栏；方式芯片 + 提交必须同屏可见。带话默认可跳过（已锁），本批不新加输入框。

**X4 补句：** 回开桌是联调/调试出口，不是课设卖点。降级后仍可离开对局；只禁「铺满底栏、和质疑并排抢戏」。

### 3.1 本表不验（避免误勾）

- 大厅烛火 / 悬停闪 / 夜馆声场 / 口播（R1–R4）——**不重开**
- L1 加载毫秒、D1 飞牌时长 / stagger——数字仍以 08 为准，**终验暂停**见 §5
- C1 角标 56×78 / 80×112——口径不改，**终验暂停**见 §5
- 质疑四拍光效、砸杯、押面子——**继续冻**
- AI 人格、旁观敲桌/画✗、`demo_seed` 高潮——不扩；TC-19 仍挂
- 战报页是否横屏——非本批硬门槛
