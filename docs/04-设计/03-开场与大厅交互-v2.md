## 2. 冷启动时间轴（默认总长 ~2.0s，可调 1.5～2.5s）

同一路由 `lb_scr_lobby` 内播完，**不另开启动页路由**（废止 `lb_scr_home` 仍成立）。  
时长做成常量（建议 `BOOT_MS_*`），总长 clamp 到 **1500～2500ms**；低端机可压到 1.5s，演示可拉到 2.5s。

### 2.1 开场帧表（已会签 · 默认 ~2.0s）

| 拍 | 时刻 | 时长 | 画面 | 媒体 / 程序 |
|----|------|------|------|-------------|
| T0 黑场 | 0 | 一帧～可忽略 | 全屏深底，无控件 | 程序色 `tavern_bg` `#1A120E`；**不是**独立路由 |
| T0→招牌 / 大厅底 | 0～0.35s | 350ms | 黑场 **淡入** `art_lobby_bg`（含招牌静帧） | `$r('app.media.art_lobby_bg')`。P0 **不强制** `art_splash_still`；需要静帧时 **复用 `art_lobby_bg`** |
| 加载暗示 | 0.35～0.9s | 550ms | 底图已在；中央或底沿 **转圈或细进度条**（二选一即可） | 程序控件，不强制新媒体。细条用 `tavern_candle`，轨道用 `tavern_shadow` |
| 荷官亮相 | 0.9～1.3s | 400ms | `lb_cmp_dealer` 淡入；`art_dealer_bust_idle` → `art_dealer_bust_announce` **轻切**（透明度交叉，禁止硬切闪白） | idle / announce 各一帧即可 |
| 分区 stagger + 招呼 | 1.3～1.7s | 400ms | 设置卡 → 主 CTA → 次级「进桌看看」依次入场；荷官字幕打出默认招呼 | 见 §2.2 / §3 |
| 稳态 | 1.7～2.0s | 300ms | 动效收住；**`lb_btn_quickstart` 可点** | 呼吸 / 烛光微动继续（§4），不再挡点击 |

**可点规则**：T0～分区 stagger 期间主 CTA **不可点**（`_disabled` 或忽略点击）。**1.7s 起**（或总轴播完）必须可点。允许点「跳过开场」直接稳态——**P1**，本批不强制。

### 2.2 分区 stagger 顺序（1.3～1.7s 内）

每层间隔约 80～100ms，单层 `opacity 0→1` + `translateY 12→0` + 略 `scale 0.96→1`：

1. 顶栏（若尚未随底图出现）  
2. 荷官区（胸像已在 0.9s 入；本拍只补字幕条）  
3. 设置卡（昵称 / 人数 / 静默）  
4. 主 CTA `lb_btn_quickstart`  
5. 次级「进桌看看」

### 2.3 荷官招呼字幕

| 项 | 口径 |
|----|------|
| 默认句（策划已给） | **夜深了，位子给你留着。** |
| 建议 key | `lb_str_dlr_lobby_greet`（**新增文案 key**，不改已锁控件 id） |
| 控件 | 挂在 `lb_cmp_dealer` 旁或下方；建议复用桌内字幕习惯，大厅用 `lb_txt_dealer_line` 或本页本地 `Text` |
| 入座满句 | `lb_str_dlr_lobby_full`「本桌四人，酒已满。」**仍留给入座满**，不覆盖本句 |
| 口播 | 非静默可播短句（无素材则静音，不挡时间轴） |
| **静默局** | **关口播 / 关强震**；**字幕必须仍出**（与 F-13、AI 规格 §1.5 一致） |
| 停留 | 打出后至少保持到稳态；可不自动淡出。若淡出，≥1.5s 后、不挡 CTA |

## 3. 大厅信息架构

竖屏。**减少「一张大褐卡片糊满」**：设置项收进 **窄卡**，荷官与 CTA **不进同一块褐底**。

```
┌─────────────────────────────┐  ← 顶栏（薄，透底）
│ 谎馆              [战绩]    │
├─────────────────────────────┤
│                             │
│     荷官胸像 lb_cmp_dealer  │  ← 荷官区（独立，不套褐卡）
│     「夜深了，位子给你留着。」│
│                             │
├─────────────────────────────┤  ← 设置卡（窄，留左右边距）
│  昵称  [ lb_cmp_nick_field ]│
│  人数 n · 命 3（只读）      │
│  静默局  [ lb_tog_silent ]  │
├─────────────────────────────┤
│                             │
│    【 快速开桌 】            │  ← 主 CTA，从背景跳出
│    lb_btn_quickstart        │
│                             │
│         进桌看看            │  ← 次级，弱
└─────────────────────────────┘
```

| 分区 | 放什么 | 视觉 | 锁名 |
|------|--------|------|------|
| 顶栏 | 标题「谎馆」；战绩入口可弱 | 透 `art_lobby_bg`，**不要**再铺一张满宽褐条 | 标题文案 `lb_str_app_title`；战绩 `lb_btn_records`（已有，可后挂） |
| 荷官区 | 胸像 + 招呼字幕 | 胸像悬浮在底图上；字幕一行 `tavern_paper` | `lb_cmp_dealer` |
| 设置卡 | 昵称、人数、静默；「一键填上次」可留在卡内弱链 | **窄卡**：左右边距 ≥16vp，圆角 12vp，底 `tavern_panel`，**不要**拉满屏宽到贴边 | `lb_cmp_nick_field` · `lb_cmp_playercount` · `lb_tog_silent` |
| 主 CTA | 「快速开桌」 | **独立于设置卡**；宽接近安全区但用高对比皮，不跟卡同色 | `lb_btn_quickstart` |
| 次级 | 「进桌看看」 | 字号小于 CTA、色 `tavern_mute`；不抢主按钮 | 文案 key `lb_str_nav_peek`（已有）。热区若补 `.id` 建议 `lb_btn_peek_table`（**新增，不改已锁名**） |

### 3.1 CTA 必须从背景跳出来

| 要 | 不要 |
|----|------|
| 填充 `tavern_accent` `#F0C14B`，字 `tavern_bg` `#1A120E` | CTA 做成与设置卡同色的褐块 + 金字 |
| 可挂 `art_btn_primary` / `art_btn_primary_on` | 无描边、无按压、与 `felt` 糊成一块 |
| 热区高 ≥56vp（对齐 01 一指原则） | 缩成细字链 |

命数仍只读 3（规则已锁）。人数 / 昵称 / 静默逻辑不变（F-11 / F-13）。

「进桌看看」：v2 升格为 **可见次级入口**（现实现是灰字展开调试导航）。落地后仍可进桌预览，**不得**做成第二个主 CTA。

## 4. 微动效（禁止全程死静）

稳态后仍要有 **轻** 循环，幅度小到不抢 CTA。

| 动效 | 何时 | 量级 | ArkUI 提示 |
|------|------|------|------------|
| 底图淡入 | 0～0.35s | `opacity 0→1`，350ms EaseOut | `animateTo({ duration: 350, curve: Curve.EaseOut })` |
| 加载转圈 / 细条 | 0.35～0.9s | 转圈一周或细条 0→100%；结束后淡出 150ms | `Progress({ type: ProgressType.Ring })` 或 `Linear`；勿用全屏挡死 |
| 荷官交叉淡化 | 0.9～1.3s | idle↔announce 各 `opacity` 交叉 400ms | 两张 `Image` 叠 `Stack`，只改透明度 |
| 分区 stagger | 1.3～1.7s | 每层 80～100ms；`opacity` + `translateY(12)` + `scale(0.96→1)` | 各层独立 `animateTo`，错开 `setTimeout` / 链式回调 |
| **荷官呼吸** | 稳态循环 | `scale 1.00↔1.02`，周期 1.4～1.8s | `animateTo` 往返；**不要**位移头像 |
| **烛光闪**（与呼吸二选一即可，鼓励都做但更轻） | 稳态循环 | 焰芯/侧光 `opacity 0.72↔1.0`，周期 0.5～0.9s，略不规则 | 罩一层极淡 `tavern_candle`，只改透明度 |
| **CTA 按压缩放** | 按下 | **≤80ms** `scale 1→0.96`；抬起 100～120ms 回 1 | 对齐 01 §1.3；可切 `art_btn_primary_on` |
| 字幕打出 | 1.3s 起 | 整句淡入 200ms，或逐字（P1） | `opacity`；静默局同样播字幕 |

**禁止**：进页后所有节点 `opacity=1` 且无循环；用闪白、大弹跳、全屏粒子。  
**静默局**：动效与字幕 **仍播**；只关口播与强震动。

## 7. 用户验收清单（逐步 · 打开 App 即走）

按顺序勾。任一步失败即本规格未落地。

| # | 用户做什么 / 看到什么 | 通过标准 |
|---|----------------------|----------|
| 1 | 打开 App | 先深底黑场（`#1A120E`），**不是**立刻一张褐卡表单 |
| 2 | 0～0.35s | `art_lobby_bg`（含招牌）从黑场淡入；无闪白 |
| 3 | 0.35～0.9s | 看见转圈 **或** 细进度条，能感到「在进馆」 |
| 4 | 0.9～1.3s | 荷官胸像出现；idle → announce 轻切，不是两张硬切 |
| 5 | 1.3～1.7s | 设置卡与 CTA **错开进场**（能看出先后），不是同时蹦出 |
| 6 | 同时 | 字幕默认句：**「夜深了，位子给你留着。」** |
| 7 | 1.7～2.0s 起 | 大厅五分区可辨：顶栏 / 荷官 / 窄设置卡 / 主 CTA / 「进桌看看」 |
| 8 | 看设置卡 | **不是**一张大褐卡片糊满中下区；卡左右有边距 |
| 9 | 看主按钮 | `lb_btn_quickstart` **醒目**（`#F0C14B` 底 + `#1A120E` 字或 `art_btn_primary`），从背景跳出 |
| 10 | 点快速开桌 | 可点；按下有缩放（≤80ms）；逻辑仍是默认 4 人桌（不改规则） |
| 11 | 停在大厅 3s | 荷官有呼吸 **或** 烛光轻闪；**禁止**全程死静 |
| 12 | 打开 `lb_tog_silent` 再冷启动（或本页再触发招呼） | **无口播 / 无强震**；**招呼字幕仍在** |
| 13 | 点「进桌看看」 | 次级、不抢主 CTA；能进桌预览（现有导航可保留） |
| 14 | 进桌后 | 局内画面 / 引擎 / `demo_seed` **与本 PR 无关、未改** |

总时长目测约 **2 秒**（允许 1.5～2.5s）。超时 3s 仍停在转圈 = 不通过。
