## 2. 冷启动时间轴（默认总长 ~2.0s，可调 1.5～2.5s）

同一路由 `lb_scr_lobby` 内播完，**不另开启动页路由**（废止 `lb_scr_home` 仍成立）。  
时长做成常量（建议 `BOOT_MS_*`），总长 clamp 到 **1500～2500ms**。缩短时按比例压各拍，**不得删掉**黑场、加载、荷官、stagger、稳态任一段。

## 3. 大厅信息架构

竖屏。**减少「一张大褐卡片糊满」**：设置项收进 **窄卡**，荷官与 CTA **不进同一块褐底**。

```
┌─────────────────────────────┐  ← 顶栏（薄，透景深底）
│ 谎馆              [战绩]    │
├─────────────────────────────┤
│                             │
│     荷官胸像 lb_cmp_dealer  │  ← 荷官区（独立，不套褐卡）
│     「夜深了，位子给你留着。」│
│                             │
├─────────────────────────────┤  ← 设置卡（窄，留左右边距）
│  昵称  [ lb_cmp_nick_field ]│
│  人数 n · 命 3（只读）      │
│  静默局  [ lb_tog_silent ]  │
├─────────────────────────────┤
│                             │
│    【 快速开桌 】            │  ← 主 CTA，从背景跳出
│    lb_btn_quickstart        │
│                             │
│         进桌看看            │  ← 次级，弱
└─────────────────────────────┘
```

| 分区 | 放什么 | 视觉 | 锁名 |
|------|--------|------|------|
| 顶栏 | 标题「谎馆」；战绩可弱 | 透景深底，不要满宽褐条 | `lb_str_app_title`；战绩 `lb_btn_records`（可后挂） |
| 荷官区 | 胸像 + 招呼字幕 | 胸像叠在景深上；字幕 `tavern_paper` | `lb_cmp_dealer` |
| 设置卡 | 昵称、人数、静默；「一键填上次」可留弱链 | **窄卡**，左右 ≥16vp，圆角 12vp，底 `tavern_panel` | `lb_cmp_nick_field` · `lb_cmp_playercount` · `lb_tog_silent` |
| 主 CTA | 「快速开桌」 | **独立于设置卡**；质感皮 + 高对比 | `lb_btn_quickstart` |
| 次级 | 「进桌看看」 | 小于 CTA，色 `tavern_mute` | 文案 `lb_str_nav_peek`。热区若补 `.id` 建议 `lb_btn_peek_table` |

### 3.1 CTA 必须从背景跳出来

| 要 | 不要 |
|----|------|
| 填充 token `tavern_accent` `#F0C14B`，字 `tavern_bg` `#1A120E`；**交件必须是质感图** | 用现挂平涂 `art_btn_primary` 当 v2 完成 |

## 4. 微动效（禁止全程死静）

| 动效 | 何时 | 量级 | ArkUI 提示 |
|------|------|------|------------|
| 静帧淡入 | 0～0.35s | `opacity 0→1`，350ms EaseOut | `animateTo({ duration: 350, curve: Curve.EaseOut })` |
| 加载转圈 / 细条 | 0.35～0.9s | 转圈或细条 0→100%；结束淡出 150ms | `Progress` Ring 或 Linear |
| 荷官交叉淡化 | 0.9～1.3s | idle↔announce `opacity` 交叉 400ms | 两张 `Image` 叠 `Stack` |
| 分区 stagger | 1.3～1.7s | 每层 80～100ms；`opacity` + `translateY(12)` + `scale(0.96→1)` | 各层独立 `animateTo` |
| **荷官呼吸** | 稳态循环 | `scale 1.00↔1.02`，周期 1.4～1.8s | 往返；不要位移头像 |
| **烛光闪** | 稳态循环 | 焰芯 `opacity 0.72↔1.0`，周期 0.5～0.9s | 极淡 `tavern_candle` 罩 |
| **CTA 按压缩放** | 用户按下 | **≤80ms** `scale 1→0.96`；抬起 100～120ms 回 1 | 对齐 01 §1.3 |
| 字幕打出 | stagger 拍 | 整句淡入 200ms | 静默局同样出字 |

呼吸与烛光至少做一种，鼓励都做但更轻。  
**禁止**进页全静态、闪白、大弹跳。静默局：**动效与字幕仍播**，只关口播与强震。

## 7. 用户验收清单（严格 1.5–2.5s 逐步）

冷启动总长必须落在 **1.5～2.5s**（默认帧表 ~2.0s）。下表按时间走；**先看后点**。任一步失败即未通过。

| 4 | 0.9～1.3s | 仍不点 | 荷官出现；idle→announce **轻切**。此拍点 `lb_btn_quickstart` **不应**开桌 |
| 5 | 1.3～1.7s | 仍不点 | 设置卡、主 CTA、「进桌看看」**错开**入场（能看出先后） |
| 6 | 与 #5 同时 | 看荷官旁字幕，不点 | 默认句：**「夜深了，位子给你留着。」** |
| 7 | 1.7～2.0s（总长不得早于 1.5s、不得晚于 2.5s） | 看整屏，仍先不点 | 五分区可辨：顶栏 / 荷官 / 窄设置卡 / 主 CTA / 「进桌看看」。设置卡 **不是**糊满中下区的大褐块。主按钮从景深底跳出（质感 CTA，不是平涂褐金块） |
| 8 | 轴结束后（≤2.5s） | **点 `lb_btn_quickstart`（「快速开桌」）** | 可点；按下整钮缩放（≤80ms）；进入默认开桌（规则不变）。若 2.5s 后仍在转圈或点了没反应 = 不通过 |
| 9 | 稳态停 3s | **不点**，只看 `lb_cmp_dealer` / 近景烛 | 呼吸 **或** 烛光轻闪。全程死静 = 不通过 |
| 10 | 回大厅后 | **点 `lb_tog_silent` 打开静默局**，再杀掉进程 **重新打开 App**（再走 1.5～2.5s） | 无口播、无强震；**招呼字幕仍在**：「夜深了，位子给你留着。」 |
| 11 | 稳态后 | **点次级「进桌看看」**（不要点成主 CTA） | 弱入口、不抢主按钮；能进桌预览。局内画面不在本规格验收范围 |
| 12 | 进桌后 | 看 Table / 引擎，**不要当本清单的美术验收** | 局内 / `demo_seed` **未改**。现挂 `$r` 冒充 v2 完成 = 不通过 |

**分层验收（`feat/art-lobby-v2-final` 真图后加勾，hex 用 §5）**：能指认远景冷雾、中景木纹/桌、近景烛、荷官层次、**独立**静帧、CTA 质感。同一张褐金底糊开场、或只有 token 色块拼贴 = 不通过。

## 8. ArkUI 提示（会签齐后才写进 `feat/client-lobby-v2`）

| 区域 | 建议 |
|------|------|
| 根 | `Stack`：黑场色 → 静帧 → 景深底 → 控件层 |
| 时间轴 | `@State bootPhase`；`aboutToAppear` 启动；总长 clamp 1500～2500 |
| 淡入 / stagger | `animateTo`：`opacity` / `scale` / `offset` |
| 荷官 | 两图交叉 `opacity`；稳态呼吸 `scale` |
| CTA | 透明 `Button` 盖质感皮；补按压 `scale` |
| 加载 | `Progress`，结束移除或 `visibility` |
| 字幕 | 静默局跳过 `lb_sfx_*`，`Text` 照写 |

**现在不要改** `Lobby.ets` / `LobbyPanel.ets` 当 v2 完成。条件见 §0.1。P0 占位 `$r` 只许联调时间轴。
