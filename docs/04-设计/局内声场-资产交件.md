曲风对拍 13：Rhodes + jazz drums + baritone sax + standup bass，慢速 dark jazz，与大厅 `bgm_lobby_night`（疏、慢、少鼓点）一耳朵能分。

### 1.3 裁转命令（锁死 · 禁止改数字另烤）

源 mp3 **不进仓**。在临时目录下载后：

```
ffmpeg -y -ss 56 -t 32 -i ruskerdax_-_moil.mp3 \
  -af "afade=t=in:st=0:d=0.4,afade=t=out:st=31.2:d=0.8,volume=-12.7dB" \
  -ar 48000 -ac 2 -c:a libvorbis -q:a 5 \
  entry/src/main/resources/rawfile/audio/bgm/bgm_table_bluff.ogg
```

| 参数 | 含义 |
|------|------|
| `-ss 56 -t 32` | 从 56s 起取 **32s** 循环体（落在 13 的 24～40s 窗） |
| `afade in 0.4s` / `out @31.2s · 0.8s` | 头尾淡化，接缝 ≥500ms 口径 |
| `volume=-12.7dB` | 压到 13 的 −14～−12 dBFS 窗 |
| `-ar 48000 -ac 2 -c:a libvorbis -q:a 5` | 立体声 48 kHz Vorbis |
