## 1. 视觉基调（一句话）

> **夜半酒馆：暖烛光贴着桌面，冷阴影压着四周；牌没翻之前全桌都在演，翻牌那一下光感切红。**

答辩可接：不是赌场霓虹，也不是写实酒吧照片，而是「能看清信息的心理张力桌」——永远看得见宣称/命数/轮到谁，高潮只靠色温与红光叠加，不靠 3D。

## 3. 灯光与氛围（程序化色温，对齐互动方案 + PRD F-23）

互动方案 §3.6：**系统「光感切红」**。  
PRD **F-23 沉浸光感 = P1**（昼夜/质疑爆灯，不进首版演示承诺）。  
**MVP（P0）必须能切色**，用全屏色罩 + 色温偏移即可，**不依赖**环境光传感器/灯效硬件。F-23 有余力再把同一套参数接到系统光感。

### 3.1 色温与罩层规格（可直接写进主题）

程序用两个可动画字段即可：

- `overlayColor`：ARGB  
- `warmShift`：白平衡倾向，`-1.0` 偏冷蓝 → `+1.0` 偏暖黄（实现可用 `Color.blend` 一层极淡滤色）

| 阶段 | 时长（表现） | overlayColor | 建议 alpha | warmShift | 画面要求 |
|------|--------------|--------------|------------|-----------|----------|
| 常态桌面 `LIGHT_IDLE` | — | `#E8B86D` | 6%～8% | `+0.35` | 桌心略暖、四角 `tavern_shadow` 压暗；信息条不被罩脏 |
| 拍1 指控 `LIGHT_ACCUSE` | ≈0.8s | `#C23A3A` | 12% | `+0.15` | 质疑者头像/姿态图标放大；**尚未满屏红** |
| 拍2 对峙 `LIGHT_STANDOFF` | ≈1.2s | `#C23A3A` | **28%～32%** | `-0.10` | **切红光感**；被质疑者表情全桌最大；押注窗嵌此拍 |
| 拍3 翻牌 `LIGHT_REVEAL` | ≈1.5s（总三拍 ≤4s） | `#C23A3A` | 18% + 牌面高光 | `+0.05` | 逐张翻；当前翻开牌加 `tavern_accent` 外发光；可砸杯 |
| 质疑成功定格 `LIGHT_SUCCESS` | 0.4s 定格 | `#D4A017` | 22% | `+0.40` | 金闪盖过红；受罚者头像一震 |
| 质疑失败定格 `LIGHT_FAIL` | 0.4s 定格 | `#3D6B4A` | 16% | `+0.20` | 绿金稳光；质疑者头像一震 |
| 惩罚泼酒 `LIGHT_PENALTY` | ≤0.6s | `#6B1218` | 24% | `0` | 酒液斜扫切片；命数格 -1 |
| 出局 `LIGHT_OUT` | 0.8s | `#6E7A86` | 20% | `-0.45` | 去饱和；头像切幽灵框 |
| 结算战报 `LIGHT_REPORT` | — | `#E8B86D` | 8% | `+0.25` | 回到暖桌，胜负条用金/铜，不再红罩 |

插值：阶段切换 **200～280ms** 线性或 ease-out；跳过三拍动画时 **一帧切到定格色**（GDD/互动：三拍可跳过）。

### 3.2 常态 vs 高潮（答辩口述稿）

| 场景 | 光 | 玩家应感到 |
|------|----|------------|
| 出牌轮转 | 暖烛、桌心亮、边座暗 | 还能演、还能看信息 |
| 拍1 | 红刚起、指控姿态 | 「有人拍桌了」 |
| 拍2 | 红铺上、表情放大 | 「要翻了，押不押」 |
| 拍3 | 红退半、牌面爆亮 | 「真假就这一下」 |
| 结算/出局 | 金或灰蓝，红撤走 | 高潮结束，读结果 |

### 3.3 F-23（P1）怎么接、MVP 先做什么

| 优先级 | 做什么 | 验收 |
|--------|--------|------|
| **P0 · MVP** | 上表 overlay + warmShift；质疑进拍2 必切红 | 演示拍2 肉眼红、拍3 牌面亮、跳过不卡色 |
| P1 · F-23 | 同一 token 驱动系统沉浸光感（若 API 可用）：拍2 偏红、结算偏暖黄 | 关系统灯效时 **UI 罩层仍在**（灯效只是增强） |
| P1 | 信任温度（互动 §3.5）：头像周缘冷蓝 `#3A5A7A` ↔ 热红 `#C23A3A` | **禁止**文案写成「说谎值」 |

静默局（PRD F-13）：**仍切色**（色不是音效）；只关强震动/嘲讽音/催促密度。

## 4. 张力层次（对齐 GDD §9.1）

三层不可抢层级。美术只提供「框/罩/光」，不把弱信息画得比宣称更大。

| 层级 | 信息（GDD） | 美术规格 | 禁止 |
|------|-------------|----------|------|
| **永远可见** | 当前宣称、轮到谁、各自剩余命、倒计时 | 顶栏/桌心宣称徽章：字 ≥18fp、对比用 `tavern_paper`/`tavern_accent`；命数 3 杯常驻；倒计时右上，剩余不足 5 秒字色改 `tavern_danger`（催促表现层，静默局可关抖） | 装饰遮挡宣称字母；命数用细线图标看不清满/空 |
| **强提示** | 被点名、被画✗、质疑窗口 | **点名**：头像框叠烛火盯梢（焰芯 `tavern_candle`，外环脉冲 0.8s）；**画✗**：头像右下角 `art_sign_no`，颜色 `tavern_danger`；质疑窗用危险按钮色 + 拍1～3 光 | 点名做成全屏黑场（会丢永远可见信息） |
| **私有手牌区** | 仅本人牌面 | 底栏独立层；默认牌背 + `art_card_privacy_mask`；长按揭开（PRD F-03）；松手收回。他人座位 **只见表情面具，不见牌** | 手牌区用高饱和装饰；揭开时牌面小于表情轮盘 |

弱化层（面子分、历史轮次）：`tavern_mute`，字 12fp，不进强提示光。

实况窗（GDD §9.2，非本岗画全套 Live View，只定色）：阶段字 `tavern_paper`，倒计时同桌面，宣称简称用对应牌符号色。

## 5. 字体 · 圆角 · 阴影（ArkUI 轻量规范）

不写品牌手册。只锁能直接抄进 `attr` 的数。

### 5.1 字体

| 角色 | 字体 | 字号 | 字重 | 色 |
|------|------|------|------|-----|
| 宣称字母（A/K/Q） | HarmonyOS Sans（设备默认无则 `sans-serif`） | 28～32fp | Medium | `tavern_accent` 或对应牌符号色 |
| 荷官播报 | 同上 | 16fp | Regular | `tavern_paper` |
| 主按钮 | 同上 | 16fp | Medium | 见表 2.2 |
| 信息条（命/倒计时/轮到谁） | 同上 | 14fp | Medium | `tavern_paper` / 紧急 `tavern_danger` |
| 话术/弹幕/战报正文 | 同上 | 14fp | Regular | `tavern_paper` |
| 弱化/设置项 | 同上 | 12fp | Regular | `tavern_mute` |

- **不要**用书法/哥特/英文衬线当正文（答辩投影糊）。  
- 牌面符号优先 **图形**（见资源清单），字母仅作后备。  
- 数字倒计时用等宽感觉：`HarmonyOS Sans` 即可，不必另嵌字体文件。

### 5.2 圆角

| 元件 | 圆角 |
|------|------|
| 全屏页 | 0 |
| 信息条/操作面板 | 12vp |
| 主/危险按钮 | 10vp |
| 牌面 | 10vp |
| 头像框（圆形裁切） | 50% |
| 头像框底托（方圆） | 16vp |
| 表情轮盘格、小图标底 | 8vp |
| 战报卡片 | 12vp |
| 轻提示/Toast | 8vp |

### 5.3 阴影与描边

| 场景 | 阴影 | 描边 |
|------|------|------|
| 常态牌/按钮 | `offset(0, 4)` blur 8，色 `#00000066` | 1vp `tavern_brass` 40% |
| 轮到谁 / 点名烛火 | 外发光 blur 12，色 `tavern_candle` 55% | 2vp `tavern_candle` |
| 质疑拍2 焦点 | 外发光 blur 16，色 `tavern_danger` 50% | 2vp `tavern_danger` |
| 手牌区 | 内阴影向上，色 `tavern_shadow` 70%（与桌面分层） | 无 |

ArkUI：优先 `shadow` + `border`；不要上复杂 `backdrop-filter` 毛玻璃（中端机抖）。

### 5.4 间距（对局桌）

- 安全边：左右 16vp，底 12vp + 手牌区。  
- 头像条与桌心池：≥12vp，避免点名光吃掉池牌。  
- 点击热区：图标视觉 48vp，热区 ≥48vp。

## 6. 明确不做

| 不做 | 原因（对齐一页纸 §5 / PRD §4.4） |
|------|----------------------------------|
| 3D 场景 / 3D 角色 / 空间建模 | 过重，非本局必要 |
| 完整立绘流水线（多服饰、全身转面、商业原画） | 课设工期；半身/胸像占位 + 表情符号即可 |
| 商业皮肤商城、付费抽皮肤 | PRD P2 / 合规；校园皮只是文案换皮 |
| 写实人脸、裸奔五官特写 | 互动方案：酒馆化面具；FaceAR 也映射到符号 |
| 用光效改胜负或「说谎值」 | 社交桌：表现层不改牌真假（一页纸假设 1） |
| 为校园皮复制第二套布局/规则 | 规则与线框不变，只换文案与少量符号 |

实现：同一套组件换 `media` 分层或运行时 `skinId`；**MVP 可不做校园皮资源**，本表给后续换皮清单。

| 项 | 夜半酒馆（默认） | 食堂饭卡局（仅皮） |

## 8. 对局桌构图（给 UI 线框，不锁死像素稿）

竖屏 1080×2340 逻辑画板（vp 按满高换算）：

```
┌ 永远可见信息条：宣称 | 倒计时 | 荷官一句 ─┐
│  对座头像（AI）                           │
│           ┌ 公共池 3 牌位 ┐               │
│  左座      │  扣牌/翻牌    │      右座    │
│           └──────────────┘               │
│  己方头像框 + 命数酒杯                     │
├ 手牌区（私有，防窥罩）+ 表情轮盘 ──────────┤
└ 操作：出牌方式 | 带话(可跳过) | 点名 | 质疑 ┘
```

质疑三拍可半屏盖住桌心+操作，**不得盖住宣称与倒计时**（除非玩家点了跳过进定格）。

## 9. 制作约束（课设）

- 风格：平涂 + 1 级暗面 + 烛光点缀；单色图形牌符。  
- 线宽：图标 2～3px（按 96 源）。  
- 所有角色 **半身/胸像或头像圆**；背景透明 PNG。  
- 出图命名与尺寸见 [关键资源规格清单.md](./关键资源规格清单.md)。  
- 验收：开发按文件名挂上后，**不必再问「用什么色/多大」**。
