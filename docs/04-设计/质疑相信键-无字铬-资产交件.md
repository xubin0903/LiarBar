## 2. 双通道规则（色盲安全）

禁止只靠红 / 绿或只靠色温。质疑 / 相信必须 **形 + 色温** 双通道可分：

| 通道 | 质疑 `*_doubt` | 相信 `*_believe` |
|------|-------------------|----------------|
| **形** | **更尖**圆角（≈14px）；更厚暗描边；左边 **斜撇** + 细横 | 高圆角 **pill**；左边浅 **勾** |
| **色温** | 冷：钢青 / teal-copper，压红抬蓝绿（同族 prior false） | 暖：烛金 `#E8B86D` / 铜 `#C4A46A` / accent（同族 prior true） |
| **ON** | 冷 teal 洗 + 钢边；**不是**暖金的色相双胞胎 | 烛金洗 + 铜边更亮 |

色盲（含红绿）仍须靠 **轮廓（尖角 vs pill）+ 撇/勾** 分清质疑｜相信。
