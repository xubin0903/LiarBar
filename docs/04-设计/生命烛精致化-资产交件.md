### 1.1 body > flame（生成脚本实测 bbox）

| 层 | bbox (x0,y0,x1,y1) | 面积 (px) |
|----|---------------------|-----------|
| body | 26, 38, 104, 156 | **9401** |
| flame_0 | 47, 25, 74, 60 | 1008 |
| flame_1 | 53, 18, 75, 61 | 1012 |
| flame_2 | 53, 27, 82, 59 | 990 |
| flame_3 | 49, 30, 77, 57 | 812 |

四帧焰面积均 ≪ body。焰底落在柱顶一带（y≈57–61），坐在身上，不另占半幅。

### 1.2 idle loop

`flame_0` → `flame_1` → `flame_2` → `flame_3` → `flame_0`。  
邻帧相关（同一泪滴质量）但不冻；3→0 可接。暖烛金 `#E8B86D` / accent `#F0C14B`，焰芯纸色。建议周期约 0.55～0.85s（对齐大厅近烛口径，UI 14b 定拍）。

### 1.3 extinguish（禁止生命态硬切）

形变序，不是三张无关静帧：

| 帧 | 形 | 核心 bbox 高（α≥48） |
|----|----|----------------------|
| `_0` | 仍是泪滴焰，开始收 | 22 |
| `_1` | 短 stub | 9 |
| `_2` | 圆残芯 / ember（非泪滴） | 8 |
| `_3` | 上升烟缕 + 灭点 | 51 |

掉命：被扣那一枚走灭序（14 §5.2 灭窗 180～280ms 可裁播），落到新稳态（残 / 濒 / 幽灵）。**不要** full 贴图瞬切 hurt。

### 1.4 旧三态暂留

`_full` / `_hurt` / `_dying` **本批不删**。已按新 body+焰合成回烤，给未接 loop 的客户端兜底。  
**以 UI 14b 终锁为准** — 14b 若改分层名，本批文件先同名保留，再开换名票。
