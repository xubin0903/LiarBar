### 1.1 补句（写死）

**R-LIFE-1 · 去 showDigit：** 「当面」= `lb_scr_table` 稳态能看见的自位生命组。无障碍仍可读「自己生命 + 剩余整数」，**不**再挂可见 `Text`。14 / 14a 旧句「自己数字可旁注 / 可叠 `lb_txt_life_self`」**被本文覆盖**。口播/字幕说「还剩 2」仍认 14a，那不是座旁数字。

**R-LIFE-2 · 烛身＞火苗：** **柱是主体、焰是冠。** 身层只认 `art_life_candle_body`；焰层只认 `art_life_candle_flame_*`。满血尤其不得焰高于柱。残/濒焰更矮，柱仍须能指认。只换色、焰仍压柱 = 仍不过。**放大后**焰须随身等比；焰变胖压柱 = **放大后焰压烛身**。

**R-LIFE-3 · 火苗循环：** 焰层三槽可 **多帧循环** 或 **同槽循环意图**（`ImageAnimator` / 同 `$r` 多帧）。美术暂无循环图：旧整图 `art_life_candle_full` / `_hurt` / `_dying` 可暂留兼容 = **占位 ≠ 终验**。**终验认新分层**（body + flame_*）。用整图静帧勾「循环已完成」= 打回本条。

**R-LIFE-4 · 熄灭时序：** 被扣那一枚播 `art_life_candle_extinguish_*`（见 §2.2 帧窗），再落到新稳态。整组瞬间换皮、或 duration=0 = **掉命硬切换态**。总窗 **180～320ms**。14 §5.2 旧窗让位本窗。全屏闪红仍禁（质疑仍冻）。**不新造** `lb_sfx_life_drop`；起势复用 15 的 `lb_sfx_card_flip`。调试路径须先开窗再 −1（R-LIFE-5）；无窗硬挂 −1 叠字 = 先打回 R-LIFE-5。

**R-LIFE-5 · 调试小钮开窗：** 只为 Rebuild 验熄灭与三态。不改 `lives_default`。  
- **入口：** 桌角 **一枚小钮** `lb_btn_debug_open`（建议顶栏角、热区 **28～32vp**）。**禁止**把 self / p1 / p2 / p3 / −1 直接铺在桌面上当叠字条。  
- **窗：** 点入口打开 `lb_cmp_debug_life`（小窗 / 面板，**不是**第五主屏）。窗内选座（复用已锁 `lb_cmp_seat_*` 或窗内文字芯片，**不另造生命隐喻**）+ `lb_btn_debug_life_dec` −1。再点入口或点窗外关。  
- **正式包：** 入口、窗、−1 一律走现挂 `DebugBuild`（与 `lifeDecShown` 同闸）全隐。正式 / release 看见任一件 = **正式包露出调试**。  
- 调试包找不到小钮、只有叠字、或开不出窗无法 −1 = **调试仍是叠字挡局** / **无调试窗无法扣血演示**。旧短句「无调试扣血无法验熄灭」并入本条，不再单列。

**R-LIFE-6 · 烛组放大：** 基线 = 现挂 `#110` / `#112` 浮点：self 22 / seat 14；L-small 16 / 12。本稿锁常档 self **30～32vp**（22×≈1.4，**上限 33**）、seat **20～22vp**（14×≈1.4～1.5）；L-small 整档 ×**1.4**（self **22** / seat **17**）。身+焰同一倍率，焰不另起。低于下沿、或评委仍觉得桌上烛点看不清 = **烛过小难辨**。超过 33vp 须仍不挡手牌 / 荷官 / 池，且自己仍须大于对手（14 F14-4）。14 §2.3 旧下限（20 / 14 / 16 / 12）**让位本窗**。
