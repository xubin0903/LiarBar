## 1. 加严五闸（可勾 · 失败短句写死）

任一条失败 = **本批生命显示 Rebuild 加严不过**。不得用「有烛了 / 旁注好看一点」交差。  
点/看列写清；听列不适用写「本条不听」。

| ID | 对照词 | 点什么 | 看什么 | 听什么 | 失败短句（写死） |
|----|--------|--------|--------|--------|------------------|
| **R-LIFE-1** | **去 showDigit** | **不点**生命组。盯 `lb_cmp_life_self` | 自位只有 3 枚烛 pip（`lb_cmp_life_pip_0\|1\|2`）。**禁止**旁挂可见「3/2/1」。卸 `lb_txt_life_self` 主路径；**禁止** `showDigit` 当面完成。对手座本来就不挂大号数字 | 本条不听 | **自位生命旁仍有数字** / **生命仍靠数字辅读** |
| **R-LIFE-2** | **烛身＞火苗** | **不点**。盯单枚亮着的 pip（满血最严） | 蜡柱/烛身可视高 **明显大于** 焰。建议：烛身高 ≥ 焰高 × **1.2**，或焰高 ≤ 该枚画板高 **40%**。焰顶不得压过烛身、不得把柱读成焰底下的小桩 | 本条不听 | **火苗比烛身高** / **焰压烛** |

| **R-LIFE-4** | **熄灭时序（禁硬切）** | 调试包点 `lb_btn_debug_life_dec`（或对局真实 −1）。盯被扣那一枚 | 掉命 **不得**瞬间换图硬切。须有可验收短时序：灭/摇 **180～320ms**（可微调，**禁 0ms**）。结束后落到新稳态（残/濒/幽灵） | 非静默可走 `lb_sfx_life_drop` / `lb_sfx_life_extinguish`（有则听，无文件不挡视觉闸） | **掉命硬切换态** |
| **R-LIFE-5** | **调试扣血线框** | **仅 debug/dev 包**：找并点 `lb_btn_debug_life_dec` | 能对自位或指定座（self / p1 / p2 / p3）**−1 命**，用来验熄灭与三态。正式包默认隐藏、不进热区 | 本条不听 | **无调试扣血无法验熄灭**（仅对调试包） |

### 1.1 补句（写死）

**R-LIFE-1 · 去 showDigit：** 「当面」= `lb_scr_table` 稳态能看见的自位生命组。无障碍仍可读「自己生命 + 剩余整数」，**不**再挂可见 `Text`。14 / 14a 旧句「自己数字可旁注 / 可叠 `lb_txt_life_self`」**被本文覆盖**。口播/字幕说「还剩 2」仍认 14a，那不是座旁数字。

**R-LIFE-2 · 烛身＞火苗：** 主读仍是烛火，但 **柱是主体、焰是冠**。满血尤其不得焰高于柱。残/濒焰更矮，柱仍须能指认。只换色、焰仍压柱 = 仍不过。

**R-LIFE-3 · 火苗循环：** 锁 **同槽帧动画**（见 §2）。美术暂无循环图时，现挂 `art_life_candle_full` / `_hurt` / `_dying` 静图 = **占位 ≠ 终验**；挂点仍是同槽，后补帧 **不改** `lb_*`、**不改** 三态主名。用静图勾「循环已完成」= 打回本条。

**R-LIFE-4 · 熄灭时序：** 被扣那一枚先灭/摇，再落到新 `art_life_candle_*` 稳态。整组瞬间换皮、或 duration=0 = **掉命硬切换态**。摇与灭可同窗或分拍，合计落在 **180～320ms**。14 §5.2 旧窗（摇 120～200 / 灭 180～280）让位本窗。全屏闪红仍禁（质疑仍冻）。

**R-LIFE-5 · 调试扣血：** 只为 Rebuild 验熄灭与三态。不改 `lives_default`。正式 / release 包看不见本钮不得用本条打回。调试包找不到入口、只能等一整局才掉命 = **无调试扣血无法验熄灭**。

### 1.2 本表不验

- 大厅烛火 R1、横屏 R-LAND、手牌贴底 / `padB` / `HAND_RING_GAP` ——**不重开**
- 质疑四拍、回血、第 4 命 ——**不做**
- 杯 / 筹 / 牌记另选题 ——本线主读已锁烛，不重开题材票
- 正式包装调钮 ——R-LIFE-5 只打调试包

## 2. 锁名（写死 · 不发明第三套）

### 2.1 控件

| id | 本稿怎么用 |
|----|------------|
| `lb_cmp_life_self` | 自位生命组。**只** 3 枚 pip，不当数字条 |
| `lb_cmp_life_seat_p1` `p2` `p3` | 对手生命组。同构缩小 |
| `lb_cmp_life_pip_0` `1` `2` | 单枚；0=最左/最满侧 |
| `lb_txt_life_self` | **废主路径**。禁止当面辅读数字；禁止 `showDigit` 当面完成 |
| `lb_btn_debug_life_dec` | **仅 debug/dev**。点一下指定座 −1；正式包默认隐藏 |

座位锁名不改：`lb_cmp_seat_self` / `_p1` / `_p2` / `_p3`。生命仍是旁挂，不是新座位。

### 2.2 美术（主读仍烛火）

| id | 本稿怎么用 |
|----|------------|
| `art_life_candle_full` | 满 / 燃。柱＞焰；同槽轻循环 |
| `art_life_candle_hurt` | 残 / 弱。柱仍在，焰更矮；同槽轻循环 |
| `art_life_candle_dying` | 濒 / 将灭。残芯+烟；同槽循环 |

**循环锁一种：同槽帧动画。**  
满/残/濒各用自己的 `$r('app.media.art_life_candle_*')` 槽播帧（`ImageAnimator` / 同槽多帧均可）。**不**另起 `art_life_candle_*_fx` 第三套媒体 id。静图占位挂点不变，后补帧仍用上列三主名。

### 2.3 调用点（有则挂 · 本 PR 不交音频）

| id | 触发 | 说明 |
|----|------|------|
| `lb_sfx_life_drop` | 掉命起势（摇/灭开始） | 只登记调用点 |
| `lb_sfx_life_extinguish` | 被扣那一枚灭尽 | 只登记调用点 |

静默局两槽都关。无文件 **不**挡 R-LIFE-4 视觉闸。
