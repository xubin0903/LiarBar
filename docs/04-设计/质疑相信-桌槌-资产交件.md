## 0. PM 打回（相对 #238 / develop）

| 打回点 | 处理 |
|--------|------|
| 槌与手牌视觉重叠 / 剪影不像木槌 | 画幅仍 **360²**，槌体 **缩小**；不透明 bbox **四边安全边距 ≥20%**（UI 可坐在手牌上方） |
| 须一眼可辨木槌；RAISE / SMASH 帧清晰 | 木工槌 **T 剪影**（粗头块 + 细柄 + 铜箍）；抬起头朝上 / 砸下头朝下 + 短冲击线 |
| 木敲 SFX 加重 | `sfx_hammer_hit` → **~120ms** · 峰值 **≈ −7 dBFS**（目标 −6～−8） |
| 相信 = **仅 rest 静姿**，无动画 | `art_fx_mallet` 平放搁置；`sfx_hammer_rest` 可选极轻落定（近静） |

## 1. 为什么这些槽

| 选择 | 主读 | 资源 |
|------|------|------|
| **质疑** | 该座木槌 **抬起→砸下**（短震 + 敲击） | `art_fx_mallet_up` → `art_fx_mallet_hit` + `lb_sfx_hammer_hit` |
| **相信** | 同槌 **平放搁置** 座旁/键旁（**无动画**） | `art_fx_mallet` + `lb_sfx_hammer_rest`（轻顿，可选） |

两态须可辨（S19-4）；暖棕木 + 铜箍；命名对外「桌槌/酒槌」，禁「法槌」。本票只交资源，**零 ets**，给人模/client 另票绑。

## 3. 实测（v1.1 · PM 打回重做）

### 3.1 美术

| 项 | `art_fx_mallet` | `art_fx_mallet_up` | `art_fx_mallet_hit` |
|----|-----------------|--------------------|---------------------|
| 尺寸 | **360×360** RGBA | **360×360** RGBA | **360×360** RGBA |
| 姿态角（约） | +5° 近水平侧放 | −78° 抬起（头上） | +68° 砸下 + 冲击线 |
| 材质 | 暖棕木 + 铜箍 · T 剪影 | 同材质 + 轻运动模糊 | 同材质 + 冲击尘线 |
| 安全边距 L/T/R/B | **0.367 / 0.439 / 0.286 / 0.392** | **0.456 / 0.286 / 0.372 / 0.367** | **0.436 / 0.372 / 0.336 / 0.217** |
| 字节 | **11330** | **11571** | **16601** |
| sha256 | `0de3aba14734201a4293c455747f4fce1d08b3d9880c9c3d4f833691f52556d8` | `d8ed33f45f9f52b0ea40a3a891defe70ed813384116caf310726b03f516f44d1` | `c219ad19768f6bbada88d8ee9c860cc5e24f00927693a124afe4a1ca70734f4c` |

| 项 | 规格 | `sfx_hammer_hit.wav` | `sfx_hammer_rest.wav` |

## 5. 禁令（写死）

| 禁 | 说明 |
|----|------|
| 同姿仅换色 | S19-4；抬 / 砸 / 搁须姿态可辨 |
| 抽象 blob / 不可辨木槌剪影 | 须 T 剪影一眼木工槌 |
| 画满画布无安全边 | 不透明区四边 **≥20%** inset |
| 相信做抬砸动画 | 相信 = rest 静姿 only |
| 旧 flip / launch / land 冒充 | 禁绑 `lb_sfx_card_flip` / `play_launch` / `play_land` 当锤声 |
| beep / 正弦 tip / 系统咔哒 | 峰 bin 与听感闸 |
| 改人模 / 换座贴图 | 设计锁：人模零改 |
| 任何 `.ets` | **本 PR 零 ets** |
| 开 `feat/art-*` 一次性支 / 合入后删 `feat/art` | 常驻 `feat/art` only |
