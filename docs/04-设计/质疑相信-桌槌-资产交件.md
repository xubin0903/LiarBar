## 0. PM LOCK（v1.4 · 主轴统一槌头朝 +X）

| 打回 / 锁 | 处理 |
|-----------|------|
| **主轴不统一** — UP/HIT 曾烤垂直/斜角，client 旋座糊 | **三帧同主轴：槌头朝 +X（右）**；REST 静置 +X；UP 抬起仍 +X；HIT 沿 +X 砸 + 冲击线 |
| **禁先烤 12 帧** | **不**做 4 向 × 3 = 12；**client 按座 0/90/180/270 旋**；四向烤帧 **仅 Rebuild 糊再开** |
| 桌面道具级（承 #251） | 画布 **512×512**；inset **≤8%**；长轴 **~85%**；`assert_table_prop_scale` + `assert_head_plus_x` |
| 一眼木槌 | **圆柱桶头** + **锥形柄** + 暖木纹 + **铜箍**；禁勺碗/法槌玩具/blob |
| REST / UP / HIT | REST=相信静置；UP=抬起（同轴抬高）；HIT=砸（同轴冲击）；相信**无动画** |
| SFX | **保留**（字节未改）：hit **≈ −6 dBFS** · 125ms · 48k mono · 头静音 0 |
| **S19-7 锤压牌** | **布局/锚点**，非本票美术 |

> **主轴统一槌头朝 +X**；client 按座旋。合入 ≠ 终验。形闸：头不在 +X / 缩略图标 / 先烤 12 帧 = 失败。

## 1. 为什么这些槽

| 选择 | 主读 | 资源 |
|------|------|------|
| **质疑** | 该座木槌 **抬起→砸下**（短震 + 敲击） | `art_fx_mallet_up` → `art_fx_mallet_hit` + `lb_sfx_hammer_hit` |
| **相信** | 同槌 **平放搁置** 座旁（**无动画**） | `art_fx_mallet` + `lb_sfx_hammer_rest`（轻顿，可选） |

两态须可辨（S19-4）；暖棕木 + 铜箍；命名对外「桌槌/酒槌」，禁「法槌」。本票只交资源，**零 ets**，给人模/client 另票绑。

## 3. 实测（v1.4 · 主轴统一槌头朝 +X）

### 3.1 美术

| 项 | `art_fx_mallet` | `art_fx_mallet_up` | `art_fx_mallet_hit` |
|----|-----------------|--------------------|---------------------|
| 尺寸 | **512×512** RGBA | **512×512** RGBA | **512×512** RGBA |
| 主轴 | **槌头朝 +X（0°）** | **同轴 +X**（抬高，非垂直烤） | **同轴 +X**（冲击线，非斜下烤） |

| 长轴填充 | **84.2%** | **84.2%** | **84.2%** |
| 字节 | **90538** | **94892** | **95061** |
| sha256 | `755a23398742951ed953793a1629bf64b3bb12d0d69dfbf3f4c30034ab96638b` | `0f41fbe06d6d83de5694f151398ed507d0e7d48024da1efd5719558b7090b2e3` | `b8ec37c9d3b0574633e386a2816095dd79af71f93b5511433ccfda798bfeb09c` |

形闸：rest/up / rest/hit alpha 掩模差脚本断言 **≥0.04**——非同姿换色。

尺度闸：`assert_table_prop_scale` — 长轴 **≥84%**（inset ≤8%）。  
**落地**：client 按座 **0/90/180/270** 旋；**禁** P0 先烤 12 张；四向烤帧仅 Rebuild 糊再开。

## 5. 禁令（写死）

| 禁 | 说明 |
|----|------|
| 同姿仅换色 | S19-4；抬 / 砸 / 搁须姿态可辨 |
| 玩具 / 法庭木勺 / 不可辨木槌剪影 | 须 **圆柱头 + 锥柄 + 暖木纹** 一眼木槌 |
| 缩略图标 / 点级主读 | 须 **桌面道具级**：长轴 ~85% 填充、inset ≤8% |
| 相信做抬砸动画 | 相信 = rest 静姿 only |
| 旧 flip / launch / land 冒充 | 禁绑 `lb_sfx_card_flip` / `play_launch` / `play_land` 当锤声 |
| beep / 正弦 tip / 系统咔哒 | 峰 bin 与听感闸 |
| 改人模 / 换座贴图 | 设计锁：人模零改 |
| 用美术「撑大」解决 S19-7 | **S19-7 锤压牌 = 布局锚点**，非本票 |
| 任何 `.ets` | **本 PR 零 ets** |
| 先烤 4×3=12 分向帧 | **主轴只 +X 一朝**；client 旋座；Rebuild 糊再开四向 |
| 开 `feat/art-*` 一次性支 / 合入后删 `feat/art` | 常驻 `feat/art` only |
