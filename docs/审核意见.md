## 第1～2批审核检查清单（可打勾）

### 一页纸
- [ ] 定位一句话是否认可  
- [ ] 「不做清单」是否要加减  
- [ ] 正式中文名是否锁定「谎馆」  

### PRD
- [ ] P0 功能是否可在工期内做完  
- [ ] Q1～Q5 开放问题是否拍板  

### GDD
- [ ] 符号牌 A/K/Q+Joker 是否同意（vs 完整扑克）  
- [ ] 3 命 / 5 张手牌 / 最多出 3 张  
- [ ] 质疑只验「上家本手」  
- [ ] 第一手不可质疑  
- [ ] 手牌耗尽方案 A 还是 B  
- [ ] 新一轮出牌权规则  

### 互动
- [ ] 旁观押面子默认开/关  
- [ ] 点名是否 P0  
- [ ] 质疑三拍是否可跳过  
- [ ] 静默局是否要做  

### 数值
- [ ] 牌张数与 Joker 比例  
- [ ] 回合 15s 是否合适  
- [ ] AI 三人格是否够
