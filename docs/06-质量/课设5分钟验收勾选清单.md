| 读者 | 评委 / 老师 / 制作人过演示 |

## 1. 现场时间轴（0:00–5:00）

每步做完打勾。超时就跳到质疑，不要解释实现。

### 0:00–0:40 讲清玩法

- [ ] 一句话：不用真人主持、手牌防偷窥、熄屏也能盯回合的鸿蒙「骗子酒吧」
- [ ] 10 秒规则：荷官定本轮符号（A/K/Q）→ 扣牌出 1～3 张（可真可假，Joker 算真）→ 下家可质疑上家**本手** → 有假上家掉命，全真你掉命 → 3 命出局，剩 1 人胜
- [ ] 点明：**第一手不能质疑**；动作只演不改牌真假（社交桌）

### 0:40–1:10 开桌 + 教学跳过 + 防窥

- [ ] `lb_scr_lobby` 智能填充昵称/常用桌（F-11，鸿蒙 P0）
- [ ] 4 人桌，3 AI 入座，开始（F-01）
- [ ] 教学直接跳过（F-12）
- [ ] 在 `lb_scr_table` 长按 `lb_cmp_hand`，`lb_cmp_peek_mask` 出现，**侧拍对比**给评委（F-03；看牌不单开屏）
- [ ] 松手收牌，遮罩关闭

### 1:10–2:00 出牌姿态 + 实况窗 + 荷官

- [ ] `lb_cmp_dealer_banner` 有宣称短句（F-09）
- [ ] 指实况窗 / 锁屏：**轮到谁 + 倒计时 + 宣称**（F-08）
- [ ] 本轮第一手：`lb_btn_challenge` 不可用（TC-04）
- [ ] 玩家或 AI 用 `lb_cmp_packet` 出牌；现场至少亮出 **2 种**方式（轻推 / 甩出 / 犹豫），课设包里 **3 种都能用**（F-04，详见 TC-07）
- [ ] AI 不是只会轻推、桌面不假死（TC-14）

### 2:00–3:20 旁观 + 质疑四拍（3 分钟脚本核心）

- [ ] 旁观：敲桌、对某人画 ✓ 或 ✗（F-06）
- [ ] 等种子高潮（约开打后 45–60s）：老千第 3 手 SLAM 掺假点名 → **杠精开质疑** → `lb_scr_challenge` 四拍；玩家也可在自己回合且 `canChallenge` 时点 `lb_btn_challenge`，二者皆可
- [ ] `lb_challenge_windup` 指控可见
- [ ] `lb_challenge_standoff` 对峙：反应表情；旁观押真假（可不中，押错 0）
- [ ] `lb_challenge_reveal` 逐张翻上家本手
- [ ] `lb_challenge_result` 定格 + 扣命；荷官一句（F-05 / F-09）
- [ ] 四拍体感短（≤4s），评委不等动画；拍 2 不并进 reveal
- [ ] （可选·种子路径）宣称 A / 真人先手 / 老千掉命 / 新宣称先手=杠精

**3 分钟节点（约 0:40 开打起算 ≤3:00）**：看牌 → 出牌 → 质疑结算 已跑通。打勾即满足「3 分钟演示脚本」。

### 3:20–4:10 战报 / 乐趣点补镜

- [ ] 打开 `lb_scr_report`（本场已终局 **或** 预跑局）（F-10）
- [ ] 战报有：胜者、质疑相关数、**高光动作一句**
- [ ] 表情轮盘点一下（无摄像头也行）（F-07，可 3 秒带过）

### 4:10–5:00 鸿蒙 + AI 收束

- [ ] PPT / 口述勾选 **≥3** 个鸿蒙特性（见 §3，P0 优先防窥 / 实况窗 / 智能填充）
- [ ] 一句 AI 融合：荷官是规则引擎裁判，**不用 LLM 判真假**；AI 牌友会出牌也会敲桌画✗
- [ ] 不问就不展开：静默局、手牌耗尽 8s 窗、返回（TC-16～18）

## 2. 3 分钟演示脚本（可单独跑）

验收前用此表连跑，稳定再上场。控件 id 同用例。

| 秒 | 动作 | 期望 | 过 |
|----|------|------|----|
| 0:00 | `lb_scr_lobby` 填充 → 4 人 3 AI → 跳过教学 → 开打 | 进 `lb_scr_table`，有宣称 | [ ] |
| 0:20 | 长按 `lb_cmp_hand`，`lb_cmp_peek_mask` 亮起，侧拍 1 次，松手 | 防窥可讲；不单开屏 | [ ] |
| 0:35 | 指实况窗 / 锁屏倒计时 | 阶段+秒可见 | [ ] |
| 0:45 | 第一手只出牌（SOFT 或 SLAM） | 不能质疑 | [ ] |
| 1:00 | 旁观敲桌或画✗；AI 继续动手 | 桌面有互动 | [ ] |
| 1:10–2:10 | 等种子高潮：老千第 3 手 SLAM 掺假点名 → **杠精开质疑**；或玩家在自己回合且 `canChallenge` 时点 `lb_btn_challenge`（二者皆可） | 进四拍 | [ ] |
| 2:10–2:30 | `lb_challenge_windup` → `lb_challenge_standoff`（押注）→ `lb_challenge_reveal` → `lb_challenge_result` | 扣命正确；只验本手；拍 2 独立 | [ ] |

## 3. 乐趣点是否可见

评委不一定问「好不好玩」，但这三格必须现场能指到。

| 乐趣点 | 怎么算可见 | 过 |
|--------|------------|----|
| 出牌姿态 | 同局出现 ≥2 种出牌方式，不是同一个「出牌」按钮感 | [ ] |
| 质疑高潮 | `lb_challenge_windup` / `standoff`（能押）/ `reveal` / `result` 四段可指，不像静默弹窗 | [ ] |
| AI 不冷场 | 90s 内 AI 有出牌姿态或敲桌/画✗/点名/表情之一；可见例：**老千 SLAM+点名** 或 **杠精开质疑** | [ ] |

任一空缺：演示判「走形式」，即使功能能点通。

## 6. 评委可能问（各 15 秒）

| 问 | 答（勿展开工程） |
|----|------------------|
| 第一手为什么不能质疑？ | 还没有上家本手，无牌可验。 |
| 手牌打光怎么办？ | 能质疑就只开 8 秒质疑窗；不能就跳过。不会按谁牌多判赢。 |
| 旁观押注改命吗？ | 不改。押对加面子，押错 0。 |
| 为什么要静默局？ | 通勤不社死；关强震动/催促/嘲讽音，规则不变。 |
| 为什么不做跨端/3D？ | 一页纸不做清单：特性必须服务这局博弈。 |
