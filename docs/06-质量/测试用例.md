## 0. 控件 ID（步骤只引用这些）

下列 id **写死**，与 UI 岗对齐；会签前勿另造屏。操作点一律 `lb_*`；媒体核对可写 `art_*`；**禁止** `lb_art_*`。

| 类型 | ID | 对应 |
|------|-----|------|
| 屏 | `lb_scr_lobby` | 启动/首页、建桌等待（**含冷启动**） |
| 屏 | `lb_scr_table` | 对局桌 |
| 屏 | `lb_scr_challenge` | 质疑流程（三拍 + 定格） |
| 屏 | `lb_scr_report` | 局后战报 |
| 控件 | `lb_cmp_peek_mask` | 看牌遮罩（揭开瞬间防窥） |
| 控件 | `lb_cmp_hand` | 手牌区（默认牌背） |
| 控件 | `lb_cmp_packet` | 出牌包（选牌 + 方式 + 带话/点名） |
| 控件 | `lb_btn_play` | 出牌确认 |
| 控件 | `lb_btn_challenge` | 质疑 |
| 控件 | `lb_cmp_dealer_banner` | 荷官播报条 |
| 三拍 | `lb_challenge_windup` | 拍 1 指控 |
| 三拍 | `lb_challenge_standoff` | 拍 2 对峙 + 旁观押注（独立拍，不并进 reveal） |
| 三拍 | `lb_challenge_reveal` | 拍 3 逐张翻牌 |
| 三拍 | `lb_challenge_result` | 定格 |

看牌在 `lb_scr_table` 上用 `lb_cmp_peek_mask` + `lb_cmp_hand`，**不单开屏**。  
步骤里未单列 id 的操作（跳过教学、静默开关、敲桌、画✓✗、表情轮盘、实况窗）写在对应屏上，不另造规则。  
废弃名（禁止再用）：`_challenge_rise` / `lb_challenge_rise` / 把拍 2 并进 reveal。
