## 3. 可读性勾选（须 O1 / LY1 / X1–X4 全过）

抄 [10 §3](../04-设计/10-局内横屏可读性与体验验收.md)。**听 / 看 / 点** 三件套；失败短句必须是 [10 §4](../04-设计/10-局内横屏可读性与体验验收.md) 原句。未落地构建 **不得勾「过」**。

对象：评委 **一眼看清四座+手牌+宣称+质疑/出牌**（PM 锁句，一字不改口径）。  
墙钟：进 `lb_scr_table` 之后的稳态桌（`CLAIM` / `TURN`，发牌飞牌期另走 D1，本表不替 D1）。  
任一条失败 = **本批局内可读不过**，不得用「功能能点通」交差。

| ID | 听 | 看 | 点 | 失败短句 | 过 |
|----|----|----|----|----------|----|
| **O1** | 本条不听 | 进桌后画面是 **横屏桌**；四座沿桌展开，不再是竖屏一条座位 `Row` 顶满 | 竖持须转到横。不点「再转回竖还能打完整桌」当过 | 局内仍竖；或大厅被逼成必须横 | [ ] |

**X1 补句（写死）：** PM 锁句 **「一眼看清四座+手牌+宣称+质疑/出牌」** = 横屏一帧内指认这四块，禁止靠竖向 `Scroll` 把座位或 CTA 推到屏外。手牌 5 张可横向微移（peek 区），**整桌**不得靠滑才露出宣称或主按钮。

**X2 补句：** 装饰轻叠（烛光、毡面）可过。牌堆锚点盖住手牌条、荷官盖住宣称、CTA 盖住牌堆飞线落点 = 致命，不过。票 B 锚点若仍飘在屏外/座位脸上，**X2 与 D1 一并不过**。

**X3 补句：** 01 竖屏「半屏出牌包」在横屏会吞掉桌。横屏用压缩底栏或侧栏；方式芯片 + 提交必须同屏可见。带话默认可跳过（已锁），本批不新加输入框。

**X4 补句：** 回开桌是联调/调试出口，不是课设卖点。降级后仍可离开对局；只禁「铺满底栏、和质疑并排抢戏」。
