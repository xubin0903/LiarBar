### 3.1 补句（写死）

**乐观飞：** 点 `lb_btn_play_confirm` **即** `PlayLaunch`，不等 T20 ack 才起飞。等 ack 才出现位移、确认后桌面停一拍再闪到身前 = C1-1 / C1-9 **无飞出纯提交**（或 **像点按钮**）。权威接受后扇形留在身前；权威拒走 C1-6，不得把「等 ack」当成免飞借口。

**飞不可跳：** 320ms（280～400）窗 **不可跳过**。有余牌时不可快进到 `AwaitChallenge`。跳过飞出、或飞未满就开质疑窗 = 第1节不过，且 **不得**用旧双轨质疑交差。本表不写第2节步骤，也不勾四拍过关。**打光（手牌=0）禁再 `AwaitChallenge`**，走 C1-7。

**本轮身前手：** `lb_cmp_play_front_pile` 只摊 **这一手 / 本轮该座身前**。新手开始、新宣称、或上家本手被后手覆盖时，不得把多轮牌无限叠在身前。墓地 / 坟场 / 历史弃牌堆 **后节**，本表不验、不得用坟场节点冒充本手扇。

**1 张：** 不扇、正中、单背可读。斜着当「扇」或缩到看不清背 = C1-1。无飞瞬切 = **出牌无飞出 / 像点按钮**。

**2 张（self 对照，挂 C1-2 同闸）：** 己方出 2 张须 **±8°**、露边 ≥10vp、能数 2。叠死 / Text 写「2」= **扣牌张数不可读**。C1-3 专打侧家/对家 2 张镜像与挡手/烛。

**3 张：** 只认 −12/0/+12 与 ≥10vp。用 15 的抬起角或随机散落交差 = C1-2。

**镜像座锚：** 四座不得共用 `dealPileAnchor` / 桌心。self 扇落在手牌主行 **之上**、桌心 **之下**；不得盖牌心热区、不得盖烛。侧家竖直中、对家上沿身前仍认 11，本轮不改环位。

**压手/烛：** 落后 HitTest None。扇叶压住 `lb_cmp_hand` 或 `lb_cmp_life_*`，或为此抬 `padB` / 改 `HAND_RING_GAP` = C1-3 / F16-3。**不得**拿「GAP 仍 24% 所以布局过」勾本批——那是仍锁，不是本表正面闸。

**吞二手：** 「再点一次没反应」且桌上仍是第一手飞程 = 过。第二手起飞、或第一手未落又叠第二手 = **动画未完又出一手**。

**回滚：** 15 的超选 / 非己回合 / 0 张 **不进** PlayLaunch，那是 F15，**不能**当 C1-6。C1-6 必须先看见乐观飞，再看见权威拒后的 pile+手牌恢复，并出 **`lb_str_play_rollback`**（**出牌未生效 / 张数已纠正**）。残留飞节点 / 无此 key 文案 = 不过。

**打光（C1-7）：** 最后一手 `PlayLanded` 扇形成型完，**再**进结算/占名次。手牌=0 后 **禁再 `AwaitChallenge`**（打光后无下一手、不被质疑下轮）。先遮后扇、无扇直接结算/占名次、或打光后仍开质疑等待 = **打光先落扇再结算遮 / 胜利遮未成形扇**（同义 **胜利遮未成形扇形**）。先打光 = 名次靠前（最先 = 第 1）；命归零 = 垫底。质疑成功次数作次序的细表属第 4 节，本表不扩。

**听闸 vs 布局闸：** C1-1 / C1-2 / C1-3 / C1-5 / C1-7 / C1-9 是布局/路径闸，勾过时 **不要**填听感。C1-4 / C1-8 是听闸：C1-4 打「有没有出牌声、像不像静默提交」；C1-8 打「是不是对槽、stamp 是否同起、有没有 flip 冒充」。两闸分开勾。静默只豁免听闸，不豁免飞出。

**双槽：** 默认 launch + land。已会签「只保留 land」可过 C1-8，仍须 stamp、仍禁 flip。未会签的单槽 / `lb_sfx_soft` 冒充本表双槽 / `lb_sfx_card_flip` 当出牌 = **flip冒充出牌 / 起播不同起** 或 **落桌无声 / 像静默提交**。

**旧路径：** 15 顶钮次路径若仍能提交，也必须飞出。半屏包提交、AUTO_PLAY 1 张，同一套 PlayLaunch。只减手牌不播飞层 = **禁回旧无飞牌纯提交**。

**AUTO_PLAY：** 16 写死超时自动 1 张走同一飞出 → 身前单张。不另走路。无飞的自动交 = C1-9。
