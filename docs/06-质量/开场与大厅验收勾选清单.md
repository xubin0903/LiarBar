| 口径 | 过 | 不过 |

| **H1 听 / 看 / 点** | 下表每一行三列齐全；先看后点 | 只有「听到 xx」或只有画面、没写点或不点 |

| **H3 静默全关** | 开 `lb_tog_silent` → 杀进程 → 桌面重开：口播 / 强震 / BGM / 环境 / 开场击点 / CTA **五层全关**；**字幕仍出**锁句 | 静默后馆里还在响；或字幕没了；或文中「压到 −24 dB」备选 |

## 4. §7.3 大厅稳态（停 ≥8s）

T6 之后（或口播回 idle 之后，取晚者）自动开循环，**无需玩家点荷官**。

| # | **点什么** | **看什么** | **听什么** | 过 |
|---|------------|------------|------------|----|
| 9 | **不点** `lb_cmp_dealer`。停在大厅 ≥8s，只盯荷官 | **真动作循环**：8s 内至少一次 **眨眼**，以及点头 / 抬杯 / 面具微动 **至少一种**（`art_dealer_idle_{blink,nod,cup,mask}`）。**仅 `scale` 呼吸 = H2 不过** | 非静默：BGM 稳态（比开场满额低 2 dB）+ 环境继续。无新击打、无第二句口播 | [ ] |
| 9b | **不点** | 近景烛焰在闪（焰，不是整屏闪）；远景烟或光尘微动（P0 允许程序尘） | 无额外 FX 音。禁止为烛光加 beep | [ ] |
| 9c | **不点** CTA（本条只看微动） | 入场后无大弹跳；CTA 若有微光，scale ≤1.01 | 无声变化（没有周期性 UI 音） | [ ] |
| 9d | **不点**。从 T4 看到 T6 之后 | 口播期间是 announce；口播结束后回 idle，再进真动作循环，不是一直举牌 | 口播结束后 BGM **200ms 回稳态**；无第二句口播 | [ ] |

## 7. §7.5 失败短句

出现任一条，v3 不过。**只记开场+大厅**，不记局内输赢。

- 验收句缺 **听 / 看 / 点** 任一列（H1）。
- 冷启动进不了 `lb_scr_lobby`（TC-01 门槛失败）。
- 总轴短于 3.0s 或长于 4.5s；或删了黑场 / 静帧 / 加载 / 荷官 / stagger / 稳态 / 声场起层任一段。
- 仍按 #24 的 **1.5–2.5s** 当时长门槛。
- **单 beep 冒充完成**；三槽同一条短波；无分层 BGM / 环境 / 口播（H2）。
- 大厅 **仅缩放交差**；无眨眼 +（点头 / 抬杯 / 面具）真动作循环（H2）。
- 无独立 `art_splash_still`，或开场静帧就是 `art_lobby_bg`。
- 口播与字幕不同起，或改锁句（不是「夜深了，位子给你留着。」）。
- 静默局仍有 BGM / 环境 / 击打 / 口播 / 强震；或字幕没了（H3）。
- 轴未完点 `lb_btn_quickstart` 开了桌；或轴完后主 CTA 仍不可点 / 无按压缩放。
- 「进桌看看」做成第二个主 CTA。
- 未审先落占位音 / 占位动效当通过。
- 改了局内 / 规则 / 锁名 / `lb_art_*`。
- 把本表扩成局内 / `demo_seed` / TC-19 联合验。
