## 1. 硬口径（先读再点）

| 口径 | 过 | 不过 |
|------|----|------|
| **独立** `art_splash_still` | 开场是门脸/招牌静帧，与大厅景深底不是同一张图 | 「复用 `art_lobby_bg` 即可交件」；静帧槽空着或糊同一张褐金底 |
| **占位 ≠ 交件** | 看见的是 #22 真分层（景深 / 荷官 / CTA 质感） | v0.x Pillow / 褐金平涂再挂一遍当完成 |
| **肉眼层次** | 能指认远冷雾、中木纹/桌、近烛、荷官、独立静帧、CTA | 同一张平涂从黑场糊到稳态；只有 token 色块拼贴 |
| **招呼句** | **「夜深了，位子给你留着。」**（挂 `lb_cmp_dealer`） | 入座满句「本桌四人，酒已满。」冒充进场招呼；无字幕 |
| **静默局只字幕** | 开 `lb_tog_silent` → 杀进程再开：无口播、无强震，**字幕仍出**同一句 | 静默后字幕消失；或重开又出声/强震 |
| **主 CTA vs「进桌看看」** | `lb_btn_quickstart` 是主按钮；「进桌看看」弱、不抢主位 | 两个一样大的主按钮；次级做成第二个 `tavern_accent` CTA |

时刻按默认 **~2.0s** 轴书写。总长若调到 1.5s / 2.5s，**拍顺序不变**，只按比例伸缩，**每一拍仍要勾**。  
轴未到稳态前，主 CTA **不可点**。「跳过开场」= P1，本批不强制。

## 2. §7 逐步勾选（#0～#12）

**先看后点。** 任一步失败即本表未通过。勾「过」= 本机亲眼看到期望。

| # | 时刻（默认轴） | 操作 | 期望 | 过 |
|---|----------------|------|------|----|
| 0 | 走完开场后对比 | **不点**。先看启动静帧，再看大厅底 / `lb_cmp_dealer` / CTA | **肉眼须能看出新层次**：独立静帧 ≠ 大厅景深底（不是同一张褐金底糊开场）；荷官有层次；CTA 有质感 | [ ] |
| 1 | 0s | **打开 App**。手离开屏幕，不点任何按钮 | 黑场（`tavern_bg` `#1A120E`）。不是立刻一张褐卡表单，也不是现挂平涂大厅当完成态 | [ ] |
| 2 | 0～0.35s | 仍不点 | **独立** `art_splash_still` 从黑场淡入。禁止「复用 lobby_bg 即交件」。无闪白 | [ ] |
| 3 | 0.35～0.9s | 仍不点 | **加载暗示**：转圈或底沿细进度条。能感到「在进馆」 | [ ] |
| 4 | 0.9～1.3s | 仍不点（此拍若误点 `lb_btn_quickstart` 也不该开桌） | 荷官出现；idle→announce **轻切**（交叉淡化，禁硬切闪白） | [ ] |
| 5 | 1.3～1.7s | 仍不点 | 设置卡 → 主 CTA →「进桌看看」**错开**入场（能看出先后） | [ ] |
| 6 | 与 #5 同时 | 看 `lb_cmp_dealer` 旁字幕，不点 | 默认句：**「夜深了，位子给你留着。」** | [ ] |
| 7 | 1.7～2.0s（总长不得早于 1.5s、不得晚于 2.5s） | 看整屏，仍先不点 | 五分区可辨：顶栏 / 荷官 / 窄设置卡 / 主 CTA / 「进桌看看」。设置卡 **不是**糊满中下区的大褐块。主按钮从景深底跳出（质感 CTA，不是平涂褐金块） | [ ] |

|----|----------|------------------------------|----|
| 远景 | 冷雾 / 四角暗 | `tavern_shadow` `#0E1A22` | [ ] |
| 中景 | 木纹 / 桌沿 / 招牌木 | `tavern_panel` `#3D241C` | [ ] |

## 4. 失败判定（短句）

出现任一条，本表判不过。**只记开场+大厅**，不记局内输赢。

- 冷启动进不了 `lb_scr_lobby`（TC-01 门槛失败）。
- 总轴短于 1.5s 或长于 2.5s；或删了黑场 / 静帧 / 加载 / 荷官 / stagger / 稳态任一段。
- 无独立 `art_splash_still`，或开场静帧就是 `art_lobby_bg`。
- 占位平涂当 v2 交件；肉眼分不出新层次。
- 轴未完点 `lb_btn_quickstart` 开了桌；或轴完后主 CTA 仍不可点 / 无按压缩放。
- 招呼句不是「夜深了，位子给你留着。」
- 静默局重开后字幕没了，或口播/强震还在。
- 「进桌看看」做成第二个主 CTA。
- 稳态全程死静（无呼吸、无烛光）。
- 把本表扩成局内 / `demo_seed` / TC-19 联合验。
