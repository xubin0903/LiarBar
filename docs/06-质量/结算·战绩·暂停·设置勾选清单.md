## 4. 暂停 / 离局 / 切后台（PAU）

量法：计时看 `lb_txt_timer`；AI 思考看思考气泡与 D2 日志 `thinkMs`；暂停一律等满 **30s** 再继续。

| ID | 怎么验 | 过的标准 | 过 |
|----|--------|----------|----|
| PAU-1 | 自己回合剩约 10s 时暂停 30s 再继续 | 暂停中数字不动；继续后剩余时间与暂停前相差 ≤1s；不因暂停直接超时 | [ ] |
| PAU-2 | AI 思考气泡出现时暂停 30s 再继续 | 暂停中 AI 不出牌、不质疑；继续后剩余思考时间接着算，不会立刻蹦出决策；思考仍满足 F-07 地板 | [ ] |
| PAU-3 | 桌面动画（出牌飞出、烛火、桌槌）进行中暂停 | 动画停住；继续后从停点接着走，不跳帧、不重播 | [ ] |
| PAU-4 | BGM 播放中暂停再继续 | 暂停中 BGM 无声；继续后从断点续播，不从头放 | [ ] |
| PAU-5 | 开牌 / 燃烛序列中按暂停，连按 3 次 | 当前序列放完（开牌 `DRAW_TO_FLIP=1000` / `REVEAL_HOLD=3000` 不被截短）才进暂停层；只弹一层；待停期间重复按不触发 | [ ] |
| PAU-6 | 暂停层逐项点 | 只有继续、结束游戏、返回大厅三项（设置、规则从这一层进）；后两项二次确认；结束游戏确认后记负标「中退」 | [ ] |
| PAU-7 | 对局中切后台 10s 再回 | 自动进暂停层，回来仍停在暂停层，计时 / AI / 序列没往前走；点继续才接着打 | [ ] |
| PAU-8 | 暂停键位置 | 不撞 `lb_btn_home`、四座桌槌锚、手牌、牌池、质疑\|相信（坐标照 22） | [ ] |
| PAU-9 | 暂停 → 继续 连做 5 次后打完整局 | 局面、烛数、出牌权不乱；无重复出牌、重复扣烛；`ai_npc_check.mjs` 与桌槌闸仍绿 | [ ] |
