### 3.1 Soft / Mid / Slam 三档质疑率窗（设计 §4b · WRITE DEAD · 挂 F-02/03/04）

> 同 InfoSet 夹具 · `n≥50` · 噪声可关或保留小 `errorRate`。  
> **三人格均有质疑基率**（Soft 也 challenges sometimes）；**连续参数调出分布**，不是 `if(persona)`。

#### Soft×1（弱可疑 / `style=SOFT` · `w·φ` 低档）→ **F-02**

| 人格 | 质疑率窗 | 硬禁 |
|------|----------|------|
| **全体** | **多数 BELIEVE**（`P(BELIEVE) ≥ 0.55`） | Soft 仍塌成「杠精必疑 / 另两必信」 |
| Karen | **10%～35%** | ≈100% 质疑 |
| Shark | **8%～30%** | |
| Timid | **5%～25%** | |

#### Mid×2（中性 · `HESITATE` 或中档 `w·φ`）→ **F-03**

| 人格 | 质疑率窗 | 硬禁 |
|------|----------|------|
| Karen | **35%～60%** | |
| Shark | **20%～45%** | |
| Timid | **10%～30%** | Timid ≈0 |

#### Slam×3（强可疑 / `style=SLAM` 或高档 `w·φ`）→ **F-04**

| 人格 | 质疑率窗 | 硬禁 |
|------|----------|------|
| Karen | **≥55%** | 未达窗 / 二值塌缩 |
| Shark | **25%～55%** | |
| Timid | **10%～30%** | **Timid floor ≥10%**；禁塌缩 ≈0（**SUPERSEDE** 旧 `<20%`≈怂货几乎不疑） |

> **相对 v0.1.x**：Slam Karen 由 ≥70% → **≥55%**；Shark 30～60% → **25～55%**；Timid `<20%` → **10～30% floor≥10%**。Soft「多数信」保留，并加分人格质疑基率窗。
