### 3.2 补句（写死）

**可读：** 主读 = 烛符号组。自位当面禁数字（R-LIFE-1）。关掉符号只留数字 = F14-6。有符号但仍说 HP / 血条 = S14-1。小档卸生命 = F14-5。4 秒指不出剩几命 = S14-2。

**自己 ≠ 对手：** 一眼能指「这是我的命、那是他的命」。四座同大 = F14-4。自己弱、对手强喊命 = S14-3。

**三态：** 必须靠 **枚数 + 形变**。满/残/濒靠色盲或凑近才分清、或 2 与 1 同形 = F14-2。

**不挡：** 生命是环上饰件，不是底栏通栏。压手牌 / 最左牌 / 荷官 / 池 = F14-3。

**3 命：** 只引用 GDD。出现 ≠3 的默认命、回血、第 4 格当规则 = F14-7。

**贴底硬修搁置：** 确认条近底口径只认 [15](../04-设计/15-局内手牌触摸出牌规格.md) / 线 B 清单，**不**回绑 11 flush。为生命改 `padB` / 环-手 / 重开 flush = F14-8。

**熄灭：** 过程 180～320ms **加** `lb_sfx_life_extinguish`（只挂 `extinguish_0..3` **末帧**；14a §3a / 14b R-LIFE-4 / #112）。熄灭起势 **禁止** 播 `lb_sfx_card_flip`（只属 S15-4）。硬切 = R-LIFE-4（**掉命硬切换态**）。只切图无收光 = S14-8（**掉血只切图假**）。非静默无灭尽声 / 无过程 = S14-9（**熄灭无过程 / 无声**）。14b：无文件不挡**视觉**闸；本表终验非静默仍须听灭尽槽。调试扣完无反馈 = 14a 附录 A **D14-4 扣完无熄灭反馈**。**不另起 R-LIFE-4b**。

**烛组放大：** 常档 self **30～32vp**（上限 33）/ seat **20～22vp**（现挂 22 / 14 的 ≈**1.4×**）；L-small ×**1.4**（22 / 17）。身+焰同比例，焰随身。低于下沿或评委仍看不清 = R-LIFE-6 **烛过小难辨** / S14-10 **烛仍豆粒难辨**。只放大焰、身仍豆粒 = S14-11 **只放大焰不放大身**。放大后门破柱＞焰 = R-LIFE-2 **放大后焰压烛身** / S14-12 **火苗又比烛身高**。不借放大重开 `padB` / flush。

**调试小钮开窗：** 调试包只见桌角小钮 `lb_btn_debug_open`，**禁止**左上叠字条。点开 `lb_cmp_debug_life`，窗内才有 `lb_btn_debug_life_dec`。关窗后 HUD 干净。正式包走 `DebugBuild` 零入口。左上仍摊开叠字 = D14-5 **左上仍叠字遮 HUD** / R-LIFE-5 **调试仍是叠字挡局**。面板不关 = D14-6 **调试永久摊开**。正式包见钮 = D14-7 **正式包还能看到调试钮** / R-LIFE-5 **正式包露出调试**。窗内 −1 仍须立刻走 R-LIFE-4（R-LIFE-5 演示闸不退）。
