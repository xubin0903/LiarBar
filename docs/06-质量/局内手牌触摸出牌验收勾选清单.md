### 3.1 补句（写死）

**单选翻面：** 先翻（或翻到一半）再抬。只抬不翻、或只换贴图无翻转 = F15-1。牌背 / 翻转中途进 Playing = S15-1。稳态手牌仍是背（09 C1 不改）。有翻面但非静默无 `lb_sfx_card_flip` 真播 = **S15-4**（不替代 F15-1）。

**翻牌有声：** 一字抄 [15a](../04-设计/15a-翻牌选牌SFX与失败短句.md) S15-4。非静默点翻面无 `lb_sfx_card_flip` 真播、只 log、系统咔哒 / beep = **翻牌无声 / 像文字游戏**。声晚于翻面 / 像延迟 = **翻牌声晚于翻面** / **像延迟**（交叉 14b / 15 §7）。静默画面在、槽关不算失败。15 §7 旧列 `card_select` / `play_confirm` 本表不另验。

**多选：** 帽 = 3。不能选第 2 / 第 3、或选了不抬起 = F15-2。

**取消：** 点空白 → Idle；再点同牌 → 取消该张。仍保持选中 = F15-3。不提交。

**非法选：** 口播锁字 **超选** / **非己回合** / **张数不符**（15 §4）。第 4 张进组或无反馈 = F15-4。别人回合能选并能交 = F15-5。0 张或超帽进 Playing = F15-6。

**按钮态：** 仅合法（己回合 + 未出局 + 已选 1～3）出条。非法仍 `_enabled` = F15-8。未选牌（含只 peek）能交 = S15-2。合法却无条 = F15-7。

**顶钮：** 新用例写 `lb_btn_play_confirm`。只点 `lb_btn_play` / 半屏包冒充本线完成 = F15-10。

**灰钮：** 占位可挂已有主钮皮，须标明占位。系统灰/蓝勾终验 = F15-9。

**贴底硬修搁置：** 确认条近底 = **可点优先级**。11 的贴底缝 / 24% / `padB` 禁令 **本轮不重开**。两条线不得写进同一验收闸。为条改环-手 / `padB` = F15-11。

**质疑仍冻：** 第一手不可质疑仍在 GDD。本线不画质疑窗。无牌边界走 §10.1，不解冻 = S15-3 / F15-12。
