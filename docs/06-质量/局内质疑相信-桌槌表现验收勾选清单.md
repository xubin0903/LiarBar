### 补句

- **调试路径 ≠ 正式路径。** 调试立刻播本地；正式须权威 Commit/Trust ACK 后全员播。  
- **H3 / H4「接线后」**：客户端尚未接正式入口时，**勿**用热重载冒充勾过；可先过 H1/H2/H5/H6（调试可达部分）。本批总过关仍须 H1～H6 齐。  
- **定格主读**：砸落后可读 **0.8～1.2s**，再收/淡出；客户端 `HOLD`→**1000ms**（窗内主读；软挂现码若仍偏短另票跟，**不**另起 H 号）。**勿**与开牌 `REVEAL_HOLD=3000` 混勾。  
- **SFX**：敲木约 80～120ms；禁 beep；禁 `lb_sfx_card_flip` / launch / land / enter / commit 冒充锤。听闸可另记，**不**另起 H 号。  
- **飞词**（`lb_str_choice_doubt_call` / `believe_call`）P0 可后置；有飞词时仍禁挡池（另票）。  
- **交叉 F2**：正式锤全员可见 ≠ 调试本地豁免；H4 失败句用 S19-3，**勿**与 S18-22 `challenge_no_broadcast` 混勾。  
- **开牌不动**：`DRAW_TO_FLIP=1000` / `REVEAL_HOLD=3000` 仍锁；本表不当过关（交叉 Rebuild R4）。
