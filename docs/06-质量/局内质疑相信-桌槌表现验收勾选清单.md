### 补句

- **调试路径 ≠ 正式路径。** 调试立刻播本地；正式须权威 Commit/Trust ACK 后：质疑座播砸、相信座静置、全员同轨。  
- **H3 / H4「接线后」**：客户端尚未接正式入口时，**勿**用热重载冒充勾过；可先过 H1/H2/H5/H6/H7/H8/H9/H10～H12（调试/进桌可达部分）。本批总过关仍须 H1～H12 齐。  
- **「搁」口径（v0.2）**：静置搁姿 / static rest pose；**不是** rest 位移动画。H2/H3/H8 同口径。  
- **v0.3 失败口径（只认三短句）**：  
  - **槌不在空位**（H10）：覆盖过小/看不见、右座无槌、位偏离开该座空位。  
  - **贴屏缘**（H11）：覆盖位偏挤左贴边等贴屏缘。  
  - **压牌**（H12）：覆盖自机压手及常驻/砸轨压牌；可与 S19-5/S19-7 交叉，**本行失败句写「压牌」**。  
  - **禁**写「必须外偏」/「外偏不足」类验收或失败句。  
- **定格主读**：砸落后可读 **0.8～1.2s**，再回搁/淡；客户端 `HOLD`→**1000ms**。**勿**与开牌 `REVEAL_HOLD=3000` 混勾。  
- **SFX / 美术**：`art_fx_mallet` 新图；`lb_sfx_hammer_hit` 加重敲木约 80～120ms；禁 beep；禁 `lb_sfx_card_flip` / launch / land 冒充锤。听验可交叉，**布局闸可不听**；外形过小仍走 H10（槌不在空位）。  
- **飞词**（`lb_str_choice_doubt_call` / `believe_call`）P0 可后置；有飞词时仍禁挡池（另票）。  
- **交叉 F2**：正式锤全员可见 ≠ 调试本地豁免；H4 失败句用 S19-3，**勿**与 S18-22 `challenge_no_broadcast` 混勾。  
- **开牌不动**：`DRAW_TO_FLIP=1000` / `REVEAL_HOLD=3000` 仍锁；本表不当过关（交叉 Rebuild R4）。  
- **合入≠终验**：合入本表 / client / art **不等于** 终验；等 client/UI 新票后再 Rebuild；**未 Rebuild 勿勾**。
