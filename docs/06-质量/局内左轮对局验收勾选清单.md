## 3. 勾选 V1-1～V1-12

| ID | 步骤 | 期望 | 失败短句 | 过 |
|----|------|------|----------|----|
| **V1-1** | 开局/新轮发牌 | 牌堆构成 **6K+6Q+6A+2Joker**；每人 **5** 张 | **牌堆不是20构成** | [ ] |
| **V1-2** | 看本轮宣称 | 已公布 K/Q/A；无宣称不得出牌 | （无宣称就出牌） | [ ] |
| **V1-3** | 第二手及以后 / 第一手 | 非第一手：可见相信/质疑。第一手：**禁**进质疑 | **第一手仍可质疑** | [ ] |
| **V1-4** | 质疑揭牌 | 真（全符合或 Joker）→**质疑者**开枪；假（有非指定且非Joker）→**上家**开枪 | **真假裁定反了** | [ ] |
| **V1-5** | 任意开枪后 | 必进 **CollectRedeal**：收牌、存活者重发 5、新指定。禁静默跳过 | **开枪后未收牌重发** | [ ] |
| **V1-6** | 实弹出局后 | 该座 **不发/不出/不质疑/不开枪** | **出局仍发牌/仍出/仍质疑** | [ ] |
| **V1-7** | 仅剩 1 存活 | 整局胜（MatchEnd）。禁旧 3命/RoundWin 公式 | **仍走旧3命或RoundWin** | [ ] |
| **V1-8** | 回归旧路径 | hand==0 **不得** RoundWin→RedealAll；胜负 **不得** 以 3命扣完为主 | **打光仍走RoundWin** / **仍走旧3命或RoundWin** | [ ] |
| **V1-9** | 存活 **≥3** 且打光 | 进 EmptySafe3：**你 / 上家**二选。**禁**强制质疑 | **≥3仍强制质疑** | [ ] |
| **V1-10** | ≥3 选「不质疑你」 | 跳过打光者、续对上家；**不揭**其最后一手；打光者 **不**开枪；进 RoundSafeWait | **未被质疑却开枪** | [ ] |
| **V1-11** | 存活 **=2** 且打光 | **强制**质疑最后一手；真→质疑者开枪；假→打光者开枪。禁 Trust/过 | **=2仍可跳过** | [ ] |
| **V1-12** | ≥3 选「质疑你」揭牌 | 假→打光者开枪；真→质疑者开枪；Joker **除外**（算符合） | **真假裁定反了** / **Joker未除外** | [ ] |

### 补句

- **相信路径：** Trust 不得进 Reveal/揭面 = **相信路径仍进揭牌**。  
- **RoundSafeWait：** 主触发=本轮任意后续开枪→CollectRedeal；收束=其余存活均 hand==0 且未开枪→CollectRedeal。禁无出口死等。  
- **相信路径仍进揭牌** 可与 V1-3/V1-4 并用记。  
- **旧 R1（#161）** 任意勾过 **无效**。
