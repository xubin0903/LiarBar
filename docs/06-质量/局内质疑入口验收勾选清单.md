| **C2-7** | **先 ack 再揭** | `canChallenge` 时点真或假；再造一次权威拒（调试拒 / NACK） | **禁止本地先开牌。** 点下去后、ack 未到之前：上家本手须仍是牌背，不得本地翻面、不得先切第3节揭牌层。ack 接受 → 才许后节揭（揭牌动效 **不是** 本表过关条件，本条只验这扇门）。ack 拒 → 不揭、入口可回；须出 **`lb_str_challenge_reject`** = **质疑未生效** | 拒后不得残留 commit 循环。本条主闸是 ack 门，不是听感 | **质疑未生效 / 本地先开牌** | [ ] |
| **C2-8** | **超时交权** | 进入 `AwaitChallenge` 后 **不点** 真/假/过，空等到时限 | 时限认 **10s**（窗 **8～12s**）。满窗必须 **过 / 交权**：离开等待、轮转下家（或权威规定的下一位），**不得**卡死 `AwaitChallenge`。倒计时环 **可选**（有环无环都能过本条）。短于 8s 闪过、长于 12s 仍停在等待、或超时仍要人强制点才走 = 不过 | 超时交权 **不要求**过 SFX | **卡死 AwaitChallenge**（含超时10s 过/超时须交权） | [ ] |

### 3.1 补句（写死）

**揭牌只在 ack 后（C2-7）：** 点真/假 = 向权威提交，**不是**本地开牌。本地先翻、先播揭牌轴、先切 `lb_challenge_reveal` / 第3节层 = **本地先开牌**。权威拒而不出 **质疑未生效**、或牌已揭不回 = **质疑未生效**。第3节揭牌好不好看、几秒翻完、押注窗 **不是** 本表过关条件。

**真假同层（C2-2）：** 真/假是同一层两枚按钮，一次点定。先「是否质疑」再「真还是假」再「确认」= **真假非二选 / 像多步问卷**。旁观旧押注 `lb_btn_bet_true` / `lb_btn_bet_fake` 属旧四拍拍2，**不得**拿来冒充本入口二选（那是 C2-6 双轨或 C2-2 问卷）。

**过 = 无声：** 点过或超时视作过，**不要求**过 SFX。把过做成必听第三槽、或非静默不过也强播 commit = 与 PM 冲突（听闸记；不过不另起 C2 号）。

**超时 10s（C2-8）：** 推荐 10，容差 8～12。这是 **AwaitChallenge 入口窗**，**不是** GDD §10.1 `challenge_only_seconds=8`（无牌仅质疑窗；打光者已不走那窗）。两窗不得混勾。倒计时环可选，无环只要满窗交权 = 过。卡在等待、超时仍要人点才走 = **卡死 AwaitChallenge**。

**只质疑上家本手（C2-3）：** GDD §6.2「翻开上家刚刚那一手」。身前扇只认本轮该座这一手（与 C1「本轮身前手」同一靶）。跨座 / 历史手 / 宣称字母当牌 = **质疑非上家本手**。

**第一手（C2-1）：** G-Q6。无 `lastPlay` / `playIndexInRound < 1` → `canChallenge==false`。第一手就打光走 C2-4，不适用「第一手可质疑」。

**打光（C2-4）：** 与 C1-7 / F16-12 同一闸、不同纸：C1 验扇先成形再结算；本表验 **禁再等待 / 禁再被质疑 / 禁再点**。打光者仍被点开真假 = **打光者仍被质疑 / 仍能点质疑**。名次谁第1、质疑成功次数怎么排 = **第4节**，本表不写。

**飞中（C2-5）：** 与 F16-7 同一闸。飞窗未满出钮、或提供跳过飞出进质疑的捷径 = **飞中出质疑钮**。C1-5 吞二手是第1节；本条专打质疑钮。

**双轨（C2-6）：** 旧四拍全屏仪式 **删**。新入口只留 `lb_scr_table` 上 `lb_cmp_challenge_await`。两套同时可点 = **质疑双轨并存**。只留旧轨、无新入口 = 本批入口未落地，**不得**勾本批过关。

**听闸 vs 布局闸：** C2-1～8 勾过时 **不要**改写成听感。听闸见 §0.4：非静默入口无 enter = **入口无声**（静默豁免）；用 flip/launch/land 冒充 = 听闸不过。听闸不过 **不**改 C2-1～8 短句。

**可选交叉：** 入口挡住本手扇或宣称条，可记 **质疑遮扇或声明**。**不当** C2 过关闸，也不因此放行 C2-1～8。

### 3.2 本表不验（避免误勾）

- 第1节 C1-1～9（飞出 / 身前扇 / 回滚出牌）——**另纸**；本表从 `PlayLanded` 接
- 开桌牌面 C1a–C1h——号不同，禁止混勾
- R-LAND-1～5 / 11 flush / `padB` 当本批正面过关——**不重开**
- 15 F15 / S15、线 A F14 / R-LIFE——另纸
- **第3节揭牌动效**、四拍演出、押注窗、翻面轴、`lb_challenge_reveal` 好不好看——**不是本表过关条件**；本表只锁 ack 前禁揭
- **第4节名次细表**（打光先后细分配分 / 面子分 / 质疑成功次数怎么加）——**后开，本表不扩**；本表只验打光禁入口
- 墓地 / 跨轮坟场几何——§2/3 后开
- 大厅 G1–G4 / R1–R4、L1 / D1、TC-19——不重开
- 3 命规则、`MAX_PLAY` 改帽、出牌权——**仍锁，不当本表勾选项**
- 倒计时环有无、质疑层是否挡扇/声明——可选交叉，不当过关
- 本表不交 wav/ogg / rawfile / ets

**拍界（给对表，不是新引擎阶段）：**

```
ConfirmReady → PlayLaunch → PlayLanded
                 ↑ 第1节 C1                              ↑ 第1节完
        hand>0 → AwaitChallenge = 第2节本表（入口 only）
                 真/假 → 等权威 ack →（接受）第3节揭牌另纸
                                   →（拒绝）质疑未生效
                 过 / 超时10s → 交权，离开等待
        hand==0 → RankSettle；禁 AwaitChallenge（C2-4；名次第4节）
```

对照 [05/02](../05-技术/02-回合状态机草图.md) 与 [出牌扣牌-状态机](../02-游戏设计/出牌扣牌-状态机.md) §6：`canChallenge` 四条件仍在。实现不得把本表 UI 拍加成 `phase` 枚举。
