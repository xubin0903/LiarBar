- [ ] 能造：① 合法新用户注册；② 已有账密登录；③ 错密；④ 重名注册；⑤ 用户名/密码长度非法；⑥ 断网或禁 INTERNET；⑦ mock 非 2xx / 缺 `token` 坏体；⑧ Preferences 损坏会话键；⑨ 设置→退出登录
- [ ] **失败短句以 §5 为准**（**键未进 `string.json`，341 不变**）：看提示文案/行为，不要等键名
  - 登录失败 → **停登录页提示；算不过：无提示进大厅**（`登录与本地令牌:202` · `lb_str_auth_login_fail`）
  - 注册冲突 → **提示冲突、不写令牌**（`:203` · `lb_str_auth_register_conflict`）
  - 字段校验 → **原地提示；非法不发请求/不写令牌**（`:204` · `lb_str_auth_field_invalid`）
  - 无网/超时 → **提示、不崩、不写令牌**（`:205` · `lb_str_auth_network`）
  - 坏响应/缺 token → **当失败；不算已登录**（`:206` · `lb_str_auth_bad_response`）
  - Preferences 失败 → **不崩可重试；不假登录**（`:207` · `lb_str_auth_prefs_fail`）
  - 令牌损坏 → **进登录页**（`:208` · `lb_str_auth_token_corrupt`）
  - 退出泄漏 → **停登录页；不可开局**（`:209` · `lb_str_auth_logout_leak`）
  - 门禁绕过 → **无令牌落登录页**（`:210` · `lb_str_auth_gate_bypass`）
  - 限流（可选） → **提示稍后重试**（`:211` · `lb_str_auth_rate_limit`）
