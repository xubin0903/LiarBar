## 0. 本文边界（禁止违反）

| 锁 | 口径 | 本文怎么守 |
|----|------|------------|
| 胜负 | 命归零出局，仅 1 人有命者胜；**禁止**手牌多者胜 | 不写终局替代条件 |
| 出牌权 | 新一轮先手＝**受罚者下家**（已出局仍取其下家） | 剧本与播报只报这个先手 |
| 第一手 | **不可质疑**（`canChallenge==false`） | 第一手模板禁用质疑口吻 |
| 质疑范围 | **只验上家本手**（`targetPlayId=lastPlay`） | 翻牌句只说「这一手」 |
| 手牌耗尽 | 方案 A：仅质疑窗 8s / 超时跳过 / 一圈无推进重建发牌不扣命 | `CHALLENGE_ONLY` / `REDEAL_STALL` 按此播 |
| Joker | **不可作宣称**；永远算符合当前宣称 | 宣称句只出 A/K/Q |
| MVP | **只人机 + 本地** | 默认座位 1 真人 + 3 AI |
| LLM | **禁止**判胜负 / 改真假 | §1.4；裁定句锁定模板 |
| 命名 | 四主屏 `lb_scr_lobby\|table\|challenge\|report`；看牌 `lb_cmp_peek_mask`；出牌 `lb_sheet_play`；四拍 `lb_challenge_windup\|standoff\|reveal\|result` | 控件 `lb_*`，媒体 `art_*`，**禁止 `lb_art_*`** |
| 人格 ID | `AI_TIMID` 怂货 / `AI_SHARK` 老千 / `AI_KAREN` 杠精 | 概率数字与数值表 §5 **逐字一致** |

程序只认：**阶段 / 窗模式 / 事件触发点 / 字符串 key**。本文给可落地的中文模板，不发明新阶段 ID。

## 1. 荷官播报模板（F-09）

### 1.1 怎么播（实现约定）

| 层 | 控件 / 资源 | 说明 |
|----|-------------|------|
| 播报条 | `lb_cmp_dealer_banner` · `lb_txt_dealer_line` | 挂在 `lb_scr_table` 顶栏 / 质疑底；1.5s～2s 淡出，不模态 |
| 胸像 | `lb_cmp_dealer` + `art_dealer_bust_idle` / `art_dealer_bust_announce` | 宣称与关键节点切 announce |
| 实况窗 | 只吃 §4 C2 的 ≤8 字用词 | **无牌面、无「他在撒谎」** |
| 离线 | 全模板本地字符串表 | 无网必须能播（PRD F-09） |

每条模板三列：

| 列 | 含义 |
|----|------|
| **口播** | `lb_sfx_*` 可读；静默局 **关口播** |
| **字幕** | 桌内 `lb_txt_dealer_line`；静默局 **仍显示**（裁定 / 宣称 / 重建发牌必须显示） |
| **key** | 建议 `lb_str_dlr_*`；已有 UI key **复用，不另造冲突句** |

**变量**（花括号原样替换，禁空则走括号内兜底）：

| 变量 | 来源 | 例 |
|------|------|----|
| `{昵称}` | 当前行动座 / 事件主体 `Seat.nickname` | 阿怯 |
| `{质疑者}` | `Challenge.challengerSeatId` | 杠精 |
| `{被质疑者}` | `Play.actorSeatId` | 老千 |
| `{被点名}` | `Play.namedSeatId` | 你 |
| `{胜者}` | `Match.winnerSeatId` | 你 |
| `{rank}` | `Claim.rank` ∈ A/K/Q | A |
| `{n}` | 张数或人数 | 2 |
| `{命}` | 扣命后 `Lives.current` | 2 |
| `{秒}` | 当前窗剩余整秒 | 8 |

### 1.2 按阶段 / 事件（可落地句）

已有 UI 句不改字：`lb_str_claim_fmt`「本轮出 {rank}」· `lb_str_challenge_disabled_first`「第一手还没人出过牌」· `lb_str_hand_empty`「没有牌了，只能质疑」· `lb_str_peek_hint`「按住看牌 · 松手收起」。

| 触发点（程序已锁） | key | 口播 / 字幕模板 | 备注 |
|--------------------|-----|-----------------|------|
| `LOBBY` 四人入座满 | `lb_str_dlr_lobby_full` | 本桌四人，酒已满。 | 线框已用此句；1.5s |
| `DEAL` 开局发牌 | `lb_str_dlr_deal` | 发牌。每人 {n} 张。 | `{n}=hand_size_default`（5） |
| `CLAIM` 公布宣称 | `lb_str_dlr_claim` | 本轮出 {rank}。{昵称} 先出。 | 桌内宣称徽章仍用 `lb_str_claim_fmt` |
| `TURN` + `NORMAL` 且是真人 | `lb_str_dlr_turn_you` | 轮到你。 | 第一手叠加 `lb_str_challenge_disabled_first`（按钮侧） |
| `TURN` + `NORMAL` 且是 AI | `lb_str_dlr_turn_other` | 轮到 {昵称}。 | 不报手牌、不报概率 |
| `TURN` + `CHALLENGE_ONLY` 进入 | `lb_str_dlr_chal_only` | 手牌空了。可以质疑上家这一手，也可以过。 | **C4**；勿说「必须质疑」；桌内可叠 `lb_str_hand_empty` |
| `TURN` + `CHALLENGE_ONLY` 超时跳过 | `lb_str_dlr_chal_only_skip` | 没开。过。 | **C4**；不扣命 |
| `TURN` 无牌且不可质疑（T14） | `lb_str_dlr_skip_empty` | {昵称} 没牌，过。 | 第一手无牌等极端 |
| `PLAY` 确认后（T20）无点名 | `lb_str_dlr_play` | {昵称} 出了 {n} 张。 | **不报牌面** |
| `PLAY` 确认后有点名 | `lb_str_dlr_play_named` | {昵称} 出了 {n} 张，点了 {被点名}。 | **C3**；被点名座短震 |
| `PLAY` 第一手提交后 | （复用 `lb_str_dlr_play`） | — | 不追加「可以质疑了」 |
| `TIMEOUT` + `AUTO_PLAY` | `lb_str_dlr_auto_play` | {昵称} 超时，代出 1 张。 | 不改 AUTO_PLAY 选牌规则 |
| `REDEAL_STALL`（T17） | `lb_str_dlr_redeal` | 一圈没人推进。不扣命，重新发牌。 | **C5**；随后再走 `DEAL`→`CLAIM` |
| `RECAP` 入 `lb_scr_report` | `lb_str_dlr_recap` | {胜者} 留下。 | 高光动作句另见 §1.6 |

### 1.3 质疑四拍（各一句）

仪式总长 ≤ `challenge_ritual_max_seconds`（4s），可跳过。跳过：切 `lb_challenge_result` 或直入 `JUDGE`，**仍播裁定句**。拍 2 **必须独立**，不并进 reveal。

| 拍 | 锁名 id | key | 荷官一句 | 时长参考 |
|----|---------|-----|----------|----------|
| 1 指控 | `lb_challenge_windup` | `lb_str_dlr_windup` | {质疑者} 开 {被质疑者} 这一手。 | ~0.8s |
| 2 对峙+押注 | `lb_challenge_standoff` | `lb_str_dlr_standoff` | 押真假。不改谁掉命。 | ~1.2s；押注窗 `lb_cmp_bet_bar`，2s 或进拍 3 先到先关 |
| 3 翻牌 | `lb_challenge_reveal` | `lb_str_dlr_reveal` | 翻上家这一手。 | ~1.5s；只翻 `targetPlay` |
| 4 定格 | `lb_challenge_result` | （空，接裁定句） | — | 立刻切 §1.4 |

旁观砸杯 / 起哄是互动层，**不替换**上表荷官句。

### 1.4 裁定句（只陈述结果，不改真假）

引擎先算 `Challenge.result`（GDD §6.2：存在 ≥1 张非宣称且非 Joker ⇒ `SUCCESS`），**再**填句。禁止根据「看起来像不像谎」换句。

| 结果 | 条件（只复述规则，不新造） | key | **锁定句**（禁止润色） |
|------|---------------------------|-----|------------------------|
| `SUCCESS` | 本手有假 | `lb_str_dlr_judge_success` | 有假。{被质疑者} 掉 1 命。 |
| `FAIL` | 本手全真（宣称或 Joker） | `lb_str_dlr_judge_fail` | 全真。{质疑者} 掉 1 命。 |

**禁止**出现：他在撒谎 / 我看是真 / 荷官改判 / 投票改判。可选 LLM **不得**碰这两句。

`PENALTY` 追加（仍是陈述，不改命数）：

| 事件 | key | 模板 |
|------|-----|------|
| 扣命后仍 ≥1 命 | `lb_str_dlr_penalty_life` | {昵称} 还剩 {命} 命。 |
| 命归零 → `GHOST` | `lb_str_dlr_penalty_out` | {昵称} 出局，旁观看戏。 |
| 仍 ≥2 人存活 → 新 `CLAIM` | 复用 `lb_str_dlr_claim` | 本轮出 {rank}。{昵称} 先出。（`{昵称}`＝受罚者下家） |
| 仅 1 人有命 | 复用 `lb_str_dlr_recap` | {胜者} 留下。 |

### 1.5 静默局（F-13）哪些静音、哪些仍出字幕

关：强震动、鼓点催促、公开嘲讽音效、弹幕起哄密度→0（互动方案 §8）。**不关**防窥、实况窗、智能填充（**C7**）。

| 播报 | 口播 | 字幕 | 理由 |
|------|------|------|------|
| `DEAL` / `CLAIM` / `REDEAL_STALL` | 关 | **开** | 规则信息 |
| `TURN` 轮到谁 / 第一手禁用提示 | 关 | 开 | 节奏 |
| `CHALLENGE_ONLY` 进入 / 超时过 | 关 | **开** | 8s 窗必须看得见 |
| `PLAY` 确认 / 点名 | 关 | 开（点名座仍可短震，见 C3；静默则震也关） | |
| 四拍荷官句 | 关 | 开（拍 2「押真假」建议保留） | 仪式可跳过，信息还在 |
| `JUDGE` / `PENALTY` 裁定句 | 关 | **必须开** | 公平；禁嘲讽音 |
| `RECAP` | 关 | 开 | 战报可读 |
| 催 `lb_sfx_hurry` / 嘲讽向四拍音 | **关** | — | 静默定义 |
| 看牌气泡 `lb_str_peek_hint` | 无口播 | **开** | 防窥仍开 |

### 1.6 战报一句（模板，非裁定）

高光从 `eventLog` 抽，**不改统计数字**。例：

| 条件 | key | 句 |
|------|-----|----|
| 有人甩出后被成功质疑 | `lb_str_dlr_hl_slam_caught` | {被质疑者} 第 {n} 手甩出后被拆穿。 |
| 质疑失败 | `lb_str_dlr_hl_fail` | {质疑者} 开错了，自己掉命。 |
| 兜底 | `lb_str_dlr_hl_fallback` | 本局最险的一次质疑在第 {n} 手。 |

## 2. 三人格牌友行为表（展开 GDD §8.2 + 数值表 §5）

决策：**概率表 + 手牌启发式**，不要求完美最优。引擎字段 `Seat.aiPersona` = `TIMID` \| `SHARK` \| `KAREN`；对外人格 ID 用下表全名。

### 2.1 MVP 默认座位

`default_players=4`。顺时针固定，**1 真人 + TIMID + SHARK + KAREN**：

| `seatId` | 角色 | 人格 ID | 显示名 | 座位控件 | 媒体 |
|----------|------|---------|--------|----------|------|
| 0 | `HUMAN`（开桌人） | — | 智能填充昵称 | `lb_cmp_seat_self` | 系统头，不用 `art_ai_*` |
| 1 | `AI` | **`AI_TIMID`** 怂货 | 怂货 | `lb_cmp_seat_p1` | `art_ai_timid_*` |
| 2 | `AI` | **`AI_SHARK`** 老千 | 老千 | `lb_cmp_seat_p2` | `art_ai_shark_*` |
| 3 | `AI` | **`AI_KAREN`** 杠精 | 杠精 | `lb_cmp_seat_p3` | `art_ai_karen_*` |

`first_actor_policy` 默认 `random`（状态机）。**演示种子局**用 §3 强制先手，不改这张默认座次。关 AI 后人数不足则不能开局（GDD §2.1）。

### 2.2 数值键（禁止改默认值）

下列数字 **抄自** [数值与牌堆配置.md §5](../02-游戏设计/数值与牌堆配置.md)，试玩只改表。本文只加行为与文案。

**出牌 §5.1**

| 人格 | `p_play_truth_when_can` | `p_prefer_slam` | `p_prefer_hesitate_bluff` | `avg_play_count_bias` |
|------|-------------------------|-----------------|---------------------------|------------------------|
| 怂货 TIMID | 0.85 | 0.10 | 0.15 | 偏 1 张 |
| 老千 SHARK | 0.45 | 0.35 | 0.25 | 偏 2 张 |
| 杠精 KAREN | 0.55 | 0.25 | 0.20 | 偏 1～2 |

出假时选牌（数值表原文）：优先丢非宣称非 Joker；若要掺真，保留 Joker 作后续。

**质疑 §5.2**（最终 `clamp(p, 0.05, 0.85)`）

| 人格 | `base_p_challenge` | 上家连续出牌 +1 手时加成 | 上家 SLAM 时加成 | 手牌很强时（真牌≥3）抑制 |
|------|--------------------|--------------------------|------------------|---------------------------|
| 怂货 | 0.12 | +0.05 | +0.05 | -0.05 |
| 老千 | 0.28 | +0.08 | +0.10 | -0.02 |
| 杠精 | 0.42 | +0.10 | +0.12 | 0 |

**表演 §5.3**

| 人格 | 出牌后 emote | 敲桌 | 画✗ | 点名 |
|------|--------------|------|-----|------|
| 怂货 | 0.2 | 0.05 | 0.05 | 0.05 |
| 老千 | 0.5 | 0.15 | 0.15 | 0.25 |
| 杠精 | 0.45 | 0.25 | 0.35 | 0.20 |

**时限 §5.4**（全人格同一键，不另造超时规则）

- `ai_think_ms = 400~1200` 随机  
- 上限不超过 `turn_seconds - 2`  
- 普通窗超时仍走 `timeout_auto_play`；仅质疑窗超时=`skip`（数值表 §6）

表现层可 internally 偏置抽样（怂货偏长、杠精偏短），**不得写出表外的新概率键当默认**。

### 2.3 怂货 `AI_TIMID`

| 维 | 可实现行为 |
|----|------------|
| 出牌偏好 | 能真则高概率出真（0.85）；`avg_play_count_bias` 偏 **1 张**；方式默认 `SOFT`；少 `SLAM`（0.10）；掺假时才偶尔 `HESITATE`（0.15） |
| 质疑偏好 | `base_p_challenge=0.12`，轻易不开；真牌≥3 再抑制；第一手 / 无 `lastPlay` **绝不质疑**（规则，不是性格） |
| 表演 | emote 0.2；敲桌 0.05；画✗ 0.05；点名 0.05。默认 **不催** |
| 被质疑反应 | 优先 `art_ai_timid_break`（破防）；少数 `art_ai_timid_hold`（死撑）。拍 1 被开时缩颈，不反嘲 |
| 超时倾向 | 思考偏 `ai_think_ms` 上限一侧；仍须在 `turn_seconds-2` 内提交。仅质疑窗常选「过」 |
| 出牌带话（可跳过） | 「就…一张。」 / 跳过（`lb_str_skip_line`） |
| 质疑姿态（若开） | 举杯轻问（互动方案 §3.6） |

**局内可观察差异（答辩能指着说）**

1. 连续两手几乎都是 **1 张轻推**，很少砸桌。  
2. 旁观很少敲桌、几乎不画✗。  
3. 被开时破防脸（`_break`）比另两人勤。

### 2.4 老千 `AI_SHARK`

| 维 | 可实现行为 |
|----|------------|
| 出牌偏好 | 能真也常掺假（0.45 出真）；偏 **2 张**；`SLAM` 0.35；掺假时 `HESITATE` 0.25（可伪造心虚） |
| 质疑偏好 | `base_p_challenge=0.28`；上家 SLAM 再 +0.10，爱开甩出的人 |
| 表演 | emote 0.5；敲桌 0.15；画✗ 0.15；**点名 0.25**（三人最高） |
| 被质疑反应 | 优先 `art_ai_shark_hold`（死撑 + 假笑）；破防用 `_break` 较少 |
| 超时倾向 | 思考取中段；普通窗少吃 AUTO_PLAY |
| 出牌带话 | 「整整齐齐」 / 「你敢开？」 |
| 质疑姿态 | 拍桌指控 |

**局内可观察差异**

1. 爱出 **2 张 + 甩出**，点名真人（头像 `_called`）。  
2. 被开时死撑假笑，不像怂货先裂。  
3. 质疑更冲着「上家刚 SLAM」而不是乱开第一手（第一手本来就不能开）。

### 2.5 杠精 `AI_KAREN`

| 维 | 可实现行为 |
|----|------------|
| 出牌偏好 | 出真 0.55；偏 1～2 张；`SLAM` 0.25 |
| 质疑偏好 | **`base_p_challenge=0.42`（三人最高）**；连续出牌 +0.10、上家 SLAM +0.12；手牌强 **不抑制**（表值为 0） |
| 表演 | emote 0.45；敲桌 **0.25**；画✗ **0.35（三人最高）**；点名 0.20；剩余秒进入 `low_time_threshold`（5s）时可跟风 `HECKLE` / 催 |
| 被质疑反应 | `art_ai_karen_hold` 死撑或反嘲（指回去）；少先破防 |
| 超时倾向 | 思考偏短；`CHALLENGE_ONLY` 更常点质疑而不是空过（仍受 clamp 与规则约束） |
| 出牌带话 | 「看着办。」 |
| 质疑姿态 | 指人怒斥 |
| 旁观口头禅 | HECKLE：「假的吧」 |

**局内可观察差异**

1. 对上家画✗ 最勤（`SIGN_NO` 0.35）。  
2. 三人里最爱点 `lb_btn_challenge`。  
3. 被开时指回去，不像怂货先裂、不像老千只假笑。

### 2.6 共用硬约束（人格改不了规则）

| 情境 | 全人格相同 |
|------|------------|
| 本轮第一手 | 只能出牌；`lb_btn_challenge` `_disabled` |
| 质疑对象 | 仅 `lastPlay` |
| 无牌可质疑 | 仅 8s 窗，超时跳过，不自动质疑 |
| 无牌不可质疑 | 立即跳过 |
| 幽灵 | 可起哄 / 押面子，不可出牌质疑、不可看他人手牌 |
| 人机强退 | 该座转 AI 接管，阶段不变 |

## 3. 演示种子剧本（`demo_seed_value=20260906`）

与教学局 **分两段**：教学走 GDD §11（AI 先出第一手 → 玩家质疑）；演示种子保证 **约 90s 内完整四拍质疑**。现场 5 分钟清单：教学可跳过，靠本种子出高潮。

### 3.1 程序 hook（假设，不发明规则）

数值表 §7.1 已锁：`demo_seed_enabled=true`，`demo_seed_value=20260906`。状态机 T01：若开关开，则 `Match.seed=20260906`。

| hook | 作用 | 不是什么 |
|------|------|----------|
| **固定 seed** | 洗牌 / 宣称随机 / AI 掷骰共用同一 seed，便于复现 | 不改胜负公式 |
| **可选强制事件列表** `demo_force_events` | 若到点仍未出现质疑，按表插入 **合法** 事件（仍走 T11→四拍→T31） | 不是新规则；不可强制第一手质疑、不可改裁定公式 |

建议实现顺序：先 seed 掷骰；若 `playIndexInRound` 达到 3 仍无 `CHALLENGE`，执行强制表第 4 步（杠精开老千本手）。玩家若提前合法质疑，**以玩家为准**，强制表后续 CHALLENGE 作废——仪式照样完整，仍算验收通过。

### 3.2 桌面与发牌约束（本种子）

| 项 | 锁定值 |
|----|--------|
| 人数 / 命 / 手牌 | 4 / 3 / 5 |
| 座次 | §2.1 |
| 本轮宣称 | **A**（`CLAIMABLE`，非 Joker） |
| 先手 | **seat 0 真人**（仅种子局覆盖 `first_actor_policy`；非种子局仍按状态机） |
| 玩家手牌约束 | ≥1 张合法（A 或 Joker）且 ≥1 张假（K 或 Q）→「前两手有机会掺假」 |
| 老千手牌约束 | ≥1 张假，供第 3 手掺假 |

余牌 8 张弃置本轮不用。重建发牌不在本 90s 高潮路径上。

### 3.3 强制事件列表（建议 JSON 语义）

```
demo_force_events:
  - { at: CLAIM, rank: A, firstActorSeatId: 0 }
  - { at: PLAY, seatId: 2, playIndexInRound: 3, count: 2, hasFake: true, style: SLAM, namedSeatId: 0 }
  - { at: CHALLENGE, seatId: 3, afterPlayIndex: 3 }   # 杠精开老千本手
  - { at: RITUAL, skip: false }                       # 走满四拍；评委可跳过，跳过仍裁定
```

玩家第 1 手 **不强制**掺假（给演示者表演）；seed 只保证「有机会」。怂货第 2 手不进强制表，按人格出 1 张真 `SOFT` 即可。

### 3.4 时间轴（≤90s 到完整质疑）

从点 `lb_btn_quickstart` / `lb_btn_start` 起算（已跳过教学）。AI 思考按 `ai_think_ms`，下表用中位。

| 秒 | 阶段 / 窗 | 谁 | 发生 | 荷官句 / 控件 |
|----|-----------|----|------|----------------|
| 0:00–0:06 | `LOBBY`→`DEAL` | 荷官 | 入座、发 5 张 | 本桌四人，酒已满。 / 发牌。每人 5 张。 |
| 0:06–0:08 | `CLAIM` | 荷官 | 宣称 A，先手 seat 0 | 本轮出 A。{你} 先出。 |
| 0:08–0:22 | `TURN` `NORMAL` 第 **1** 手 | 真人 | 可长按看牌；出 1～2 张（建议含 1 假作表演）。**不可质疑** | `lb_sheet_play`；`lb_btn_challenge` `_disabled` |
| 0:22–0:32 | `TURN` 第 **2** 手 | 怂货 | 1 张真、`SOFT`、少表演 | {怂货} 出了 1 张。 |
| 0:32–0:44 | `TURN` 第 **3** 手 | 老千 | **2 张掺 1 假、`SLAM`、点名真人** | {老千} 出了 2 张，点了 {你}。 |
| 0:44–0:48 | `TURN` | 杠精 | **发起质疑**（只指向老千本手） | 进 `lb_scr_challenge` |
| 0:48–0:49 | `lb_challenge_windup` | 杠精 | 指人怒斥 | 杠精 开 老千 这一手。 |
| 0:49–0:51 | `lb_challenge_standoff` | 老千死撑；旁观押注 | 押真假。不改谁掉命。 |
| 0:51–0:53 | `lb_challenge_reveal` | 荷官 | 逐张翻 **本手 2 张**，见假 | 翻上家这一手。 |
| 0:53–0:54 | `lb_challenge_result` + `JUDGE` | 引擎 | `SUCCESS` | **有假。老千 掉 1 命。** |
| 0:54–0:58 | `PENALTY` | 老千 | 3→2 命；清空本轮池；**不补牌** | 老千 还剩 2 命。 |
| 0:58– | `CLAIM` | 荷官 | 新宣称；先手＝老千下家＝**杠精** | 本轮出 {rank}。杠精 先出。 |

**谁掉命**：老千（被质疑者）−1。质疑成功因本手有假，不是荷官改判。

最坏（真人把 15s 用满、AI 思考顶格）：发牌+宣称约 8s + 15+13+13 + 质疑决策 3s + 仪式 4s + 惩罚 3s ≈ **59s**，仍在 90s 内。若强制表关闭且杠精选择出牌、轮回真人时玩家自己开——仪式同样完整，验收通过（玩家只能在**自己的回合**且 `canChallenge` 时质疑，不能在第一手或别人的回合抢开）。

**验收一句**：开 `demo_seed_enabled`、seed=`20260906`，从开打起约 90s 内必现一次 `windup→standoff→reveal→result`，且只验上家本手、裁定句与引擎一致。

### 3.5 教学局（GDD §11，与种子分开）

**禁止**在本轮第一手教质疑。教学可跳过；设置可重进。叠在 `lb_scr_table`，不另开路由。

本段先手改为 **seat 3 杠精**（真人之上家），以便「AI 先出第一手 → 玩家作为下家质疑」。**不要**复用 §3.4 的「真人先手」。

| 步 | 内容 | 玩家 | 荷官 / 特性插入 |
|----|------|------|-----------------|
| 1 | 宣称是什么 | 看 | 本轮出 {rank}。{杠精} 先出。 |
| 2 | 长按看牌 + 防窥 | 做一次 | `lb_cmp_peek_mask` + `lb_privacy_on`；气泡见 **C1** |
| 3 | **AI 出本轮第一手**（杠精 1 张 `SOFT`） | 看 | 第一手还没人出过牌 |
| 4 | **教质疑**上家本手 | 点 `lb_btn_challenge` | 进四拍 |
| 5 | 翻牌 + 结算简述 | 看 | 只播 §1.4 裁定句 |
| 6 | 动作词典四套 | 可跳 | 无新规则 |

教学掺假与否由教学脚本发牌保证「有假可看一次结算」即可；**不占用** `20260906` 的 90s 承诺。

## 4. C1～C8 玩法话术（填满选型 §8）

程序只认触发点。选型正文不在本目录重复。速查表见 [鸿蒙特性玩法话术.md](./鸿蒙特性玩法话术.md)。

### C1 看牌防窥 · 桌内提示

| 项 | 成品 |
|----|------|
| 触发 | `lb_cmp_peek_mask` 开/关 · `lb_privacy_on`（叠在 `lb_scr_table`，禁 `lb_scr_peek`） |
| 常驻 hint（已有，不改字） | `lb_str_peek_hint`：**按住看牌 · 松手收起** |
| 教学步 2 / 首次气泡 | `lb_str_peek_first`：**侧边看不清点数。桌上仍看得出你在看牌。** |
| 开启瞬间（可选弱字） | `lb_str_privacy_on`：防窥已开 |
| 松手 | 收起遮罩；无额外恐吓句 |
| 不要做成 | 「系统保证没人看得见」 |

### C2 实况窗三字段 · 对外用词

胶囊只准：① 阶段文案 ② 剩余整秒 ③ 宣称简称。桌内宣称继续用 `lb_str_claim_fmt`「本轮出 {rank}」。

**宣称简称（对外）**：**出 {rank}**（例：出 A）。不用「本轮 A」，不用「他在撒谎」。

| 阶段 / 窗 | 对外用词（≤8 字） | 桌内对照 |
|-----------|-------------------|----------|
| `TURN`+`NORMAL` 自己 | 轮到你出牌 | `lb_txt_timer` |
| `TURN`+`NORMAL` 别人 | 等待出牌 | 座位 `_turn`（勿把长昵称塞进胶囊） |
| `TURN`+`CHALLENGE_ONLY` | 可质疑 | `lb_str_hand_empty` |
| `PLAY_REVEAL_SELF` | 确认出牌 | `lb_sheet_play` |
| `lb_challenge_windup` | 起势 | `lb_cover_challenge` |
| `lb_challenge_standoff` | 对峙 | `lb_cmp_bet_bar` |
| `lb_challenge_reveal` | 翻牌中 | `lb_cmp_reveal_row` |
| `lb_challenge_result` / `JUDGE` | 定格 | 只示意输赢，无牌面 |
| `PENALTY` | 结算命数 | `art_fx_wine_splash` |
| `CLAIM` / `DEAL` | 新一轮 | `lb_txt_claim` |
| `REDEAL_STALL` | 重新发牌 | 与 C5 一致 |
| `RECAP` | （停窗） | `stopLiveView` |

### C3 被点名

| 项 | 成品 |
|----|------|
| 触发 | `Play.namedSeatId` 非空 |
| 桌内荷官 | 复用 `lb_str_dlr_play_named` |
| 被点名座 | 头像 `_called`；非静默可短震 `lb_hpt_press` |
| 实况窗 | **进胶囊**：`{名}点了你`（无牌面、不改质疑规则） |
| 他人胶囊 | 不播点名细节（避免泄露施压对象到锁屏） |
| 不要做成 | 点名改 `canChallenge` / 改扣命 |

### C4 仅质疑窗 8s · 荷官口头禅

| 时机 | key | 句 |
|------|-----|----|
| 进入 `CHALLENGE_ONLY` | `lb_str_dlr_chal_only` | 手牌空了。可以质疑上家这一手，也可以过。 |
| 超时 / 主动过 | `lb_str_dlr_chal_only_skip` | 没开。过。 |

不要暗示「必须质疑」。超时=`challenge_only_on_timeout=skip`，不扣命、不自动质疑。

### C5 重建发牌 `REDEAL_STALL`

| 时机 | 句 |
|------|----|
| 一圈无推进进入重建 | 一圈没人推进。不扣命，重新发牌。 |
| 重发后 `CLAIM` | 本轮出 {rank}。{昵称} 先出。 |

`{昵称}`：有 `lastPenalizedSeatId` 则为其下家；否则荷官随机（状态机 §3.1）。**不要**说成流局判负、不要比手牌。

| 系统建议出现 | `lb_str_autofill_hint` | 用系统建议名 |
| 一键填上次按钮 | `lb_str_fill_last` | 一键填上次 |
| 成功带出 | `lb_str_fill_ok` | 已填上次：{n} 人 · {命} 命 |
| 填失败 | `lb_str_fill_fail` | 填不出来就手打，不用登录 |
| 主按钮（已有） | `lb_str_quickstart` | 快速开桌 |

### C7 静默局 × 三特性

| 项 | 成品 |
|----|------|

### C8 答辩 3 分钟时间轴（特性插入点）

从第二次开桌或「再来一局」进 `lb_scr_lobby` 起算。教学六步可跳；高潮靠 `demo_seed`。不要单独开「特性展览页」。

| 秒 | 动作 | 插入点 | 期望 |
|----|------|--------|------|
| 0:00–0:20 | `lb_cmp_nick_field` / `lb_str_fill_last` → 4 人 3 命 → `lb_btn_quickstart` | **第二次开桌智能填充（F-11 / C6）** | 无账号带回上次；3 步能开打 |
| 0:20–0:40 | 跳过教学（或只做步 2）→ `lb_scr_table` → 长按手牌 | **防窥看牌（F-03 / C1 / 教学步 2）** | `lb_cmp_peek_mask`；侧拍看不清点数；不单开屏 |
| 0:40–0:55 | 上滑锁屏 / 按电源（不杀进程） | **锁屏实况窗（F-08 / C2）** | 轮到你出牌 + 秒 + 「出 A」；无牌面 |
| 0:55–1:15 | 解锁回桌；第一手只出牌 | 规则锁 | `lb_btn_challenge` 禁用 |
| 1:15–1:40 | 旁观敲桌或画✗；指三人差异（怂货轻推 / 老千甩出 / 杠精画✗） | AI 规格 §2 | 桌面不冷场 |
| 1:40–2:20 | 等到种子第 3 手后杠精质疑（或玩家合法开） | `demo_seed` §3 | 进 `lb_scr_challenge` |
| 2:20–2:40 | 四拍走完 + 裁定句 | F-05 / F-09 | 拍 2 独立；「有假。老千 掉 1 命。」与引擎一致 |
| 2:40–3:00 | 口播收束 | 一页纸卖点 | 「荷官是规则引擎，不用 LLM 判真假。」可点战报或再来 |

与 [课设 5 分钟清单](../06-质量/课设5分钟验收勾选清单.md) 的 3 分钟表兼容：本表把 F-11 明确放到 **开场 20s**（第二次开桌），F-08 放到 **看牌后锁屏**，不另起一套规则。
