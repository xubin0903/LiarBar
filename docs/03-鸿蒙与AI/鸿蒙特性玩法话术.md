## 1. C1～C8 成品表

| # | 触发点（已锁） | 成品文案 / 用词 | 不要做成 |
|---|----------------|-----------------|----------|
| **C1** | `lb_cmp_peek_mask` 开/关 · `lb_privacy_on`（叠在 `lb_scr_table`） | 常驻 `lb_str_peek_hint`：**按住看牌 · 松手收起**。教学步 2 / 首次：`lb_str_peek_first`：**侧边看不清点数。桌上仍看得出你在看牌。** 可选弱字：防窥已开 | 「系统保证没人看得见」 |
| **C2** | `TURN` / `CHALLENGE_ONLY` / 四拍 / `JUDGE` 等 | 胶囊三字段：阶段 + 整秒 + 宣称简称 **出 {rank}**。阶段用词（≤8 字）：轮到你出牌 / 等待出牌 / 可质疑 / 确认出牌 / 起势 / 对峙 / 翻牌中 / 定格 / 结算命数 / 新一轮 / 重新发牌 | 加牌面；加「他在撒谎」 |
| **C3** | `Play.namedSeatId` 非空 | 荷官：`{昵称} 出了 {n} 张，点了 {被点名}。` 被点名胶囊：`{名}点了你`（无牌面）。非静默可短震 | 改质疑规则 / 改扣命 |
| **C4** | 进入 `CHALLENGE_ONLY`（8s） | 催（可开可过）：**手牌空了。可以质疑上家这一手，也可以过。** 超时跳过：**没开。过。** | 暗示「必须质疑」；超时自动质疑 |
| **C5** | `REDEAL_STALL` | **一圈没人推进。不扣命，重新发牌。** 随后：`本轮出 {rank}。{昵称} 先出。`（先手＝受罚者下家；无记录则随机） | 说成流局判负；比手牌 |
| **C6** | `lb_cmp_nick_field` · `lb_btn_quickstart` | 空态：**怎么称呼（不用登录）**。建议：**用系统建议名**。按钮：**一键填上次**。成功：**已填上次：{n} 人 · {命} 命**。失败：**填不出来就手打，不用登录**。主按钮仍用 `lb_str_quickstart`「快速开桌」 | 引导注册 / 华为 ID |
| **C7** | `lb_tog_silent`（F-13） | 旁注：**静默局：关催促、强震和嘲讽音。防窥和实况窗仍开。** 关：催、强震、嘲讽音、起哄。仍开：防窥、实况窗、智能填充、荷官字幕、裁定句 | 静默时关防窥 |
| **C8** | 教学步 2；锁屏一下；第二次开桌 | 见下节 3 分钟时间轴 | 单独开「特性展览页」当主演示 |

## 2. 答辩 3 分钟时间轴（C8）

预跑或「再来一局」后，从 **第二次** 进 `lb_scr_lobby` 起算。`demo_seed_enabled=true`，`demo_seed_value=20260906`。教学可跳。

| 秒 | 动作 | 特性插入点 | 过 |
|----|------|------------|----|
| 0:00–0:20 | 昵称 / 「一键填上次」→ 4 人 3 命 → 快速开桌 | **F-11 第二次开桌智能填充** | [ ] |
| 0:20–0:40 | 进 `lb_scr_table`；长按手牌；侧拍；松手 | **F-03 防窥看牌**（教学步 2；不单开屏） | [ ] |
| 0:40–0:55 | 锁屏 / 熄屏，指胶囊 | **F-08 实况窗**：轮到你出牌 + 秒 + 出 A；无牌面 | [ ] |
| 0:55–1:15 | 解锁；第一手只出牌 | 第一手不可质疑 | [ ] |
| 1:15–1:40 | 敲桌或画✗；指三人格差异 | AI 不冷场 | [ ] |
| 1:40–2:20 | 等到种子质疑（第 3 手后杠精开老千，或玩家先开） | `demo_seed` 90s 承诺的现场压缩版 | [ ] |
| 2:20–2:40 | `lb_challenge_windup` → `standoff` → `reveal` → `result` | 拍 2 独立；裁定句不改真假 | [ ] |
| 2:40–3:00 | 「荷官是规则引擎，不用 LLM 判真假」 | 可点 `lb_scr_report` / 再来 | [ ] |

完整种子分镜、谁第几手、谁掉命：主文档 §3。五分钟现场版：`docs/06-质量/课设5分钟验收勾选清单.md`。
