## 2. 问题与价值主张

### 2.1 问题陈述

年轻人喜欢虚张声势类聚会游戏，但：

1. 缺主持人则流程乱  
2. 手机上只有出牌按钮，丢失“演与读”  
3. 手牌易被旁边窥视  
4. 人少开不起局  

### 2.2 价值主张

用 **规则引擎 AI 荷官** 解决组织成本，用 **鸿蒙防窥/实况窗** 解决隐私与节奏，用 **动作+舆论互动层** 还原线下博弈张力。

### 2.3 产品原则

1. 公平第一：胜负只认牌面规则  
2. 表演第二：动作系统鼓励骗，但不透视  
3. 单机可玩：无第二部手机也能演示  
4. 特性服务玩法：不为堆特性而堆

## 3. 用户与场景

### 3.1 用户角色

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| 开桌人 | 建房、选人数/命数 | 30 秒内能开打 |
| 牌手 | 出牌/质疑/表演 | 手牌安全、操作跟手 |
| 旁观/幽灵 | 出局或未入座 | 仍能起哄、不冷场 |
| AI 牌友 | 补位 | 会出牌也会敲桌画✗ |

### 3.2 关键场景

| 场景 | 描述 | 成功样子 |
|------|------|----------|
| 寝室开黑 | 1 人建桌 AI 补 / 或 4 人局域网/联网 | 10 分钟打 1～2 局 |
| 答辩演示 | 1 真人 3 AI | 3 分钟内完成看牌-出牌-质疑-战报 |
| 地铁静默 | 关强表现 | 可玩，不社死 |

## 4. 范围划分

### 4.1 进 MVP（P0）

| ID | 需求 | 验收标准（Given/When/Then 简写） |
|----|------|----------------------------------|
| F-01 | 人机快速开桌 | 选择 4 人桌 → 3 AI 入座 → 可开始 |
| F-02 | 经典规则对局 | 宣称→出牌→质疑→扣命→胜负，见 GDD |
| F-03 | 长按看牌 + 防窥 | 看牌时防窥开启；松手收牌 |
| F-04 | 出牌包 | 选 1～3 张 + ≥3 种出牌方式 + 可选带话/点名 |
| F-05 | 质疑三拍 | 指控姿态 → 反应表情 → 逐张翻牌 |
| F-06 | 旁观互动 | 敲桌、画✓✗、质疑时押真假（面子分） |
| F-07 | 手动表情轮盘 | 无摄像头可完成全部表演 |
| F-08 | 回合倒计时 + 实况窗 | 熄屏/锁屏可见阶段与剩余秒 |
| F-09 | AI 荷官播报 | 关键节点短句模板（可无网） |
| F-10 | 局后战报 | 撒谎次数、质疑成功率、高光动作一条 |
| F-11 | 智能填充 | 昵称/常用配置一键填 |
| F-12 | 教学 60 秒 | 首局可跳；含动作词典 4 套 |

### 4.2 演示增强（P1，有余力）

| ID | 需求 | 说明 |
|----|------|------|
| F-20 | FaceAR 真表情 | 与轮盘等价映射到符号面具 |
| F-21 | 智感握姿 | 单手时快捷区改侧；换手“重整”动画 |
| F-22 | 互动卡片 | 进行中牌桌、再来一局 |
| F-23 | 沉浸光感 UI | 昼夜/质疑爆灯 |
| F-24 | 加注谎 / 盲出 | 见 GDD |
| F-25 | 开局 vs 破防表情对比卡 | 战报素材 |
| F-26 | 扫码直达进桌 | 可选 |

### 4.3 明确延后（P2）

- 联网好友房完整匹配  
- 语音房  
- 排位/赛季  
- 演技桌数值检定  
- 邻座私语窃听  
- 多皮肤商城  

### 4.4 不做

见[一页纸 §5](../00-立项/01-项目一页纸.md)。

## 5. 用户故事（P0 节选）

1. **作为**开桌人，**我希望**一键人机开桌，**以便**一个人也能玩和演示。  
2. **作为**牌手，**我希望**长按才显示手牌且防窥，**以便**旁边人看不清我的牌。  
3. **作为**牌手，**我希望**甩出/轻推等不同出牌方式，**以便**用姿态欺骗他人。  
4. **作为**旁观者，**我希望**敲桌和画✗，**以便**参与带节奏而不是挂机。  
5. **作为**玩家，**我希望**质疑时有翻牌仪式和旁观押注，**以便**高潮有全员参与感。  
6. **作为**演示者，**我希望**实况窗显示倒计时，**以便**熄屏也能展示鸿蒙特性。  
7. **作为**玩家，**我希望**局后看到谁在哪手开始骗，**以便**复盘和分享。

## 7. 非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 对局 UI 操作反馈 <100ms 体感；AI 决策人机局 <500ms |
| 弱网 | 人机局全本地可玩；荷官模板离线可用 |
| 隐私 | 摄像头权限可拒；拒后走手动表情 |
| 无障碍 | 静默局关闭强震动/强催促特效 |
| 适配 | 手机竖屏优先；折叠屏不承诺首版 |
